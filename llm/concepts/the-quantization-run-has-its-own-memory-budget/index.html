The quantization run has its own memory budget

post-training-quantization has an accounting blind spot it has never noticed. Every entry on it reports what the quantized model costs — bits per weight, GB resident, quality at a bit-width. Not one reports what running the quantizer costs, because the papers all assume a machine on which that question is uninteresting.

For curvature-based methods it is the question. A two-sided Kronecker-factored Hessian has to be accumulated over the calibration set, and YAQA's arrangement holds O(ℓ) of that accumulation in accelerator memory — which, the authors say plainly, is impractical without many GPUs. BaKron replaces it with a recursive accumulation needing O(log ℓ) accelerator-resident memory and O(ℓ log ℓ) compute, with the activations streamed in from host RAM. The entire method's hardware requirement changes class.

This is the same structural move this vault has recorded twice on other maps and never on this one. frozen-weights-can-be-streamed-which-is-a-peft-only-memory-axis streams what does not need to be resident during a fine-tune; nvme-offload-removes-the-model-scale-ceiling pushes the ceiling down the storage hierarchy entirely. Both are answers to "the working set is bigger than the card." A quantizer's Hessian accumulation is a working set with exactly that shape, and until now nobody in this vault had asked where it lives.

The practitioner form is a question to ask of any quantization method before adopting it: what does the quantization pass itself need resident, and for how long? For round-to-nearest the answer is nothing. For GPTQ it is one layer's Hessian. For the two-sided family it was, until this paper, more than a consumer machine has. That is a real reason a method can be better on paper and unavailable in practice, and it is invisible in every quality-versus-bits table on this map.

Held as suggestive: the memory claim is a complexity result plus an implementation, not a measured peak-memory table, and the paper's headline is the solver rather than the accumulator. What is measured is that the whole thing runs on a single workstation card — a low bar, and the first entry on this map to clear it for a curvature-based method.
