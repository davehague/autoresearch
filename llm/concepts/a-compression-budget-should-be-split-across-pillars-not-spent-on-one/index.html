The ratio is not the quantity that predicts the damage

post-training-quantization has spent most of its length on where the bits go within one pillar — per channel, per layer, per expert, per modality, per rounding decision. This asks the level-up question and answers it with the one experiment that settles it: hold the compression ratio fixed at 8× and vary only how it is achieved.

Both single-pillar routes land at ≈31% against a dense 54.61%, which on eight multiple-choice-style tasks is functionally chance. The hybrid at the identical ratio recovers 52.38%. Nothing about the memory footprint distinguishes these rows. What distinguishes them is that each pillar has a regime where it degrades gracefully and a regime where it falls off a cliff, and composing two moderate settings keeps both inside the graceful part.

This is the matched-budget version of a claim the vault has been assembling piecewise. post-training-quantization already knows 4-bit is nearly free and 2-bit is a different animal — at-two-bits-model-family-outranks-model-size, below-three-bits-the-quantization-procedure-outweighs-the-format. What it did not have was the comparison against spending the same budget elsewhere. The answer is that at 8×, staying at 4 bits and taking the rest out of structure beats going to 2 bits, by more than twenty points.

The rider is inside the table. The two hybrid rows are both 8× and differ by 4.41 points — 4-bit + 50% unstructured (52.38) against 4-bit + 2:4 (47.97). So the pattern matters as much as the ratio, and the hardware-friendly pattern is the worse one on quality. A practitioner without sparse tensor cores gets the better number for free; one who needs the 2:4 speedup pays 4.4 points for it. That is the same shape as a-quarter-of-the-parameters-costs-an-eighth-of-the-capability and sparsity-damages-more-than-quantization-at-half-the-compression: structure is expensive, and structured regularly is more expensive still.

Where this bites hardest is the boundary this vault cares about most. Below 4 bits is exactly where a 7B–14B model starts to fit a consumer card, and it is exactly where calibration-content-is-the-dominant-term-below-four-bits and the whole sub-3-bit literature says the procedure stops being reliable. Splitting the budget is an escape route from that regime rather than a way further into it — and unlike the sub-3-bit methods, it needs no new format and no new kernel.

Limits. One model, one metric family, no seeds or intervals; each row is the best of a selected field; and the composed rows are the author's own framing tables for a thesis arguing this exact position, which is the least adversarial place for a claim to be measured. The 8× accounting also treats a bit of precision and a removed weight as interchangeable currency, which is true for weight memory and false for compute on any runtime that cannot exploit the sparsity pattern — where 50% unstructured sparsity buys bytes and nothing else. And this is a static-weight result: nothing here touches the KV cache, which is the other half of an 8× memory budget at long context (kv-cache-management).
