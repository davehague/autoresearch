Reference-free self-distillation already does most of the work; a privileged reference's marginal value is cross-mode access, not extra information

This map's privileged-information-helps-only-if-the-student-could-reconstruct-it (T3, secondary source) named a reconstructibility ordering — the most informative privileged signal (a final answer, a full worked solution) is the riskiest to hand a self-distillation teacher, because it lets the teacher shortcut deliberation rather than model it. That review flagged "a complete ranking of information types under one protocol" as unresolved. AMPLE-Math is the first T1 primary in this vault to run that comparison under one controlled protocol, on answer-matched problems across six reference types, against a reference-free control.

The result reframes the question rather than resolving the ranking. Reference-free OPSD — a thinking-enabled teacher scoring the student's own direct-response rollouts, no privileged content of any kind — already captures most of Qwen3-1.7B's measured gain. The privileged references add a smaller, and for three of four types roughly comparable-sized, increment on top — and the one reference whose increment is closest to the reference-free baseline's own size (Clean Solution, +1.30 pts) doesn't survive multiple-comparison correction. On external benchmarks, no reference type shows a consistent edge over reference-free at all. SmolLM3-3B adds a checkpoint-dependent twist: Full Trace leads at step 50 but every configuration, including reference-free, falls below the untrained base model by step 100 — so a reference ranking read off one checkpoint is not guaranteed to hold at another, independent of which reference is best.

The paper's own mechanistic claim is the most useful thing this note carries forward: "the value of a privileged reference is what it adds to this cross-mode transfer, not how much of the solution it reveals." OPSD's teacher is thinking-enabled while the student trains on direct-response rollouts; the paper's reading is that most of the gain — reference-bearing or not — comes from the student accessing reasoning capability that already exists under its own thinking-enabled mode, reachable through parameters shared across inference modes. Three follow-up interventions (correctness-aligned log-probability shifts that reverse sign between direct-response and thinking-enabled prefixes for the same reference type; relaxed-loss marker pressure that barely changes marker usage; a loss-window extension whose apparent gain evaporates once checkpoint is controlled for) each show token-level supervision changes decoupled from behavioral outcome, which the paper states directly: "changing the training signal does not necessarily produce the intended change in the student."

Graded extends, not pushes-back: this does not contradict the reconstructibility ordering — it's a different, complementary claim (how much references add on top of a reference-free baseline, versus which references are riskiest when you do use one) and the two could both be true simultaneously. Graded suggestive rather than strong: quantified with real ablations across two model families, but the headline reference-vs-reference-free deltas are small, one key comparison fails correction, external-benchmark evaluation uses only 30 problems per benchmark, and the six non-Answer-Only/Full-Trace views were generated and reviewed by a single model (Qwen3.6-35B) that may share blind spots with what it grades. Discounted for scope: short-run LoRA only, mathematics only, two model families.

Rebutted by: none — extends rather than contradicts the existing privileged-information ordering.
