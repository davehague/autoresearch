3:T5db, Hybrid language models mix self-attention with recurrent layers whose state updates happen in place, which makes ordinary prefix caching awkward: saving state only at a coarse grid of positions throws away most reusable prefixes, while saving it everywhere a prefix might later be reused means cutting the prefill forward pass at each mid-prompt checkpoint — and those extra scheduler steps can cost more than the reuse they enable. FrontierReplay exploits the observation that, across multi-turn chat, agent loops, document QA, and tree search, prefix reuse almost always resumes at predictable structural boundaries (a turn's end, a known branch point) rather than at arbitrary positions. It materializes exact checkpoints only at those boundaries while letting the prefill pass run uncut, logging a short window of recurrent-layer inputs around each boundary and using a cross-layer, state-only replay kernel to reconstruct the exact state from that log — 6-37x cheaper per token than full recomputation, with no host synchronization required. A frontier-aware retention policy prioritizes active anchors and promising branches, lending unused checkpoint slots to the ordinary attention KV cache instead of leaving them idle.
