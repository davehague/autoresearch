3:T43e, Gated linear-attention architectures compute a per-step forget/decay gate from the token representation alone — a deliberate design choice that is what makes chunkwise-parallel training possible. The cost is that the gate is state-independent: the same token always produces the same gate, even when the layer's actual recurrent state differs a lot between two occurrences of it. SDG computes an element-wise gate from how much the chunk's memory changed, and applies it only at the chunk boundary — giving the gate real feedback about the state while leaving within-chunk computation exactly as parallel as before. The authors derive SDG as an element-wise ridge-regression proximal step under a signal-noise memory-reconstruction model when the gate is fixed, and ship fused kernels for Gated DeltaNet, Kimi Delta Attention, Gated DeltaNet-2, and Mamba-3.
