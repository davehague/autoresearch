Quantizing only the residual shrinks QLoRA's error

The QPiSSA result sharpens why adapter initialization is not cosmetic — it changes what the quantizer sees. In QLoRA you quantize the entire base weight W to 4-bit and absorb the full quantization error; the low-rank adapter, initialized as a no-op, cannot correct it. In QPiSSA you first factor out the principal singular components into a full-precision adapter, then quantize only the residual W_res. Because the high-energy directions have been removed, the tensor being quantized has a smaller spectral range, so its 4-bit error is smaller from step one. Reported: LLaMA-3-70B GSM8K 86.05% vs QLoRA's 81.73% (+4.32), at the same 4-bit memory budget.

This connects two of the vault's threads that had only met as an "interaction" note before. QLoRA (quantized-bases-preserve-finetune-quality) established that a 4-bit frozen base preserves fine-tune quality; the illusion-of-equivalence work (intruder-dimensions-are-the-mechanism-of-lora-forgetting) established that a merged adapter hands the quantizer a different spectrum. QPiSSA is the constructive version of that observation: choose the adapter's subspace so that the residual left for the quantizer is easier. The quantization error is not a fixed tax on the base — it depends on which slice of the weight you kept in full precision.

Same caveats as adapter-initialization-determines-the-lora-ceiling: author-evaluated on task benchmarks, no forgetting/domain-acquisition test, and a one-time SVD cost. But the practical rule for the vault's premise is clean and cheap: QPiSSA over QLoRA when you're fine-tuning a 4-bit base, for a free 4-point swing on these tasks. Whether it survives a genuinely new domain is unmeasured here (peft-methods remains contested on that axis).
