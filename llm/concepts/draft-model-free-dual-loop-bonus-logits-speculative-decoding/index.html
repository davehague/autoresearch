A second clock speed inside the same stack: cheap early-layer bonus logits explore, one authoritative pass both verifies and reseeds

This map's drafter-provenance axis has, until now, offered two shapes: a separately trained/pretrained checkpoint (EAGLE-family, Osprey's target-agnostic pretraining) or a self-speculative mechanism that borrows the target's own shallow layers for one pass (LayerSkip, self-speculative decoding). ECHO is a third shape that neither of those is: it does not add a checkpoint and it does not stop at one shallow read. It structures the entire stack into two loops running at different frequencies — a high-frequency inner loop reading early-layer bonus logits to grow a multi-step draft tree cheaply, and a low-frequency outer loop where the one full-model forward pass that verifies the tree also harvests final-layer bonus logits to correct wrong paths and seed the next round's candidates. That second detail is the part worth keeping distinct from ordinary tree verification: the expensive pass's byproduct feeds the cheap loop's next iteration rather than being thrown away once verification is done.

Graded extends, strong: quantified across six model/size combinations with an ablation that isolates the logits-draft-tree component (2.70x -> 2.16x when removed), code released, and the 2.4x-2.9x range sits inside the spread this map already has for draft-model-free methods and tree-based speculators. Discounted for scope: single-GPU only (RTX 3090 / A40), no concurrency sweep — so this map's standing complaint that a speculative speedup is quoted at an unstated concurrency (a-speculative-speedup-is-quoted-at-an-unstated-concurrency) applies here too, and there is no accuracy-preservation table alongside the throughput numbers. The "one-shot fine-tuning dependency for optimal acceleration" is a real cost the abstract states plainly rather than burying: the strongest numbers reuse Meta's LayerSkip checkpoints, which already went through a comparable fine-tuning pass for a different purpose, so this is not proven as a fully training-free drop-in for an arbitrary off-the-shelf model. Nothing here is tested on a MoE backbone or a hybrid linear-attention architecture (this map's expert-union and cache-structure caveats — speculation-multiplies-the-expert-union-not-just-the-tokens, verification-cost-is-a-property-of-the-backbones-memory-structure — are untested by this source).
