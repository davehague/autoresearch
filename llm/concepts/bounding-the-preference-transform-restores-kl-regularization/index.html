Bounding the transform is what restores the KL term

The constructive half of the ΨPO analysis, and the smallest possible fix for the defect in bradley-terry-substitution-is-what-makes-dpo-overfit: if the problem is that Ψ(q) = log(q/(1−q)) is unbounded, use a bounded Ψ. The identity is the natural choice, giving max_π p*(π ≻ μ) − τ·D_KL(π ‖ π_ref) — direct regularized optimization of total preference, with no Bradley-Terry step and therefore no reward, pointwise or otherwise.

The empirical form is the surprise: a squared loss. Writing h_π(y,y') = log[(π(y)π_ref(y'))/(π(y')π_ref(y))], IPO minimizes E[(h_π(y_w,y_l) − τ⁻¹/2)²]. The mechanical difference from DPO fits in one sentence — IPO regresses the log-likelihood-ratio gap onto a finite target set by τ, where DPO pushes that same gap as far as the data permits. The regularization coefficient becomes an explicit target value rather than a competing penalty term, which is why it cannot be overwhelmed.

This is a third structural move in the same direction as this map's other post-DPO variants, and naming the pattern is useful: preference-alignment-collapses-into-a-single-stage deletes the reference model and the stage boundary; preference-training-should-optimize-the-metric-you-decode-with changes what the implicit reward is normalized by; this one changes what the objective is a function of. All three edit the loss rather than the data, and none of them requires a new annotation.

For this map's framework layer, IPO's real significance is that ΨPO is a second mechanism-level account of the preference zoo, independent of the HALO taxonomy this map consolidated on (binary-feedback-can-replace-preference-pairs). HALOs classify these losses by the human value function they imply; ΨPO classifies them by the transform they apply to the preference probability. Neither cites the other, they slice the same set of methods differently, and no source reconciles them — which is now this map's sharpest unfilled cell.

Graded single-study deliberately despite T1 provenance: the convergence and regularization behaviour is proved for the population objective, but the only demonstration that it produces better policies is three-action bandits with a softmax over θ ∈ ℝ³. Whether the squared loss trains stably on a 7B model, how τ should be set in practice, and whether the smooth-in-τ behaviour survives a real policy parameterization are all untested here — the authors close by asking for exactly those experiments.
