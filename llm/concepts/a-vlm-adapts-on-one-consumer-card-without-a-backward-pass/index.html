A number, finally — for half the model

vision-language-models has carried the same complaint since 2026-07-27: neither VLM family has ever been priced on consumer hardware. No latency, no throughput, no memory, no quantized variant, for early or late fusion. This is the first source that reports all four, and the honest headline is that it prices the encoder, not the model.

CLIP ViT-B/16 on a single RTX 4070 Ti SUPER at batch size 1: 196.73 MB and 26.04 ms per sample at 8 bits, 139.63 MB and 14.92 ms with the vision tower at 4 bits. The gradient-based test-time adaptation baseline it is sold against costs 2,700 MB and ~88 ms; the strongest comparable baseline (TDA, full precision, also gradient-free) costs 355.71 MB and ~30 ms. So the advertised 19.9× memory reduction is against the weakest entry in the study, and against the strongest it is 2.5× on memory and 2× on latency — still real, and a tenth the size of the headline.

The adaptation mechanism is the reason the numbers are this small: two FIFO caches, one of high-confidence exemplars and one of high-entropy ones, with each incoming image's quantized features scored against them by cosine similarity and the logits adjusted by the similarity-weighted votes. No backward pass anywhere; the loop runs entirely in INT8/INT4. Accuracy averaged over seven datasets is 65.56% against unadapted CLIP's 61.05 — the paper's "4.5% improvement" — though the margin over the strongest baseline is 0.59 points, which is the number to carry.

What this does not price is the half that matters to this vault's premise. There is no language model here, no KV cache, no autoregressive decode. Every quantity that makes a generative VLM hard locally — early fusion's 4,096 image tokens per 512×512 image forcing a 131,072-token context, decode-time memory bandwidth, prefill cost — is absent by construction. 196 MB / 26 ms is the perception front-end's bill, and the map's standing complaint about the generative half stays open.

Two further scope problems worth stating rather than burying. The hardware is a consumer desktop GPU with 16 GB, not a phone, SBC or NPU; "edge" here is simulated by fixing batch size to 1, so every latency figure comes off a card with more memory bandwidth than any device the word normally names. And batch size 1 only means no throughput number exists at all — which is the same gap local-inference complains about across its own serving sources, arriving here for a different reason.

Still, the direction is the one this vault's premise cares about: the perception stage of a late-fusion VLM is not the expensive part on one card. If the map's early-versus-late-fusion contest is ever settled on cost rather than capability, this says the deciding term will be the language model and the image-token load it carries, not the encoder.
