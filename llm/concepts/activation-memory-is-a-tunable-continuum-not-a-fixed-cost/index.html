The knob nobody exposes

This vault has argued by elimination since 2026-07-24 that gradient checkpointing is the one memory technique PEFT cannot delete: sharding, tensor parallelism, adapters and CPU offload all attack terms proportional to trainable parameters, while a 70B model's forward activations are identical whether you update every weight or 0.01% of them. This is the primary source for that lever, and it prices it — ~30% more compute, memory sublinear in depth.

The construction is one equation. Divide n layers into k segments, store only each segment's boundary output, and recompute a segment's interior during its backward pass:

cost-total = max_i cost-of-segment(i) + O(k) = O(n/k) + O(k)

At k = sqrt(n) that is O(2*sqrt(n)), paid for with exactly one extra forward pass per minibatch — and since the backward pass costs roughly twice a forward one, the marginal cost is about a third of a step. Applied recursively, g(n) = k + g(n/(k+1)) solves to g(n) = k*log_{k+1}(n), so k = 1 gives log_2(n) memory for O(n log_2 n) forward cost.

The framing that matters is continuum, not switch. Every framework exposes checkpointing as a boolean, which is a single point on that curve — k = the number of transformer blocks, chosen for you. The paper instead does a budgeted search: given a memory budget B, greedily assign nodes to recompute or keep, then grid-search B over [B/sqrt(2), sqrt(2)*B] starting from sqrt(x*y). That is the same shape as sharding-is-a-dial-between-memory-and-communication and as the-parallelism-configuration-is-searchable-not-a-dial — three independent systems concluding the right setting is a search over a budget. None of the three searches ships in the tooling this vault's readers use.

A cheap special case worth knowing: drop the low-cost operations and keep the expensive ones. In a Conv-BatchNorm-Activation block, keep the convolution output and recompute the rest — nearly free memory for nearly no compute. The transformer analogue is obvious and unmeasured.

Where the effect was largest is the long-sequence case, not the deep one: the LSTM unrolled to 1,024 steps gained more than 4× over an already optimized plan, against 2–3× for depth. Activation memory scales with sequence length as well as depth, which is where this vault expects the constraint to bind, given that context is context-length-is-a-cheap-post-hoc-edit-not-a-pretraining-property and the sequence-parallel alternative is ruled out on consumer interconnect by overlap-requires-a-block-size-above-the-flops-to-bandwidth-ratio.

Bound: 2016, ResNet and LSTM, MXNet, a Titan X — there is not a transformer in the paper. The 30% figure does not transfer unexamined to a transformer block, and since FlashAttention the attention op already recomputes its largest intermediate (attention-is-memory-bound-not-compute-bound), so part of this win is double-counted for modern models. Memory numbers count feature maps only — parameters, gradients, optimizer states and workspace excluded. The O(log n) result is theoretical and unmeasured. Compare rematerialization-trades-compute-for-the-activation-memory-nothing-else-shrinks, which reached the same lever from the pipeline-parallelism side.
