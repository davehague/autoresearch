Nine variants, one hyperparameter

The last two weeks of this vault added five ways to build a better low-rank adapter. PiSSA initializes on the base weight's principal singular components (adapter-initialization-determines-the-lora-ceiling). LoftQ initializes on the quantization error (quantization-aware-init-extends-lora-below-the-4-bit-floor). DoRA decomposes magnitude from direction (weight-decomposition-recovers-lora-gap). AdaLoRA learns the per-matrix rank allocation (where-the-adapter-budget-goes-matters-more-than-how-much-there-is). rsLoRA corrects the scaling divisor (the-lora-scaling-factor-collapses-gradients-at-high-rank). Each arrived with a measured win, and after each one the map recorded the same gap: nobody had run them against each other.

Run properly, they are the same method.

Ten methods — vanilla LoRA plus nine variants spanning initialization (OLoRA, PiSSA, MiLoRA, Init[AB], LoRA-GA), architecture (DoRA, GraLoRA, RandLoRA) and optimization (LoFT) — on four base models from 0.6B to 13B, across mathematical reasoning, code generation, commonsense reasoning and instruction following. The search is the contribution: up to 16 learning rates from 1e-6 to 1e-3 at four points per order of magnitude, crossed with six batch sizes and seven ranks. Once each method is evaluated at its own optimum rather than at a shared default, every peak lands within 1–2% of every other peak — and within 0.52% on the tightest configuration, where PiSSA's advantage over LoRA is 0.22 points against a ±0.79 standard deviation.

What the methods genuinely differ in is which learning rate they want, and by a lot: PiSSA's optimum sits 10× below vanilla LoRA's, OLoRA's and LoRA-GA's 18.2× below. The second-order analysis supplies the mechanism, and it is not adapter-specific at all — these methods change the largest Hessian eigenvalue of the loss surface (up to 100× higher for OLoRA and LoRA-GA, ≈10× for PiSSA, ≈2× for Init[AB] and MiLoRA), and the optimal learning rate moves inversely with curvature, which is textbook optimization. A clever initialization drops the optimizer into a sharper basin; a default learning rate then overshoots it; tuning the rate recovers the difference. The published gains were real measurements of an under-tuned baseline.

Two boundaries keep this from being larger than it is. No full fine-tuning baseline appears anywhere, so the domain-acquisition contest that makes this map contested (low-rank-capacity-binds-when-the-domain-is-new) is untouched — this is a null result among adapters, on task adaptation, where low-rank-adapters-match-full-finetuning already held. And no quantized base is tested and LoftQ is not among the nine, which matters because LoftQ's claim is specifically that initialization decides whether 2-bit LoRA converges at all. So "initialization doesn't matter" is established on full-precision bases, and the one setting where the vault has evidence that it matters enormously is the setting not run.

The practitioner form is unusually clean, and cheap: use vanilla LoRA and spend the compute on a learning-rate sweep. Sixteen short runs at one rank beat picking among nine method implementations, and on one consumer card the sweep is affordable in a way the comparison never was.

Rebutted by: the-peft-ranking-flips-between-text-and-image-backbones — holds for language adaptation of models that already do the task, not across modalities: on a diffusion backbone learning a new concept, OFT beats LoRA on quality and peak memory simultaneously, and two-axis dominance is not something a shared-default learning rate can manufacture because memory is a property of the parameterization rather than the optimizer.

Rebutted by: the-minor-singular-directions-are-where-new-knowledge-fits — holds for task adaptation, not for domain acquisition. MiLoRA (minor-singular-vector initialization) is among the nine variants nulled here, and the same idea is reported to be worth ~10 points on a held-out quiz over an injected corpus, where every task in this study is one the base model was already trained to do. That is a scope condition rather than a contradiction, and it lands on exactly the axis peft-methods is contested about.
