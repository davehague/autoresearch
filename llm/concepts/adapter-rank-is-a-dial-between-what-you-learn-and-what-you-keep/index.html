Rank 64 is dominated on both axes, and the field's default safety argument does not survive it

low-rank-adapters-match-full-finetuning is the claim this map was coined on, and its everyday form is not the paper's careful statement about task adaptation but a folk theorem: PEFT is safe because it touches so little. This is the first source in the vault to sweep rank against a full-fine-tuning arm on a controlled knowledge-injection task and read both axes at once, and it turns that folk theorem into a dial with a cliff on it.

The design earns the reading. Entity names are replaced with synthetic identifiers so the base model cannot answer from pretraining — verified, not assumed: Qwen3-4B scores 2.43% exact match on the anonymized training facts before adaptation, against 8.10% non-anonymized. alpha/r is held constant at 2 across the sweep, so the effective update scale is not the confound (which matters here, given the-lora-scaling-factor-collapses-gradients-at-high-rank). Five seeds. And the acquisition/retention comparison is re-cut at matched paraphrase accuracy, which is the only version of this comparison that means anything.

Three things in the numbers deserve to survive the summary.

Acquisition saturates at rank 16 and then reverses. 79.4 → 85.8 → 85.4 → 83.1 across r = 8/16/32/64. Rank 64 is not buying more knowledge. It is buying more damage for less knowledge — dominated on both axes by rank 16, at every acquisition target measured.

The damage is not uniform across capabilities. TruthfulQA is nearly flat everywhere (50.5 → 47.7) while IFEval falls 80.2 → 14.6 and BBH 70.8 → 17.3. What a high-rank adapter destroys is instruction-following, code and multi-step reasoning — the compositional behaviours — not whatever TruthfulQA scores. Anyone evaluating a fine-tune on a single knowledge benchmark will see none of this.

Seed variance grows with the damage (±16.5 on HumanEval at r=64, ±11.5 on MMLU). At high rank the outcome is not merely worse, it is unstable — which means a single-seed report from that regime is close to uninformative.

The result is not about quantization. The unquantized LoRA control on a different model reproduces the whole shape, so the quantized base is the setting rather than the cause — and this note therefore constrains ordinary LoRA exactly as much as it constrains QLoRA.

Where it does not reach. The regime is 1,938 examples for 100 epochs and there is no epoch ablation, so how much of the rank-64 collapse belongs to rank and how much to a hundred passes at high capacity is not separated — the honest statement is that rank sets how much a fixed over-training budget can destroy. The paper never states the base bit-width despite naming the method QLoRA. One model at 4B for the main sweep. And there is no mechanism here: the paper reports that spectral departure tracks the damage and stops, which is where spectral-departure-from-the-pretrained-basis-is-dose-dependent-in-rank picks it up.

Read against low-rank-capacity-binds-when-the-domain-is-new, the two together close a loop this map has held open since 2026-07-18. That note found low rank is a real capacity ceiling when the domain is new. This one finds that raising rank to clear the ceiling is what destroys the base model. The low-rank budget is not a limitation to be engineered away; it is the thing doing the protecting — which is lora-regularizes-more-than-it-adapts measured as a dose-response curve instead of an observation.
