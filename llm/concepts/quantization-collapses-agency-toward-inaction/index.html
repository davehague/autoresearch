Quantization collapses agency toward inaction

If quantization added noise, a damaged agent would misfire — calling tools it should not, choosing the wrong one, filling arguments badly. It does none of those. Under quantization-multiplies-the-decision-margin the margin contracts toward zero and the residual term b — the model's own prior over the two continuations — decides the near-ties. At 3 bits on Qwen3-4B that prior points one way: 96.3% of should-call decisions flip to not-calling, against 20% the other way. The agent goes quiet.

Two details make this more than a curiosity.

The damage is selective in a way that maps onto decision structure. Whether to call a tool is a binary with a contested margin and it collapses; which tool to call is a multi-way selection and it survives essentially intact — none of forty selections changes in 32 of 34 conditions. A selection over many options is a ranking; a threshold decision is a magnitude test against an implicit zero. The distinction an-int4-proxy-ranks-channels-it-cannot-compute drew for feed-forward channel selection reappears here at the level of an agent's behaviour, which is the first time this vault has seen it outside a kernel.

The failure is deterministic, not stochastic. 77 of 77 should-call items and 16 of 16 should-not-call items flip identically under two different quantizers with different mean margins. This is not noise sampling badly; it is the same underlying ordering being compressed past the boundary. So re-quantizing with a different tool will not shake the failure loose, and an evaluation that samples different items each run will not find it — you have to test the same items before and after.

For a local reader the operational form is blunt. The behaviour a quantized model loses first is initiative, and it loses it silently: a 3-bit agent that answers fluently and never reaches for a tool looks like a working model with a personality change. Nothing in a benchmark average, and nothing in perplexity-does-not-rank-quantization-formats's aggregate, will report it. The refusal literature should read the same way — the paper's safety family shows the same contraction, and a refusal is a threshold decision that needed headroom.
