The map's four-failure-mode enumeration gets a fifth type, and a reason the "ordered protocol" it wants has never been written

evaluation-contamination already names leakage, construct mismatch, infrastructure non-equivalence, and judge bias as the field's failure modes, and repeatedly flags that no source gives a practitioner an ordered, budgeted procedure for clearing all of them. This source resharpens the leakage side of that enumeration into five named types (direct, derivative, temporal, distributional, acquired) — organized not by mechanism but by which existing mitigation each one survives — and then explains, empirically, why the missing protocol is hard to write: when two independent coders applied a disclosure protocol to 41 real papers' contamination sections, they could not agree on what those papers actually reported (median kappa 0.21) even though the same instrument is reliable in principle (0.84 test-retest). The instrument is fine; papers' self-reports are not legible enough for a third party to audit consistently.

This is a mixed-direction finding for the map: it improves the field's vocabulary (a cleaner taxonomy, organized usefully around what defeats what) while degrading confidence in every paper's own contamination section as evidence (13% report an elicitation budget; none cover all five types). Practically, it means any source in this vault whose contamination handling is taken at face value — which is most of them — should be read as unverified on that dimension unless it independently supplies the missing detail (what was checked, how hard, against what corpus).

Distributional contamination — the eval population being unrepresentative of the claim, with no leakage involved at all — is a genuinely new axis for this map: evaluation-contamination's existing "construct validity" thread is adjacent but framed as narrowness of the benchmark surface, not as sampling mismatch between the eval population and what a headline claim needs.

Bound: this is a measurement of the field's reporting practice, not a new detector — it makes no claim about which in-vault models are actually contaminated. The fetched summary does not specify which venues/years the 41 papers were drawn from or whether coders were blinded to authorship, which bears on how far the low-agreement finding generalizes.
