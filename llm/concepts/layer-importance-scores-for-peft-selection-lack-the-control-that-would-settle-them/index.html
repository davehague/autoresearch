This map already ran the control this paper needs, on a different but structurally identical question, and found the control usually wins -- which is the reason to hold this source open rather than adopt it

peft-methods carries a hard-won, specific finding from a much more rigorously controlled paper: at a fixed protected-layer budget matched on parameter count, eight of ten random layer selections beat a top-K-by-importance-score rule, and a second control in the same paper found choosing layers by weight density similarly lost to random (the-count-of-protected-layers-carries-the-effect-not-their-identity). The map's standing reading is that "in this literature a per-unit importance score usually earns less than the decision to be non-uniform in the first place" -- i.e. the win usually comes from not treating every layer identically, not from correctly ranking which layer matters most. Pre-PEFT Probing proposes exactly the kind of per-unit importance score that finding is skeptical of -- rank layers by weight-statistic and perturbation-robustness criteria, then adapt the top-ranked ones -- on a new object (VLM vision encoders) this map has not tested the claim on before. But it compares its picks only against positional baselines (first-k, middle-k layers), not a random-selection control matched on parameter budget, which is precisely the comparison the map's existing evidence says is the one that matters: random beat rank-by-importance in the prior source specifically because ranking captured no more signal than being non-uniform did. Without that control here, this source cannot be read as either confirming or contesting the map's rule -- it simply has not run the experiment that would settle which side of the pattern it falls on.

Graded open-question rather than confirms or pushes-back: the missing control makes this genuinely undecidable against the map's existing finding, not a data point on either side. Graded mixed direction: the paper reports both statistically significant per-layer gains from its top picks and, on the one budget-matched comparison it does report, gains too small (0.07-0.34pp) to distinguish from noise absent an interval or a random-baseline distribution to compare against. Graded single-study: two VLM vision encoders, one short (6-page) paper, no multiple-comparisons correction stated alongside p-values small enough to warrant discussing one, no code-verified reproduction attempted here. The map's own remedy is already known and cheap to apply if anyone wants to settle this: rerun the paper's layer-selection comparison with a random-layer control matched on adapted-parameter count, the same design that resolved the question for LLM-side protected-layer selection.

Rebutted by: none — this note itself withholds judgment rather than contesting a claim already on record; it is not the rebuttal of an existing note.
