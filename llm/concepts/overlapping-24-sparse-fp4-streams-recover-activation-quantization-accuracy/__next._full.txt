Khaki, Wang, Han and Wang's VR-SparseQuant exploits elementwise 2:4 structured sparsity, a feature of NVIDIA's unreleased Vera Rubin GPU generation that (unlike Blackwell's coarser paired-position sparsity) can select any two of four positions per group independently. They represent each activation block as two such sparse streams: a coarse stream fit to the block's largest values, and a fine stream that can either cover a position the coarse stream missed or correct the coarse stream's own rounding error at a position it already covered. Because the two streams' sparsity patterns are allowed to overlap, the total number of stored FP4 values stays equal to a single dense grid's — nothing is added to the format, only reallocated. An offline-calibrated ratio fixes both streams' scales from the block maximum, so no scale search runs at inference; two cheap greedy per-quartet selections (by measured noise reduction) assign which positions each stream covers, and a shared-weight sparse GEMM kernel multiplies both streams against the same staged weight tile in one FP32 accumulator.
