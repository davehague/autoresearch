The memory hierarchy has a third tier, and using it costs nothing where the alternatives still fit

offloading-the-optimizer-demotes-memory-instead-of-distributing-it established the demotion argument: don't distribute the state across more devices, move it down the memory hierarchy to somewhere slower and larger. ZeRO-Infinity runs that argument to its endpoint. NVMe is the last tier before the network, and on a DGX-2-class node it is over 50× larger than GPU memory, which is enough that model scale stops being the constraint — the paper reaches 32 trillion parameters and projects 128T.

The number that matters for this vault is not the headline. It is that at 500B parameters, where 3D parallelism can still fit, the two are within a point of each other (47 vs 46 TFLOPS/GPU). Offload is not a fallback you accept a penalty for; where both options exist they cost the same, and past that point one of them simply stops. And on a single node, ZeRO-Infinity runs a trillion parameters against 3D parallelism's 20B and ZeRO-Offload's 50B — with no model parallelism at all.

That last clause is the load-bearing engineering claim and it depends on a technique separate from the offloading: memory-centric tiling. The reason large models normally require tensor-slicing even when their states are offloaded is Model State Working Memory — forward/backward on the single largest operator still needs 4 × hd × 4hd contiguous bytes, which past 100B parameters is multiple gigabytes and fails from fragmentation rather than capacity. Tiling rewrites one large linear operator as a mathematically equivalent sequence of smaller ones executed in turn, so working memory falls proportionally to the tile count. Model parallelism becomes unnecessary, and with it the code refactoring that tensor-parallelism-splits-a-layer-across-gpus demands.

Read against this map's other axes, this sharpens the vault's standing suspicion rather than settling it. ZeRO-Infinity's win is dominated by relocating the fp32 optimizer states and fp32 parameters — 16 of the 20 bytes per parameter that mixed-precision Adam costs. Under LoRA on a 4-bit base (quantized-bases-preserve-finetune-quality) almost none of that state exists, so the NVMe tier should be more moot under PEFT than the CPU tier, not less. The part that survives PEFT is the activation path — see offload-efficiency-is-a-bandwidth-arithmetic-intensity-problem and rematerialization-trades-compute-for-the-activation-memory-nothing-else-shrinks.

Bound: V100-era 2021 hardware, so absolute TFLOPS carry this vault's expiry rule (kernel-performance-expires-with-the-gpu-generation) while the ratios follow from byte accounting. Fourth first-party DeepSpeed/FSDP source in-vault, benchmarked against baselines its own authors configured; no neutral comparison exists. Superlinear scaling is a weak-scaling result. No PEFT experiment anywhere in the paper, and "fine-tune a trillion-parameter model on one node" means full-parameter fine-tuning of a model with no open weights.
