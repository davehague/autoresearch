Each update spends the same fraction of what is left

Most continual-learning findings in this vault are about forgetting — intruder-dimensions-are-the-mechanism-of-lora-forgetting, self-training-corrupts-what-it-already-solved, lora-learns-less-forgets-less — which is a statement about what an update destroys. This is a statement about what an update can still be, and it is specific to learning in a bounded space.

Four disjoint 500-fact tasks, written in sequence into the same in-cell residual, artifact verified after each. The good news first and it is not the interesting part: zero violations after all four tasks, over 1.4 × 10⁹ weights each time, so the bit-identity guarantee is not a single-shot property. Then three things go wrong at once. Cross-domain ability degrades monotonically (37% over anchor after the first task, 52% after the fourth). Old tasks are forgotten in the ordinary way — the first task retains 31% of its recall after three subsequent updates. And, distinctively, plasticity itself decays: each task learns less than the one before, 50.9 → 42.7 → 35.8 → 29.7%, as the writable room falls 44%.

The third effect was predicted, not fitted. If the displacement available to an update is scaled by the room itself, a bounded update consumes a constant fraction of what remains, so the decay must be geometric. The measured ratios are 0.8271, 0.8254, 0.8238 — geometric to three decimal places, β = 0.825 ± 0.002 — with new-task absorption following the same law and staying proportional to the room available before each task. This is the first predicted-then-confirmed quantitative regularity this vault has read in the adaptation literature, and the authors also report a sharper second claim from an earlier draft that measuring it refuted, which is the reason to take the first one seriously.

The operational consequence is the one to carry: an artifact under in-cell maintenance has a countable number of updates left, and the decay constant tells you the number. Lifetime capacity without re-quantization is finite. That is a scheduling input — it prices the cadence at which the release has to be re-cut and re-certified, which is the exact cost the-quantized-release-as-a-frozen-reference-frame was designed to avoid paying. The method does not remove the cost; it converts an unpredictable one into a budgeted one.

n = 1 sequence, one model, one quantizer, and no unconstrained control sequence, so the 52% cross-domain cost is a measurement of this method over four tasks and not a comparison against anything.
