Predicting the token is not predicting the path

expert-routing-is-predictable-one-layer-ahead established the cheapest fact in this vault's offload thread: run layer L+1's gating function on layer L's hidden states and you know, at recall ~0.8–0.9, which experts the next layer will want — so you can prefetch them, and being wrong is free because the weights were going to be loaded anyway. That result reads routing predictions off the target model's own hidden states.

This source needs the same predictions from a drafter's hidden states, which is a harder ask, and in doing so it separates two things the distillation literature usually conflates. A four-term ablation adds one loss at a time and watches two metrics: whether the target accepts the drafted token, and whether the drafter's router correctly names the experts the verifier will need.

Residual and logit/token distillation drive acceptance from 47.7% to 87.1% and drag prefetch hit rate along from 61% to 73%. Then adding an explicit KL between the target router's and the drafter's router distributions at every layer does something clean: acceptance does not move at all (87.1 → 87.0) while prefetch hit rate goes 73% → 88%. Two objectives, two payoffs, almost no interference.

The mechanism is not mysterious once stated. A drafter that produces the right token has matched the target at the output layer; a drafter that produces the right route has matched it in the hidden state at every MoE layer, and the second is a strictly stronger condition. Token agreement can be reached by a model whose internal path to the answer differs — which is the same structural point quantization-preserves-the-answer-and-changes-the-derivation makes about precision reduction and intruder-dimensions-are-the-mechanism-of-lora-forgetting makes about adapters. Matching the output is a weak constraint on matching the computation, and this vault now has three unrelated literatures saying so.

The practical form is specific to offloaded MoE and worth stating because it inverts an intuition: a better drafter is not automatically a better prefetcher. If you are distilling a draft model for an MoE whose experts are streamed, the routing loss is not a refinement of the token loss — it is the term that buys the memory-hierarchy win, and it costs nothing on the acceptance side. Without it, the prefetcher wastes 27% of its transfers on experts the verifier does not want; with it, 12%.

Bound: one ablation on two models of the same MoE shape (64 routed + 2 shared, top-6), single author, no venue, no code. The router-agreement metric is a KL, and the paper reports "top-k expert-set agreement" only as an optional validation metric, so the mapping from 0.86 KL to 88% hit rate is measured once and not characterized. Whether the separation holds for a coarse-grained MoE with 8 experts, where routing is a much lower-entropy decision, is untested.
