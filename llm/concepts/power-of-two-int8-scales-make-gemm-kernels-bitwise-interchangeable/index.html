Cross-kernel INT8 reproducibility is a scale-format choice, not a tolerance-tuning problem — and this map's accuracy numbers implicitly assume the serving kernel doesn't silently drift

Every INT8/INT4 accuracy number post-training-quantization carries so far is a property of a quantized model evaluated on a kernel — the map has never asked whether swapping the serving kernel (same scaled-INT8-GEMM interface, different implementation) preserves that number. This source answers a narrower but load-bearing question: no, not under standard tolerance-based conformance, because the fault classes that actually cause kernel drift (scale precision, double rounding, multiplication order, output truncation, fused- operation ordering) each move the output by at most one bfloat16 spacing — inside any tolerance a conformance suite would plausibly set, so 4 of 5 are undetectable regardless of how tight the tolerance is, and the 5th only becomes detectable if scales already happen to be powers of two.

The fix is not a better test but a format constraint: restrict quantization scales to powers of two, and requantization becomes bitwise-exact across kernel implementations (196/196 and 252/252 layers agree bit-for- bit, vs. 8/196 and 10/252 under standard scales) — the paper attributes 99.8% of previously-observed cross- kernel degradation to this scale-format mismatch rather than to arithmetic differences per se. The cost is small: sub-1% perplexity variance and identical greedy output across kernels on every tested prompt.

This is the map's first source about kernel-implementation reproducibility rather than model-level accuracy — a production-reliability question that sits underneath, not alongside, the map's existing accuracy-vs- compression trade-offs: an INT8 accuracy number is only as trustworthy as the assumption that the kernel producing it is the kernel that will serve it, and this source shows that assumption fails by default (4 of 5 fault classes slip past standard conformance) and is fixable cheaply (constrain scales to powers of two).

Graded extends: adds a reliability/reproducibility dimension the map didn't have, without contradicting any existing accuracy-vs-compression finding. strength: strong — quantified effect (bitwise agreement counts, perplexity deltas) with a stated fault-injection methodology, though single-author and single model family (Qwen3, three sizes).
