The fidelity/consumability decoupling this map found between sender and receiver models also holds inside a single state-reconstruction problem, once the object being reconstructed is path-dependent rather than a plain cache

TL;DR: This map's cross-model question has so far been answered for plain full-attention KV caches: a-kv-cache-is-linearly-transferable-within-a-model-family (closed-form ridge regression, 2026-08-05) and fidelity-consumability-decoupling-kv-caches (2026-10-16, numerical closeness to a reference cache does not predict whether a reader model can use it) both operate on the single-object case. HST extends the cross-model-transfer thread to hybrid linear-attention models, where "the cache" is three interacting objects — full-attention (FA) cache, recurrent state (REC), and convolution history (Conv) — and finds the fidelity/consumability split recurs inside the reconstruction problem itself, for a reason the single-object case never had to confront: REC is path-dependent (its update at any step depends on the whole history that produced it, not just the instantaneous value), so a numerically-closer REC reconstruction can still continue worse, because closeness at one timestep does not certify the right path was taken to get there. Conv compounds this: even though convolution histories are overwritten and gone after the kernel window passes, perturbing them changes the keys/values recurrent layers see in the meantime, and that effect on REC persists after Conv itself is no longer observable. HST's fix calibrates its REC/Conv adapters against the frozen target model's own continuation outputs — the actual downstream behavior transfer is for — rather than against a fidelity proxy, merges FA cache-map updates offline, and reaches 89.88%/94.11% mean task retention with ~21.7x/21.9x handoff speedup on Qwen3.5 4B->27B / 9B->27B.

What it says. The mechanism generalizes a lesson this map already learned the hard way at the sender/receiver scale (fidelity ≠ consumability) to a new scale (within one model's own reconstructed internal state) and names why it recurs: path-dependence. That is a property REC has and a plain KV cache (append-only, position-indexed) does not — which is likely why the single-object cross-model-transfer sources never surfaced this failure mode. Practically, it means any future hybrid-linear-attention cache-transfer or compression method that optimizes a reconstruction-error loss against REC risks exactly the trap HST's ablation exposes: training toward numerical closeness without checking continuation quality directly.

Caveats. No code or checkpoint release stated. All numbers are one model family (Qwen3.5), two size-pair directions — generalization to other hybrid linear-attention architectures, or to REC mechanisms built differently from Qwen3.5's, is untested. Retention figures are mean across five benchmarks with no per-benchmark breakdown reported at ingest, which this vault's evaluation-contamination thread has repeatedly shown can hide which specific capability degrades. Speedup figures assume the source cache is already available/live, isolating handoff-body cost from the cost of producing or holding that source state — a cold-start, single-model-resident scenario (the one a local, one-or-two-consumer-card reader is actually in) is not measured.
