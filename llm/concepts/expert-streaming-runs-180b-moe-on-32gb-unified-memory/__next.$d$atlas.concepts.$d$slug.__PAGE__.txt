Qwen3.8-Flash-Next is a 180B-parameter mixture-of-experts model — comfortably too large to fit in 32GB of RAM at any reasonable precision if treated uniformly. The fix splits the model by structural role: the dense, always-active layers (a small fraction of total parameters) stay resident at 8-bit precision, while the routed experts — most of the parameter count, each touched only sparsely per token — are quantized to 3 bits and kept on SSD, streamed into a fixed-size "slot pool" cache sized to the remaining RAM, with one guessed expert per layer prefetched ahead of when it's needed. A separate 51GB n-gram lookup table stays on disk entirely.
