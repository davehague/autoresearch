Two things called MoE × LoRA, pointing opposite directions

This map has carried "MoE × LoRA" as an open cell since 2026-07-21, phrased precisely: freeze-the-experts was demonstrated full-rank, never with adapters. The question is what a parameter-efficient update does when the frozen substrate underneath it is a routed sparse layer — whether a low-rank update can even be well-defined against a weight that only some tokens visit, whether rare experts get any gradient, whether the router should move.

The MoE-PEFT literature sounds like it answers this and does not. MoEGen, MoELoRA, MoLA and the mixture-of-LoRA-experts family put the mixture inside the adapter: several low-rank updates (or, here, several generated ones) with a router selecting among them, sitting on a dense backbone. Every backbone in this source is dense — LLaMA2-7B, LLaMA3-8B, Qwen3-8B-base. The sparsity is a property of the thing being added, not the thing being adapted.

The distinction is not pedantic, because the two setups have opposite failure modes. Adapter-side MoE inherits the routing problems this map already knows — load balance, collapse, router-z-loss-buys-moe-stability-for-free — applied to a handful of small matrices where the stakes are low and the router can be regularized freely. Base-side MoE inherits something this map has no evidence about at all: the expert weights are frozen and unevenly visited, so an adapter's effective training-set size differs per expert by whatever the routing distribution is, and experts-specialize-by-syntax-not-semantics says that distribution is not organized around anything a practitioner selected.

One detail from this source is worth keeping as a hint rather than a finding. Its routing runs on a frozen sentence encoder — an externally supplied semantic signal — rather than on a learned router over hidden states. Read against experts-specialize-by-syntax-not-semantics, that looks like a design response to a known problem: if learned routers organize by syntax and you want topical experts, impose the topic signal from outside. But the ablation puts that encoder's worth at 0.7 points (61.5% → 60.8%), so the imposed semantics are doing much less than the architecture implies, which is itself weak evidence that semantic expert assignment is not where adapter capacity comes from.

Graded open-question and suggestive deliberately: this source's contribution to this map is a clarification of what remains unanswered, not a measurement. The cell stays open, and it is now stated more sharply — train an adapter over a routed expert layer of a sparse base (Mixtral, Qwen3-MoE, an upcycled checkpoint) and report per-expert gradient coverage alongside the task score. The sibling ingest salt-subspace-aligned-ultra-lora-serving independently names a sparse base as out of scope for its own method, which is two adapter papers in one night declining the same question.
