A third position in the allocation-unit debate: rank cheaply within blocks, budget expensively across them

This map's allocation strand has moved from AlphaQ's per-layer framing to expert-bit-allocation-should-be-global-not-per-layer (GEMQ)'s flat global program over every expert — at a stated cost of 191 GB peak GPU memory during quantization, which GEMQ's own authors flagged as potentially exceeding single-GPU capacity for larger MoEs. Q-Strata's bi-level design — a cheap per-block proxy for within-block ranking, a true model-level objective only for the coarser across-block budget decision — reads as a candidate answer to exactly that memory-cost problem, but the abstract does not state whether Q-Strata's authors frame it that way or report a comparable memory figure, so this is recorded as an open question rather than a confirmed resolution.

This is graded extends rather than pushes-back: it refines the granularity of "global" (block-level budgeting plus within-block ranking) rather than contradicting GEMQ's directional claim that scope should be global, not layer-local.
