A LoRA update confined to the null space of reasoning hidden-state activations adapts to new tasks without overwriting RL-elicited reasoning — at a fraction of the cost of the only baseline that retains reasoning as well

RL post-training elicits reasoning capability that plain supervised fine-tuning to a new task routinely destroys: averaged across nine diverse SFT target tasks, vanilla LoRA drops reasoning-benchmark accuracy from a 63.8% pre-SFT reference to 13.9%±18.3 on Qwen2.5-3B (RL'd on MATH-lighteval) and from 80.1% to 16.7%±23.7 on Qwen2.5-1.5B (RL'd on GSM8K) — high variance, with several individual target tasks collapsing reasoning to near zero.

The authors show this collapse has room to be avoided: probing the eigenspectrum of hidden-state second moments (HᵀH) across representative layers finds reasoning-relevant directions concentrated in a small subspace, so a 99%-energy-retention threshold leaves a substantial null space for adaptation to move in without disturbing what a reasoning probe measures — and this null space is estimable from as few as 32 reasoning examples (tested up to 512). Null-Basis LoRA (NB-LoRA) builds a fixed orthonormal null basis Nₛ from reasoning hidden states, then reparameterizes the LoRA update as ∆W = BCNₛ⊤ with Nₛ frozen and only the low-rank factors trainable — any B,C satisfies the preservation constraint HNₛ = 0 by construction, so the guarantee is structural rather than an added loss term or a per-step gradient projection.

Across both models and all nine target tasks, NB-LoRA matches vanilla LoRA's target-task accuracy (0.846 vs. 0.847 avg on Qwen2.5-3B; 0.792 vs. 0.798 on Qwen2.5-1.5B) while holding reasoning accuracy at 0.632±0.006 (pre-SFT reference: 0.638) and 0.800±0.005 (reference: 0.801) respectively — the smallest per-task variance of any method tested. Two weaker null-space baselines (LoRA-Null, MiLoRA) only partially mitigate the collapse (reasoning averages 0.550 and 0.158 on Qwen2.5-3B). The one baseline matching NB-LoRA's retention, NSCL (full-model training with the previous task's gradient projected onto its own null space every step), costs 6.3x more wall-clock time and 2.1x more peak CUDA memory on Qwen2.5-3B — the structural cost of maintaining full-model optimizer state plus an O(d²)-sized per-layer projector applied at O(d³) cost per step, against NB-LoRA's low-rank reparameterization. A null basis built from one anchor reasoning corpus also holds on three held-out reasoning benchmarks not used to construct it (e.g. Qwen2.5-3B's MATH-500 accuracy stays at 0.622-0.626 across reference and NB-LoRA rows, versus 0.052 for vanilla LoRA).

Graded extends on peft-methods: this is a fourth kind of constraint in the map's low-rank contest — structural null-space confinement, distinct from rank size, initialization, module placement, or the optimizer-geometry axis this map picked up on 2026-09-26. It also directly answers a question post-training-rl flagged on 2026-08-01 ("how post-training RL composes with PEFT") with a method, not just a diagnosis — RL-elicited reasoning is fragile under downstream SFT, and the fragility is fixable cheaply without the full-model cost NSCL requires.

Caveats: single institution (Samsung Research America + Purdue), no independent replication, no code-availability statement found. Only two base models tested, both same family (Qwen2.5) — generalization to other architectures or larger scales untested. The main reasoning-retention table measures on the same RL training distribution used to build the null basis; the cross-benchmark generalization check is real but narrower (three held-out benchmarks).
