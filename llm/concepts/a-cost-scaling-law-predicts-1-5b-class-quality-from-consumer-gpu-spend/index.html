The first from-scratch pretraining number in this vault priced in a consumer unit of account, not a datacenter one

Every prior from-scratch pretraining result this vault carries assumes cluster-node-hours or an A100/H100-fleet compute budget. This is the first to run the whole pretraining loop — up to 1.4 trillion tokens, FP8 precision — on consumer RTX 5090 GPUs and publish what it cost: under $6.9K for a checkpoint approaching Qwen2.5-1.5B, against the paper's own >$1.5M and >$700K estimates for reproducing Llama-3.2-3B and SmolLM3-3B respectively.

The scaling law is the more durable artifact than the single run. Puro's fitted cost-scaling law predicts ~$4.4K as already sufficient to match Qwen2-1.5B (note: Qwen2, not the Qwen2.5 the $6.9K run targets — these are two different reference points, not one number restated). A law that predicts a floor is falsifiable in a way a single run is not: a future consumer-GPU pretraining attempt landing near or below that floor would be the first independent corroboration.

One paper, one lab, no independent replication of either the run or the law. Full recipe, data, code and weights are released under Apache 2.0, so replication is possible but has not happened yet — hence emerging, not consolidating, for the map this founds.
