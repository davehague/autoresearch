Alignment losses are human-aware value functions — and that names the whole family

The map's biggest gap has been narrative: DPO, ORPO, SimPO, KTO read as a pile of variants with no account of why any of them work. KTO's framing contribution supplies one. A HALO (Human-Aware Loss) is any alignment loss that scores a completion by the value of its reward relative to a reference point — the KL-anchored reference policy — passed through a value function that is concave for gains, convex for losses, and loss-averse (prospect theory's shape). The claim: DPO's log-ratio against a frozen reference and PPO's KL-penalized advantage both fit this template, so they succeed partly because they encode human cognitive biases (reference dependence, loss aversion), not despite it.

This is the first source in post-training-rl that turns the zoo into a taxonomy. The successive-deletion trajectory the map has tracked — reward model, then reference model, then the pairing constraint — now has a common substrate: every one of those methods is a HALO differing only in which value function and what reference point. That is what tips the map from "listing variants" toward "one mechanism, several instantiations."

Two honest limits keep this suggestive, not settled. The prospect-theory grounding is a motivating analogy: the value function's curvature and loss-aversion constants are hyperparameters the authors set, not measured human parameters — "prospect theoretic" is inspiration, not a fit. And the paper's own result is that no HALO is universally superior — the best choice depends on data form, noise, and task, which means the taxonomy explains the family without crowning a default. It unifies; it does not settle. The instrument caveat (llm-judges-match-human-agreement-and-carry-systematic-bias) applies to the empirical comparisons as everywhere in this map.
