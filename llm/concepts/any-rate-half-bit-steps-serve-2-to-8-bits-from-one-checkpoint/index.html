Serving many precisions from one checkpoint is a separate axis from picking the best single precision — and half-bit granularity between 2 and 4 bits is where whole-bit nesting hurts most

TL;DR: post-training-quantization's allocation sub-thread has always been about where the bits go for one fixed precision (channels, layers, experts, the residual, the rounding bit). Any-Rate asks a different question: how do you serve several precisions from the same checkpoint, so a device can read only as many leading bits as its current memory/energy budget allows? Prior nested-precision methods only offered whole-bit jumps (2→3→4 bits), and the jump cost the most accuracy exactly in the 2-4 bit range this map cares most about. Any-Rate closes that gap with half-bit steps: it restricts some bit-planes to extended Hamming codewords over 8-weight blocks (an error-correcting-code mechanism, 0.5 bits/weight), shares one lookup table per row across all served precisions, and trains all precisions jointly with a separate loss target per precision so sharing the bit-planes costs less accuracy than it otherwise would.

What this adds to the map. Every other allocation-axis source here (rotation granularity, scale-selection, rounding-bit allocation) optimizes a single deployed precision. Any-Rate's claim is orthogonal: multi-precision serving flexibility is itself a design axis, worth the accuracy cost of sharing bit-planes across precisions, if that cost is small enough — and the paper's main contribution is making that cost small specifically in the 2-4 bit band via coded bit-planes rather than naive bit-truncation.

Caveats. No institutional affiliation stated. Code released (github.com/hoonki2002/Any-Rate) but not independently verified by this vault. Four LLMs only, no MoE model tested. Decode-speed and energy claims are "roughly matches existing kernels" (qualitative) and an LPDDR model estimate (not a measured deployment), respectively. Untested in composition with this map's own rotation (Hadamard) or calibration-free scale-selection (Midmax, SoScale) levers, which operate on a single fixed precision rather than a family of them.
