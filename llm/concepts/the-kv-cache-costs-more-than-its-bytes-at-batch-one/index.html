The KV cache costs more than its bytes at batch one

kv-cache-management prices everything in bytes. Grouped-query attention is 5.4× decode because it stores fewer key–value heads; the K-quant cache formats are graded by bits per element; eviction, rotation and anchor-plus-residual are all arguments about how many bytes to keep. The unit is load-bearing across the whole map.

Daedalus states its bandwidth model before measuring, precisely so the measurement can disagree with it — and it does, in the model's favour, by a widening margin.

The model is M(t) = W + κ·t, weights plus cache bytes per context token. For the hybrid κ = 6,144 B; for the parameter-matched all-attention twin κ = 12,288 B. It predicts a decode advantage of 1.06× at depth 0, 1.09× at 512 and 1.17× at 2048. Measured: 1.20× / 1.45× / 1.76×. Seventeen percent predicted against seventy-six percent measured, and the discrepancy grows with depth rather than sitting as a constant offset.

The author rejects the bandwidth-only hypothesis and localises the residual to two effects the equation does not model. Attention traverses the cache with a dependent softmax reduction — a latency-bound operation, not a bandwidth-bound one, which degrades sharply once the working set exceeds last-level cache; a depthwise convolution instead streams a two-element state with perfect locality. And the twin runs 24 layers to the hybrid's 18, so per-layer fixed costs are paid a third more often.

The corollary is the part this map should keep, because it constrains what optimisation can achieve: improving attention kernels narrows this gap but cannot close it, since the cache you do not keep cannot be optimised. Every entry on this map is a way of making a cache cheaper. This is evidence that the cheapest cache is bounded away from no cache by more than the byte count says — at batch one, on a memory hierarchy small enough that the working set escapes it.

Two bounds. This is a single 150M-scale experiment on an unspecified CPU at 8 threads by a single author, so the magnitude of the under-prediction is not a transferable constant. And the effect is explicitly a batch-size-one, last-level-cache-bound phenomenon; under batched GPU serving with high bandwidth and a cache that stays resident, the byte model is the right model, which is why this map has been able to use it. The claim is scoped: the byte model is a lower bound on cache cost, and the bound is loosest exactly where this vault's premise lives.
