One boolean, five points

the-lora-scaling-factor-collapses-gradients-at-high-rank entered this vault graded strength: suggestive: one group, Llama-2-7B and GPT-J, showing that LoRA's standard alpha/r divisor provably damps adapter gradients toward zero as rank grows — so the field's belief that raising rank does not help was confounded by the parameterization — and that dividing by sqrt(r) instead restores monotone improvement with rank.

This is an independent replication, and its provenance is what makes it matter. It comes from the maintainers of the library everyone uses, on a different base model (Llama-3.2-3B rather than Llama-2-7B), a different dataset (MetaMathQA rather than OpenOrca), and a different metric (downstream test accuracy rather than fine-tuning perplexity), inside a benchmark whose whole purpose is holding the base model, data, training code, eval code and hardware identical across arms. 53.2% against 48.1%, at 22.6 GB against 22.5 GB.

Put that number next to the rest of the table and next to this map's history, because the comparison is the point. Every adapter variant this vault has graded moves the number by one to two points — adapter-rank-behaviour-is-small-real-and-method-specific measured surviving differences of about one point after learning-rate tuning; in this benchmark the best alternative parameterization beats rsLoRA by 1.7 points and costs 3 GB to do it. The scaling rule is worth 5.1 points and costs nothing. A map that has spent a year finding that adapter variants do not matter now has a clean statement of what does: the variants are noise and the parameterization is not.

The practitioner form is a single line of configuration and this vault should stop hedging about it: set use_rslora=True. It ships in Hugging Face PEFT, it is not the default, and it is the largest free number in the PEFT design space.

Two things this does not settle. It is one run per configuration with no seed variance reported anywhere, on one model per task — T2 evidence with a public reproducible suite, not a replicated T1. And it does not resolve the open question this map has carried since 2026-08-02, which is whether the placement results (where-the-adapter-budget-goes-matters-more-than-how-much-there-is, a-random-non-uniform-rank-profile-already-beats-a-flat-one) survive the switch: under alpha/r a module's adapter is damped in proportion to its own rank, so a non-uniform rank profile is also a non-uniform effective-step-size profile, and the coupling disappears under alpha/sqrt(r). A benchmark showing the divisor is worth five points makes that ablation more urgent, not less. Nobody has run it.
