Fit the approximation where the reader stands

The mechanical reason a language-modeling head needs its own compressor is stated in one sentence: an LM-head error "is not followed by normalization, a residual path, or another learned transformation; it reaches the softmax directly." Everywhere else in the stack, an approximation gets absorbed — RMSNorm rescales it, the residual stream dilutes it, the next layer's weights were trained around noise of roughly this shape. At the head, nothing does.

So the objective changes. Fitting the correction to minimize plain weight-space error gives 76.95% top-1 agreement with the dense head; fitting the same-rank correction in an activation-derived metric — weighting directions by how much the actual input distribution excites them — gives 93.05%, with KL falling 0.1671 → 0.0113 and logit MSE falling by a factor of fifteen, at the same storage.

The reason to grade this note separately from the-lm-head-is-the-tensor-four-bit-quantization-skips is that the principle has now arrived three times in this vault, in three unrelated literatures, none of which cites the others:

  • Cross-model KV transfer (reconstruction-error-is-the-wrong-loss-for-a-mapped-cache): regression R² on the mapped cache correlates with downstream retention at −0.20 while attention-output cosine correlates at +0.57 — measure the error after attention, not in KV space. Swapping the fit to respect that bought +24.3 and +36.8 points on the two failing model pairs.
  • Feed-forward activation sparsity (an-int4-proxy-ranks-channels-it-cannot-compute): a quantity consumed as a ranking tolerates error a quantity consumed as a value does not — INT4 proxies beat FP16 proxies by up to 9.0 points when used to select channels, and cost 18.1–24.3 points when used as magnitudes.
  • The output head, here: fit in the metric the softmax reads.

Stated generally: the right loss for an approximation is defined by what consumes its output, and weight-space error is the default only because it is the one you can compute without knowing that. post-training-quantization already carries the consumer-based partitioning as its fourth allocation axis; this makes the same idea a statement about the objective function rather than about the bit budget, which is a different lever on the same insight.

It also predicts where the vault should look next. Every calibration-based quantizer in this map — GPTQ's second-order reconstruction, AWQ's salience scaling — minimizes a layer-output reconstruction error, which is the right metric only if the next layer treats all directions alike. expert-bit-allocation-should-be-global-not-per-layer already found that per-layer reconstruction objectives are not comparable across layers and that scoring on the MoE-layer output fixed it, which is the same complaint from a third direction. Nobody has run the controlled version: one model, one bit budget, the same method fitted under a weight-space metric and under an activation-derived one, scored on a reasoning benchmark.
