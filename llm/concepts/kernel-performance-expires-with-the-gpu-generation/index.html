Kernel performance expires with the GPU generation

transformer-architecture added a rider on 2026-07-19, reasoning from FlashAttention-2's explicit A100 tuning, that systems progress expires with the GPU generation it was tuned for. FlashAttention-3 measures it: FA2 achieves 35% utilization on H100, against the ~73% of A100 peak it was celebrated for. Same kernel, same mathematics, one hardware generation later, roughly a third of the machine. This is an in-vault prediction confirmed by a source read afterward.

This note is the measurement half of a pair. attention-kernels-are-tuned-to-a-gpu-generation records FA2 predicting its own expiry — its author stating that Hopper's TMA, 4th-gen Tensor Cores, and fp8 were worth another 1.5–2× and were not implemented. Read together they are the vault's cleanest instance of a forecast and its confirmation from two separate sources, which is why the claim is now confirms rather than an extension.

The rebuild is entirely about the silicon, which is the point. Asynchrony: Hopper's Tensor Cores and Tensor Memory Accelerator run independently of the SM, so warp-specialization splits warps into producers (moving data) and consumers (computing). Interleaving: block-wise matmul is software-pipelined against softmax, whose non-matmul operations otherwise stall the Tensor Cores. Low precision: FP8 through block quantization plus incoherent processing — multiplying by a random orthogonal matrix to spread outliers before quantizing — worth 2.6× lower numerical error.

Two things follow. First, the vault's rule for reading any throughput claim hardens: a number is meaningless without a kernel, card, and precision stamp (local-inference). Second, incoherent processing is the same outlier-spreading trick the weight-quantization literature uses (gptq-post-training-quantization), applied to activations inside a kernel at runtime — so precision is not only a storage decision made ahead of time but a transient compute-time one (post-training-quantization).

Caveats: every number is H100-specific, and authors sit at NVIDIA/Meta/Together — vendor adjacency on a hardware-utilization claim. The 2.6× error figure is against baseline FP8 attention, not a downstream model-quality result. By its own logic these numbers expire too.
