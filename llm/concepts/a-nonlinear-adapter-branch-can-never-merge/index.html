A nonlinear adapter branch can never merge

adapters-can-merge-away-inference-latency is one of the oldest settled claims on peft-methods: ΔW = BA folds into W at deploy time and the served model is indistinguishable from a fine-tuned one. It has already been narrowed once. every-quantization-backend-now-accepts-an-adapter found merging breaking on aggressive base formats — AQLM cannot merge at all, torchao merges correctly only for one configuration and is silently wrong otherwise — because folding a full-precision low-rank product back into a codebook index is not a defined operation.

This is the same property failing from the other side, and it is more general. AuroOFT's adapter path computes B·φ(A x) with φ a learned nonlinear basis. There is no matrix M such that Mx = B·φ(Ax) for all x. The merge is not unsupported by some backend; it does not exist. Any base format, any precision.

So the four levers this map has tracked since 2026-07-27 — placement, initialization, parameterization, rank — gain an axis with a hard trade nailed to it: expressivity against mergeability. Everything in this map's literature so far has lived on the linear side of that line and inherited zero-cost serving for free. Cross it and you are choosing to pay a per-token tax forever.

The paper crosses it and does not price it. Not a millisecond, not a megabyte, in a study whose entire premise is a 4-bit base on constrained hardware. That omission is expensive in context: four-bit-fine-tuning-buys-vram-with-time-and-energy measured a merged adapter against a quantized base and found 76% higher inference latency for the unmerged path — a real, large number for exactly the configuration AuroOFT permanently commits to. Against a 1.30–2.70-point accuracy gain, an unmeasured latency cost of that order is not obviously a good trade, and nobody can tell from this paper.

The practitioner form: decide whether you will merge before you choose an adapter architecture. If the fine-tune's purpose is to produce a checkpoint you quantize and ship (local-inference's whole pipeline), a nonlinear adapter is disqualified regardless of its benchmark. If the purpose is hot-swappable per-task artifacts served over one frozen base, merging was never on the table and the trade is free.

Source: aurooft-nonlinear-residual-quantized-orthogonal-finetuning
