A defense with no signal

evaluation-contamination has carried leakage as failure mode one since coining, anchored on benchmark-scores-can-be-memorization: rebuild a benchmark from scratch and several model families drop up to 8%. What the map has not carried is a graded claim about the remedy. Every corpus builder in this vault decontaminates the same way — strip training documents that share an n-gram with a test item (GPT-3 set the convention at 13-grams; GPT-4's report uses a 50-character span). FineWeb does it, and data-curation-choices-are-ablatable-and-non-monotonic credits it as one of the things that makes that corpus trustworthy.

Measured against paraphrase, the method has an F1 of 0.000. Not degraded — blind. The same detector scores a perfect 1.000 on unrephrased test items, so it is working exactly as designed; it simply has no purchase on a sentence with reordered clauses, a synonym substitution, or a translation. Across three MMLU subjects in two languages and HumanEval in three programming languages, it is at zero in every cell, against a random baseline of 0.500.

The consequence is demonstrated rather than inferred. Fine-tune Llama-2 13B on rephrased test items and MMLU goes 54.8 → 89.9, above GPT-4's 86.4. GSM-8K goes 28.7 → 95.3. CodeLlama-13B's HumanEval goes 36.0 → 81.1, against GPT-4's 67.0. Every one of those models passes n-gram decontamination clean.

Two things stop this from being a story about adversaries.

It happens by accident. The MATH training set contains 79 rephrasings of its own test items — 1.58% of the test set, self-contaminated, no attacker involved. CodeAlpaca, a 20K instruction set generated by an LLM from seed tasks, carries 21 rephrased HumanEval problems (12.8%). An LLM asked to produce examples similar to a public benchmark is a rephrasing machine whether or not anyone intends it, which is why this finding reaches into data-curation and not only into evaluation.

The obvious upgrade doesn't hold. Embedding-similarity search is the natural next detector and it is language-bound: 0.985 on rephrased English MMLU but 0.179 once the item is translated to Chinese; 0.903 on rephrased Python HumanEval but 0.438 once translated to C. Swapping in a multilingual encoder fixes translation and then fails on a different subject (0.111 on US History), because the distribution of within-subject similarity differs enough that no single threshold works across subjects — a threshold tuned for abstract algebra floods sociology with false positives.

The detector that does work — retrieve the top-k most similar training items by embedding, then ask a strong LLM pairwise whether each is a rephrasing — reaches 0.940–1.000 everywhere. But it requires the training corpus, which places it firmly on the supply side. That matters because the vault's other contamination tool, pretraining-membership-leaves-a-detectable-tail, is a demand-side method usable at AUC 0.72 with no corpus at all. The strong detector needs exactly what a model consumer does not have, and the tool a consumer can run is the weak one, so the two do not compose into a workflow.

The operating rule this vault should now hold: "we decontaminated" is uninformative unless it says how. The modal decontamination claim in the field is an n-gram claim, and an n-gram claim is a claim about verbatim copies only. This is the same failure shape as quantization-calibration-sets-leak-their-domain-into-the-model — a reproducible, honestly reported number that still cannot be compared to anyone else's, because a load-bearing step in the protocol went unstated.

Bounded honestly: the training regime that produces those inflated scores is deliberately maximal (16 epochs on nothing but rephrased test items), so this shows what is possible, not what an accidental exposure to a fraction of a percent of contaminated pretraining data actually costs — no dose-response curve exists. Detection is measured on 200 pairs per setting across three MMLU subjects and HumanEval, with the rephrasings generated by the same model that then judges them. And it is all 2023 vintage.
