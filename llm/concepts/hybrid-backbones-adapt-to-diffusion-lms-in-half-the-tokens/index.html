The diffusion-decoding map's founding sources are all about what parallel emission costs at inference; this is the first about what it costs to build the diffusion model in the first place, and the answer is architecture-dependent

Everything diffusion-decoding has carried since coining is inference-side: sampler cost, exactness, serving throughput, KV-cache drift. dQwen3.5 answers a training-side question the map has never touched — how much adaptation compute does converting an existing AR checkpoint into a DLM cost, and does that cost depend on the AR checkpoint's own architecture? The map's coining source (diffusiongemma-discrete-diffusion-open-weights) already established that a decoding regime is a cheap post-hoc conversion (<10% of the original pretraining budget) rather than a pretraining commitment, for a full-attention MoE backbone. dQwen3.5 narrows that claim: the "cheap conversion" story was demonstrated on full-attention transformers, and the AR frontier has since moved to hybrid attention/recurrent architectures whose recurrent layers cannot be unmasked the way attention can. This source shows the conversion recipe still works on a hybrid backbone, and unmasking only the attention sub-layers is not merely sufficient but cheaper than full-attention adaptation — 2.21x fewer tokens to the same loss in the one controlled comparison the paper runs.

Two things temper how far that generalizes. First, the token-efficiency win does not carry over into a uniform benchmark win at matched adaptation budget — the hybrid trails on knowledge/math benchmarks (MMLU, GSM8K) and leads on code benchmarks (HumanEval, MBPP) against its full-attention control, so "adapts faster" and "adapts to a better model" are different claims and only the first is well supported here. Second, the comparison against other published DLMs (Dream, LLaDA) that motivates the "beats models trained on 6-46x more adaptation tokens" framing is not architecture-matched — different base models, tokenizers, and data mixtures confound the comparison, so it is suggestive of the general trend rather than a clean ablation of the hybrid-vs-full-attention question.

Graded extends: this adds a training-cost dimension to a map that had none, rather than confirming or contesting an inference-side finding. Graded strong: a quantified median-multiplier effect size with stated methodology (matched trunk size, controlled data/training recipe) across four model scales, with released code and weights — but discounted by scope, since the single clean architecture-matched comparison is one pair at one scale with differing tokenizers, and the broader DLM comparisons are uncontrolled. Cross-map: this is also a data point for mixture-of-experts's and transformer-architecture's running theme that architectural properties (sparsity, context length, and now decoding regime) are turning out to be post-hoc, cheap fine-tunes rather than pretraining-time commitments — dQwen3.5 extends that pattern to hybrid-attention/recurrent backbones specifically, which neither map has evidence on yet since neither tracks recurrent-layer architectures.

Rebutted by: none — extends the map's post-hoc-conversion finding to a new backbone class rather than contradicting anything on record.
