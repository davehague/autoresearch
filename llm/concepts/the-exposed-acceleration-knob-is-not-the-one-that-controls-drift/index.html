The exposed acceleration knob is not the one that controls drift

The image-swap intervention is the result to remember. Under the default refresh schedule, you can replace the input image entirely and get a byte-identical description back, 10 times out of 10. The accelerated model is not looking at the picture; it is elaborating on a stale cached view of one. That is not a subtle consistency artifact, and no threshold setting reveals it — sweeping the confidence threshold across its entire documented range moves agreement by 0.0056, which is a null with a tight confidence interval attached.

The generalizable claim is about instrumentation, not diffusion models. A system's exposed dial is not evidence that it is the dial that matters, and this vault has now recorded that failure three times in three unrelated stacks:

  • the-attention-backend-decides-whether-cache-compression-pays — the compression ratio you configure is dominated by a backend choice the paper did not vary.
  • adapter-variant-gains-are-a-learning-rate-artifact — the adapter variant you pick is dominated by a learning rate the comparisons held fixed.
  • Here — the acceleration threshold you tune is dominated by a refresh interval nobody advertises.

Each was found the same way: by sweeping the parameter the literature treated as an implementation detail. That is a cheap and repeatedly productive experimental move, and it is the one this vault should ask of any serving result it reads.

The mechanism is worth keeping separately because it is specific and actionable. Drift comes from staleness of cached state, and the ablation separates the two sources: stale visual state contributes more than stale generated-text state (0.498 vs 0.454 at interval 4) but neither alone accounts for it. So the failure is a cache-coherence problem wearing an accuracy problem's clothes, and it belongs as much to kv-cache-management as to the sampler — with the twist that here the cache is not being compressed or evicted, only refreshed too rarely, which is a failure mode nothing else in that map covers.

One honest bound: this is one base model and one primary implementation for the causal work. The diagnosis replicates on dLLM-Cache (0.394 vs Fast-dLLM's 0.420) and LaViDa, but LaViDa has no refresh knob to test the remedy with.
