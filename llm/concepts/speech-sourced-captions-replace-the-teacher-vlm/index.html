Ask people to talk, not type — speech-sourced captions replace the teacher VLM

The reason the field reached for GPT-4V to write training captions is throughput, not capability: typing a dense, exhaustive image description is slow, and annotators asked to do it produce thin ones. Molmo's move is to change the input modality of the annotation task. Annotators speak for 60–90 seconds per image — objects and counts, text present, spatial layout, background, style — the audio is transcribed, and a language-only LLM cleans the transcript into written prose. The LLM never sees the image. Speech is fast enough to produce genuine density in real time, so the property that made teacher distillation attractive is recovered from people. 712k images, ~1.3M captions, up to four versions each as natural augmentation.

The same instinct runs through the rest of PixMo: PixMo-Points has annotators point at a referent, describe it, then exhaustively point to every instance plus explicit absent-negatives (2.3M question-point pairs) — supervision no captioning model could have produced, and the source of Molmo's counting advantage. PixMo-Docs generates charts and documents from code and derives Q&A from the generating code rather than from the rendered image. PixMo-CapQA synthesizes questions text-only from ground-truth captions. In every case the pattern is the same: find a channel where ground truth is structurally available, rather than asking a model to guess it back out of pixels.

This is a data-curation result as much as a VLM one, and it lands where data-curation has been thinnest. That map's discipline so far is filtering a corpus that already exists (data-curation-choices-are-ablatable-and-non-monotonic); this is supply-side — designing the collection protocol so the data is dense and clean at the source. And it is the counterexample to synthetic-instructions-from-a-blind-teacher-bootstrap-a-corpus: both papers solved "there is no multimodal instruction corpus," one by proxying the image through a blind teacher, the other by routing around models entirely. Molmo's result says the teacher was a convenience, not a necessity — at the cost of a human-annotation operation most practitioners cannot run, which is the honest limit on how far this transfers. What it does transfer is the question to ask before generating synthetic data: is there a channel where the ground truth already exists?
