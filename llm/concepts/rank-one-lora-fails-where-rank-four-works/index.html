The rank sweep everyone runs starts one rung above the cliff

This vault's position on adapter rank is settled and deflationary. adapter-rank-behaviour-is-small-real-and-method-specific records a sweep across r = 4 → 256 in which method differences are 0.33–1.67% and flip sign with rank, and the practitioner rule that came out of it was to use vanilla LoRA and spend the compute on a learning-rate sweep instead. Rank, on that evidence, is a dial that barely matters.

That sweep starts at r=4. One rung below it, something else appears to be happening. A plain r=1 LoRA on Mistral-7B-v0.3 scores MultiArith 11.03% — not a degraded score, a non-functional one, near what guessing would produce on a task the same base handles at usable rank. SPIDER 30.34%, MBPP 15.75%. Holding the base, the data and the parameter count fixed and only changing how the rank-1 subspace is chosen (SALT's pinned domain centroid plus residual) takes MultiArith to 86.21% — a 75-point swing at identical rank.

The correct inference is narrow and worth stating precisely: the vault does not know what happens below r=4, and the one datum it now has says the behaviour there is qualitatively unlike the behaviour above. "Rank barely matters" is a claim about r ≥ 4, and it should carry that scope from now on.

Two candidate explanations, and this source cannot separate them.

A capacity floor. lora-rank-has-a-matching-lower-bound supplies a theoretical shape for this — there is a rank below which the target update is not representable — and r=1 on a 7B model is a plausible place for that to bind. If so, SALT works because the pinned centroid supplies the missing capacity and the residual only has to steer within a subspace that already contains the answer.

Another instance of the untuned-step-size artifact. adapter-variant-gains-are-a-learning-rate-artifact found that methods altering the adapter's conditioning shift the optimal learning rate by up to 18.2×, and that a default step size then overshoots into a sharper basin. A rank-1 adapter is the most extreme conditioning change available, and neither this source nor the rank-sweep paper reports a learning-rate sweep at r=1. An 11% score is also consistent with a run that simply diverged.

The experiment that separates them is cheap and nobody has run it: r = 1, 2, 4 on one base and one task, each at its own tuned learning rate, reporting whether the cliff survives tuning. If it does, the vault has a capacity floor and the ultra-low-rank serving literature is solving a real problem. If it does not, that literature is measuring against a broken baseline — the same defect expert-capacity-can-be-decoupled-from-adapter-storage is held at single-study for, arriving from the opposite end of the rank range in the same night's ingest.

Graded single-study: one base, one paper, five tasks, and the r=1 LoRA numbers are a baseline in a paper proposing an alternative, which is the position in a table where a weak configuration is least likely to have been fought for.
