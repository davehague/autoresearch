Fewer trainable parameters, more memory

The vault's organizing inference about training memory is that PEFT deletes the terms scaling with trainable parameters — optimizer state, gradients — and leaves the activation term standing, which is why rematerialization-trades-compute-for-the-activation-memory-nothing-else-shrinks is the lever PEFT cannot make redundant. That argument is correct about terms and it is insufficient about totals.

Twenty fine-tuning configurations measured under a hard 2 GB VRAM budget, and on one architecture the ranking inverts outright. BitFit trains bias terms only — the smallest trainable set in the study — and peaks at 3,307 MiB on TinyViT where LoRA, AdaLoRA and QLoRA all sit near 1,260 MiB, at the same batch size, on the same data. The inversion reproduces on the second dataset (3,313 vs ~1,200 MiB). On ViT-Small the same method is the cheapest in the study at 648 MiB. Same method, same parameter count, opposite ranking, two architectures.

The mechanism is placement rather than count. Bias terms live in every layer including the earliest ones, so gradients must flow all the way back and the full activation stack stays alive; an adapter concentrated in later blocks lets the backward pass release everything before it. Where the trainable parameters sit decides how much of the forward pass has to be retained, and a parameter count carries no information about that.

This is the memory-side twin of a result the vault already holds on the quality side. where-the-adapter-budget-goes-matters-more-than-how-much-there-is measured a 10.7-point accuracy spread at a fixed 0.28M trainable budget depending purely on which matrices got it. Neither paper knows about the other, and together they say the same thing: placement is the lever, and it is a memory decision as well as an accuracy one. No in-vault source has ever priced it that way, and the tooling exposes placement as a target-module list with no memory reporting attached.

The energy column is the cleaner and less surprising finding: QLoRA costs 25–28% less energy than full fine-tuning for a 1–2 point accuracy cost, consistently across both datasets — the first watt-hour measurement of a PEFT method anywhere in this vault.

Held at suggestive rather than strong for a reason that matters. Every model here is a 21–32M-parameter vision backbone on small-image classification; there is no decoder-only LLM and no 4-bit base of the size where PEFT's memory argument is normally made. The inversion is a real measurement and its generalization to a 7B transformer is untested — the specific mechanism (early-layer trainable parameters pin the activation stack) does not depend on the modality, but its magnitude entirely might.
