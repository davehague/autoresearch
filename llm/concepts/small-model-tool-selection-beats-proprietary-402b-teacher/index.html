A small model can learn the orchestration skill of agentic tool selection well enough to beat the 402B model that taught it, and the skill survives a change of retriever and tool domain — the vault's premise, demonstrated on a new axis

This vault's premise is using data and compute to make an open-weights model outperform a frontier model on a specific task, then run it on affordable hardware. Every existing map that embodies this premise does so on a performance axis — reasoning accuracy (distillation-small-models), preference alignment (post-training-rl), format efficiency (the quantization maps). This paper demonstrates the same premise on a different axis entirely: agentic orchestration capability, specifically the skill of decomposing an instruction into substeps and matching each substep to the one tool it needs out of a corpus too large to fit in context. The result that a 1.7B-8B open model, trained via SFT (on a proprietary 402B model's own filtered decompositions) then GRPO, beats every tested workflow built directly on that same 402B teacher is structurally identical to distillation-small-models's founding result (a distilled small student beating the frontier generalist it learned from) but on a capability axis — tool selection, not question-answering or math reasoning — that no existing map's standing question covers.

Why this earns its own map rather than folding into an existing one. distillation-small-models's core objects are reasoning traces and performance parity/superiority on benchmarks the teacher could also attempt directly. post-training-rl's core objects are preference losses and verifiable-reward reasoning elicitation. This paper's object — picking the right tool from a corpus of thousands, under a retriever that doesn't know which candidates are actually needed — is an orchestration problem with its own failure modes (candidate-cap sensitivity, retriever-swap robustness, cross-domain transfer) that neither existing map's standing questions are built to hold. Coined here as a new, thin map; flagged for review.

What stays open. Supervision traces back to the proprietary teacher for gold-tool filtering and SFT traces, so this is a distillation-RL hybrid rather than a from-scratch result — the "beats its own teacher" framing should carry that lineage. TaskBench is a disclosed exception where the teacher's workflow retains the lead. No test yet against a different proprietary teacher, a larger open-weights student, or a non-ToolBench-family tool corpus built independently of this paper's own data pipeline.
