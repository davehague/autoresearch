Routers were assumed independent objects; they are not, and the shared structure buys a free-standing perplexity win

mixture-of-experts carries "expert routing is predictable one layer ahead" as a within-router finding — a layer's own gating function applied to the previous layer's hidden state predicts the next routing decision, which is the mechanism behind speculative expert-prefetch caching. This source is a different, deeper claim: routing-relevant states across independently-trained routers at different layers share one geometric structure, visible only after stripping each router's private coordinate system via generalized orthogonal Procrustes alignment. That is an architectural-organization finding, not a caching trick — nothing about MoE training explicitly couples routers across layers, and yet the coupling is there to find.

It sits one level underneath "routers learn syntax, not topics" (two labs, independent): if the routing geometry itself is shared across layers rather than idiosyncratic, that is consistent with — though not the same claim as — the syntactic-not-semantic finding, since a shared, low-dimensional control structure is more plausible if what is being routed on is a stable surface property (syntax) than if each layer is chasing a different domain-specific signal.

The practical result — a training-free-sounding perplexity improvement (15.7% OLMoE, 6.2% Phi) from using the shared transition as an inference-time prior — is the kind of cheap, general win this vault should hold to a higher bar precisely because it sounds too easy: the fetched summary does not state whether applying the prior requires any retraining or fine-tuning of the router itself, which determines whether this is a free inference-time correction or a training-time technique being reported at inference-time granularity.

Bound: model sizes for Phi/OLMoE not given; "persistence baseline" not defined operationally (repeat expert index vs. repeat routing logits); no test of whether the shared geometry holds across model families rather than only within one trained model — the more useful transfer question for anyone hoping to reuse a learned prior across checkpoints is untested.
