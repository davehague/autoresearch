Activation quantization's calibration requirement was never a separate problem from weight quantization — the weight-reconstruction scale already contains the signal

This map's allocation strand has carried rotation-based calibration-free methods (QuaRot, SpinQuant) and calibration-based per-channel scaling (SmoothQuant) as two separate families with a quality/convenience tradeoff between them — rotations avoid calibration data but can degrade badly on microscaled formats (outlier-companion-grouping-fixes-nvfp4-collateral-error names exactly this failure for NVFP4's shared per-block exponent). DualQuant's contribution is a third option that is calibration-free and competitive with SmoothQuant specifically because it does not try to avoid calibration by a geometric trick (rotation) but by discovering that the weight-only reconstruction objective already contains an effective activation scale as a byproduct — no separate activation-statistics pass is needed at all.

Why this is a new mechanism, not a tuned version of an existing one. Every calibration-free method this map already tracks (QuaRot's Hadamard rotation, SpinQuant's learned rotation) works by transforming the geometry of weights and activations so a fixed-grid quantizer has an easier time — the calibration-free- ness comes from not needing activation statistics to choose the transform. DualQuant instead solves a weight-only optimization (minimize reconstruction MSE via block coordinate descent) and observes, as a post-hoc empirical finding, that the resulting per-channel scale correlates strongly with the scale SmoothQuant would have computed from actual activation statistics (Pearson +0.83 to +0.97 across projections at zero correlation-penalty). The authors are explicit that this correlation does not prove equivalence, but the downstream accuracy numbers back it up across four formats and six models.

Where it sits relative to this map's format progression. The map's format axis has moved INT4 → MXFP4 → NVFP4, with NVFP4 generally the hardest format for calibration-free methods to handle cleanly (the OCGQuant finding, and QuaRot's own outright divergence on some NVFP4 settings here). DualQuant is the first calibration-free method on this map's allocation strand to beat SmoothQuant specifically on NVFP4 (Llama-3.1-8B zero-shot, all five tasks) rather than merely approach it.

Caveats carried from the source. The win against SmoothQuant is mixed, not universal — DualQuant trails on Llama-3.1-8B MXFP4/C4 perplexity and is essentially tied (not ahead) on Llama-2-7B NVFP4/WikiText-2. The comparison against calibration-free rotation methods (QuaRot) uses the paper's own numbers in one table rather than a dedicated head-to-head against this map's full rotation-based family under matched formats and calibration-set-free settings. The real packed-kernel validation (2.61x memory, up to 2.46x throughput) is one model, one format (INT4, G=64), one GPU (RTX 4090) — not yet shown for MX/NVFP4 on real hardware. The solver's convergence rests on an assumption ("iterates eventually stop changing") the authors call "generic" and support empirically on a subset of blocks rather than prove in general.
