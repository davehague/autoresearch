Cache repair after an in-context document edit is a different problem from eviction — and here too, position beats importance scoring

Every eviction source this map carries answers a budget question: given a cache smaller than the full context, what do you drop? This paper poses a staleness question instead: nothing was evicted, but a document already in context was edited (a RAG-style correction or update), and because causal self-attention lets each token's KV state depend only on what came before it, everything computed downstream of the edit point is now running against context that no longer matches the prompt. Full re-prefill is correct but wastes all the compute already spent on the unaffected prefix.

Given a recompute budget smaller than full re-prefill, the paper compares a contiguous edit-local window (refresh positions near the edit, chosen by proximity alone) against attention-based, KV-deviation, and structural selectors — the same importance-scoring family used throughout this map's eviction sub-thread, repurposed here for repair. The contiguous window wins clearly: ≥0.94 of the post-edit answer margin recovered, 13-21x faster than full re-prefill, across three model families on matched direct and derived edit cases. The advantage is explicitly conditional — it "largely disappears when the answer-bearing text moves downstream" of the local window, i.e. proximity to the edit is a good proxy for "what changed" only when what matters for the answer is itself near the edit.

This is the second source in one ingest run finding that a non-importance heuristic beats explicit importance scoring on its own task — fp8-weights-win-cost-quality-latency-frontier-naive-fp8-kv-cache-fails shows speed-only certification failing on correctness, and independently, prompt-preservation-not-scoring-explains-eviction-quality-on-reasoning-tasks (a prior ingest) shows random eviction matching scored eviction once the prompt is protected. Graded extends rather than pushes-back: this is a different object (a repair budget, not an eviction budget) from every existing eviction source, so it doesn't directly contradict any of them — but it strengthens a pattern the map is now accumulating: importance- scoring's premise does not automatically win against simpler position- or randomness-based heuristics, and which wins depends on task structure.

Caveats: "derived edit cases" implies at least some edits are synthetically constructed; construction methodology not detailed in material read at ingest time. Three model families tested but not named; baselines named only by category, not specific prior methods, in material available. The scope condition (fails when answer-bearing text is far downstream) is the paper's own honest limitation, not a hidden gap.
