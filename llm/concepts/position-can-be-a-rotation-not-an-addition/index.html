Position can be a rotation, not an addition — and then it is relative for free

The 2017 block treats order as a signal you add to the token embedding before attention. RoPE treats it as a rotation applied inside attention: multiply the query and key projections by a block-diagonal matrix of d/2 independent 2×2 rotations at frequencies θ_i = 10000^{-2(i-1)/d}, scaled by the token's absolute index. Rotations compose, so R_mᵀR_n = R_{n-m} and the score q_mᵀk_n collapses to a function of the offset alone. You encode absolute position and get relative dependency out of the algebra, with no learned bias terms and no extra terms in the attention-score decomposition.

Three consequences make it the scheme every current open-weights model ships. There is no position table — nothing sized to a maximum length, so the encoding is defined at any index. Attention decays with distance by construction (an Abel-summation bound, not a tight rate) rather than having to learn to. And because rotation preserves the norm of Q and K, it survives the kernel factorization that Performer-style linear attention needs — which additive relative schemes (Shaw, Transformer-XL, T5 bias, DeBERTa) break. That compatibility is the paper's stated reason for choosing rotation over the alternatives.

This lands directly on the map's component vocabulary (attention-alone-scales-sequence-modeling): positional encoding was named as a required component in 2017 and is the one component whose form has since changed under the field's feet. It also sits upstream of a fine-tuning-adjacent lever the vault has not yet sourced — because there is no table to resize, the effective context of a released checkpoint can be renegotiated after training (position interpolation, NTK scaling, YaRN). That line is later work; this paper makes no length-extrapolation claim, and RoFormer-1024 was trained at 1024 rather than extrapolated from 512. The evidence itself is 2021-vintage and BERT/WMT-scale, and the GLUE result is a genuine split decision — the durable content here is the mechanism, not the benchmark margin.
