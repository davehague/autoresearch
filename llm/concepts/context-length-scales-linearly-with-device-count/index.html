The sixth memory axis, and the only one that partitions the sequence

This map's five other axes all attack terms indexed by parameters: sharding partitions replicated optimizer/gradient/parameter state (sharding-is-a-dial-between-memory-and-communication), tensor parallelism splits one layer's math (tensor-parallelism-splits-a-layer-across-gpus), expert parallelism gives each device unique experts (one-expert-per-token-is-enough-to-scale), offload demotes cold state down the hierarchy (offloading-the-optimizer-demotes-memory-instead-of-distributing-it), and pipeline parallelism splits depth while re-materializing activations (pipeline-parallelism-splits-depth-and-pays-a-bubble). Ring Attention attacks the term indexed by sequence length, and it is the only one that does.

The mechanism turns on a property of attention that is easy to state and load-bearing: attention between a query block and a group of key/value blocks is permutation-invariant — the KV blocks can be visited in any order provided the softmax rescaling statistics are combined correctly. That freedom means the KV blocks can simply circulate. Each host holds one query block permanently and passes its KV block to the next host while receiving the previous host's, computing blockwise attention and blockwise feedforward on whatever it currently holds. Communication for step i+1 overlaps with computation for step i.

The memory consequence is the whole result. Prior memory-efficient attention reduced the constant on a term linear in sequence length; 6bch contains no s at all. Six blocks per host: the query block, the current KV pair, the incoming KV pair, and the output. So the ceiling moves from "how long a sequence fits on one device" to "how many devices are in the ring," and a model trainable at context s on n devices becomes trainable at ns. Measured, that is 8× on eight A100s and 512× on TPUv4-1024 — 16 million tokens.

What makes this credible rather than merely large is the MFU column. Longer contexts shift FLOPs toward self-attention, which has lower MFU than the feedforward, so a small decline is expected; the measured decline is about one point and there is no communication penalty on top of it. The overlap is real, and it holds because of the block-size condition in overlap-requires-a-block-size-above-the-flops-to-bandwidth-ratio — which is also where this technique stops working on modest hardware.

This is the same tiling insight as attention-is-memory-bound-not-compute-bound with the tiles distributed across hosts rather than staged through SRAM, which makes it a further instance of the vault's recurring finding that capability headlines are frequently systems progress on an unchanged block (attention-alone-scales-sequence-modeling).

Bound: no language-modeling quality comparison — every headline is capacity or efficiency, not whether the resulting model is better. Full precision rather than mixed, which is unusual and makes the throughput figures hard to compare with the rest of this vault. The 512× figure is a 3B model on 1024 TPUs; the largest model tested is 30B and GPU results top out at 32 devices. Venue-less preprint.
