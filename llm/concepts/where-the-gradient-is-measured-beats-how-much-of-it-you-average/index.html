Where the gradient is measured beats how much of it you average

peft-methods is contested, and one reason is a shelf of initialisation papers whose margins keep landing in the band that adapter-variant-gains-are-a-learning-rate-artifact indicts. LoRA-GA² is the (n+1)th entry on that shelf and its headline deltas over GoRA — +0.66 GLUE, +1.03 GSM8K, +0.87 HumanEval — sit squarely in that band, under a protocol that keeps each baseline's own published optimiser settings rather than sweeping learning rate per method. the-initialisation-papers-answer-a-question-the-learning-rate-critique-did-not-ask carries that objection.

One number inside the paper survives it, and it is a different claim from the headline.

The gradient-guided initialisation family — LoRA-GA, LoRA-One, GoRA — accumulates gradients at the pretrained checkpoint and initialises the low-rank factors from their principal directions. LoRA-GA² instead runs a short AdaLomo probe that actually takes optimiser steps, accumulates gradients along that brief trajectory, and restores the weights before formal training. The obvious confound is that a trajectory probe sees more minibatches. So the ablation fixes the budget: 64 minibatches in both arms, same method, same optimiser settings, same three seeds, weights frozen in one arm and moving in the other.

Freezing them costs 1.81 GSM8K points (73.94 → 72.13). HumanEval moves less (49.85 → 49.65), which the authors read as code generation being less sensitive to this particular trajectory signal.

That is a within-method contrast with nothing to tune between the arms, which is what makes it immune to the learning-rate critique in a way the cross-method comparison is not. The claim it supports is narrow and general at once: the gradient at the pretrained checkpoint is a biased estimate of the gradient the fine-tune will follow, and the bias is worth about a benchmark point at 8B. The improvement is not from averaging more minibatches; it is from collecting them somewhere else.

The magnitude wants context from the same table. Removing SVD initialisation altogether — falling back to random low-rank factors while keeping everything else — costs 5.02 points (73.94 → 68.92), nearly three times as much. So aligning with some gradient is the large effect and aligning with the right gradient is a real but second-order refinement. This map's standing summary of the initialisation literature does not have to change; it gains a term.

The premise reading is negative and should be stated with the finding. The probe peaks at 108 GB of GPU memory and formal training at 137.7 GB, reported across a 4×H200 node. LoRA exists on this map because it fits a fine-tune onto one or two consumer cards; a preprocessing pass needing an order of magnitude more memory than the adapter training it precedes is not a local recipe. Nothing here is run against a quantized base, which is the configuration a single-card user would need. Until someone runs the probe on a 4-bit base, this is a finding about gradients, not a method anyone local can execute.
