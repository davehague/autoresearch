Transformer architecture (attention & the block) — map

Coined 2026-07-16 during the seed ingest — first evidence in the "Transformer internals" group. Status note: the architecture is the field's decade-settled baseline, but this ledger's Status reflects in-vault evidence only (three T1s as of 2026-07-18); it climbs as replicating sources land. The tutor's guardrails already treat foundations as stable regardless of this label.

Status: emerging

What we believe now:

  • Attention alone suffices for sequence modeling, and dropping recurrence bought the parallelism that made pretraining scale. The original result is translation (WMT14 En→De 28.4 BLEU, >2 over prior best including ensembles; En→Fr 41.8 single-model SOTA) at a fraction of prior training cost (3.5 days × 8 GPUs) — but the durable consequence is that training computes over all positions at once. [T1]
  • The component set defined here is the vocabulary of the whole craft: scaled dot-product attention over Q/K/V, multi-head attention, the block (attention + position-wise MLP + residuals + layernorm), and explicit positional encoding (attention is permutation-invariant — order must be injected). The projections LoRA adapts, the K/V tensors the cache stores, the matrices quantization compresses are all named in this paper. [T1]
  • The block's cost is memory movement, not arithmetic — and that is fixable without changing the math. FlashAttention re-schedules exact attention against the GPU memory hierarchy (tile Q/K/V into SRAM, never materialize the n×n matrix in HBM, recompute it in the backward pass from softmax statistics): memory goes quadratic → linear in sequence length, with 3× on GPT-2 (seq 1K), 2.4× on long-range arena, +15% on BERT-large, and the longer contexts it made affordable bought quality too (0.7 perplexity on GPT-2, +6.4 points long-document classification; first Transformers above chance on Path-X 61.4% at seq 16K and Path-256 63.1% at seq 64K). The output is bit-identical. [T1]
  • A large share of what reads as architecture progress is systems progress on an unchanged architecture. Neither FlashAttention nor the KV-cache work altered the 2017 block's computation; they changed how it meets the hardware. Worth holding while reading this field. [T1]
  • The KV cache is an architectural choice, not a fixed cost. Grouped-query attention shares g key/value heads across groups of query heads (MHA and MQA as endpoints). On T5-XXL, GQA-8 reaches 47.1 average vs MHA's 47.2 at 0.28 s/sample vs 1.51 s — 5.4× decode speed for 0.1 points — and an existing multi-head checkpoint converts by uptraining at 5% of original pretraining compute. This is why nearly every open-weights model in current use ships with GQA. [T1]

Through-line (newest first):

  • 2026-07-18 — ingest of gqa-grouped-query-attention (Ainslie et al., Google Research, EMNLP 2023, T1): the first modern block refinement in-vault, and the architectural lever on the KV cache; creates a three-lever interaction (architecture / precision / placement) noted in post-training-quantization and local-inference. See sharing-kv-heads-buys-decode-speed-at-near-zero-quality-cost.
  • 2026-07-18 — ingest of flashattention-io-aware-attention (Dao et al., Stanford/SUNY Buffalo, NeurIPS 2022, T1): the IO-awareness reframing — exact attention, linear memory, and the clean statement of the memory-bound principle the vault's inference maps keep re-deriving. See attention-is-memory-bound-not-compute-bound.
  • 2026-07-16 — seed ingest of attention-is-all-you-need (Vaswani et al., Google, arXiv, 2017-06-12, T1): the origin paper, read as the source of the component set rather than a spec of current practice — modern open-weights models are decoder-only stacks of this block with later refinements (RoPE, RMSNorm, SwiGLU) not covered here. See attention-alone-scales-sequence-modeling.

Open questions:

  • The decoder-only lineage (GPT-line) and the remaining modern block refinements — RoPE, RMSNorm, SwiGLU/gated MLPs — have no in-vault sources yet (GQA/MQA landed 2026-07-18); the tokenization and generation/sampling ends of Track A are similarly unserved (see index "Open gaps").
  • Where knowledge lives (params vs activations; what fine-tuning actually moves) needs its own evidence thread — it is the internals question the fine-tuning craft leans on hardest. The intruder-dimension result (intruder-dimensions-are-the-mechanism-of-lora-forgetting) is the vault's first spectral purchase on it and belongs to this question as much as to peft-methods.
  • The kernel lineage is dated in-vault. FlashAttention's tile choices are A100-era; FlashAttention-2 (2023) and -3 (Hopper, 2024) exist because the tuning does not transfer across GPU generations, and neither is ingested. Same for GQA: T5-XXL encoder-decoder evidence, with the decoder-only Llama-class replication universal in practice but unmeasured here.
  • Nobody in-vault has stacked the levers. GQA (fewer KV heads), KV quantization (fewer bits), and paging (less waste) all attack the same memory budget; a measured combined result on one runtime is the sharpest missing number across this map and local-inference.
