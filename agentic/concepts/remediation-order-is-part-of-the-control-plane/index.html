Two guardrails that both know how to fix things are a rewrite system, and rewrite systems have an order

Once you accept that a control may repair an action rather than merely refuse it (a-gate-that-remediates-invalidates-every-other-gates-verdict), the next question is forced: with two repairers in the plane, does it matter which runs first?

It does, and the demonstration is mechanical rather than statistical. The two operators are ordinary and unremarkable — one substitutes a governed value for a corrupted one, the other scales a quantity down to fit a budget — and both write into fields the other's inputs are derived from. Substitution changes unit cost, which changes order value (authority) and predicted cost (resource). Downroute changes quantity, which changes the same two. A finite-model checker runs both orders over a 243-point grid of the real functions and finds 86 points where they disagree. When an independent reviewer probed continuous points off the registered grid and found divergence there too, the artifact promoted the probe into the checker and reseeded it from a declared constant rather than the git HEAD, so the published number stops drifting with every commit: 150 of 200 off-grid points disagree. That is a small methodological detail with a large lesson — a reported count that is derived from the repository's current state is not a finding, it is a moving target.

The mechanism is the same one, one level up. Where the orders disagree, a budget check ran against a value that had not yet been corrected and was never re-checked once it was. So non-commutativity is not a separate phenomenon from single-pass unsoundness; it is that phenomenon with the second remediator playing the role the first plane's parallel evaluation played.

The operational rule. A fixed order is required, and it must be specified, versioned and auditable rather than emerging from whichever middleware happens to be registered first. That is the governance-plane analogue of a dependency order in a build system, and the reason it belongs in this map is that most agent guardrail stacks today are a list of middlewares in a config file where order is an artifact of who added theirs last. The artifact's own workflow spec pre-registers evidence-gate-first as a consequence of the checker's result rather than a convention.

The limit is stated harder than the result. A fixed order is not a general solution. With three or more operators, applying one can make an earlier one relevant again; and the paper explicitly does not solve arbitrary non-idempotent remediators, cycles, global termination, unique fixed points, confluence across arbitrary operators, concurrent state updates, or serializability across multiple agents. What it establishes is a sound one-shot protocol for the bounded, idempotent setting, plus the demonstration that anything richer needs an explicit termination-and-confluence theory. Its soundness lemma depends on substitution being idempotent and on an external predicate contract it composes but does not itself prove, and is classified checked-scope-only on that basis.

The vocabulary here — confluence, normal forms, operator ordering, termination — is term-rewriting theory, and the paper says so rather than reinventing it, while declining to become a term-rewriting paper. For this vault the transferable claim is narrower and sharper: any agent control plane where more than one component can modify the action before it executes has an ordering semantics, and if nobody wrote it down, it still has one.

Related: an-intermediary-on-the-response-path-voids-client-side-gates and admit-an-agent-response-per-component-not-whole for other cases where a transformation between decision and effect invalidates the decision; keep-the-agent-interruptible-and-reversible for why remediating rather than blocking is attractive in the first place.

Bounds. Two specific operators; the paper is explicit that the result does not generalise to remediators with different structure without re-deriving the checker. Deterministic artifact, zero model calls, synthetic metadata layer over open payloads, no prevalence claim.
