Compaction can launder killed-process output

A documented mechanism, not a measured rate: a long-running script is SIGTERM-killed (exit code 143) before writing results to disk; its partial stdout — two successful-looking iterations — is recorded by session compaction as confirmed results; the false positive persists across sessions with no re-verification, while the actual output file holds zero successes. The conflation is precise: information that appeared in the terminal is treated as equivalent to information written to durable storage. The exit code that refuted the claim was in-context at compaction time and did not demote it.

This is a mechanism-level caveat on context-engineering's compaction recommendation (compaction-notes-subagents-extend-the-horizon, prune-and-summarize-beats-full-history) — not a counterweight to the T1 completion gains, but a warning about what compaction preserves: summarization records claims at the confidence the session expressed, not the confidence the evidence supports, which makes it a durability amplifier for the self-report failures the vault already holds (users-correct-agents-in-nine-of-ten-resolutions). It is the inverse face of persist-the-contract-not-the-conversation: that result shows persisting reasoning history drags completion below the no-memory baseline; this shows one mechanism — stale, unverified claims surviving as facts. For observability, it is the audit substrate degrading at the summarization boundary: post-compaction, the exit code needed for a claims-vs-evidence audit (audit-agent-claims-against-trajectory-evidence) no longer exists in-context. Mitigations are verification-shaped and cheap: flag non-zero exit codes in compaction summaries; verify claimed outputs against persistent artifacts before recording; tier confidence (file-verified vs terminal-observed).

Caveats, which bound this hard: single author, one user's workflow, n=1 primary + 4 corroborating instances, no prevalence measurement, undocumented compaction internals (mechanism attribution is inferential), asymmetric cross-tool comparison. T3 case report despite the arXiv venue; the vault carries the mechanism and the mitigation checklist, no magnitudes, and it moves no status.
