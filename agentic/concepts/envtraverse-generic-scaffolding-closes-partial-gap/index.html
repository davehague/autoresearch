A single generic procedural instruction moves scores in two of three unrelated environments on an unchanged agent — but a hand-specialized reference still beats it, and the lever that closes most of the gap is removing one decision from the model's hands entirely

This map's design-lever sub-thread has repeatedly measured what a hand-engineered harness component buys (bash vs. typed tools, context-pruning policy, tool-interface wrappers) and its pair-attribution sub-thread has measured what happens when a harness is given to different models. Neither strand has isolated a third, narrower question this source supplies directly: holding a harness's code, tools, and architecture completely fixed, does a purely generic procedural instruction — not a new fact, not a new tool, not an environment-specific rule — change what the model does with capability it already has? EnvTraverse answers yes, with a specific mechanism and a specific limit.

The "Stop-and-report" instruction (report difficulties, return control for automatic continuation rather than persist alone) raises mean scores on two of three tested environments (ARC-AGI-3, AGI Maze) while leaving Terminal-Bench flat with no consistent direction — itself evidence that "generic procedural guidance helps" is not a universal claim but an environment-dependent one, on this map's running theme that no harness lever is portable across tasks without qualification. More useful than the headline is the diagnostic experiment that follows: even with Stop-and-report, the general agent trails a reference agent carrying ARC-AGI-3-specific organization and control — a reference that supplies no new game rules, only prescribed ways of using information the general agent already has access to. Transferring just the RESET decision (when to restart a failed attempt) from the model to a scripted controller recovers roughly 34-60% of that gap. That is a concrete, minimal instance of this map's founding pair thesis at the smallest possible grain: one decision, moved from model to harness, buys a measurable fraction of a specialization advantage.

The AGI Maze tutorial result cuts the other way and belongs on the same throughline: giving the agent seven tutorial mazes before the target maze reduces performance for most tested configurations — a second, independent demonstration that more available information/experience does not translate automatically into better use of it, the paper's own stated throughline and one this map has not previously carried in this form (distinct from the compaction/pruning findings, which are about discarding information under budget pressure rather than supplying more of it without using it well).

Why open-question rather than confirms/extends a specific standing claim: no existing note on this map makes a directly comparable prediction about a purely generic (non-architectural) procedural instruction's transfer value across unrelated environments — this is a new axis (a single-instruction lever, not a tool/context/interface lever) rather than a replication or rebuttal of anything already here.

Bounds: single author, one Codex-based agent architecture, no ablation separating "better procedure use" from "more or differently allocated inference" — the paper is explicit that the reported gains come with higher token-based cost and are improvements under the tested execution policies, not matched-cost wins. The released EnvTraverse framework and Baseline agent are offered as infrastructure for further testing, not a finished claim about which generic instructions transfer.
