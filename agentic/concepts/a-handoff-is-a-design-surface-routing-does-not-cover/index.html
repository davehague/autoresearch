The boundary between two models is a component, and most harnesses do not have one

Coding-agent products expose /model as a setting. This measures it as a component, and finds that the spread it controls is wider than the spread between the strategies it is usually confused with. Holding the models, the scaffold, the tools, the prompts and the switch points fixed, and varying only what crosses the boundary, moves GPT escalation from recovering 36% of the available quality gain to recovering 84%. That is not a tuning parameter. That is the difference between a manoeuvre that is not worth doing and one that is.

The reason a handoff cannot be folded into routing is structural, and this map has the vocabulary for it already. Routing is a decision about the next call. A handoff in a long-horizon coding agent is a decision about the carried state, and there are two kinds of carried state with different properties: the trajectory, which the harness can transform freely, and the working tree, which it cannot — the receiver inherits files another model edited whether or not it inherits the reasoning behind them. Every interface tested preserves the working tree; only the trajectory varies. So the design question is never "does the receiver start fresh" but "how much of the story behind these edits does it get", and the answer is direction-dependent (what-crosses-at-a-handoff-should-flip-with-the-direction).

The information-dynamics extensions are the part that generalizes past coding. Whether escalation is worthwhile depends on what task-relevant state exists at the switch. When requirements arrive in shards over turns, the receiver is the first model able to see the fully specified task, escalation recovers 86% of the gap, and the coding ordering reverses. When evidence accumulates through search, escalation nearly closes the quality gap and still produces no savings. So a harness that wants to place switches well needs to know something about when its tasks become solvable, which is a property of the task family rather than of the model pair — the same axis route-after-scouting-the-repository-not-from-the-issue-text found for the initial routing decision, arriving one layer down.

This is the same class of finding as subagent-delegation-adds-a-silent-handoff-failure-class and verify-a-handoffs-claims-before-the-next-agent-reads-them: the interfaces between agents are where the harness's real behaviour lives, and they are systematically less designed than the agents on either side. Those two measured agent-to-agent handoffs and found silent failure and false claims. This measures a model-to-model handoff of the same trajectory and finds a cost–quality tax. Three different boundaries, three different taxes, one omission.

Bounds. The interface comparison is established on one benchmark and two model pairs; the extensions vary information dynamics only under raw transfer, so the interface ranking is not shown to transport past coding. Switch points are fixed rather than policy-triggered by design, which isolates the handoff but leaves the practically important question — an adaptive, progress-aware trigger that decides when and what to pass — explicitly open.
