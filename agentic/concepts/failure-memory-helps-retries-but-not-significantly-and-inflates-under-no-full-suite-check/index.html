Failure memory looks like it helps a repair retry, and mostly it does not reach significance -- the one methodological finding that does travel is that nobody checked the full test suite

This map's within-agent repair-loop sub-thread has measured mostly when to intervene once a loop is running, and has generally found that giving an agent more information about its own failure helps. This source is the most carefully powered test yet of whether it helps at all, and the honest answer is: probably a little, not reliably, and the most confident-sounding version of the intervention (a model-written lesson distilled from the failure) buys nothing over just handing back the raw transcript despite costing an extra model call.

The methodologically load-bearing finding is the post hoc full-test-suite check. Memory-equipped retries edit more narrowly when they do edit — touching files the reference fix also touches more often than a plain retry does — which looks like better targeting. But the same retries more often silently break other tests the reference fix passes, undetected by any evaluation that scores only the originally-failing test. Any prior or future source in this map claiming a resolve-rate gain from failure memory, measured only against the target test, should be read with this discount in mind unless it reports a full-suite check.

Interaction edge: early-stopping-gains-come-from-easy-issues-not-selection — both are careful, well-instrumented null-or-near-null results on this sub-thread's standing intuitions (early-stop prediction, failure-memory retry), landing the same week and sharing the same corrective shape: a measured effect that looks real in a pooled read and mostly disappears once the comparison is made properly (within-task AUC there; full-test-suite breakage here).

Bounds: single language (Python), single dataset (BugsInPy), mostly one model-family size swept (gpt-5.4-mini, partial gpt-5.4 replication); exploratory by the authors' own framing, with sample-size estimates supplied for a confirmatory follow-up rather than this run substituting for one. Variance between individual failures dwarfs variance between conditions.
