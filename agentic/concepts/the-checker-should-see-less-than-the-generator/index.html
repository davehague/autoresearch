Independence is a property of the information set, not of the model card

The standard fixes for agent hallucination pick a side and lose. Intrinsic self-reflection — Reflexion, Self-Refine — has the same model critique its own output with the same context, so it inherits the bias that produced the error. External validators — program analysis, type checks — are reliable exactly where they apply and cannot adjudicate a semantic review comment at all. This is a third position, and its whole content is a boundary: the reflector uses the same LLM but is shown strictly less than the agent it checks.

The design has three parts and each is load-bearing.

Asymmetric information. The SubAgent explored the repository with tools; the reflector sees the diff alone. Deliberately: the SubAgent may have formed a comment from context the reflector cannot verify, and rather than trying to re-derive that context, the reflector's job is narrowed to the subset it can adjudicate. Note that this is the opposite of the intuitive design, where you give the checker more evidence.

Falsification, not verification. Flag a comment only where the diff carries direct counter-evidence to its key claim. A comment that references logic in another file or runtime behaviour the diff cannot show is left alone — the agent may hold valid evidence. So the filter's errors are asymmetric by construction: it can fail to remove a bad comment, and it structurally cannot remove a good one whose support lies outside its view.

Filter-only, fail-open. The reflector deletes and never generates, so reflection can only reduce false positives and never introduce new ones; if its response will not parse, everything is retained. Breadth of findings is determined solely by the SubAgent's exploration, and reliability of each finding is checked separately. That separation of concerns is separate-the-generator-from-the-evaluator implemented without a second model or a second budget.

Where this sits against what the vault already holds. an-independent-checker-beats-the-same-model-checking-itself measured that a different cheap model re-deriving from the original request recovers near-oracle amounts of injected error. This says the model swap may not be the operative variable — what the checker is denied is. verifier-diversity-is-not-verifier-independence argues the same negative from the other direction: a cross-family verifier was the worst of three, and independence has to be measured as error correlation rather than asserted from a vendor diff. Put together, the emerging rule is that independence is engineered by controlling evidence flow, and the model boundary is neither necessary nor sufficient. a-verifier-sharing-the-interpretation-shares-the-error is the standing caution: a narration-blind verifier with an external anchor still missed nine value errors in ten, so restricting the information set buys precision on the class it can see and buys nothing outside it.

Bounds. The reflection module is never ablated — its contribution is inferred from the precision profile of the whole pipeline against baselines that differ in three other ways as well, so the effect attributed here to the boundary is not separately measured. Reported precision is against a fixed expert-verified set adjudicated by an LLM judge; a correct comment matching nothing in the ground truth scores as a false positive, which flatters a conservative filter. Nothing measures the filter's own false-rejection rate on true findings. "Same model, less context" is tested on one task shape (review-comment adjudication against a diff), and the authors themselves offer generalization to other tasks as future work rather than a result.
