"Gate what an agent may do" assumes the tool it named is real — a fabricated tool call is a blind spot no downstream gate can see

This map's standing claim is layered enforcement: environment sandboxing, a pre-execution classifier, and human-last review, over the transitive closure of agents/tools/peers/gateways/stores/skill-sources. This source names a layer that sits before all of those, and proves formally why order matters here specifically: a causal gate's admissibility decision reads risk and authorization off the tool's registry entry (R[n]); for a hallucinated call, n ∉ R, so R[n] is undefined and no risk-based or authorization-based rejection is even expressible — the gate is not fooled, it is structurally unable to render a verdict, and under the standard fail-open convention (anything not explicitly rejected executes) that means every hallucinated call runs. Placing the same existence-check logic after the gate — inside a contract verifier, say — fails for the identical reason: there is no trusted contract for a tool that was never registered, so there is nothing to verify against.

The measured part sharpens this map's model-capability findings elsewhere: hallucination rate under the unconstrained (MCP-bridge-style) surface tracks the invocation surface, not model capability or scale — a 675B frontier open-weight model and an 8B one land within 2 points of each other (0.55 vs 0.57), and even Claude Opus 4.8, clean on the constrained schema surface, hallucinates at 57% on the MCP multi-server surface because collision and shadowing are properties of the merge, not of any model's generation quality. This is a concrete instance of this map's environment-first-layering principle: the fix that actually closes the gap is a placement decision (put the check before the causal gate, resolve the merge before trusting a flat name), not a more-capable model. One class survives by construction — a borrowed argument shape that is schema-indistinguishable from a valid call to a different tool — and the paper correctly scopes that residue as a tool-selection problem for a different layer to solve, not a resolution failure.
