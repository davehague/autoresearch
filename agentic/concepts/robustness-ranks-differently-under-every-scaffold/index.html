The apparatus term shows up in a place this map had not looked: not in the score, in the stability of the score

Every entry in this map so far measures the apparatus by moving it and watching the number move — swap the loop implementation, the scaffold, the serving wrapper, the inference backend (the-loop-implementation-is-a-larger-term-than-the-model-tier, the-inference-backend-is-a-term-in-the-score, the-review-harness-reorders-the-model-leaderboard). This measures something the same layer does that no swap-based instrument can see: the scaffold determines how much a model's score moves when the codebase around the task is rewritten into an equivalent form.

The perturbation is a repository-level rewrite that preserves behaviour — if/else switching, loop rewriting, operand permutation, local renaming, always-true guards, redundant try/except, and two decoys planted from the issue description itself, an unread string assignment and an unreachable method carrying a keyword the agent is likely to grep for. Test files are excluded, so the oracle is byte-identical before and after and no score change can be attributed to a moved target.

The jaggedness is the finding. Mean degradation is positive in 13 of 16 configurations and significant in 6, but no scaffold-model pair is significant on both benchmarks, and no ordering of models by robustness holds across scaffolds or across benchmarks. Qwen degrades 0.2 points under mini-SWE agent on SWE-bench Verified and 5.5 under OpenCode — the most robust model in one cell and the most brittle in the other, same model, same benchmark, same tasks. MiniMax moves the other way. Opus takes the largest drop in the study (6.7 points, mini-SWE agent on Pro) and is the least degraded of four in an adjacent cell. Every model is among the most robust in at least one cell and among the most brittle in another. So a practitioner who chose a model for how it held up under one scaffold on one benchmark can get the opposite outcome after changing either.

The one term that does hold, and why it is credible. Averaged over four models, the simpler scaffold degrades less on both benchmarks — 1.34 against 1.88 on Verified and 1.88 against 3.65 on Pro. What makes this more than "the better scaffold is also the steadier one" is that absolute strength flips between the benchmarks: mini-SWE agent resolves 89.05% of unperturbed Verified runs against OpenCode's 81.20%, but 76.35% on Pro against 79.33%. The robustness gap survives that flip. A richer scaffold gives the agent more surface — more retrieval, more tool paths, more context per turn — and more surface to be perturbed through.

Where the brittleness actually sits. Not in models and not in repositories: no instance degrades under all eight configurations on either benchmark, and the aggregate is carried by a heavy tail — three instances alone account for roughly two-thirds of the largest configuration's 6.7-point mean. Brittleness attaches to particular instance-configuration pairs. That is the same shape as an-aggregate-gain-and-a-reliable-regression-coexist-in-every-cell one layer over, and it means a configuration-level robustness number is a summary of a few cells rather than a property of the arm.

The trajectories say what the mechanism is. Localization degrades when dead string assignments carrying the issue's own keyword dilute a grep. Agents "fix" perturbed code while patching, inflating the diff. One agent misattributes a genuine test failure to a split string literal, reasons that the split was not its own edit, and submits the incorrect patch without resolving the error — a corrupted patch-validation step, which is the failure mode this vault should care about most because it is silent. And some agents detect the rewrite and revert the repository via git reset, which the authors had to cap the decoys to prevent, because it destroys the measurement rather than making it harder.

Bounds. 54 instances, selected to be solvable by one model under standard conditions, so this is a lower bound on a favourable set. Sampling is deliberately non-adversarial and not feedback-guided, which makes every figure a floor — a guided adversary can only do more damage. No hyperparameter search (one configuration is 2,160 agent runs). Semantics preservation is established by differential testing against three projects' suites, not by proof. Two scaffolds is enough to show rankings do not transfer and not enough to characterise which scaffold properties cause it.
