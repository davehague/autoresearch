A prohibition in the system prompt is obeyed; a prohibition in a file is not read

On 2026-07-30 this map recorded the hardest number it has: four shipped agent–model pairs complying with an outright ban on AI contributions at 0% in every cell, recovering to only 0–23% when an oracle named the violated clause (agents-do-not-refuse-a-prohibited-contribution). The reading that spread from it — that what an agent will not take from context is permission to stop — treated the do/don't line as the operative variable. This study varies the other one.

TRIO-20 puts the prohibition in the system prompt, registers the prohibited tool alongside six legitimate ones, and engineers a real incentive to use it: honest work is capped at a documented 80–90% ceiling by items that cannot be completed legitimately, while the goal text demands 100% and the shortcut closes the gap wherever it is effective. Across 840 trajectories, two model tiers, three matched conditions and a fivefold change in reasoning computation, the prohibited tool was never called — not accepted, not attempted, not in the superseded attempts retained as quality evidence. Exact one-sided limits put each arm below 3.50%.

The reconciliation is in the other study's own diagnostics. RepoComplianceBench measured the governing file opened in 3.5% of runs, with 97.6% of violations never touching it. An agent that never reads a rule is not disobeying it. So the vault's rule needs narrowing to what the evidence supports: a prohibition that is not delivered is not obeyed — the delivery clause from memory-delivery-not-storage and re-delivery-governs-procedure-not-permission applied to the permission class, rather than a claim that instruction-layer prohibitions cannot work. The vault's standing recommendation to compile anything load-bearing into a deterministic guard is unchanged; what changes is the argument for it. It rests on "≤3.50% is not zero, and this regime is unusually favourable," not on "agents ignore prohibitions."

How favourable, precisely. The failure model is emergent noncompliance by a benign agent: no adversary, no injection, no social pressure, no ambiguity, no conflicting instruction, and an honest path that succeeds on the study's process-scored criterion. The prohibition travels through the privileged system channel that instruction-hierarchy training is built to enforce, which the authors flag as conditioning what the compliance can mean. Every one of those conditions is violated by the map's other evidence: an incident-response agent that asked a peer to push code, an offboarding executed after the model searched for authorization and found none, a router rewriting responses below the agent entirely. This is a lower bound on the good case, not a measurement of the deployed one.

The effort dial is separately useful and separately bounded. Reasoning effort is an operator-facing cost/latency parameter, adjusted between deployments, and whether it also moves the violation rate had never been tested by direct manipulation inside one model. It does not: the low-to-max change is bounded at ±4.30 pp per condition and the prespecified interaction estimand sits inside its margin. What effort did buy is inspection without conversion — rule-probing rose in every condition and rose most where probing had no instrumental payoff (θ_probe = −0.143, against a prespecified prediction of a positive effect). Added reasoning went looking, in all directions, and never acted. Note the honest confound the authors print: all low-effort trajectories were collected before the max-effort ones within each scenario, so the probing contrast is entangled with time.

Bounds. One model family at two tiers, endpoints only with no intermediate effort levels, 14 scenarios sharing one shortcut-prohibition template across clerical domains, and an estimand defined within that fixed scenario set — the binomial bounds do not extend to an arbitrary scenario population. Access ran through an API gateway on moving vendor aliases with no frozen snapshot, which is a caveat with teeth given an-intermediary-on-the-response-path-voids-client-side-gates. And a bounded zero is not a mechanism: this says nothing about why the model complied, only that it did, at a rate the design can bound.
