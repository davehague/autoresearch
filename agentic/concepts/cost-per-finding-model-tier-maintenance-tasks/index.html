A real production maintenance workload prices the cheap-model-plus-better-prompt question this map has mostly asked in the abstract

This map's CI/CD thesis is that mechanical, out-of-band verification is what makes agent-authored change safe to land at volume; this source is the first here to put a dollar figure on which model tier to run that verification and cleanup with. The cheapest tier tested (GPT-6.1 Sol Medium, $0.06/finding) and the mid tier (GPT-6.1 Sol Ultra, $0.12/finding) both land far below the frontier tier (GPT-6 Astra Ultra, $0.77/finding) while Sol Ultra alone recovers 92% of Astra's findings — and the team closed most of the remaining gap (a single named pattern, constant flags used as dependencies of other flags) with a corrective prompt rather than upgrading the model. That is a concrete, if single-vendor, instance of model-routing-token-economics's standing question — routing to the cheaper tier plus a targeted prompt fix beats paying for the frontier tier on this bounded task class. The guardrail design (verify against live state before deleting, one small PR per change, forbid touching live configuration, escalate the ambiguous case rather than auto-resolving it) is the same constrain-the-blast-radius pattern this vault's governance sources recommend for authorization gates, here applied to housekeeping work instead.

[T2, single-vendor, self-reported, no control group or independent replication; outcome counts only, no reported defect-escape or revert rate on the 1,400+ merged PRs; the cost-per-finding comparison is one audit on one codebase at one point in time, and "findings" were spot-checked by hand on the high-impact subset rather than independently validated in full.]
