Governance conversion: discover controls from the failures agentic work makes visible

In a 12-week first-person build, the deliverable that dominated was not the product (420 KLOC) but the governance apparatus around it (1.16 MLOC, 2.75× the product). The induced process theory — governance conversion — runs: high agentic velocity surfaces recurring structural failure classes → human architectural/contextual judgment classifies each as a local defect vs a structural weakness → structural failures are converted into durable, preferably deterministic controls → the environment's governability compounds as conversions layer (the deepest defensive stack reached 14 complementary mechanisms). Two worked incidents: agent-checked structural invariants that stopped scaling were reified as a typed component catalog, converting non-deterministic agent audit into deterministic static/dynamic enforcement; and constraint under-specification at dispatch was fixed by dynamic context injection that slices the exact governing rules into the agent's brief before it edits. The distinguishing claim vs prior governance models: controls are discovered from failures that only become visible during agentic work, not derived from known obligations up front.

This extends runtime-action-governance from what layers to install to how the layer set is found and hardened over time — the socio-technical face of "convert an observed agent failure into a deterministic containment/enforcement mechanism." The "constraint under-specification at dispatch" failure class is underspecified-targets-drive-unsafe-actions observed in the field, and the remedy (inject the target rules) is the map's specify-the-target, put strictness in the gate rule applied at dispatch time. It is also the first sustained account of building the substitute gate that automated-review-displaces-human-review-at-scale measured at org scale.

Caveat: N=1, single expert, no control arm, no defect-outcome data — theory-generating, not a test; the 2.75× overhead is one project's number. T3 / single-study, earning weight by producing falsifiable predictions (velocity-exposure; human-judgment thesis; does conversion compound?).
