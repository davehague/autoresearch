Put it in the interface, not in the instructions

The vendor that popularized agent-facing documentation now recommends moving most of it off the documentation plane. Examples become tool parameter design (a status enum carries the protocol that a demonstration used to), repeated instructions become tool descriptions, memory becomes a feature rather than a section of CLAUDE.md, and depth becomes references fetched at point of use — with CLAUDE.md demoted to repository-specific gotchas, organized as a tree.

The stated reason to drop examples is worth flagging because it cuts against standard practice: few-shot examples "constrain [newer models] to a certain exploration space." No experiment is offered for that, so it is an assertion — but the direction rhymes with strip-the-prompt-when-the-model-improves on the same source, and with the map's own generated-context-files-cost-more-than-they-help (a generated repo overview costs 0.5–2 points at +20–23% tokens): a context artifact that tells a capable model how to do something it can already do is paying twice, in tokens and in narrowed search.

Where this earns its place in the map is as the vendor's own account of the content plane's limits. Every content-plane measurement in this vault has come back small or negative — 8.3% compliance for a requirement nobody scores (instructions-fail-to-govern-non-functional-requirements), generated context files net-negative, and a seeded memory store drawing zero voluntary reads in 114 turns (memory-delivery-not-storage). The prescription here is the corresponding move: relocate the content onto surfaces the agent traverses whether or not it chooses to — a parameter it must fill, a description it receives with the tool, a memory the harness injects. That is the content-plane → control-plane shift argued from the product side rather than measured.

It also lands on the map's disclosure result. Anthropic ships exactly one routing level — skills invoked on demand, tool schemas deferred behind a search step, a CLAUDE.md tree whose leaves are fetched at use — which is the boundary one-level-of-disclosure-is-enough measured as the point past which a second always-resident routing layer collapses accuracy by up to 36 points. Independent lines, same design rule, and the vendor's version has no experiment behind it while the T1's does.

Caveat: T2 vendor guidance about its own product, no measurements, and written for the Claude 5 generation specifically. Carried as a design direction that agrees with three independent measurements, not as an established effect.
