The correction was fitted to the noise it was fitted on

This map's standing demand is that a delta be read against a measured null rather than an assumed one. The demand has a second floor underneath it that nothing here had reached: the null is a measurement too.

The instance is clean enough to be a worked example. An expansion statistic separates a problem the model acquired from one it merely got better at expressing: a problem counts as expanded when the base model produced no correct sample in k draws and the trained model produces at least one. Run it on a frozen model evaluated against itself and it returns 0.280 — a model that did not train "expands" more than a quarter of the problems it had not reached. That much is coordination-deltas-need-a-measured-noise-floor applied to a new statistic, and the audit catches it.

The interesting failure is the repair. Every one of the seven frozen expansions is exactly one correct sample in 128, so requiring two removes all of them and the null on that comparison is exactly zero. The threshold looks certified. It is not: that zero is one realisation over 25 problems, and the same study already contains eleven independent k=128 evaluations of the untrained model — one at every arm's checkpoint 0 — giving 110 ordered pairs at no marginal cost. Pooled over those, the "repaired" null is 0.058 [0.038, 0.078], above the 0.048 it was invoked to dismiss. The threshold was fitted to the noise it was fitted on, and m turns out to be benchmark- and k-specific in exactly the way the statistic it corrects is.

The operational form. Every arm's untreated starting point is a replicate of the same measurement. Harvesting them costs nothing and is the difference between a null and a number that looks like one. But the paper attaches the count, which is the part worth carrying: four is not enough — over subsets of size 4 the same null still ranges 0.022–0.098, wide enough to certify a false zero — and nine is where the estimate holds within ±0.02 of the eleven-replicate value. Most multi-arm studies in this vault run three or four arms. They own the replicates to notice the problem and not enough to settle it.

Two more instances in the same design, both correcting in the conservative direction. A four-checkpoint no-op built from five independent evaluations moves a corruption floor from 5 to a median of 8 over 120 orderings, so the treatment arms clear it by 11–13× rather than the 18–21× the two-checkpoint control advertised — this is match-the-controls-design-to-the-arms as a distinct requirement from having a control at all. And a frozen solve-rate envelope widens from 0.188 to 0.234 once twenty pairs are used instead of one, which changes how many observed movements count as real.

The general rule the source states and this map should carry: the replicates that bound a null already exist in any multi-arm study, provided there are enough of them. A null reported without an interval is the same error as an effect reported without one, one level up — and it is the level nobody checks, because a null is what you cite when you want to stop measuring.

Sits directly beside report-a-null-as-a-bounded-interval-not-a-failed-test, which governs how to publish a null you found; this governs how to earn the null you are reading against.
