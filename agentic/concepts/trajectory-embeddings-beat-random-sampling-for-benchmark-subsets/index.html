A second, independently-designed method for the exact problem this map priced one ingest ago — cheap re-evaluation of a production agent that keeps changing — converging on the same shape from a different mechanism

This map's newest entry, adaptive-testing-cuts-production-eval-cost, measured the same economic problem this source addresses: a production agent gets re-evaluated on every change, and running the full benchmark every time is not viable. That source solved it with Item Response Theory adaptive testing — calibrating item difficulty from historical runs and selecting a small, informative question subset, the framework standardized testing uses to estimate ability without administering the whole exam. This source solves the same problem with a different instrument: trajectory- embedding proximity within historical outcome groups — grouping instances by whether they historically passed or failed, then picking the instances whose full behavioral trajectory (steps taken, tests run, errors produced), not just their final label, sits closest to each group's centroid. Where IRT's signal is a calibrated difficulty parameter estimated from outcome history alone, this source's signal is the shape of the agent's process on each instance — a genuinely different information source used to solve the identical selection problem, and both report the same qualitative result: a small, well-chosen subset (IRT: 38.5% of the full benchmark; here: 5-10%) tracks the full-run number closely enough to trust for regression decisions, at a large fraction of the cost eliminated.

This also sharpens rather than settles that entry's own carried caveat — IRT's validation was for score fidelity (does the subset reproduce the aggregate mean), explicitly not diagnostic fidelity (does it still surface a specific narrow regression). This source's estimation-error framing (gap between subset resolve rate and full-benchmark resolve rate, including a worst-case / 95th-percentile bound, not just an average) is a stronger fidelity claim than a mean-tracking number alone, but it is still an aggregate resolve-rate metric, not a per-instance regression-detection test — so the map's diagnostic-fidelity gap stands open for both methods alike, and a genuinely decisive comparison would need to test whether either subset-selection method still catches a narrow, real regression a full run would have caught.
