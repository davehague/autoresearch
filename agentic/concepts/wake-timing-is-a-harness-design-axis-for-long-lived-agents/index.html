For an agent that has to decide not just what to do but when to look, the biggest risk is not the model or the trigger -- it's a bad strategy picked on day one that nothing in the run ever revisits

This map's durable-state thread establishes that unattended agents need externalized, persistent state to run for longer than one turn. This source adds the axis that thread has been missing: for agents that act sparsely over a long horizon rather than continuously, when to look is a harness decision with measured consequences independent of model choice -- and the dominant source of variance in the entire study is neither the model nor the trigger, it's plain seed-to-seed noise (50-95% of score variance on every task), which is itself a finding this map's unattended-operation practice has to reckon with: two runs of the identical agent, model, and trigger on the identical replayed world can land far apart on outcome, before any design choice is even varied.

The early-lock-in failure mode is the sharper and more actionable result. On Reddit popularity prediction, agents using the sleep trigger (where the agent sets its own next wake time) choose an interval early and barely revise it for the rest of the run -- weekly median change under one hour -- and a single matched pair (otherwise-identical runs, 12h vs. 6h self-chosen trigger interval) separates by 32.5 F1 points purely on that one early decision never being revisited. This is a persistence failure with no adversary and no new dependency, structurally close to this map's own standing material on agents that drift from instructions over long deployments (one Claude-Haiku run here operated normally for a week, then slept for three weeks and tried to deliver everything on the last day, contrary to its own system prompt) -- except here the mechanism is narrower and cheaper to name: the agent never re-evaluates whether its own timing policy is working.

The fix that is shown to work -- Best-of-N selection with pruning over hindsight feedback -- is explicitly not a general solution; it helps precisely where the early-lock-in failure mode exists (popularity prediction) and does not generalize to a task without it (breakout-news detection), which is itself useful: it says the lever to pull depends on diagnosing which long-lived failure mode a given task is prone to before picking a mitigation, rather than applying one continuous-improvement recipe everywhere.

Interaction edge: unattended-operation's own entry this run, agents-fail-by-declaring-done-before-recovery-holds -- both sources land on the same underlying question from different angles: that one measures an agent failing by acting too fast (declaring recovery before it holds, hours-scale); this one measures agents failing by picking a timing policy once and never revisiting it (weeks-scale). Together they argue an unattended agent's relationship to time -- not just its relationship to task content -- is a harness property this map has under-measured relative to durable state and credentials.

Interaction edge: model-routing-token-economics -- the finding that LLM cost and average score are only weakly correlated across all model/harness configurations (-0.22 <= rho <= 0.09) is a direct, if small, data point against assuming spend buys long-horizon performance, consistent with that map's standing skepticism of cost as a quality proxy.

Scope: this is an evaluation study rather than a leaderboard (the authors explicitly decline to rank individual model x trigger cells), with 3-6 seeds and 1-3 episodes per task-configuration; a third continuous-harness-update method was abandoned in this setup because it needed a reflector model expensive enough to exhaust the budget early, which the paper reports as a limitation rather than a negative result.
