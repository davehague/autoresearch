The agent cannot clean up after itself — and this one is a search problem

The vault's most reliably replicated pattern is that an agent cannot audit its own output. It mis-reports completion, with 91.49% of visible misalignment resolutions requiring explicit user correction (users-correct-agents-in-nine-of-ten-resolutions). It rationalizes artifacts it generated when asked to verify them (separate-the-generator-from-the-evaluator, verifier-catch-and-false-alarm-rates-are-measurable). Its self-improving harness invents failures that never happened (harness-optimizers-fabricate-failures-to-fix) and is capped by its own judge (harness-self-evolution-is-capped-by-its-proxy-judge).

This adds a form that is neither judgment nor perception: the agent cannot perform a well-defined mechanical operation on its own artifact. Given the final patch, its own repair trajectory, or both, plus the same test suite and a generous budget, an agent removes a fraction of the redundancy a deterministic search removes — and in up to 44.9% of runs produces an invalid result, including reintroducing the bug it had just fixed. The information was present; the operation was not. The authors' framing is the durable part: patch minimization is fundamentally a search problem rather than a generation problem.

The design lesson is where to put the structure. The trajectory's temporal ordering approximates the dependency structure between edits, so dropping whole edit sequences first prunes the space before any reasoning about individual changes — which is why it matches exhaustive delta-debugging quality at roughly half the validation budget with a bounded worst case, the property that actually decides whether you can put it in a pipeline where one validation costs half an hour. The signal consumed is the trajectory's structure, not its content, so no model reads it: a cleaner instance of the principle that trajectory evidence can drive a control loop rather than merely diagnose (evolve-the-harness-from-trajectory-observability, audit-agent-claims-against-trajectory-evidence). It also belongs with restrict-the-tool-surface-to-cut-cost-not-capability as evidence that removal is an under-used class of harness edit.

Caveats: the agentic baseline is one minimization agent (mini-SWE-agent) driven mainly by Gemini-3-Flash with a smaller Sonnet 4.6 arm, so "agents can't do this" is measured on a narrow instantiation; the comparison is at fixed budget, and a much larger budget is untested. Requires a trustworthy oracle to re-run.
