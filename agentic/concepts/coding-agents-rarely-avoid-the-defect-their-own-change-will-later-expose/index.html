The defect an agent won't catch isn't hypothetical — it's the one a real later commit in the same repository ends up fixing, and across eleven models the agent avoids it at most a quarter of the time

This map's standing argument is that independence is a property of the checking arrangement, not the checker's identity, and that a self-report or self-review is exactly the channel a checker must be denied (self-report-leakage-gui-agent-completion-judging, self-asserted-pass-claims-fail-verification). Every one of those findings relies on either a controlled manipulation (show/withhold the self-report) or an author-constructed fault. Foresight-SWE grounds the same failure mode in uncontaminated real-world evidence: each of its 212 samples is a real pull request paired with a real second pull request, written later by real engineers, that fixes a defect the first one introduced — so the "bug the agent should have caught" is not a planted fault or an author's judgment call, it is whatever a project's own subsequent history confirms was actually wrong.

Scored against that ground truth, eleven LLMs' foresight resolve rate — completing the stated task and avoiding the defect the repository's own future confirms was there — tops out at 24.53% and runs as low as 6.13%. That is a tighter, less generous number than this map's completion-judgment findings tend to report, because nothing here depends on an LLM judge's fallibility or a self-report channel at all; the ground truth is a second commit that already happened. It is the sharpest available confirmation that the map's core claim generalizes past review and completion-judging into the generation step itself: an agent asked to do X is not reliably checking itself against "and don't introduce the thing a reasonable continuation of this codebase would need fixed," and no amount of asking it to try harder substitutes for a checker denied the agent's own blind spot.

It also sharpens unattended-operation's BOBA-Bench finding from the same week (boba-bench-coding-agent-chains) that chained requests fail roughly twice as often once they build on an undetected self-certified defect: Foresight-SWE is evidence for why that defect goes undetected in the first place — the agent that introduced it was never going to catch it on its own, because the defect's shape is exactly the kind of foreseeable-but-unstated consequence FRR measures agents missing.

Bounds. 212 samples is a modest benchmark for an 11-model comparison, and the PR pairs are mined from whichever real repositories happened to contain a later defect-fixing commit — not a systematic sample across defect types, so the benchmark's defect-class mix is whatever naturally occurred rather than designed coverage. No experiment isolates why models fail to anticipate (training objective, context window, absence of explicit lookahead incentive) — the paper names the gap and raises the training/alignment question rather than testing a specific cause.
