The map's core claim gets a name, a controller-theory frame, and its first purpose-built factorial

Every prior arrival on this map found the apparatus term by stumbling on it — a benchmark vendor's incidental grid, a single-author's post-incident audit, a root-cause framework study varying something else and noticing the harness moved the number too. This source is the first this map has seen that sets out, from the position-paper stage, to measure the ratio itself with a purpose-built factorial: three models × three harnesses, 100 tasks, and a variance decomposition reported directly as HV̄/MV̄. The 7.80× figure is not the map's largest single apparatus term in absolute points — the frozen- artifact and root-cause-analysis arrivals report 20–46 points and 37 points respectively — but it is the first source that expresses the term as a ratio to the thing it is usually compared against, which is exactly the quantity this map's disclosure argument has been assuming without measuring: that the apparatus is not merely large in absolute terms but large relative to model choice, the variable every leaderboard treats as the object of comparison.

The control-theoretic framing — harness as controller managing state transitions, model as open-loop policy conditioned only on what the controller constructs — gives this map's running argument ("the apparatus is a term of the order of the effect being reported") a mechanism rather than only a measurement. It also supplies three new trajectory-level diagnostics (Recovery Rate, Context Retention, Control Lag) that operationalize why a harness swap moves a score, where this map's prior arrivals have mostly reported that it does.

The ETCSOVG disclosure standard directly answers this map's own open question — "What does a harness card have to contain to be sufficient?" — with the most comprehensive proposed schema this map has seen: seven layers (Execution, Tool, Context, Scheduling, Observability, Verification, Governance) against the prior best of a 5-field schema (harness-as-score-confound, 2026-07-13) and an ad hoc backend-name/version/config list. It does not resolve the open question's own caveat — "nothing establishes that any of these lists is complete," and the 2026-07-28 wrapper-level output-cap incident this map already carries is exactly the kind of failure a seven-layer checklist could still miss if nobody thinks to name that specific layer. But it is the strongest candidate answer on offer, and worth flagging against the next disclosure-audit arrival this map ingests.

Interaction note: the same night this map received this source, agent-harness-architecture received an independent source-code taxonomy of eleven harnesses converging on seven canonical subsystems (agent loop, LLM integration, tools & actions, memory & context, safety & permissions, orchestration, extensibility) — a structurally different seven-way decomposition, arrived at by reading source code rather than by designing a disclosure schema, with partial but not exact correspondence to ETCSOVG's seven layers (both name a tools layer, a context/memory layer, a safety/governance layer; neither names the other's loop-vs-scheduling split the same way). Two independent efforts landing on "seven layers" is worth watching as its own pattern rather than treating as coincidence, but is not itself evidence either taxonomy is complete.

Bounds

Scope is explicitly long-horizon, multi-step tasks with error recovery among comparable frontier models; "comparable" is informally anchored to harness-confounded leaderboard proximity, which the authors flag as circular — a non-confounded comparability test is proposed but not run. No principled harness-distance metric exists, so the reported HV̄ depends on an unstandardized sampling distribution over the three chosen harness configurations; a different choice of three harnesses could report a different ratio. The paper is explicit that it does not resolve whether disclosure alone prevents adversarial harness selection (cherry-picking the harness that flatters a given model) or whether the field needs locked harnesses instead — left as unresolved, which matters because this map's own standing remedy is disclosure, and this source neither confirms nor undercuts that remedy's sufficiency, only its comprehensiveness. The planned perturbation stress-test (Appendix C) is unexecuted; Schema Compliance Rate and Action Efficiency are named but not measured.
