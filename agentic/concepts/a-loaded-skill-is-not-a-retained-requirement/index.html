High coverage, failed artifact

Hold a code-audit task, its starting artifact, its tools and a frozen 24-check verifier constant; vary only the surrounding context. Strict pass rate goes 8/10 → 3/10 in both a long same-workflow context and an equal-length unrelated archive. But requirement coverage barely moves — 98.8% clean, 92.1% and 93.8% long — and a separate historical inventory passes 97.98% of individual checks across 44 failed trajectories.

That gap is the finding, and it is more useful than the headline. The agent has not forgotten the skill. It retains and satisfies almost every stated obligation, and then omits one required array — turning 23/24 into a failed audit artifact. So the natural metric ("did the instructions survive?") is nearly always yes and nearly useless; what an audit needs is the strict conjunction, and that is what long context degrades. The most severe observed run is the same shape at larger scale: it completes the first two of four tasks in full, leaves the other two missing five components each, passes 14/24, and terminates normally.

What decays, then, is not the instruction set but the active worklist — which is compaction-selection-is-all-or-nothing's block-selection behaviour showing up in task state instead of facts, and the state-not-steps thesis (long-horizon-failure-is-state-not-steps) localized to a specific casualty. It rhymes precisely with instructions-fail-to-govern-non-functional-requirements: presence in context is not compliance. Here the requirement is scored, the agent does hold it, and it still drops out of the plan.

Two negative results are worth carrying because they close off intuitive explanations. Semantic relevance does not order the two long conditions — 3/10 both, Fisher p = 1.0, and the deepest single failure is in the unrelated archive — so same-domain competing material is not reliably worse than generic length, and length, structure, active-task count and prior state remain entangled. And 86.4% of failed runs close with an explicit success or completion message, which is audit-agent-claims-against-trajectory-evidence with a third number behind it.

The mitigation is a separate note and it is the reason to keep this one: restate-the-checks-externally-at-completion takes the same long-context condition from 5/10 to 10/10.

Caveats: T3, single independent researcher, n = 10 per cell, and the main effect does not clear its own α (p = 0.0698) with wide Wilson intervals. The extension from five to ten runs followed inspection of the five-run estimates, so this is explicitly not preregistered — and the irrelevant-long cell moved 0/5 → 3/10 on extension, which the author reports as evidence that small agent samples produce unstable headlines. A second task passes every condition, so there is no universal length threshold here. One primary model–task pair (gpt-5.4-mini under Codex). Character-matched contexts do not equalize tokens or structure. Carried for the coverage-versus-strict-pass distinction, not the 50-point effect.
