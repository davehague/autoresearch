Withhold the rule first, then find out whether the rule did anything

The paper's opening sentence is the finding: when a coding agent obeys a rule, it may simply have been going to do that anyway. Every instruction-following number this vault has read — every "the agent followed 84% of the policy" — has been a mixture of two quantities, obedience and coincidence, with no way to separate them. Harness-IF separates them by the only method that works: re-run the task with the rule withheld and keep only the rules the agent then violates.

Why the correction cannot be waved off as a level shift. If the inflation were a constant, it would cancel in every comparison anyone actually cares about and the raw number would still rank builds correctly. It is not: the gap runs 3.6 to 7.4 points and varies about twofold across the cohort, so the correction is a model-specific discount. Applying it exchanges three adjacent rank pairs. The build at the top survives — which is the useful, deflationary version of the result. The instrument resolves the prior-alignment contrast model by model (every paired interval positive) while leaving every adjacent build comparison unresolved, so it is more trustworthy as a statement about the metric than as a leaderboard.

This is the same disease as a benchmark whose reference solution the agent already agrees with. reliability-and-capability-rankings-diverge and one-run-scores-an-implementation-not-an-idea both say a headline number is answering a narrower question than its label; this names the specific confound for the instruction layer, and supplies the control that removes it. It also gives a sharper reading of the-agents-final-report-is-its-least-reliable-artifact: an agent that reports policy compliance while violating the sections it names is not necessarily lying about effort — on the prior-aligned majority of rules it genuinely did comply, without the rule ever mattering.

What David's fleet should take from it. Any CLAUDE.md or skill rule that codifies what the model already does is invisible in production and free in evaluation — it inflates a sense of governance without buying any. The rules worth auditing are the ones that cut against the default, and the cheap audit is exactly the paper's probe: run the task once with the rule deleted. If nothing changes, the rule is not load-bearing and belongs in the pruning pile an-agentic-context-file-grows-until-someone-bulldozes-it says nobody ever gets to. That reframes the deletion problem — the O(2^n) counterfactual audit deletion-hazard-falls-because-the-rationale-decayed prices is unaffordable in general, but a single zero-injection probe per suspect rule is O(1) and answers the narrower question that matters.

Bounds. AP-Acc is a behavioral stratification over observed or curated defaults, not a claim about a model's internal priors, and fewer than half the AP-Acc denominator carries recoverable zero-injection evidence — the remainder is curated, plus 1,824 verdicts (9.4%) of unknown lineage. One benchmark, one rule library, 12 builds; the direction is uniform and the magnitudes are not settled.
