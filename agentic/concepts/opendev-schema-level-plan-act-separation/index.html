A schema-level fix for a failure mode this map has never seen named: a planning state machine that gets stuck, and removing the write affordance from the schema rather than gating it by prompt closes it by construction

This map's hand-engineered-design-levers strand holds several measured harness levers (context management, tool-set design, planning). This source is weaker evidence by construction — a single-author systems report with zero benchmark numbers — but it names a concrete failure mode none of this map's measured sources describe: a four-tool state machine for plan/act separation that the author reports would sometimes get stuck in planning mode, unable to transition to execution. The fix is architecturally specific and worth recording even absent a benchmark: move the plan/act boundary from a prompt-level permission check (the model is told not to write during planning) to a schema-level tool-set restriction (the write tools are not present in the Planner subagent's schema at all, so there is nothing to be talked into calling). This is the same shape as this map's existing bash-vs-typed-tools and MCP-annotation findings — where an affordance lives (in the schema an agent reads, versus in an instruction an agent is expected to obey) changes what failure modes are structurally possible, not just how the model chooses to behave inside them.

Two secondary design choices corroborate rather than extend already-measured claims: the five-stage staged-escalation compaction pipeline (cheap local operations before expensive LLM summarization) matches the cost-shape this map's context-management-value-shrinks-as-budget-grows source found empirically effective, arrived at independently here as an engineering convention rather than derived from that evidence — a second, unrelated team converging on the same staging idea. The persisted "playbook" memory layer is a design pattern this map has not previously named as a distinct object from episodic/working memory; whether it earns its keep is untested here.

Read this as a design-pattern catalogue to cross-check against measured evidence, not as evidence on its own — the source ships zero comparative numbers, and the author states that scope choice explicitly rather than treating it as an omission.
