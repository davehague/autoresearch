On a weak enough answerer, every memory architecture scores the same — so a memory benchmark measures the pair, not the design

This vault keeps rediscovering that a component's measured value belongs to the configuration it sits in. the-loop-implementation-is-a-larger-term-than-the-model-tier, the-inference-backend-is-a-term-in-the-score, the-review-framework-is-a-term-in-the-detection-rate, robustness-ranks-differently-under-every-scaffold — and, closest of all, a-skill-set-helps-the-weaker-harness-and-hurts-the-stronger. This is the same phenomenon in the memory layer, and it is worth recording because memory-system leaderboards are published as though the number belonged to the system.

The measurement. Among methods that produce plausible answers at all, on Qwen-3.5-9B the drift rate is 60.9–65.5% for everything: holding the entire transcript, Mem0, BM25 retrieval, and an explicit state tracker. Four architectures spanning no-memory-at-all to a dependency-graph state store, indistinguishable. Move to DeepSeek-V4-Flash and only the state tracker moves — down 15 points, with 42 more correct answers — while the baselines shift by 1–3 points and 0–9 answers. The authors' reading: a capable answerer converts would-be drifts into gold once the state representation makes the operative value explicit, and where the answerer cannot do that conversion, the memory layer's gain comes mainly from turning non-answers into answers rather than from resisting the trap.

The corollary for the baselines is the more interesting half. Long-context, Mem0 and BM25 barely move between backbones, which says their bottleneck is the memory layer and not the answerer. So the same benchmark separates two distinct limits, and which limit binds depends on which model you plugged in.

The methodological trap this source builds an instrument for. A naive drift rate rewards a system for being useless. LightMem and MemoryOS post the lowest drift rates in the table — 32.0% and 14.9% — because they land off-pool on 60–94% of cells: they rarely produce a recognisable answer at all, so they rarely produce the wrong recognisable one. The closed-pool design catches this by reporting in-pool engagement alongside drift rate, and it is the reason the state tracker's numbers are credible: it has the fewest off-pool answers on both substrates, so its accuracy is not abstention in disguise. This is the memory-layer instance of price-the-checkers-abstention-as-lost-coverage and report-current-correctness-not-only-ever-correct — any error-rate metric needs its denominator's engagement reported beside it, or a system that declines to play wins.

One mode looks like a model property rather than a design one. On salience errors — where nothing was superseded but a louder competitor wins — every Qwen arm scores ≤0.18 against 0.569 for GPT-5.4-Nano. No memory design in the table recovers it on the weak substrate. If that holds, salience resistance is bought with the answerer and status/sequence resistance is bought with the representation, which would be a genuinely useful split for anyone deciding where to spend.

What to do with it. Two things. When choosing a memory system, evaluate it on the model you will actually serve, because the ranking on a cheaper backbone may be flat. And when reading a memory-system result, ask which backbone produced the separation — a design validated only on the strong model has not been shown to help the cheap deployment, which is usually the one the memory system was supposed to make viable.

Bounds. Two backbones, both small-to-mid-scale for cost reasons, so "capable answerer" here means DeepSeek-V4-Flash and not a frontier model — behaviour above this range is untested and the authors say so. Single run per configuration at temperature 0. The benchmark is synthetic, its scenarios are well short of a modern context window, and the state tracker mirrors the policy family behind the traps, so its margins are an upper bound. The cross-backbone comparison is descriptive: no formal interaction test is reported for the drift-rate difference, which is why this is graded suggestive rather than strong despite the T1 tier.
