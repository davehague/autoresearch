Selected context cuts trajectory tokens at equal localization

The map's fifth clause is re-derive state from its source rather than carrying your reading of it (re-derive-file-state-instead-of-storing-snapshots), argued so far at the level of a single file — a registry plus a deterministic re-read before each reasoning cycle. This is the same argument built as infrastructure: the repository becomes a versioned store with per-commit lexical, dense and structural views, every answer carries a repository-relative source address the agent can re-resolve, and nothing is pinned into the trajectory except that address.

Two design choices are worth more than the headline number. The compaction step is deterministic — a one-time history rewrite with no summarization model in the path — which sidesteps the failure the map measured directly: across 246 summaries, no summary ever carried a strict subset of the planted facts, and the first boundary dropped everything (compaction-selection-is-all-or-nothing). And the token claim is stated conditional on preserving localization, so it is a genuine efficiency result rather than a quality trade dressed as one — the form goal-hinted-pruning-beats-generic-compression and prune-and-summarize-beats-full-history argued for and this measures across five models.

It also answers, architecturally, the acquisition-stage problem the map opened on 2026-07-29: real agents miss every required file on 27–35% of tasks and no retrieval family dominates (context-acquisition-is-an-unmeasured-failure-surface, no-retrieval-family-wins-across-agentic-relevance-types). The response here is not a better ranker but keeping all three families materialized and addressable, with a dense–graph fusion modestly improving file-success coverage — the same conclusion Agent Retrieval Bench reached from the measurement side a week earlier. Two groups, independently, arriving at multi-view rather than best-view.

The honest limit: this measures localization and interaction, not repair. There is no resolve-rate or pass@1 arm anywhere in the paper, so nothing here shows that cheaper, better-localized context fixes more bugs — the same downstream gap Agent Retrieval Bench left open, and the reason this is carried as an efficiency finding rather than a capability one. Other caveats: five models, only one from a frontier family (whose compact arm was backfilled rather than run concurrently); the static index does not match a live language server on 37% of navigation requests, so this supplements rather than replaces a semantic path.
