Shared context wins when it is verified, compact, and unrouted

DeLM coordinates a decentralized fleet through a shared context — and wins on SWE-bench Verified (65.7% vs 56.4% for the strongest multi-agent baseline, at half the cost per task). Taken at the headline, that pushes back on event-passing-beats-shared-context-in-agent-fleets: here is a shared-context system beating everything on exactly the task class where shared context was the suspected tax.

But DeLM's shared context is nothing like the pools in the Google scaling sweep. Three properties differ: (1) admission-time verification — only verified claims enter, and the ablation shows this is the load-bearing part (−4.9 points without it; "unsupported claims can corrupt downstream reasoning when they enter the shared context unchecked"); (2) compactness — ~100-token gists, with raw content unfolded on demand, never full transcripts; (3) no serializing router — agents write and read directly, where centralized designs force "every useful finding… back to the main agent," which dilutes, distorts, and drops discoveries (the paper documents a sub-agent's hard constraint getting "softened into a tradeoff" in the router's rewrite).

So the substrate hypothesis sharpens rather than flips. The reconciliation that covers all three T1s: the sweep's topologies share raw, unvalidated context through a serializing controller and degrade; icat-agent passes small validated messages and wins; DeLM shares small validated gists and wins. The variable is not shared-vs-private — it is unit size × validation × routing. icat-agent's events and DeLM's gists are near-duals, which predicts the decisive experiment's result: an event-passing arm and a verified-gist arm should perform similarly, and both should beat the raw shared pool. That also reframes the 17.2×-vs-4.4× error-amplification result — the orchestrator's value was never scheduling, it was validation (agentic-code-review's "never accept an agent's 'done'", applied at every fleet write), and validation can be decentralized to the admission gate instead of centralized in a router.

Rebutted by: pre-write-admission-buys-reliability-by-serializing — not on the numbers but on what admission-time validation is worth: with a serial reference arm in the design, deterministic admission recovered the serial score and no throughput, by serializing 96.7% of executions. Holds the mechanism, contests the value claim.

Caveats: SWE-bench Verified with no reported egress/.git constraint — benchmark-scores-inflate-when-agents-can-retrieve-the-fix applies to absolute numbers, less to the same-model relative comparison. Verification overhead acknowledged, not priced. One lab, unreplicated.
