Independence as a channel property: it is not what the checker knows, it is what the checker is allowed to say

Every design in this map so far engineers independence by controlling information — withhold the issue text, withhold the exploration trace, freeze the referent, watch what the checker just finished doing. This one holds information constant and changes the communication channel, and it moves the outcome by more than most information interventions in the vault.

The starting state is a genuine failure: a reviewer and a critic exchanging free-text review over a frozen artifact converge on agreement without evidence, and score below a single reviewer (two-agents-told-to-agree-will-agree). The repair is one prompt, and its shape is the finding. The critic's verdict space goes from two options to three:

  • AGREE — accept the review as written.
  • DISAGREE_EVIDENCE: <code citation> — cite specific code that contradicts a flag.
  • DISAGREE_CONCERN: <epistemic objection> — raise an objection that cannot point at contradicting code.

And the reviewer's response rule is bound to which it received: on AGREE, keep every flag unchanged; on DISAGREE_EVIDENCE, revise against the cited code; on DISAGREE_CONCERN, cite code in the diff that confirms the bug and keep the flag, or cite code that refutes it and drop the flag. Same three agents, same model, same graph, same token budget shape. F1 goes from lowest of four to highest of four.

Two mechanisms are doing the work and they are worth separating. First, the third verdict makes the quality of a disagreement explicit: an objection that cannot cite code is admitted as a legitimate move but labelled as unevidenced, so it can no longer masquerade as a refutation. Previously the critic's only ways to express doubt were "DISAGREE" (which invited a confident rebuttal) or "AGREE" (which dropped it). Second, the reviewer can no longer end a disagreement by sounding certain — the response rule demands a citation in every branch, so a file-level argument citing nothing is not an available move. That closes the exact failure the traces recorded, where a real bug died to a confident rebuttal with no code in it.

The generalizable statement, in the authors' own framing, is the one this map should adopt: multi-agent oversight should not be judged by whether the agents converge, but by whether the path to convergence preserved dissent, evidence and accountability. Typing the disagreement is what turns that path into an auditable object. It is the cheapest instance in this vault of independence bought at the protocol layer rather than the model layer — no second vendor, no second family, no extra agent — and it sits alongside the-referent-not-the-reviewer-carries-the-separation as evidence that the arrangement is a bigger lever than the identity of the checker.

Two limits the authors state and this map should hold them to. The fix rests entirely on instruction-following, which they flag as degrading as the context window fills — so a typed-disagreement protocol is exactly the kind of control that works in a short review exchange and may quietly stop working in a long one, with no signal that it has. And the protocol fixes the evidence axis and not the scope axis: the same loop still turns a speculative reviewer question into an out-of-scope edit that fails the tests, because nothing forces the critic to reject a concern as out of scope the way it now forces it to ground one in code. The authors name scope discipline as the next constraint to encode, which reads as a prediction this map can check.

Bounds. One model family across every agent and benchmark, so protocol and model are not separated. One prompt iteration, stopped deliberately at the first success to keep the protocol minimal — so this is a single measured point, not a characterised design space. The endpoint is an LLM judge matching against human PR comments, with the usual risk of penalising valid comments that differ from the human's. Claims are empirical, not formal.
