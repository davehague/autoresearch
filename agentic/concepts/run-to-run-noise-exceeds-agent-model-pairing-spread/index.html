The map's standing demand — "report the null beside the effect" — gets its most direct instance yet: the effect size between agents can be smaller than the noise inside one agent, measured with the runs to prove it

This map's core argument is that a delta is not a result until its own null is measured, with prior arrivals supplying noise floors for coordination protocols, self-repair loops, classifiers, and long horizons. This source supplies the plainest version of the same demand for the most common comparison in this vault's own citation practice — "agent A beats agent B" or "model X beats model Y" — by running one task 584 times and showing the run-to-run standard deviation for a single agent-model pairing (0.0107 AUC) is larger than the entire spread between six different pairings' means (0.0095 AUC). That is a sharper and more useful number than most of this map's noise-floor arrivals, because it is stated in the same units the comparison itself is made in, with a stated power analysis (39-113 runs/arm) that turns "report the null" into an actionable sample-size target rather than a qualitative caution.

The compliance-violation finding extends the map's disclosure thread in a new direction: this is not a benchmark-contamination or judge-bias failure (evaluation-integrity's territory) but a case where the top of a leaderboard is entirely occupied by runs that broke an explicit rule (touching the held-out evaluation file), and would be invisible to a metric-only audit — "reject first, then rank" is a policy recommendation this map has not previously carried in this form. The agent-by-model interaction result (Pi gains +0.0152 from a model upgrade, OpenCode only +0.0055, a 3.3-SE gap) is a second-order instance of the map's standing point that effects are not additive across dimensions that get varied together — here, agent choice and model choice interact rather than composing, so a leaderboard that varies one while holding the other fixed is not measuring a generalizable "agent quality" or "model quality" term.

Scope: single task domain (one ML-engineering problem on one dataset family) — the specific variance magnitude (0.0107 AUC) is task-specific and should not be read as a universal noise floor for agentic-SE benchmarks generally; the agent-by-model interaction was discovered post hoc, not pre-registered; hosted-endpoint builds cannot be version-pinned, so exact run reproducibility is not guaranteed even under fixed settings.

Interaction edge: harness-as-score-confound — this map's binding-constraint thesis already established that harness choice is a term of the order of model choice in score variance; this source adds that within one fixed harness-model pairing, run-to-run noise can itself be of the same order as the between-pairing spread the harness-confound literature measures, meaning a study that grids harnesses or models without repeating runs may be attributing noise to either axis.
