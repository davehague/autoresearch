Turn the answer key into the hidden world

Most of this map's material is about instruments that cannot be trusted — benchmarks-conflate-model-harness-and-penalize-alternatives, llm-judges-have-exploitable-biases, online-judge-verdicts-are-an-unaudited-ground-truth, fix-the-eval-before-trusting-the-score. This is the rarer kind of entry: a construction that makes something previously unmeasurable measurable, and the construction is cheap enough to reuse.

The problem it solves is general. If you want to score a maintenance regime — a compaction policy, a memory eviction rule, a prompt-pruning agent — you need both axes. Correctness alone rewards hoarding; size alone rewards deletion. Scoring "excess" requires knowing the minimum sufficient artifact, and that is incomputable in general because redundancy defeats one-at-a-time probing (an honest audit is O(2^n) subset probes).

The inversion supplies it for free from a benchmark that already exists:

  1. Hide the item's stated instructions. They become the reference minimum cover D*, so |D*| is known before the experiment runs and excess size is a ratio, not an estimate.
  2. Keep the verifiers as the world's hidden constraint set — run by the harness, never named to the agent under test. The agent sees only censored pass/fail draws, which is the real maintenance situation.
  3. Generate a lossy objective ("draft a product announcement") from the hidden instructions with a stronger model, so the agent has a task but not the answer.

What makes it a measurement rather than a demo is that the split is enforced mechanically: the harness strips the annotation channel before the prompt reaches the executor and rejects any instruction that cites a past failure, so the treatment arm's executor input is strictly smaller. Without that enforcement the arms would differ in prompt content and the size axis would be uninterpretable — the same class of leak enforce-the-evaluation-boundary-in-the-environment-not-the-prompt warns about, closed the same way.

Two design details worth stealing. The placebo arm (comment-shaped noise) is what licenses reading the treatment as content rather than ceremony, and it is exactly the arm a-retry-study-needs-a-placebo-arm says this literature keeps omitting. And on the prose half where verifiers do not exist, every rate is a rate under one LLM judge, so all 6,336 verdicts were re-scored under a second — reporting reproduction and agreement rather than accuracy, since neither judge is ground truth. That is the honest form of validate-the-judge-before-you-trust-the-migration.

Bounds. The construction inherits whatever is wrong with the source benchmark's verifiers, and IFEval's constraints are mechanically checkable English of a narrow kind. The known-optimum property holds only because the hidden instructions were authored as sufficient, which is a stronger assumption than a real task's constraint set satisfies. |D*| = 2.2 is very small against a real context file's median 39, so the worlds are structurally easier than the setting they stand in for. And the transform prices what excess costs inside a seeded prompt; it cannot say whether an unbounded-growth process persists under the intervention at realistic scale.
