The continuity-bearing substrate this map has been asking about has a first controlled measurement, and it names which representation actually survives

This map's article carries an open item: a continuity-bearing substrate survives model, harness, and host swaps individually, but the combined-axis case — and specifically what happens to memory content itself across a model swap — remained untested. This source is a direct, controlled answer for the model-swap axis alone: representation choice is not a detail, it decides whether a model upgrade quietly degrades what an agent remembers. A fixed schema constrains what gets written to a small, model-agnostic vocabulary the next model can parse the same way; free-text notes let the writing model's own compression habits leak into storage, so a "summary" is actually partly a fingerprint of the model that wrote it.

The repair-asymmetry result is the operationally sharper half: whether a corrupted memory can be fixed after the fact depends entirely on whether the raw source was kept alongside the derived representation. A store that discards raw history to save space cannot be repaired past a ceiling regardless of how much repair effort is spent on the notes themselves (0/48 vs. 34/48). For any scheduled agent that persists memory across model version bumps, this converts "keep the raw transcript" from a storage-cost decision into a repairability decision.

Bounds: one cross-family model pair (Llama/Qwen), both similarly-sized and open-weight — untested whether the asymmetry holds for same-family upgrades (e.g., Sonnet 4→5) or much larger capability gaps; scripted rather than natural conversations; synthetic workloads with definitive numeric-style answers rather than open-ended memory use. The combined-axis question (model swap and harness swap and host swap together) this map's article names is still unrun — this closes one axis, not all three.
