External Effect Gate Closes The Sibling Leak With Formal Verification

Because the failure the paper measures lives in each framework's own control flow — its scheduler is the thing that races — the paper argues the repair must live outside every framework's control flow rather than patch each one internally. SoundGate is a small, dependency-light Rust admission core sitting at the tool-invocation boundary: every side effect submits for admission before it is performed, and externalizes only on release. It enforces four properties as an execution monitor in the classical reference-monitor tradition (complete mediation): hold-until-decided (an approval-gated effect is never released until a decision is recorded), reject-cancels (a rejected effect stays refused, even on resubmission), dedup-on-replay (an identity released once is unaffected by later resubmission — closes replay double-execution), and fence-on-cancel (a cancelled run's later effects are refused even from a zombie thread — closes cancellation orphaning and timeout zombies).

Verification is unusually deep for a single-author artifact: a Verus model of the sequential admission core proves all four properties with zero errors; TLA+/TLC model-checks every interleaving of the concurrent submit/decide/cancel/close protocol exhaustively up to a 74,805,201-state space (from 4.2×10⁹ generated candidates); TLAPS proves the safety invariant inductively (68/68 obligations, holding at unbounded scale); Loom exhaustively checks the actual deployed concurrent Rust under the C11 memory model; and a differential conformance harness drives the abstract model and the deployed binary through 1.2×10⁷ operations across 2×10⁵ randomized traces with zero divergences, closing the model-to-code gap the proofs alone don't cover. This isn't decoration — the process caught two real defects during development (a double-release bug and a late-rejection-after-release bug), both fixed and now encoded as regression tests.

Empirically, the repair is demonstrated end-to-end on all six frameworks, closing every violated axis each ships: on live models it takes the sibling-leak rate from 215/1,200 unmediated to 0/1,200 mediated (Wilson upper bound 1.3% per arm) across four models and three runtimes (two Python, one Node), and the same real webhook demo that lands a POST 512ms before rejection returns refused_rejected with zero POSTs when routed through the gate. Structural, kernel-enforced routes (loopback-only network namespaces; cgroup eBPF egress hooks) additionally close the "forgotten wrapper" bypass case for network egress specifically, converting a silent leak into a loud EPERM/ENETUNREACH failure rather than requiring wrapper discipline alone. Cost is modest: a median 1.1ms round-trip per gated write (max 3.3ms) against real τ-bench-gated episodes with zero fail-closed refusals of legitimate effects, and total episode latency statistically unchanged (37.9s vs 37.3s over 20 episodes — the paper flags this as a first signal, not a precise parity claim). The durable, group-committed (write-ahead-log) mode sustains roughly 12,000-26,000 admissions per second on a single reference workstation.

Caveats: complete mediation is a stated assumption, not a proven guarantee — an unwrapped tool bypasses the gate at the wrapper layer, and only the network-egress channel is closed structurally at the kernel level in the paper's demonstrations; filesystem, local IPC, and shared-memory channels need an additional seccomp/Landlock policy the paper shows works but doesn't universally apply. Effects are modeled at a single commit point, so multi-phase external actions (authorize-then-capture) get no cross-phase atomicity from the gate itself. Availability/scale testing is single-node; a replicated Raft deployment demo shows failover in ~1.9s but the consensus layer around the verified gate is "operational, not verified." Single author, unreviewed arXiv preprint, released four days before ingestion.
