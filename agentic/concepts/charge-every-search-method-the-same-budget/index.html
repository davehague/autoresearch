Charge every search method the same budget, and score it off-distribution

A method that repeatedly generates, evaluates and revises candidates is spending inference to buy performance. So is best-of-n. Comparing the first against a single-shot baseline and attributing the difference to the method is a category error, and it is the default in the harness-evolution literature. Two practices produce it: searching with unit tests and then reporting on the same task set, and giving the proposed method a search budget the baseline never receives. Correct both and, in the one controlled test run so far, the advantage disappears entirely — the evolved harness scores below an equal-budget parallel-sampling arm and transfers +0.6 points to held-out tasks.

The protocol this implies is three lines long and applies well beyond harnesses — to self-improving agents, prompt optimizers, agentic search, any loop whose cost scales with iterations: (1) the optimization task set and the evaluation task set must be disjoint; (2) every arm gets the same feedback signal and the same inference budget; (3) the reported number is the held-out one.

This is evaluation-integrity's thesis applied to a method rather than a model, and it completes a set. agent-benchmarks-underdisclose-their-harness found under-specification explains score spread; coordination-deltas-need-a-measured-noise-floor found noise explains much of the paired delta; this finds unmatched budget explains the rest of a whole research direction's headline. The same relationship holds as with harness-self-evolution-is-capped-by-its-proxy-judge: when the misgrading proxy is what selects an agent's own improvements, the error compounds instead of merely misleading — here the misgrading is in the comparison that justified running the loop at all. Pairs naturally with measure-whether-evidence-reconstructs-the-claim: the budget table is part of the evidence that licenses the claim.

Caveat: derived from a single paper's controlled study on one benchmark. Carry the protocol as the durable content; the specific magnitudes are one benchmark's.
