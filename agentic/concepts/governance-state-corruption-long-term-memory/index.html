Retrieval accuracy and use-validity are different properties, and this map has only been measuring the first one

context-retrieval-and-acquisition frames its whole territory as a pipeline question: what reaches the model's window, and how it got chosen. Every prior source on this map answers some version of "was the right content found" — recall at scale, exact-file selection versus compression, preselection before execution. This source asks a question the pipeline framing had not yet separated out: once the right content is found, is it still valid to use? The authors' own vocabulary — a data plane (stored content) separate from a control plane (lifecycle/validity state: current, superseded, deleted, temporally updated) — names exactly the distinction this map's retrieval-accuracy metrics cannot see, because they all operate on the data plane.

The result is a clean causal demonstration rather than an inference from a downstream score. Holding the task, the stored evidence, the oracle, and the model fixed, and varying only whether the control-plane state is clean, corrupted, or oracle-restored, corruption changes which records are admitted into context in 96.25% of matched pairs, and restoration recovers the correct admission every time it was checked. That is this map's acquisition pipeline's "serving" stage, isolated as an independent failure surface for the first time — a perfect retriever handing the model stale, deleted, or superseded content because nothing downstream checked whether the record it found was still current.

The downstream numbers (40.54 points of LongMemEval correctness, 30.60 of Memora FAMA) are where this source is most honest about its own limits, and that honesty is itself worth carrying: the authors explicitly separate their native-metric-validated 298-triplet panel from a larger, full-cohort frozen- scorer measurement they call "descriptive proxies, not validated native semantic population effects" — naming the exact gap between an instrument's internal agreement and a validated behavioral claim that this vault's evidence model asks every source to clear, and rarely sees named so precisely by the authors themselves.

Bounds: all four authors are independent researchers with no institutional affiliation and no disclosed funding; the paper is not yet peer-reviewed. The full six-provider frozen-scorer effects are proxies by the authors' own statement; only the smaller 298-triplet panel carries native-metric validation, and agreement between the frozen proxy and independently-evaluated native decisions on a same-unit LongMemEval check is only κ=0.259 — weak enough that this map should treat the headline magnitude as directionally right rather than precisely measured. Deletion as a fault type occurs only in the Memora benchmark; small provider-source cells (DeepSeek-Memora, Grok-Memora) have damage intervals covering zero. Causal claims hold for paired governance interventions with everything else fixed, not for deployed fault prevalence in a real fleet.
