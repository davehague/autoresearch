The apparatus term reaches the input artifact: the same document is worth different amounts depending on who reads it

This map's catalogue of where the apparatus term hides now runs from the scaffold to the container to the transport parser to the inference backend to the fine-tuning weights. Every one of those is something around the model. This arrival puts the term somewhere new: in the artifact the practitioner authored and expects to reuse.

The setting is deliberately mechanical — Oracle PL/SQL to PostgreSQL, with a reference implementation to score against — precisely so that "the specification contains the knowledge" is not in doubt. The knowledge is the same. What changes is who reads it, and one cell of the transfer matrix falls out of the bottom: Gemini consuming Kiro's specification lands at Token F1 0.035 and SQL syntax validity 2.33%, against 0.73 and 45.5% on its own. The authors found the first run anomalous enough to rerun it independently, and the rerun reproduced the qualitative collapse.

The structural finding is the asymmetry, not the collapse. C(Kiro→Gemini) ≠ C(Gemini→Kiro): the reverse direction improves — Kiro reading Gemini's specification beats Kiro reading its own on Token F1 and AST similarity. And a third agent, Copilot, reads the same Kiro specification with no meaningful loss at all. So the phenomenon is not "foreign specifications are worse", a claim the paper refutes in the same table that establishes the effect. It is that the pair (document, consumer) is the unit, which is exactly the pair thesis this map inherited from the-harness-shifts-benchmark-rank-order and install-time-security-is-a-harness-model-pair-property — arriving here at a layer nobody had checked.

The rewrite experiment is the mechanism test, and it is clean. Asking the consuming agent to restate the foreign specification in its own idiom before generating recovers Gemini almost entirely (0.035 → 0.68 Token F1, 2.33% → 43.62% SQL validity) while the knowledge source is unchanged — only the representation was transformed. That isolates representational compatibility from missing information as the failure channel. The same rewrite does little for Copilot, which is the map's usual finding restated: the remedy is a pair property too.

And size predicts nothing. Kiro's specification is roughly eight times longer than Gemini's (1,597 lines against 193) and does not consistently produce better code. This is the third independent route to the same conclusion this atlas has recorded — the-specs-format-is-not-what-pays found notation null, a-specification-buys-executability-not-agreement found completeness bought executability and not agreement, and now length is null too. What is left, on this source's account, is the decomposition it proposes: a specification is ⟨knowledge, representation, dependency structure, granularity⟩, and knowledge preservation does not imply operational interpretation preservation.

The practical read for a multi-agent workflow is the paper's own: a specification that worked for one agent is not automatically suitable for another, so agent substitution is a change that needs re-validation and not a swap. Of the three ingestion strategies tested, retrieval-was-the-only-ingestion-on-both-pareto-frontiers records the one that behaved most consistently.

Related: a-post-training-gain-is-scored-in-the-harness-it-was-tuned-in and fine-tuning-installs-the-training-scaffolds-conventions for the map's other cases of an artifact carrying its origin's conventions; declare-what-each-step-reads-and-writes for the constructive alternative — a representation whose dependencies are explicit rather than idiomatic.

Bounds — this is the weakest-instrumented source on this map and should be read as an existence proof. One task family (a mechanical migration with a reference implementation), so nothing establishes the effect on open-ended feature work. No inferential statistics at all — no intervals, no significance tests, and the only repeated configuration disagreed with itself by a factor of twenty on Token F1 (0.68 vs 0.035) while agreeing qualitatively, which is itself a variance signal the paper does not quantify. The transfer matrix is incomplete: every Copilot-origin specification consumed by another agent is unevaluated, so the asymmetry claim rests on one reciprocal pair. The Kiro/Kiro row in the cross-agent table (0.365) disagrees with the tuned baseline table (0.56) without reconciliation. Most importantly, runnability is near-zero throughout the cross-agent stage (0–2.38%) — the metric closest to a working outcome barely discriminates, so nearly all of the reported separation lives in lexical and structural proxies. Agent versions are not pinned.
