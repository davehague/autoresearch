Half the attempts never produced an artifact, and only one condition bore it

This map catalogues proxies that misgrade agents. Here is a bookkeeping failure upstream of any proxy: about half the attempts in a controlled study produced nothing to grade, and the losses were not spread evenly. 29 valid runs against 28 exclusions — seven process-start failures, fourteen first-token stream disconnects, four host terminations, two resultless starts, one null-usage record — with 20 of the 28 concentrated in one experimental condition.

The author's handling is the practice to copy: define a valid run as one with a completed result record, non-null usage, and verifier output (a verifier FAIL is a valid outcome), exclude the rest from the model-success denominator, and retain them in a separate operational denominator with a per-cause audit. Pooling them would have inflated the apparent model failure rate; hiding them would have made the study look cleaner than it is. Because the missingness is condition-imbalanced, the author states plainly that success-among-valid-runs and operational scoreability have to be read separately, and that the imbalance may not be random — which is a real threat to the study's own headline, printed by its author.

Almost no agent evaluation reports this split. The map already holds that agent benchmarks disclose their harness and cost far less than classical ones (agent-benchmarks-underdisclose-their-harness: 0/8 papers disclose cost or full container; agent 0.38/1.0 vs classical 0.66). Scoreability is the same disclosure gap one layer lower — not "which container" but "how many runs the container ate, and were they the hard ones." When the losses correlate with condition, an unreported exclusion policy is a silent selection effect on the comparison being published.

Two nearby results make this more than hygiene. control-the-data-draw-before-the-seed, ingested the same run, finds the dominant variance component on hard cells is which data you drew, and that constructing the sample wrongly can erase a catastrophic-failure mode entirely — imbalanced attrition is another route to the same hidden instability. And this study's own extension moved a cell from 0/5 to 3/10, retiring the five-run significance, which is coordination-deltas-need-a-measured-noise-floor's lesson reached by accident in a second domain. The composite rule for reading any agent number: ask for the attempt count, the valid count, and their distribution across arms.

Caveats: T3, one study, one gateway, one primary model — the 50.9% figure is a property of this author's infrastructure and transfers as a category, not a rate. The causes are self-reported from run records rather than independently diagnosed, and the study cannot say whether long context caused any of the stream disconnects or merely co-occurred with them.
