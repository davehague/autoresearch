An unattended agent's tool call reporting success is not evidence anything happened -- the harness's stdin plumbing decides that, below where any permission check or self-report lives

unattended-operation's durable-state facet has mostly asked what an agent needs to keep track of across a run it cannot be watched during. This source names a prior-to-that failure mode: the agent's most basic primitive, "I ran a command and it returned 0," is not reliable at all when the command is interactive and the harness's terminal setup silently decides what happens to the unanswered question. The mechanism is almost comically cheap to produce (close stdin, the program reads EOF, takes a default path, reports success) and almost as cheap to detect (read what the process is actually blocked on via the kernel, not what it claims) -- which is exactly the shape of result this vault keeps finding where a near-zero-cost deterministic check closes a gap that no amount of better prompting would touch, because the gap is below the level where prompting operates at all.

It interacts directly with loop-engineering's and runtime-action-governance's shared concern about actions executing without the agent -- or anything watching it -- knowing what actually happened: this is a concrete instance where "nothing watching" literally means "nothing inspecting process state," and the fix doesn't require touching the agent or the LLM at all. It also sharpens verifier-independence's standing finding that the cheapest, most effective checks are the ones structurally incapable of sharing the agent's own interpretation: RECEIPT's detector reads kernel syscalls, which cannot be narrated around.

[T1, strong; generalization bounded to 8 Linux / 2 Windows harnesses tested in the controlled experiments (the 23-harness/19-LLM figure is only the uncontrolled trajectory survey); the benchmark (Tripwire) was authored alongside the detector, partially mitigated by freezing the detector before the last 10 of 25 pairs; most comparisons use 3 repetitions; production logs are not released for independent audit]
