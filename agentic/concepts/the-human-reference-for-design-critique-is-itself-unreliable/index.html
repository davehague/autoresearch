The gold standard for "is this criticism justified" is 65% agreement

Every judge-validation result in this vault is measured against human labels, and the standing question is whether the labels are worth the deference. Here the reference instrument is measured directly, on exactly the task where agent review agents are now deployed: given a design artifact and a natural-language description of what it should capture, is this reported issue actually a defect?

Four trained annotators, 428 reported issues, two independent labels each. They assigned the same initial label 65% of the time; Krippendorff's α = 0.32. Adjudication by a fifth annotator produces a usable reference and — the authors are explicit — does not remove the underlying ambiguity, it decides it. This confirms estimate-reference-reliability-before-it-drives-repair and report-judge-agreement-per-condition-not-per-panel on a task nobody had measured, and it puts a floor under how much any "agreement with humans" number can mean here: a judge cannot be shown to exceed a reference whose own reliability is 0.32.

The second half is what those adjudicated labels say about the judges. Post-adjudication precision on unmutated artifacts — where the correct number of reported issues is close to zero — is 31.6% to 63.7% by model and 26.9% to 48.6% by prompt. Between a third and three-quarters of what these judges volunteer about a clean artifact is unsupported. That is the false-positive side of a-review-agents-default-failure-is-volume-not-blindness, measured against an adjudicated reference rather than against merge outcomes, and it is why a defect-injection score alone is not enough (mutate-the-artifact-to-test-the-judge): sensitivity and restraint are separate quantities and a verbose judge trades one for the other.

The operational consequence for anyone running an LLM reviewer on design-level questions: precision on unchanged artifacts is a measurable, reportable number and it is bad. Measure it before deciding how much of the reviewer's output to surface, and expect that two of your own engineers will disagree about a third of the calls when you try.

Bounds. Ten baseline entries, only five drawn from the curated set (randomly selected), so precision values and configuration ordering could move with a larger sample. Manual annotation evaluates only issues that were reported, so it is a precision measurement and says nothing about what the judges missed. Domain class diagrams in PlantUML; the subjectivity result may be worse or better on code review, where more of the criteria are mechanical.
