The same principle, stated as algebra, on a checker with no model in it

Every design on this map so far engineers independence by controlling what a model is shown: withhold the issue text, withhold the exploration trace, swap the backbone, freeze the referent in time. The map's own framing is that independence is a property of the checker's information set rather than of its model card. Here is that claim made without a model anywhere in the checker, and the payoff is that the mechanism stops being a tendency and becomes an identity.

Let an oracle assert |m − e| ≤ τ, equivalently m/e ∈ [1−ε, 1+ε]. Suppose e is obtained by calling the module under mutation, or is a function of state that module produces, and a fault scales the underlying quantity by k. If the measurement is also proportional to that quantity, then m′ = km and e′ = ke, so m′/e′ = m/e exactly. The comparison is invariant under the mutation. The property does not merely fail to fail on the inputs that were generated — it cannot fail on any input. That is why the suite in question ran green on every one of 29 commits in a month while a real, shipped, visibly-wrong behaviour sat underneath it.

Four channels, three of them unnamed before. The expected value the assertion compares against (the one the test-smell literature has, under several names); the width of a tolerance band; a conditioning variable read at evaluation time; and a generator that places the scenario, which runs before any assertion exists. The paper's central instance carries two of them in one line — a holding-pattern containment property whose yardstick is 2 * holdTurnRadiusNM(ac.trueAirspeedKt), so both the function and the speed it is evaluated at come from the module under mutation. A speed-table mutation of 230→200 knots shrinks the radius by (200/230)² = 0.76, a 24% error against a ±6% band, and the oracle passes because it sized its band at the same wrong speed. Closing the named channel recovers 1 mutant; closing the unnamed conditioning channel recovers 8.

The intervention runs in both directions and the second one is what makes it a mechanism. Removing anchoring recovers 8 with no assertion added — one value flow moved, nothing else. Deliberately state-anchoring a healthy oracle — replacing a streak the test recomputes from its own trace with the controller's own accumulated timer, a change a reviewer would wave through as removing redundancy — costs 4. And the sizing condition is stated as a restriction rather than sold as universal: self-reference costs detection only when the anchored value sizes the comparison and the fault moves it proportionally; where it merely places a scenario, feeds a bound with slack, or measures something another suite covers, the self-reference is latent, real and free. Six instances found, six ablated, two costly, and the author insists the prevalence figure never travels without that split.

Scope-relativity is the result that separates this from propagation distance, which was the author's own working explanation for most of the study. One unchanged oracle, two declared mutate targets differing only in whether they contain the producer of the value it reads: recovery 0 in one cell (diff empty in both directions) and +3 in the other — and not one of the three lies in the block the oracle exists to test; they are all in the producer. Distance predicts no difference, because the oracle and the producer stand in the same call relation in both cells. Anchoring predicts opposite outcomes, and opposite outcomes are what happened. So an oracle is not state-anchored in the abstract; it is state-anchored with respect to a declared target, and a report that a checker is independent is incomplete until it says independent of what.

What this does to the map's open questions. It answers a version of is the model boundary worth anything once the information boundary is in place on one population, from the other end: three designs, one 19-mutant set — reference-model conformance 18/19, specification-anchored model-free properties 18/19 with the identical kill set and the identical survivor, state-anchored properties 14/19. A reference model is an independent source of expected values and is structurally incapable of this defect; that turns out to buy nothing here that specification anchoring does not, so the reason to prefer a model is maintainability, not detection. What does cost detection is the move a model-free author naturally makes — reaching for the running system because there is no other source of expectations. That is a mechanism for a-verifier-sharing-the-interpretation-shares-the-error rather than a restatement: the shared thing is not an interpretation, it is a number, and the cancellation is provable.

It also lands hard on the map's newest boundary. a-kernel-checked-proof-still-needs-an-axiom-allowlist established that independence is a property of what the checker is denied and of who authors what the checker checks. This adds a third term: and of where the checker's expected value comes from. All three are provenance questions, and none is visible to any published oracle-adequacy metric — every one catalogued from 2007 to 2023 measures forward influence, so a self-referential oracle scores perfectly on all of them, and vacuity detection does not merely miss the defect but certifies the oracle healthy.

Bounds, and one of them is uncomfortably on-topic. One system, one author, who wrote the code, both suites and the study. He widens rather than softens it: the work was done throughout with a language-model assistant, and on the module carrying the central result the production code and both covering suites were authored in sessions with the same model — so oracle and code under test share an authoring source, which is this paper's own defect one level up, named as a threat rather than offered as a disclosure. Cutting the other way, a coding agent wrote the ablation repairs and the state-anchored negative control to specifications fixed in advance. Four modules chosen to span the structural range rather than sampled; equivalent mutants classified exhaustively on only two of them. The 8 recovered mutants form a single dynamic subsumption class and the 4 costed form two, so the counts partly reflect how many replacements a syntactic site admits — which is why the density-independent property-only column (0 → 1) is the comparison the author actually draws. And redundant guards are named as a third survival mechanism invisible to both anchoring and distance, unmeasured.
