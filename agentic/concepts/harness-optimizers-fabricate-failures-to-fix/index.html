Harness optimizers fabricate failures to fix

In a deterministic micro-lab where the provably correct self-edit is no action, harness optimizers shown all-legal episodes containing a harmless pattern that merely resembles a familiar game rule enabled guards against nonexistent failures — citing oracle-refuted violations — in 15/60 runs (vs 0/60 on featureless input). Three conditions are each necessary: a rule-shaped pattern, an open-ended rule set, and instructions presupposing failures exist; remove any one and fabrication drops to zero. The failure is invisible by construction: the phantom guard is a strict no-op, so an empty harness and a phantom-laden one score identically under suppression-only acceptance — it is neither reward hacking (nothing is gamed) nor over-refusal (nothing is traded), but unwarranted complexity the metric cannot see. Under accept-if-not-worse it enters monotonically and never leaves; under warrant-aware acceptance — credit a guard only when it cites oracle-confirmed failing episodes — it never enters (0/60).

This pushes back on agent-harness-architecture's self-evolution enthusiasm one step past the judge cap. harness-self-evolution-is-capped-by-its-proxy-judge showed the loop selecting badly among real candidates; this shows it inventing work — and it partially answers the map's open question about the unmeasured adversarial worst case: fabrication needs no adversary, just a failure-presupposing prompt over an under-specified rule set. The remedy is procedural and cheap: (1) instruction hygiene — don't assert failures the evidence doesn't show (the self-modification cousin of underspecified-targets-drive-unsafe-actions's "specify the target"); (2) state rule-set completeness; (3) make every self-edit carry a warrant — evidence that licenses it — which is measure-whether-evidence-reconstructs-the-claim applied in-loop. For evaluation-integrity, this is a new proxy-failure shape: a metric blind to unnecessary work lets complexity accrete ungraded, and never-subtract acceptance loops compound it.

Caveats: board-game micro-lab, not a production harness; effect concentrates in weaker proposer models (deepseek/qwen/GLM-5.1 variants); the 25% rate is lab-specific — carry the existence proof, the necessary-conditions ablation, and the acceptance-rule remedy, not the rate.
