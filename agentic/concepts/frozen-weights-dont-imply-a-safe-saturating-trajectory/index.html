This map's governance sub-thread has been asking "can anything supervise the authoring step" — this source answers a prior question: supervise what, if a frozen checkpoint is the wrong audit target to begin with

Sub-thread (2) of this map has accumulated adversarial governance findings — a benchmark-poisoning trusting-trust attack that survives subsequent clean-benchmark evolution (poisoned-benchmark-contaminates-self-modifying-agent), an in-context skill-authoring hazard — all of which implicitly treat "the weights are frozen" as the safety baseline being attacked or defended. This source formalizes why that baseline was never sufficient on its own: a fixed reachable edit set is what forces diminishing returns (the mechanism this map's sub-thread (1) has measured empirically many times as "the search stops paying"), and scaffold rewriting — the exact kind of tool/verifier/decomposition change every source on this map's design-lever and self-evolution threads studies — expands that reachable set without ever touching a weight. So a governance regime that certifies safety by checking "are the weights frozen" is checking the wrong invariant; the paper's own framing, "audit the scaffold, not the checkpoint," names precisely the blind spot this map's adversarial sub-thread has been probing from the attack side without naming the underlying structural reason weight-freezing under-delivers.

The orchestration-ceiling half extends sub-thread (1)'s search-pays question to a topology this map hasn't yet formalized: this map has measured multiple instances of a harness search beating (or failing to beat) a matched budget spent elsewhere, but treats "spend budget on more workers" as one lever among others. This source proves a hard limit on that specific lever — best-of-k cannot exceed its best individual worker's own ceiling, full stop, regardless of k — and the one arrangement that could beat that ceiling, a diversity- weighted vote, empirically fails on a real same-family worker pool (a majority vote failing 23/55, 42%, "on tasks that defeat every worker"). That is a structural reason a harness-search loop cannot buy its way past a ceiling merely by running more parallel copies of the same searched configuration — width buys success rate at the ceiling, not a higher ceiling.

The production-session control (Part C) is methodologically the sharper contribution for this map's epistemics: it runs the one falsification test its own theory-specific claim needs and reports the null honestly. Geometric churn-decay is not AI-specific (a 9,395-session pre-AI human baseline shows the same shape), and the one discriminator that would have supported a capability-driven reading of the decay (higher-tier models preserving more net progress per unit of churn) returns a clean null. The paper's own reading — this is a fact about the survivor-ratio proxy metric rather than about the models, since a separate arm of the same paper (Part B) finds a large, real capability effect on a comparable contrast — is the kind of self-undercutting honesty this map's evidence-tier discipline should reward: a result that could have been oversold as "AI-specific self-improvement dynamics" is instead reported as an open mechanism question.

Scope: the authors' own ranked "Limitations" flags the harness-stops-scoring-once-a-task-passes artifact as a critical caveat — the per-round edge measurement conditions on a shrinking, hardening subsample of still- live tasks (Sonnet 113→49 of 275 rows by round 3), so part of the observed decline is a change of subsample rather than of behavior; reading either the pooled or surviving-cells estimator as a clean unconditional edge measurement would overread the data in opposite directions, by the authors' own statement. Part C's model-tier "assignment" is observational, not randomized (Opus is often used for planning, Sonnet for execution), a task-type confound the survivor-ratio null removes as an explanation without making it a demonstrated zero effect. The worker-diversity failure (23/55) is measured on one same-family 30-worker pool — the authors state directly it "settles only the pessimistic half" of the diversity question.
