Harness evolution loses to test-time scaling once the budgets match

Automatic harness evolution is itself a search procedure — it runs candidates, reads outcomes, revises — so comparing it to a single-shot baseline credits the harness design with gains that belong to the extra rollouts. Charge every arm the same feedback and inference budget on Terminal-Bench 2.1 (Claude Opus 4.6, GPT-5.4, GPT-5.4-mini) and the ranking inverts: harness evolution averages 67.4, below the 68.2 direct-sampling baseline, while dumb parallel sampling gets 72.3 and harness scaling 71.8. Giving every arm unit tests widens the gap (parallel sampling 86.0 pass@1, sequential refinement 91.8 pass@5, vs harness evolution's 75.8 / 86.2). The generalization result is the decisive one: on held-out tasks the evolved harness is worth +0.6 points (+0.0 for GPT-5.4) — it fitted the tasks it searched on.

The remedy is a protocol, not a better optimizer: separate the search task set from the evaluation set, match budgets across arms, and report held-out performance rather than in-distribution score. Note what survives — harness scaling still beats direct sampling, so structural search is not worthless; what fails is the claim that the evolutionary loop beats a simpler use of the same compute.

This is the third and heaviest cap on agent-harness-architecture's self-evolution limb. harness-self-evolution-is-capped-by-its-proxy-judge showed the loop selecting badly among real candidates (50% committed, 64% available); harness-optimizers-fabricate-failures-to-fix showed it inventing work that never needed doing; this shows the headline effect not surviving a fair control. It lands precisely on the caveat TTHE named and did not test (evolve-the-harness-at-test-time-without-labels is transductive — forward generalization unestablished), which is why the +0.6 is more damaging than a mere non-replication. Combined with scaffolding-releases-swing-quality-without-improving-it — the human version of harness improvement, 35 releases, no trend — the map moves to contested on this limb. For evaluation-integrity it extends agent-benchmarks-underdisclose-their-harness from disclosure to comparison: an unmatched budget is an under-specified experiment, and the field built a research direction on one. See charge-every-search-method-the-same-budget.

Caveats: one benchmark, three models, and an authors' reproduction of harness evolution rather than a specific published system — an advocate can contest fidelity. It bounds the claim, not the idea.
