Agent tests trade stability for edge coverage

Across 204,673 test files (179,732 agent-generated, 24,941 human), static analysis on three quality dimensions finds a specific trade rather than a uniform deficit. Agents beat humans on edge-case coverage — nearly double the boundary-check variety (0.62 vs 0.32), more null-safety (13.40% vs 8.3%) and zero-input (27.7% vs 11.2%) testing — because an LLM mechanically enumerates the boundaries a human skips. They roughly tie on strong assertions (85.37% vs 88.08%) but emit 8× the unrecognized assertion patterns (11.58% vs 1.46%), and their tests carry a higher flakiness-candidate rate (0.41 vs 0.30), driven by non-deterministic functions and un-stubbed file I/O — missing the environmental awareness to isolate a test from its machine.

For ci-cd-for-agents this decomposes the backstop's quality. The map already holds that the agent-written suite quits early and self-certifies (lazy-generation-caps-agent-test-coverage); this adds what the written portion is made of, and each half cuts a different way. The flakiness half compounds the relaxed-gate position's unpriced cost: flaky agent tests are a candidate mechanism for pipeline reliability falling as agent-PR volume rises (ci-reliability-degrades-as-agent-pr-volume-rises) — unlinked, but the same direction. The edge-coverage half warns against romanticizing the human baseline: on boundary enumeration the agent gate is better, so "same CI as humans" is not automatically the conservative choice. Operationally: gate agent tests on isolation hygiene (stub I/O, pin non-determinism) rather than presence or count, and lint the assertion vocabulary — the drift is maintenance surface (agentic-code-review: agentic-pr-review-targets-more-than-correctness).

Caveats: static risk candidates, not observed flaky runs — no test was executed; attribution inherits AIDev labels; the human corpus is 7× smaller and unmatched. The descriptive contrasts are large-N and quantified (strong); the causal reading is interpretation.
