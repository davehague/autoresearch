The volume this map has been measuring has a name for the mechanism that turns it into risk: opacity degrades review speed and review catch-rate at the same time, not as a tradeoff between them

This map's review-capacity-and-throughput strand already holds population-scale numbers on how much review agent-authored code receives and how fast it merges. This source supplies the causal mechanism those numbers have been missing: a large-N (3,100-document), independently-coded synthesis of practitioner discourse, built into an explicit causal model rather than left as a set of loose observations. Two constructs matter most for this map. First, code opacity — missing design rationale behind an AI-authored change — is modeled as degrading review efficiency and effectiveness together, not trading one for the other; a reviewer facing an opaque diff doesn't get to choose "slower but thorough," both dials move the wrong way at once. Second, the model states plainly that review is "the control point through which a coding agent's effect on software is decided" — reframing this whole map's throughput and verifier-independence strands as instances of one underlying claim: nothing about an agent's code quality is fixed until review has (or hasn't) happened. This is consistent with, and gives explicit causal structure to, this map's existing finding that review depth also functions as the mechanism for reviewer skill development and collective ownership — a shallow review isn't only a quality miss, it's a capability-transfer miss.

The observed-behavior numbers sit alongside this map's throughput strand rather than extending it: 40.1% of agent PRs get only the invoking developer as reviewer (vs 21.5% human), but the no-review rate closing from >50% to ~12% year-over-year says the field's review practice is adapting toward the human baseline faster than a purely volume-driven story would predict — worth tracking against whether the volume keeps rising as fast as the review rate recovers, which this source's causal model would predict trades off against depth even as raw review presence improves.

Authors' own caveat carried forward: the causal model is explicitly "proposed," not validated — its structure is a strong qualitative synthesis, not a set of measured interventions, and grey literature is acknowledged to over-represent vocal early adopters.
