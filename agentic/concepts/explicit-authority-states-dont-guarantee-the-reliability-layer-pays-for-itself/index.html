A harness that makes every authority transition explicit still has to show the explicit version does something a cheaper one doesn't -- and the one controlled test of that question here is a tie bought at a real token cost

This map's central argument is "enforce runtime permission below the prompt, in layers" -- environment, classifier, human-last -- and its running tally of what breaks that enforcement has mostly been about failures of the layers that exist (sibling leaks, stale-approval windows, over-refusal). Praxa is useful to this map for a different reason: it is an architecture proposal for what those layers should look like, named explicitly (proposed -> admitted -> dispatched -> externally verified -> reconciled -> promoted, with promotion kept as a separately reviewed step rather than folded into verification), built on the same fail-safe-defaults and complete-mediation lineage this map already cites -- and its own single controlled comparison of "does the explicit reliability layer help" returns a tie at a real cost (17/36 both arms, +37-51% tokens), which the paper reports as non-support for its own H3 rather than reframing as a partial win. That is the honest version of a result this map's ledger otherwise mostly sees from the losing side: a governance layer that adds verification, checkpointing and rollback machinery without the controlled comparison to show it buys anything beyond cost.

The result this map should weigh more cautiously is the development comparison (equal accuracy, 33-38% lower cost) -- not because the numbers are wrong, but because the paper itself names the reason they shouldn't be read as a second controlled trial: the "successful" partition the candidate was tested on was shaped by earlier development iterations rather than held out untouched. A resource-reduction-at-matched- accuracy result on a self-shaped partition is a different evidentiary class from the Terminal-Bench pilot's null, and Praxa's own Table 1 keeps them in separate rows rather than combining them into one architecture verdict -- a discipline this map's own practice (keep enforcement-layer claims separate from cost claims) already asks for.

Interaction edge: ci-cd-for-agents -- Praxa's "promotion" stage (a separately reviewed step before a candidate is treated as production-eligible, explicitly distinct from passing verification) is this map's admission question one lifecycle stage later: that map's standing contest over how strict a merge-time gate should be is, in Praxa's vocabulary, a question about what evidence is sufficient to promote, not what evidence is sufficient to admit a single action. Neither map's evidence moves on this source; the vocabulary overlap is what's new.

Scope: single independent-researcher study, no external replication, a non-interleaved and non-randomized pilot design, and an explicitly incomplete reproducibility boundary (raw per-test transcripts and provider traces withheld). The paper's own limitations section runs unusually long and specific for this evidence tier (construct, internal, statistical, external and evaluator-dependence validity named separately) -- which is itself a data point in this source's favor on honesty-of-reporting, even though it does not change the strength of what was actually measured.
