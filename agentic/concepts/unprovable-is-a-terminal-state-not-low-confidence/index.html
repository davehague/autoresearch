A two-valued answer forces a guess exactly where guessing is worst

The question an agent faces at the start of a session after an upstream has moved is not binary. A prior claim can be unaffected, affected, or unprovable — the third when the dependency changed and its new content was not shipped, was placed beyond an accessible boundary, or was simply omitted. A system with only the first two outcomes forces a guess precisely where no evidence exists to guess from, and modelling unprovability as low confidence invites the agent to act on it anyway, because a low-confidence value is still a value.

Two separations do the work, and both are cheap. Evidence is independent of freshness — PROVEN / PARTIAL / UNKNOWN describes grounds, FRESH / STALE describes time — with a refusal rule attached: if any fact on a derivation path is stale the query is refused with a rebuild obligation naming the drifted anchors, at whatever evidence grade it would otherwise have carried. Freshness is not a caveat attached to an answer the agent is going to use. And claim status is independent of artifact disposition: an artifact whose claim has gone unprovable is not thereby wrong, it is unverifiable, so the last verified content can be retained with its prior verification record and the reason its reference is unavailable. Collapsing those two encourages an agent to destroy working code merely to express uncertainty.

There is also a quarantine rule worth stealing wholesale, because it is the same shape as this vault's independence findings: no model output enters at PROVEN. Every LLM-proposed edge is PARTIAL, and promotion requires deterministic re-extraction or observation. That is treat-agent-output-as-a-claim-not-lifecycle-state implemented as a type rather than as a review habit, and it composes with gate-lifecycle-claims-on-fresh-hash-bound-evidence: the hash decides freshness, the quarantine decides grounds, and neither delegates to the model whose work is being graded.

The behavioural result is the reassuring half and the measurement result is the instructive half. Across 42 sessions with three definitions withheld per world, no session fabricated withheld content — the failure mode the design was built to provoke did not occur in either model tier. But the study's own headline repair metric, (terminal − entry) / (ceiling − entry), conflated three outcomes: failure to repair, collateral breakage, and correct refusal of unverifiable output. Every session scoring below its entry state had refused rather than broken something; after decomposition, collateral damage across the entire study came from a single session, and the smaller model's repair rate fell from the net estimate to 10%. A metric that nets refusals against damage penalizes the discipline it is meant to encourage, which is a general warning for anyone scoring an agent that is allowed to decline — and a sibling of scoreable-runs-are-a-separate-denominator: the denominators have to be kept apart or the honest behaviour reads as failure.

Bounds. The withheld set is ground truth by construction in a generated testbed, which is what makes the fabrication count meaningful and also what makes it a bounded claim — real upstreams do not redact on request, and no equivalent census exists on real repositories. One observation per cell. The refusal machinery was exercised only for the withdrawal query; the model's write and kill effects, its multi-hop evidence meet, and its PARTIAL/UNKNOWN grades were defined but not evaluated. And the boundary the paper draws on itself applies here too: identifying what can no longer be supported is not repairing it, and in one session it preceded destroying the artifact outright.
