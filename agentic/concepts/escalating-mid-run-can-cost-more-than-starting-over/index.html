The escape hatch is the expensive path

This map has priced routing as a selection problem: which model should act next, given the task (route-after-scouting-the-repository-not-from-the-issue-text), the role (route-the-premium-model-to-the-governing-role), or a deploy-time dial (expose-a-cost-quality-dial-not-a-fixed-policy). Every one of those decides who acts. None of them prices the moment the decision changes mid-run, which is the only form of routing that most engineers actually perform by hand — you watch a cheap model flail and you type /model.

That moment turns out to have its own economics, and they are bad. The receiver is not extending its own reasoning; it is continuing someone else's — another model's phrasing, hypotheses, tool idioms and dead ends. The authors call the resulting penalty the handoff tax, and it is large enough that for the Claude pair the entire manoeuvre is dominated: abandoning the trajectory, eating the cost of the work you already paid for, and restarting Opus from the original task state is cheaper and better than continuing. That is not a marginal call between operating points. It says the default escalation interface is worse than the crudest possible alternative.

Two things stop this from being a blanket rule, and both are load-bearing. First, the size of the cost premium is a property of the pair, not of escalation: HC costs about 8× LC for the GPT pair and only about 2× for Claude, so GPT's Raw escalation stays cheaper than HC-only while recovering even less quality. Second, the direction reverses the verdict. Downshift — run the strong model through the hard reasoning, hand the finish to the cheap one — is a genuinely good intermediate point in both families, and it is the manoeuvre nobody talks about.

This sits directly against solve-sets-are-nested-so-route-for-cost-not-accuracy, which found that weak-model solve sets are largely contained in strong-model solve sets and concluded you should route for cost. Nesting is an argument about whole runs, and it holds. What this adds is that the nesting does not license mid-run rescue: if the cheap model is going to fail, the containment property means the strong model would have solved it, but starting it fresh captures that value and continuing does not. The cost mechanism is measured rather than assumed — Raw escalation makes each post-handoff HC step 2.2× more expensive at a similar step count, so the premium is inflated calls, not a longer continuation.

Bounds worth carrying. Two model pairs, one primary benchmark, one episode per (task, configuration) so there is no within-configuration variance estimate — the authors compensate by scoring every interface on the same switched subset and reporting task-clustered bootstrap intervals. Switch points are fixed percentiles rather than triggered by a progress-aware policy, deliberately, to isolate the handoff from the policy that would fire it; an adaptive trigger might escalate only where it pays. The hard-task exception (reduced-context interfaces become cheaper than HC-only while recovering 65–74% of the gap) rests on cells averaging ~24 instances and the authors label it exploratory. Dollar conclusions move with provider pricing and cache rates.
