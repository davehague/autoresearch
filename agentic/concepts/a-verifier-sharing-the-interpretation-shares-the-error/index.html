The gate has the external anchor and still misses nine errors in ten

The verifier here is built the way this vault would build one. It is narration-blind — its context contains only the verbatim task instruction and machine access, never the agent's message history, plan or rationale, so it cannot be led into agreement with the trajectory's story. It is state-grounded — it reads the actual persisted artifact rather than any account of it. It is anti-capture — it must independently locate the deliverable the task names, and evidence found only in a side file the agent created is rejected. And correction is bounded at three rounds. This is an-independent-checker-beats-the-same-model-checking-itself and audit-agent-claims-against-trajectory-evidence implemented without compromise.

It still passes 68 of the 76 wrong answers it sees.

The authors are explicit that this is not the bias the field guards against. It is not narration-conditioned agreement — the gate is structurally independent of the agent's account. It is a common-mode failure: shared interpretation of the source. The gate can decide whether the file is missing, unsaved, at the wrong path or in the wrong format. It cannot decide whether the value in it is right, because arriving at the right value requires the same reasoning the agent already got wrong, from the same inputs, with the same reading of an ambiguous instruction. Of the 68 misses only 14 are things a structural check could have caught; the rest are the dominant recoverable failure class the run's own audit names — agent reasoning, 38 of 79 non-perfect tasks.

This is the third arrival of one mechanism in five days, and it should now govern every independence claim the map carries. An agent's reproduction test and its fix, emitted in one trajectory, fail together at 1.87× the independence rate, because both are drawn from a single reading of the bug (cogenerated-tests-and-fixes-fail-together). A grid varying independence and capability together found the most independent condition was the only significantly harmful one, and reconciled it as: an independent checker wins where there is an external anchor to re-derive from (reviewer-value-tracks-capability-headroom). This completes the statement. The anchor is necessary and not sufficient. This gate has the anchor — the real file, the real calendar store, the real spreadsheet cell — and misses anyway, because independence was arranged over what the checker may see and not over how it reads the source.

What follows for practice is a split rather than a discouragement. A cheap, generic, narration-blind gate is genuinely worth shipping: it is 88.9% precise, costs one prompt-level check with zero per-task engineering, converts 21.4% of the retries it triggers, and its removal costs 3.8 binary points. Just buy it for what it sells — structural completeness, the class this vault also calls "did the agent actually save it, in the right place, in the right format." For value correctness you need a check that differs in interpretation: a differently-derived expectation, an oracle constructed from something the agent never read (fail-to-pass-does-not-constrain-the-fix is the same move in the test-generation domain), or a hard-coded per-task verifier — which wins on exactly this axis and loses all generality.

Caveats: computer-use desktop tasks, not code review, so the mechanism transfers and the magnitudes do not; 108 tasks with 9 rejections makes the 88.9% precision a small-denominator figure; vendor research on its own harness; the failure taxonomy is the authors' manual audit with no inter-rater statistic.
