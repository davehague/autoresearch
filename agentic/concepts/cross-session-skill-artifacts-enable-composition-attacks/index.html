This map's operator surface grew to six things to enumerate after the ClawHavoc skill-poisoning campaign (agents, tools, peers, gateways, stores, skill/MCP sources); this source names a seventh — the artifact itself, trusted across a session boundary no individual permission check ever sees

This map's running enumeration has been built almost entirely around who may act — agents, tools, peers, gateways, stores, install-time skill sources. SkillRelayBench's three attack mechanisms (Instruction Propagation, Data Boundary Violation, Evidence Poisoning) all route around that enumeration by construction: every individual tool call stays inside its own declared scope, and the compromise lives entirely in what a different skill, in a later session, chooses to trust about an artifact it didn't create. This is the closure-over-everything-on-the-path lesson this map keeps re-deriving (peers → gateways → stores → skill sources) arriving at its next hop: persistent artifacts are also on the path, and a permission model that enumerates agents and tools but not the provenance of what they read is enumerating the wrong set again.

The 64.7%/50.2% baseline numbers sit in the same high-ASR, high-legitimate-completion band this map's other composition attacks occupy — the 2026-07-28 API-router injection study found 0% defense success across every client-side layer tested precisely because nothing in the agent checked whether a response's provenance matched its apparent source; this source finds the same shape one layer up, for artifacts rather than responses. SkillRelayGuard's own ablation is the map's clearest demonstration yet that attribution alone is insufficient and advisory review alone is insufficient but together they compound: context-restoration (telling the agent where data came from) barely moves ASR (77.4%→73.3%) on its own, while the advisory review does most of the heavy lifting (→25.9%), and only the combination reaches 17.4% — a concrete data point for this map's standing tension between structural (non-model) controls and model-adjudicated ones, since here the model-adjudicated layer is doing more work than the structural one, the reverse of this map's usual finding (e.g. the branching/information-flow-control result where "no model sits in the decision path" was the load-bearing property).

Connects directly to the flagged-but-uncoined "agent skills as an artifact class" theme (open gap, 2026-08-09): this is now a tenth claim on that theme, and the first to measure a multi-skill composition attack specifically rather than a single skill's own install-time or execution-time risk — a genuinely new facet (cross-skill trust) rather than another instance of an existing one.

Bounds: the Agent-as-Judge scoring (GPT-5.4) may misjudge borderline attack-success cases; no repeated-run variance is reported for any cell, so point estimates carry unquantified stochastic noise; the full defense combination was tested with exactly one configuration per scaffold and the ablation used only Codex CLI, so cross-scaffold generalization of the ablation specifically (as opposed to the headline defense numbers, which are reported per-scaffold) is unverified; residual risk is explicitly named — an agent can ignore restored provenance or proceed past a review warning, and the defense's own numbers (10.9%/10.0%) show this still happens in roughly one case in ten.
