The documentation surface that matters to an agent is the one agents made, and the genre every documentation tool targets is 1.3% of it

This map's subject is what reaches the window and how it got chosen. Every finding here so far has been about retrieval — indexes, packing policies, skill pools, phase-conditioned selection. This arrival measures the layer underneath all of it: which artefacts an agent opens at all, in real sessions, coded by file path rather than by asking anyone.

The distribution is not the one the tooling market is built for. Instruction files get 27× as many interactions as API references. Agent-authored working notes — plans, thoughts/ directories, brainstorms, verification logs — are a quarter of everything, and the category did not exist in the authors' initial coding scheme; it emerged from a residual bucket that Tier-1 path rules could not classify, which is a good sign that nobody was looking for it. Troubleshooting documentation, the genre the field assumes an agent reaches for when stuck, is eleven events across the entire corpus.

What this vault should take from it. The instruction-file findings already here have been about quality — that a rule file is the-project-rule-file-is-written-once-and-abandoned, that a-stale-convention-file-costs-more-than-no-file, that generic-context-files-do-not-move-correctness, that an-agentic-context-file-grows-until-someone-bulldozes-it, that agents-md-is-a-map-not-a-manual. Every one of those is a claim about a surface whose share of attention nobody had measured. This supplies the denominator, and it says the surface is roughly half to two-thirds of everything an agent reads that is not code. The practical reallocation the authors state — improving instruction files reaches agents far more often than equivalent work on API reference prose — is now backed by a count rather than by intuition. It also raises the stakes on the-instruction-file-is-an-ungoverned-security-surface and project-documentation-is-a-code-execution-attack-surface: the most-read artefact class in the corpus is the one with the weakest provenance controls.

The write side is the newer half. Documentation is nearly as much an output as an input here, and the direction is asymmetric in time: where order is observable across commits, code comes first in 82.5% of cases. So the artefact is a residue of work rather than an input to it, which is the same shape as agents-curate-a-field-guide-for-the-agents-behind-them — but measured on a large public corpus rather than one system. And the loop closes: AGENTS.md was changed in 692 pull requests, CLAUDE.md in 362. Agents are editing the files that configure agents, which is generated-context-files-cost-more-than-they-help and an-agentic-context-file-grows-until-someone-bulldozes-it operating at ecosystem scale with no hygiene tooling that has a category for it. Repository quality metrics, review checklists and documentation staleness tooling have no bucket for a thoughts/ directory.

The honest reading of the 60.5%. The authors' own robustness table is the reason not to quote it flat. Under agent-reweighting the consultation half sits at 50.1% — right on the boundary — so the defensible claim is that agent-facing documents are about half of what an agent reads and a clear majority of what it writes. The load-bearing numbers are the extremes: 1.3% and 0.4% are stable under every weighting, and they are the ones that indict the tooling.

Bounds. Documentation is identified by file path, so docstrings, inline comments and in-source prose are invisible and every absolute rate is a lower bound, non-uniformly across languages. The 25.1% working-notes figure rests on unvalidated language-model classification of 500 ambiguous paths with no human coding — the authors say the existence of the category is more robust than its magnitude, and that dual coding with Cohen's κ is the required next step. SWE-chat is opt-in telemetry with 87% of the corpus from one agent family; AIDev over-represents repositories receptive to agentic contribution; neither generalises to private codebases. Per-agent rates are confounded with extraction coverage (one agent registered zero events until shell-embedded paths were parsed) and must not be read as behavioural differences. This is a snapshot of a convention roughly two years old, and the authors expect the category's prominence to persist, not the exact share.
