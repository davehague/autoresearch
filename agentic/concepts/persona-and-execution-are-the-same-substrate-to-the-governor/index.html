A self-improving agent edits the one channel its governor cannot type

This map's contest is whether harness self-evolution actually earns its cost, and its sharpest recent arrival — the-agent-authors-the-malware-so-submission-screening-cannot-see-it — found the failure lives on the authoring step: the agent writes a new artifact into its own trusted library, under a name it chose, and no defence keyed on the attacker's submission can see it. This is the same architectural gap stated as a governance property rather than an attack, and it explains why the authoring step is unguarded in the first place.

The premise is the contribution. In an LLM agent, the persona (instructions, tone, self-presentation, skill bindings) and the execution semantics are the same kind of thing: natural-language context. Editing the persona is editing prompt text. Changing what the agent will do is also, at the level that matters to the model, editing prompt text. There is no compile-time or runtime signal that reliably separates the two, because both modify the same substrate. So a governance layer sitting inside one trust domain sees one channel carrying both concerns and cannot distinguish them by construction.

The author is careful to refuse the stronger claim, which is what makes the weaker one credible. A single-domain governance engine can assign rules by object type — XACML does it per resource, per-tool policies do it per tool — so this is not a logical impossibility. The claim is that delivering free drift, execution traceability and their decoupling inside one domain forces you to introduce typed change objects (a way to declare at edit time which kind of change this is), an enforcement point outside the LLM context (because in-context gating is overridable by injection), and a stable audit anchor (a record that does not drift with the persona) — and that those three, jointly, are the separated architecture rebuilt at higher coupling cost. Parnas's form: change economics, not impossibility.

What this says to the self-evolution literature. Every result on this map assumes a harness that rewrites its own prompts, tools or skills and then measures whether the rewrites help — an-unguarded-skill-pool-peaks-then-degrades, gate-a-skill-update-on-a-replay-of-what-it-might-break, the transfer results. All of them treat the content of an evolution step as the object of scrutiny. This says the harder problem is upstream: a self-evolving system generates a stream of edits to a channel where "this changes how it talks" and "this changes what it is allowed to do" are indistinguishable to any governor reading the diff. Gating a skill update on a replay of what it might break is a good answer precisely because it is behavioural — it does not try to type the edit, it types the effect. This concept is the argument for why a text-level review of an agent's self-edits cannot be made to work.

And it names the cost honestly. Three prices are stated rather than assumed away: a governed bridge with its own overhead, two governance regimes operators must both understand, and identity-mapping machinery so one logical agent stays continuous across the boundary. This map's standing complaint about self-evolution results is the missing compute-matched control; this adds a second missing column — the governance overhead of an evolving agent is never priced in these papers at all, and here at least it is enumerated.

Bounds, which are the paper's own. This is a single development/pilot deployment in one domain, operated by the author's team, and there is no comparative evaluation: R = 0.00 verifies that no path from persona edits into the approval and audit machinery exists in this implementation — including under an adversarial "skip approvals / rewrite audit" perturbation — and does not show that the separated design is cheaper than a measured single-domain baseline. Proposition 1 is explicitly an architectural argument, not a formal theorem. The platform comparison is a 2022–2026 scan by the author across eight platforms and a research cluster, on dimensions he defined. The pattern's decisions are frozen; its operational realization is young, and identity-continuity binding and production-scale operation are outside the evidence base.
