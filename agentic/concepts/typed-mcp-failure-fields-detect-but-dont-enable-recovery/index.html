A retry decided by prose-guessing is not the same governance primitive as a retry decided by a typed contract

This map's runtime-action-governance standing argument is that permission and control belong below the prompt, enforced by something other than the model reading instructions — this audit supplies the adjacent failure-recovery half of that argument, evaluated at the result boundary rather than the request boundary the map has mostly measured. The finding is specific enough to act on: the protocol's typed fields (JSON-RPC error codes, isError) are enough to detect that something went wrong but essentially never enough to say what to do about it deterministically — and reaching for the human-readable content prose to fill the gap trades a typed-field problem for a natural-language- interpretation problem, which is exactly the kind of in-context, injectable channel this map's governed- layer argument treats as untrustworthy for anything consequential (runtime-action-governance's enforcement-below-the-prompt thesis). Neither reading path, typed or prose-assisted, ever reaches the two capabilities (executable repair, replay-safety) a client would need to autonomously retry a corrected call rather than escalate — the gap is not "needs better prompting," it is a missing field in the protocol's completed-result shape.

The proposed two-plane response (a small machine-checkable control-plane object alongside the unchanged human-readable content) is the same shape this vault already endorses for permission enforcement — a typed, host-validated layer that does not require removing or degrading the natural-language channel models and humans still read — applied to failure recovery rather than action authorization.

Bounds

Single author, single-coder audit, no independent validation pass. 10 servers from a non-probability sample — not a prevalence estimate for the MCP ecosystem. Probe design deliberately excludes rate limits, upstream faults, timeouts, partial commits, and idempotency-uncertain failures — arguably the higher-stakes cases for the replay-safety dimension specifically. No agent was run to test whether richer failure information, once available, actually gets used correctly; this measures information availability, not recovery behavior.
