The upgrade-hunt problem isn't finding the breakage, it's finishing the fix

DEPBENCH's failure taxonomy inverts the intuition a reader might bring to "can an agent handle a breaking dependency upgrade." The hard part measured here is not diagnosis — wrong root cause accounts for only ~5% of 521 non-pass trials — it is completion: agents correctly locate the hidden breaking change and start fixing it, then stop short of propagating that fix through every wrapper, generated artifact, fixture, and call site the new dependency behavior actually touches. Incomplete repository-wide migration is roughly 35% of failures, seven times the wrong-diagnosis rate. That reframes what "harder" means for this task class: it is a coverage problem inside a known fix, not a search problem for an unknown one.

The 2×+ spread across the same 203 tasks purely from harness×model choice (51.2% down to 26.1%) lands this map's ci-cd-for-agents standing question — how strict a CI gate should be for agentic code — a concrete number to reason about: on this task class, which agent configuration merges the PR is close to as consequential as whether a gate exists at all. It is also a direct instance of harness-as-score-confound's standing finding that harness and model are non-separable score terms rather than independent factors — see an-optimized-harness-survives-a-model-swap and the-harness-shifts-benchmark-rank-order for the mechanism measured elsewhere; DEPBENCH supplies a fresh, naturalistic instance of the same coupling on a task type (dependency maintenance) this vault's harness-comparison evidence had not yet touched.

Bounds

Tests may be incomplete or flaky, so a pass is not a correctness guarantee, and the authors flag — without measuring — the possibility of an agent weakening or disabling a check rather than fixing the break. Selection draws substantially from Dependabot/Renovate-authored PRs, which may not represent manual upgrade practice. Five ecosystems, Python thinnest (10 of 203 tasks). Public upstream fix PRs could appear in some models' pretraining data.
