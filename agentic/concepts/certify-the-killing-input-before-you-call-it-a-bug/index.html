The agent writes the adversarial suite; something deterministic decides what it proved

This map has spent two weeks establishing that a green result is frequently a null result. The human suite executes no changed line at all in 64.8% of Python agentic PRs (agent-written-tests-miss-the-lines-they-add). Fail-to-pass does not measure constraint, so a test that reaches the line can still admit a patch that suppresses the symptom (fail-to-pass-does-not-constrain-the-fix). The agent's own mid-trajectory checks pass on the unfixed code 46.0% of the time. The remedy the map arrived at was constraint from an adversary — grade the test against mutants of the current patch (adversarial-critic-rounds-add-kills-over-a-frozen-suite).

This points that remedy at a human expert suite and it holds. Five off-the-shelf coding agents, each given only a problem statement and one reference solution and never the official tests, verdicts or the submissions under audit, build adversarial suites that land within 1.7 points of what a hand-built hidden suite catches (0.919–0.932 against 0.936) where budget-matched random generation trails by 10.9. Where no official suite exists — 41 post-cutoff Codeforces problems — the agent arm leads five reproduced baselines at every input budget with no crossover, reaching cov@50 = 0.952 against the strongest baseline's 0.809, while using the fewest inputs of any generator arm. The target-blindness is what makes this the map's strongest independence result: the auditor cannot be aiming at the submission it kills, because it never sees it.

And the agent is the cheap half. What converts a disagreement into a finding is a chain with no model in the deciding position: a consensus oracle over eight independently accepted human solutions supplies the expected output, brute-force solutions adjudicate disputes, and a per-problem input-legality validator — written from the statement alone, blind to the killing inputs it will judge, and itself gated on accepting every official input and rejecting the empty one — admits an input as evidence or discards it.

The measurement of what that chain is worth is the number to carry into any adversarial-testing deployment: across the five arms the gates dropped 1,094 submissions whose every killing input was illegal, plus 24 floating-point false positives. Without legality certification those are reported bugs. This is the same architecture as gate-the-edit-on-evidence-observed-not-claimed and the same lesson as verifier-diversity-is-not-verifier-independence from a new angle: the model proposes and something deterministic disposes, and the reason it works here is not that the auditor is independent but that the adjudication is not a judgment at all.

Two more things the design gets right and most agentic-testing work does not. A workflow-versus-model arm: the same base model in a single call reaches cov@50 = 0.665 against the agentic wrapper's 0.903 (paired delta 0.238, [0.074, 0.417]), so the scaffold is doing the work rather than the backbone. And a refusal: at the smaller k=20 budget the interval crosses zero and the authors decline the claim outright — "the small-budget lead is directional and under-powered."

Bounds. Competitive programming, C++, single-answer problems; multi-answer and special-judge problems are excluded by construction. This is a suite-adequacy result on self-contained programs and not yet a claim about repository-scale test suites, which is the artifact this map cares about — the certification chain in particular depends on having many independent correct implementations of the same specification, which a real codebase does not supply. The formal noninferiority test covers two pre-designated engines and the five-engine panel is descriptive. Freshness on the post-cutoff set removes the direct memorization channel for one engine's declared cutoff, not for all five.
