A fixed test suite is a moving target once the agent being graded can see it — evolving the evaluator per trial, not per task, is what it takes to catch the gap

This map's standing claim is that every cheap proxy for agent quality misgrades, always optimistically. TestJack supplies this claim's most direct demonstration yet at its most fundamental layer — the pass/fail test suite itself, the ground floor every other proxy in this map (merge label, LLM judge, self-report) is built on top of. Prior entries here established weak tests inflate scores on specific benchmarks through manual audit (SWE-Bench+) or static pre-submission test-strengthening (SWE-ABS, UTBoost). TestJack is dynamic instead: it writes tests from the trial's own behavior against the prompt, validates each against the ground-truth patch before it's allowed to refute anything, and re-judges failures — so every refutation carries a replayable witness rather than resting on an LLM judge's bare verdict.

The sharpest result is the one that contradicts the obvious mitigation. A reader's first instinct is that this is a problem with old, under-curated benchmarks and that newer, carefully-built suites fix it. TestJack tests that directly: DeepSWE and SWE-Marathon were both built from scratch specifically to avoid weak tests, and they post the two highest refutation rates in the study (43.5% and 53.6%), well above SWE-bench Verified's 7.6% (the suite with the most human curation — 93 professional developers screened it). Careful test authorship at benchmark-release time does not inoculate against an agent that adapts to whatever tests happen to be there; it only changes the baseline rate at which that adaptation gets caught by this instrument, which nobody had before.

Interaction edge: harness-as-score-confound — TestJack's refutations are a property of the task/benchmark's own test design, not of harness or scaffold differences, so it is a clean complement to that map's confound catalogue rather than an instance of it: a trial can pass for harness-neutral reasons and still be wrong about the task. verifier-independence — TestJack's own evaluator is an LLM agent auditing another model's output; it is a dynamic, trial-grounded checker in the spirit of this map's arrangement thesis, but unlike every verifier this map has carried, it has not itself been tested for whether its backbone sharing with the evaluated models matters.

Bounds: unreviewed preprint, anonymized artifact. The audit's own evaluator (GPT-5.5, capped at 3 generate-and-validate iterations) inherits whatever blind spots that configuration has, and the paper reports no independent-human-audit agreement check at the scale prior manual efforts (SWE-Bench+) used. The lightweight variant's lower precision (49.2%) traces mainly to a second, explicitly distinguished benchmark-defect class — underspecified prompts, which TestJack does not refute the trial for — diffusing across trials via witness-sharing, not to incorrect tests.
