Learn when to stop, not just which model

route-the-session-not-the-query established that agent spend should be allocated sequentially, under a global budget, by a policy learned offline rather than greedily per query. SCATE reaches the same structure from a different object. SeqRoute routes models; SCATE allocates iterations — including the decision to quit — with a LinUCB contextual bandit over three actions (Default, Analysis, Stop), driven by seven cheap observable features (LOC, weighted methods per class, response-for-class, current line/branch coverage, missed complexity) under an explicit cost penalty. It beats both the greedy baseline and the fixed schedule: more coverage, higher mutation score, and lower cost than a forced 8-iteration run.

Different objects, same economics — which is what lets this count as confirmation of the shape rather than of the number. The map's founding claim generalizes: the unit of routing is the next increment of effort.

The new instruction is the agent-conditional one, and it is immediately actionable. The same framework, with the same features and the same reward, learns opposite policies for two agents: against Claude Code — whose zero-shot output is already strong (84.3% line coverage at iteration 1) — it learns to stop early on 95% of classes, averaging 2.1 iterations. Against the weaker, cheaper Gemini-CLI it runs 7.9 iterations and reaches for the analysis tool three times as often. So the fixed iteration cap that ships as the default in essentially every agent harness is wrong in both directions simultaneously: it over-spends on the strong agent that finished at iteration 2, and under-spends on the weak one still climbing at iteration 8. This is the sibling of agent-cost-spans-orders-of-magnitude — quality-parity does not imply cost-parity, and now iteration-parity does not imply value-parity.

Honest scope. This does not replicate SeqRoute's specific result (6–73.5% cost savings from budget-aware model routing remains one setup's number, unconfirmed). What replicates is the structure. The policy is also not transferable: each agent gets its own retrained policy, at a real one-time cost ($48.40 / 13 hours for Gemini-CLI; $127 / 22.7 hours for Claude Code) — there is no zero-shot cross-agent transfer experiment, and the paper does not claim one. And "cost-effective" is not uniform: SCATE is ~13% cheaper than the Default-8-iteration baseline but ~22% more expensive than the Analysis-8-iteration one, which it beats on quality.

Caveats: Java only, Defects4J only (a corpus heavily represented in LLM training data — contamination risk on absolutes, which the authors mitigate by leaning on relative deltas), 120 classes, single study, code not yet released.
