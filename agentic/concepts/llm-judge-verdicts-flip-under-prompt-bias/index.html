The map's LLM-as-judge reliability strand gets its sharpest single-paper effect size yet: a 74.7-point verdict swing on the identical code pair, purely from how the prompt frames it, with unit-test judging the most fragile of three SE tasks

This map's proxy/judge-reliability strand has already established that LLM-as-judge results in software engineering carry systematic biases (position effects, self-enhancement, verbosity preference) that can change which candidate "wins" a comparison. Bias in the Loop sharpens that into a controlled, quantified design: hold the underlying code artifact fixed, vary only the prompt's presentation of it, and measure how far the verdict moves. The headline number — a 74.71-percentage-point swing on the same A/B pair, from 88.12% to 13.41% A-correct, driven purely by a "refined" prompt framing — is among the largest single bias effect sizes this map carries for any SE judging task. The chain-of-thought result on code repair adds a distinct failure mode beyond magnitude: the same bias treatment moves the verdict in opposite directions depending on which side (A or B) happens to hold the correct answer (67.38% → 79.02% vs. 67.38% → 32.64%), meaning the bias isn't a uniform inflation or deflation — it interacts with answer position in a way a single average bias-correction factor could not fix.

The task-level finding — unit-test-generation judging is consistently the most bias-fragile of the three SE tasks tested — is new to this map and matters directly for any pipeline (this map's and agentic-code-review's) that uses an LLM judge to grade generated tests rather than generated code: test-quality judging may need tighter controls than code-quality judging by this evidence.

Scope: three judges, none current frontier-class (no Claude Opus- or GPT-5-class judge tested), all three tasks drawn from one benchmark family — whether the swings shrink on a frontier judge (increasingly what production LLM-as-judge pipelines actually deploy) is untested here. stance: pushes-back against any note in this map that reports an LLM-judge comparison without controlling for prompt presentation; no specific prior note in this map makes an uncontrolled point comparison claim, so no back-edge target exists yet — flag for future rebuttal-linking if one is added.
