The retrieval metric got worse by a factor of nine and the outcome did not notice

This map's organizing claim is that acquisition is a real, separately scoreable stage — that a benchmark reporting only end-to-end resolve rate is hiding a retrieval failure (context-acquisition-is-an-unmeasured-failure-surface, retrieval-benchmarks-omit-the-quality-axis). This result holds the claim's first half and breaks its second. Scoring retrieval separately is right. Assuming the score predicts the outcome is not.

Expose the entire skill library at execution time, preselect nothing, parse which skills the agent actually opened, and grow the pool from 5 to 100. Actual-use precision collapses 29.6% → 3.3%. Downstream success goes 36.4% → 39.3% — flat for one stack, rising for the other (35.4% → 42.0%). Recall stays at 54–74% while precision sits at 0.7–8.1%, which says exactly what is happening: the agent opens the right thing along with several wrong things and does not restrict itself to the annotated ground truth. It does not need to. Related-but-not-labelled skills still carry usable procedure, and the labelled one is not always what unblocks the task.

The consequence for anyone scoring a retrieval stage: ground-truth overlap is a measurement of the annotation, not of the acquisition. It is the same failure this vault flags in proxy metrics generally (proxy-metrics-rank-models-not-suites, resolution-rate-is-not-precision) arriving at the retrieval layer, and it means a pipeline diagram of retrieve → use → succeed is the wrong model: the paper deliberately runs its three arms as independent measurements with no output passed between them, because they are not stages.

Two things that do degrade cleanly are worth keeping. Offline identification falls on confusability, not size — embedding top-1 precision drops 70.5% → 53.4% on semantically similar distractor pools while random pools only go 97.7% → 84.1% — and explicit agent selection is worse than embedding ranking throughout. So if there is a real acquisition problem in a skill library, it is near-duplicates, which is precisely the shape of the published population (the-skill-population-is-half-copies-with-no-registry).

Bounds. One benchmark with ground-truth task–skill annotations; two agent–model pairings, one of them substituted for availability, so the numbers are within-pairing comparisons and not comparable with the study's other experiments.
