A harder, brownfield-scale version of this map's founding claim: even when the requirement arrives whole and reconstructed, not piecemeal, full delivery is still rare — individual correctness is not the bottleneck, integration and completeness are

This map's founding claim is that the specification is a contract that must be held outside the agent, and its SLUMP evidence already showed that even when requirements are held constant, how they arrive (single-shot versus emergent across many turns) swings resolution 16/20 papers for Claude Code. This source holds the arrival constant too — PRDs here are reconstructed into a single standalone document, consolidating a full multi-turn conversation plus later clarifications before the agent ever sees them, so the piecemeal- delivery failure mode SLUMP measured is specifically controlled for. Full delivery is still rare (14% at best), and the authors' own failure attribution names a different mechanism than this map's prior sources: not a decayed or lost requirement, but incomplete implementation and missing cross-module integration at real brownfield scale (median 1,465 changed lines across 15 files) — the agent builds working pieces that individually pass their own criteria (weighted scores reach 78.1/100) without assembling them into the whole the PRD asked for. This adds a scope condition to the map's "hold the contract outside the agent" prescription: holding the contract outside and presenting it whole is necessary but, at this task scale, not sufficient — the gap this source measures sits downstream, at the point where individually-correct parts must compose.

Interaction edge: agentic-code-review — a benchmark that can tell "agent built one more broken component" from "agent built every component but didn't wire them together" is exactly the criterion-level diagnosis a reviewer needs to target effort; this source's layered evaluator (structural check, call-graph- scoped evidence gathering, semantic judgment) is a candidate instrument for that map's review-cost thread, not yet cross-linked there because no agentic-code-review source has used criterion-level PRD coverage as its unit.

Bounds: single-company source corpus (Alibaba Taobao/Tmall, two ecosystems); "complete delivery" is a binary gate per task despite the weighted-criterion scoring underneath it, so the 14% figure is sensitive to how generously the per-criterion weights already forgive partial credit; the evaluator's reported accuracy is benchmarked against this paper's own expert panel, not an external ground truth.
