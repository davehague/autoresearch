The stale-convention-file finding gets its missing mechanism: it isn't that the agent blindly obeys whatever document it reads, it's that repository precedent specifically outranks the agent's own defaults, and a written priority clause is what lets a new instruction break that ranking

This map's sharpest practice-facing result is that a stale convention file beats no convention file at all — the agent follows the document in all 39 trials regardless of whether it's right (a-stale-convention-file-costs-more-than-no-file), and a follow-up mechanism result shows the agent defaults to treating an instruction file as instruction and surrounding code as mere tool output, a ranking one added sentence can reverse — stale-rule-following holds at 90.1% even when the agent flags the conflict, and one priority sentence reverses it to 91.4% code-following with zero unwanted rewrites (added to this map's Status block, 2026-10-23). This paper runs the complementary experiment: instead of document-vs-code, it isolates default-preference-vs-precedent-vs-instruction as three separate sources of guidance, and finds the agent's own defaults lose to repository precedent almost every time precedent is present at all — even before any written instruction enters the picture. That sharpens rather than contradicts the existing findings: it is not merely that agents over-trust documents specifically, it is that un-authored, implicit precedent (ordinary existing code) already outranks an agent's own judgment, and an explicit document is simply the loudest, most legible form that ranking takes.

The form-sensitivity result (three local files vs. sibling-resource files vs. file location alone) is new to this map and gives the persist-and-deliver sub-thread a concrete, actionable lever: where and how a precedent is expressed changes how strongly it is followed, independent of what the precedent actually says. And the written-priority-rule result extends the map's instruction-channel-framing finding with the other half of the fix — not just "tell the agent code outranks the document" but "tell the agent explicitly which source wins when they conflict," which is the general form of the one- sentence fix that reversed stale-rule-following to 91.4% in the prior finding.

Bounds: controlled purpose-built repositories first, validated in only four real repositories across three languages; six author-curated implementation-choice pairs, not a broad sample of real-world precedent/instruction conflicts; four coding agents, not a harness sweep; the priority-rule result compares one phrasing against one alternative, not a sweep of instruction framings.
