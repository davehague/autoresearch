The apparatus term doesn't just exist — it has a sign that flips with model strength and task type, and a controlled ablation shows why: harness components net out to a mixed sum, not a uniform boost

This map's Binding Constraint Thesis and its dozens of grid/swap studies establish that the harness is a term of the order of the model in score variance. This source is the first here to decompose that term into two moving parts at once — model strength and task type — on the same benchmark family, and then open the harness itself to show why: a controlled five-component ablation (NanoHarness) finds the "harness effect" is really a signed sum, with context compression and general (non-task-specific) subagents costing points at the same model and task where tool registries and task-specific subagents gain them. That reframes every whole-harness swap this map has already logged (dozens of them) as measuring a net that could be hiding components pulling in opposite directions — a harness that "does nothing" in a marginal comparison could still contain a positive lever and a negative one that cancel, exactly the same shape this map's 2026-09-14 native-vs-neutral-harness arrival found at the task-type level (a null average masking a -9.0pp/+23.7pp task-type interaction).

The model-strength-dependence half connects directly to the map's existing "capability moderates the apparatus term" instances (the optimizer-capability result, the adaptive-vs-scripted RCA framework split): as a model gets stronger, an increasingly large share of what a heavy harness used to supply (structured exploration, tool discipline) the model begins supplying itself, so the harness's marginal contribution shrinks toward zero on tasks the model can already handle — but the same source shows the opposite holds on tasks that are harder for the model (open-ended repository generation), where only the strongest models can even make productive use of the harness's extra structure. That is a genuinely new instance for this map: harness benefit is not monotonically decreasing in model strength, it is conditional on whether the task sits above or below the model's unassisted capability ceiling.

Scope: limited to five ablatable components (others — retrieval strategy, verifier design — untested); component-ablation concentrated on ProgramBench rather than run identically across all three benchmarks; restricted to Qwen/DeepSeek open-weight families, no frontier closed-weight model in the controlled ablation; single-seed reporting per configuration at temperature 0, which this map's own serving-cache and inference-backend arrivals have shown is not sufficient to guarantee reproducibility even at temperature 0.
