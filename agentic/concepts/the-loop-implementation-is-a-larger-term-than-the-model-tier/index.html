The loop is the second half of the pair

This map holds that a published number is jointly produced by the agent and the apparatus, and that the apparatus term is the size of the effect being reported. Every instance so far has varied the harness — the tools, the container, the wrappers, the serving stack. LoopsBench varies the layer above it: the loop, the control surface carrying objectives, progress criteria and residual work across an extended run. Its central design choice is that the loop implementation is a named, swept variable rather than an unstated constant, and the paper's title states the thesis directly.

The sweep is the cleanest cross-harness grid this vault has ingested for coding agents, because it is crossed in both directions on one benchmark. Hold the model at gpt-5.4 and vary only the loop: 18.75% (Codex) down to 7.14% (mini-swe-agent), 11.6 points absolute and a 2.6× ratio. Hold the loop at Claude Code and vary the model across eight backends: 25.00% (Opus-4.7) down to 4.46% (Grok-4.1-FR). The two spreads are of the same order. A comparison that reports one and not the other is reporting a term of a sum and calling it the whole.

Three secondary readings sharpen it.

The continuation policy alone is worth several points, uniformly. Every cell in both sweeps gains 3.6–8.0 points from adding an outer continuation loop, with nothing else changed. That is a single boolean in the runner, and it is larger than most published model-to-model gaps in this vault.

The loops differ structurally, not just in strength. Closed-source loops recover more of the prerequisite DAG (Edge F1 0.71/0.67/0.58) and organize execution as a tree, sitting slightly above the reference concurrency budget; open-source loops driven by linear control flow form a near-chain (critical path ratio 0.85–0.97, width ratio 0.24–0.39) and produce patches 2.3–2.5× the gold length against 1.6–1.8× for the closed ones. So the loop term is not a scalar you could hope to correct for — it changes the shape of what the agent does, which is no-harness-ordering-holds-across-models's interaction-not-offset finding arriving one layer up.

The benchmark-to-benchmark gap is the map's disclosure argument in one figure. The strongest configuration here resolves 25.0% where top solve rates elsewhere read 95.0, 83.4, 80.0 and 64.4. Some of that is task difficulty. But the instrument difference is the point: end-state benchmarks score a submitted artifact, and LoopsBench scores the loop state that produced it — releasing tests along the dependency frontier and keeping completed units enforced. A metric that never asks whether the run kept its earlier promises cannot report a loop that drops them (context-renewal-does-not-discharge-a-completed-obligation).

The rule this adds to the map's existing pair — treat a single-harness leaderboard gap under ~10 points as unresolved; a model evaluated on someone else's harness has not been evaluated for your system — is a third field for the harness card, and it is the one nobody prints: the loop implementation and its continuation policy. A resolve rate published without them is 11 points of somebody else's runner.

Rebutted by: the-apparatus-term-collapses-inside-the-adaptive-band — the loop term is not uniform across the design space. Six frameworks at a fixed model span 37 points, which is this claim at its strongest, but the three that run an open-ended adaptive investigation span only 2.0 points among themselves while a backbone swap moves the same framework 10.8. Holds where the compared loops straddle an architectural boundary; inside the adaptive band the model is the dominant lever and a loop swap resolves almost nothing — so the sampling of loops, not their count, decides what a grid can detect.

Bounds. One benchmark, single configurations per cell in the main tables (pass@K appears in an appendix only as a within-family monotonicity check), so the spreads carry no intervals. The loop sweep pairs each frontier model with the vendor infrastructure it is typically deployed under in the model dimension, which is realistic and not fully crossed — the fixed-model loop sweep is the crossed arm and it uses one model. The recovered DAG is a conservative lower bound on prerequisite structure, so planning-fidelity numbers are floors. Metrics bind to the released suite rather than to semantic equivalence.
