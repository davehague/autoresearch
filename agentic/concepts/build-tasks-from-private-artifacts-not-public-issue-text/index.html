The first contamination lever upstream of the run — and the experiment that would validate it is missing

This map's contamination limb is three diagnoses and one containment remedy. benchmark-scores-inflate-when-agents-can-retrieve-the-fix found 63% of a frontier agent's SWE-bench Pro successes retrieved rather than derived; search-time-leakage-inflates-web-agent-scores replicated the leakage in a second domain from an independent group and taught the map its sharpest rule — prevalence is not inflation, measure the counterfactual; and constrain-the-eval-environment-to-measure-capability is the fix, at the environment layer: strip .git, deny egress by default.

Every one of those operates at run time. They stop the agent reaching the answer. None of them touches the channel that survives a sealed container: the task text itself being in the training data.

Construction-time resistance is the missing lever. If the prompt an agent sees never existed publicly — because it was reverse-engineered from a private commit and rewritten as a colloquial role-played request — then there is nothing to have memorized in that form, whatever the sandbox permits. And unlike secrecy, it does not decay the moment the benchmark is released, which is why the authors can ship the whole thing publicly and rest resistance on "this construction together with dataset versioning rather than on secrecy." That is a materially better bargain than the held-out-test-set treadmill: reproducibility and resistance at the same time.

Then the map's own rule applies to it. No contamination number is reported. There is no arm comparing these tasks against a public-issue-derived set, no memorization probe, no leakage estimate. By the standard this map set on 2026-07-13 — prevalence ≠ inflation, measure the counterfactual — a construction claim with no counterfactual is a design argument, not a result. The authors also name the two channels they do not close: the underlying commit or PR code may already be in training data (only the request phrasing is novel, and the fix is what a model would need to have memorized), and the public release is "exposed to being scraped into future model training data."

The residual claim is worth adopting anyway, because it is nearly free: reverse-engineer tasks from artifacts that were never issue text, and version the set. Whether it buys anything measurable is a cheap experiment nobody has run, and it is now this map's most concrete open question on the contamination limb.

Caveats: T1 with a full public artifact release, but the central contribution is untested by its own authors. Python dominates the Code subset; LLM/VLM judges grade two of four subsets (llm-judges-have-exploitable-biases); and one headline cell was run under a different instruction from every other cell, which the authors disclose. Suggestive.
