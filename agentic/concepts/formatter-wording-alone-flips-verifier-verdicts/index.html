A verifier's job is to check what a tool actually did — but it only ever sees what the tool's formatter chose to tell it, and that wording alone can flip every verdict

This source names, and then experimentally demonstrates, a mechanism this vault's verifier- independence and harness-as-score-confound threads have mostly inferred from indirect evidence: a verifier or judge that reasons correctly over the information it is given can still be systematically wrong, because the tool-output formatter sitting between the actual computation and the model's view of it silently drops scope, completeness, uncertainty, or provenance information. The author traced this to real misgrades in a production RAG research system before building the controlled test: feed the same real tool result through two formatter versions — one that omits a detail (search limits, result caps, identifier namespace), one that states it — to agents and separately to verifiers, with nothing about the underlying tool call changed.

The result is close to a clean experimental flip rather than a correlational observation: on a fixed-answer measure, three verifiers across three model families accept the identical false answer 90 times out of 90 under the warped wording, and reject it 90 times out of 90 under the clear wording. A control rules out "verifiers just need to try harder": giving verifiers the missing facts and asking a correctness question rejects all 46 tested warped-wording false answers (0/92 accepted), while asking only "is this supported by the output" with the same warped text accepts 88/92. The fix is the missing information, not more scrutiny — a verifier cannot independently recover information its input never carried.

The asymmetry across failure types is itself informative: unsupported agent overclaims drop sharply for Scope, Completeness, and Uncertainty (62-92 percentage points) when wording is clarified, but barely move for Provenance (100% -> 94%). The author reads this as evidence that provenance gaps specifically need enforcement through types or validation, not prose — clearer wording alone doesn't close that one.

Field evidence that this isn't one system's idiosyncrasy: a frozen audit prompt, run once via Codex and Claude Code, found the same formatter-warping bug class live in two unrelated, independently- maintained open-source agent systems — OpenClaw's attachments_fetch (fix PR merged upstream) and Hermes's search_files (issue/PR still open) — at a total cost of $74.44.

Bounds: one production system examined by its own author, with adversarially-selected cases — the reported rates describe a stress test of a known mechanism, not a field base rate; the harness omits the production system prompt and multi-step tool use; the "clear" condition bundles disclosure with handling instructions, so the effect can't be cleanly attributed to disclosure alone; grading relied mainly on model-consensus with limited human calibration; only three model families tested; the audit-prompt demonstration was not formally evaluated and its author already knew the system's defects going in.
