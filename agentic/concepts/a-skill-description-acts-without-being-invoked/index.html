The resident half of a skill is an unconditional intervention

memory-delivery-not-storage established the retrieval side of this: content sitting in a connected store that the agent knows about and is told to use drew 0 memory calls in 114 turns, while the same notes injected deterministically by the harness arrived every time. The vault's rule became persist the contract — and deliver it.

This is the same boundary measured from the other side, and it is the cost. The delivered half — the description that stays in the system prompt at every step — acts whether or not it is wanted. In the worked case an agent answers a numeric question correctly with no skills, and incorrectly, in the same way, under three different libraries none of which it ever invoked, with the divergence tracking words in two descriptions whose bodies were never opened. Methods that mask retrieval or count invocations are blind to this by construction, which is why the recommended ablation has three arms rather than two.

The channel is net positive and should not be read as an argument against skills: on the two stacks where bodies were rarely loaded, 84–100% of the gains were also invocation-free. The point is that presence is not neutral in either direction. A description is not an index entry; it is instruction text the model reads on every step, and it competes with the task the way any other resident context does.

This puts a magnitude on the boundary one-level-of-disclosure-is-enough found from the accuracy side. That result showed a second routing level — per-chunk descriptions promoted to always-loaded — collapsing accuracy by up to 36 points, because the always-resident index recreates exactly the pressure disclosure exists to relieve. A skill library is one level of disclosure, and this measures what its resident layer costs when it is doing nothing else. The operational consequence is unglamorous and concrete: the number of skills installed is itself a context-engineering decision, independent of whether any of them fires.

Caveats: office-automation benchmarks; labels assigned by a single author from observational paired trajectories with no inter-coder agreement and no controlled content intervention — the authors explicitly ask for the latter as the validating next step. Presence-only flips with no corroborating influence evidence were classified as noise rather than osmosis, which is the right conservatism but leaves the estimate a lower bound. Suggestive, one study.
