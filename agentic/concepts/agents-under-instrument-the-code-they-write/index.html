Agents under-instrument the code they write

Every source in observability so far concerns observing the agent — reasoning spans, process defects, pipeline stages, supervisor coverage. This one concerns the observability of the system the agent builds, and finds it degrading. Across 81 repositories, human PRs change logging more often than agentic PRs in 58.4% of them. The higher log density agents show when they do log turns out to be mostly a PR-size composition effect: agents' log-adding PRs skew smaller (median 1,279 vs 2,770 LOC), and once size is controlled the difference nearly disappears (1.64 vs 1.59 logs per 1,000 LOC).

Where the divergence is real is placement. Agents track human practice closely in try/catch blocks (58.4% similar) — the mechanical, pattern-matchable case — and diverge most in conditional branches (46.7% similar) and loops (41.5% similar), which is exactly where informational logging earns its keep and where a human decides, from context, that a future maintainer will need to know what happened. The agent writes the exception handler it has seen ten thousand times and skips the judgment call.

The consequence lands on the rest of the vault rather than inside this map. unattended-operation's entire operator surface — structured logs, stall detection, first-responder orchestration — assumes the code under the agent is instrumented. observability's in-loop audit window (decisive-errors-strike-early-and-surface-late) assumes the trajectory contains catching evidence. Both assumptions get quietly cheaper to violate as more of the codebase is agent-written. Nobody has priced this: the study measures the instrumentation gap, not its downstream cost — no incidents, no MTTR, no debugging-time data. That the gap exists is measured; that it hurts is inferred.

Pairs with instructions-fail-to-govern-non-functional-requirements (telling the agent to log does not work) and humans-silently-repair-agent-code-outside-review (someone fixes it later, off-review).

Caveats: observational; Python/Java/JS-TS only; repos ≥100 stars; the paper does not attribute PRs to named agents, so no per-agent comparison is licensed. Logging detection validated at 96% precision / 94% recall on 380 diffs.
