The component worked because the experiment told it the answer

This map's null family each name the number a result would show if its claimed mechanism did not exist: a paired same-model floor (coordination-deltas-need-a-measured-noise-floor), a content-free placebo (a-retry-study-needs-a-placebo-arm), a majority-class baseline (skewed-label-bases-inflate-classifier-headlines), a composed stage product (a-long-horizon-claim-needs-a-composed-stage-baseline), an always-serial reference (a-coordination-arm-needs-an-always-serial-reference), and — closest to this one — a no-router ablation that sends every task to one model with the rest of the pipeline intact (a-routing-claim-needs-a-no-router-ablation).

This is the sibling for detection and repair claims, and it is cheaper than any of them: keep the component, keep its licence to act, and take away the privileged fact the harness was quietly feeding it.

The setup credited a model-driven router with containing latent cascades — recovery 0.83 against a 0.08 baseline, cascade radius cut roughly 5.5× at depth 7, and an effect that grew with pipeline depth, which is exactly the shape a real containment mechanism would have. Then the authors noticed their own policy semantics: at the injected stage the router was handed the trusted upstream value and licensed to correct the anomaly. Re-run as an independent larger sweep with a llm_noupstream arm — same self-correction licence, no trusted value — recovery falls 0.67 → 0.08, a paired drop of 0.58 [0.33, 0.79] at p = 5.19×10⁻⁴. The router was never detecting the fault. It was repairing a fault the experiment had already localized for it.

The general form is worth stating plainly, because the leak is almost always in the plumbing rather than in the prompt. Any experiment that measures a component's ability to notice something must ask what else in the harness already knows. A verifier handed the reference solution. A repair loop given the failing test's name. A monitor whose input is a trace the injector annotated. An attribution agent scored on traces where the injected step is the only one with a timestamp gap. In every case the component will perform, and the performance is the harness's, not the component's. It is a-verifier-sharing-the-interpretation-shares-the-error and an-evaluator-sharing-its-reference-solver-cannot-be-self-checked pointed one layer out: not a shared error, but shared knowledge that the deployment will not have.

What survives the ablation is the part worth acting on. The Oracle row — routing to the gold repair — still contains fully, so containment is achievable given the signal; the finding is that producing the signal is the open problem, not consuming it. That is the same conclusion the fault-tier result reaches from the behavioural side (recovery-is-a-property-of-the-fault-not-the-model): detection and attribution are the necessary mechanism and no amount of licence to self-correct substitutes for them. If your orchestration layer contains cascades in staging, check whether staging is handing it the trusted upstream value that production will not.

Credit where the method earned it. The paper ran this ablation against its own most impressive row and demoted the row rather than the ablation, then reported the demoted version as the headline-adjacent result. It also picked its instrument for the right reason: with small, often-separated paired samples the percentile-bootstrap p collapses to 0 whenever every paired difference shares a sign, so an exact sign-flip permutation test is the honest choice — a concrete instance of report-a-null-as-a-bounded-interval-not-a-failed-test's discipline applied at the test-selection step.

Bounds. n=24 pairs on the ablation, one benchmark construct — a single Claude agent over a synthetic verifiable arithmetic chain with prompt-level injection, not a wired multi-agent system — and the trusted upstream semantics were themselves a modelling choice the authors made and then interrogated. The ablation is one arm on one system, so this is a demand the vault can now name with a worked example, not a rate at which the leak occurs in the literature.
