The pair thesis, finally with a distribution instead of an anecdote

This map holds that the harness-model pair is the unit that fails, and it has four dependent variables to show for it: security detection reversing on a harness swap (install-time-security-is-a-harness-model-pair-property); 255 field bugs that need both components to explain, with the same trigger crashing 79% in one framework and 2% in another (agent-reactive-bugs-need-both-components-to-explain); an industry cost study that could not attribute its result to model or harness at all (attribute-performance-to-the-stack-not-the-model); and a progressive-disclosure pack worth double digits under one harness and exactly zero under another (progressive-disclosure-buys-context-not-intelligence).

Every one of those is an existence proof — here is a case where the harness mattered. This is the first source to hold seven models fixed, vary only the harness across a whole benchmark, and report the distribution: a mean absolute shift of 8.6 points on one subset, 13.5 points in the worst cell, and — the part that matters for anyone reading a leaderboard — rank order changing.

That converts the pair thesis from a caveat into an arithmetic problem. Frontier models on this benchmark separate by roughly 2–14 points on the Code subset. The harness term is 3–6 points there and 8.6 on Security. The measurement error introduced by an unreported harness choice is the same order as the model differences being reported, which is the same structural finding as the paired coordination noise floor (coordination-deltas-need-a-measured-noise-floor) arriving on a different axis: not run-to-run variance, but a systematic term nobody discloses. It is the concrete cost of agent-benchmarks-underdisclose-their-harness and the reason benchmarks-conflate-model-harness-and-penalize-alternatives is not a purist objection.

Two practical rules follow. Reading: a model comparison that does not name the harness — and hold it fixed — has reported a sum, not a difference; treat single-harness leaderboard gaps under ~10 points as unresolved. Building: since the harness contributes points on the same scale as the model, evaluating a candidate model on your own harness is not optional diligence but the only measurement that describes your system (re-examine-the-harness-when-the-model-changes).

The shift is also not uniform, which is the detail that forbids a correction factor: Code shifts mostly upward for everyone, while Web reverses orderings and Security spreads widely. There is no scalar offset to subtract. The pair is genuinely joint.

Caveats: two harnesses only, one of them the publishing vendor's own product — though the harness finding cuts against that product in several cells, which raises rather than lowers confidence. Three runs per cell is thin for a variance claim (control-the-data-draw-before-the-seed would want more), and no intervals are given, so the 8.6-point mean absolute shift has no error bar. Two of four subsets are graded by LLM/VLM judges, and a judge could itself interact with harness output style (llm-judges-have-exploitable-biases) — the Security subset carrying the largest shift is deterministically scored, which argues against that explanation for the headline. Strong.
