A wrong value that surfaces ten steps downstream costs far more to diagnose than a hard stop at the seam

The seams cut across philosophy: the same kinds of fault line appear in a batteries-included Python framework and a minimalist TypeScript harness, which suggests they track the problem shape, not either design. That is the reason this belongs in an unattended-operation argument rather than only in a bug list — an operator running scheduled agents inherits these seams whichever harness they picked.

The four rules, stated as the author states them:

  • One mandatory canonicalisation point per trust boundary, and downstream accepts only the canonical form. The //secrets case is the cautionary one: the permission checks failed open while the adjacent read/write checks, which happened to normalise, were immune. A security control that is correct in three places and absent in a fourth reads, from outside, exactly like a control.
  • Errors carry a typed kind; regex is a last-resort fallback that must fail toward the safe side. Here that means do not compact when unsure — compacting a non-overflow is unrecoverable, while declining to compact a real overflow is not. The specimen is a transient throttle that cost a session its history.
  • Derive one async twin from the other or share a single guarded core; where both are hand-written, diff their guard clauses and test both halves against the same failure. Paired async written by hand is two copies of one intent the compiler never checks for agreement.
  • At every boundary, an unrecognised shape is an error, not a default. This is the cross-cutting one, and it is the reason the other three are expensive.

The asymmetry is the operational point. The recoverable specimen merely crashes. The irreversible ones delete a directory past a deny-rule, and overwrite conversation history. A harness is long-running and autonomous, so the cost of a wrong value is not the wrong value — it is the ten steps of work built on top of it before anyone notices. This is fail-loud-instrumentation-over-plausible-substitutes and silent-errors-dominate-agent-bug-reports reaching the same conclusion from the harness's own source; what this adds is that silent degradation was the default in every specimen examined, including in a harness whose own configuration layer raises in an analogous case.

Bounds. Explicitly presented as illustrative case reports, not an independent test: four seams induced from a small analyst-directed sample, some language-specific (the sync/async drift cannot arise in a single-threaded model), and S4 is a cross-cutting property rather than a fourth bin. Two specimens were re-derived in a sandbox; the rest were located by source reading. They suggest rather than establish that these fault lines track the problem.
