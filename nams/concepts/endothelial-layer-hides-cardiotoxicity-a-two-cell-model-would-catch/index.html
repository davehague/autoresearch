A cell type a simpler model omits can hide the very effect that model exists to catch

The finding, plainly

Most iPSC-cardiomyocyte cardiotoxicity platforms — including this vault's own cardiotoxicity-hipsc-cm-proarrhythmia — read cardiomyocytes alone or with minimal supporting cells. This source reports that adding a third, physiologically relevant cell type (vascular endothelium) to a cardiomyocyte+fibroblast model changes the measured result for at least one clinically important cardiotoxicant: doxorubicin's damage to cardiomyocytes essentially disappears once an endothelial layer is present, while the endothelium itself absorbs measurable harm. The authors' interpretation is that endothelial cells metabolize, sequester, or otherwise buffer the drug before it reaches the cardiomyocyte — a cardioprotective role invisible to any model that does not include that cell type.

Why this is a completeness question, not just a mechanism curiosity

Every NAM in this vault is built from a chosen set of cell types standing in for a whole organ. This source is a direct, quantitative demonstration that which cells are chosen changes not just the sensitivity of the readout but its direction — a model without the endothelial layer would call doxorubicin cardiotoxic to cardiomyocytes at this concentration; a model with it would not, for the cardiomyocyte compartment specifically, while still detecting drug-induced harm at the endothelial compartment. Neither reading is "wrong" — they are answering different, both real, questions ("does this drug damage cardiomyocytes when endothelium is present" vs "when it is not") — but a loop that has standardized on one cell-composition choice will get a directionally different answer than a loop that chose differently, for the same compound.

Relevance to the correlated-blind-spot rail

This is the opposite shape from the rail's usual instance. The rail describes two assays that agree because they share a blind spot, and an automated system reads the false concordance as confirmation. Here, two hiPSC-based cardiotoxicity methods sharing an origin (both derive their cells from human iPSCs, per cardiotoxicity-triculture-heart-on-chip's cross-intervention note) might instead disagree on the same compound, for a structural reason — one includes endothelium and one does not — that has nothing to do with which method is "more correct." A loop trusting agreement between hiPSC-based cardiotoxicity readouts should be equally alert to the possibility that disagreement reflects cell-composition choice rather than a real discrepancy in the underlying biology.

Honest ceiling

One laboratory, two compounds (only one — doxorubicin — shows the effect; isoproterenol was a barrier-function control), no blinded validation, no comparison to clinical outcome data, and no numeric decision rule of any kind. evidence_tier: single-lab-exploratory. Whether the endothelial-protection effect generalises beyond doxorubicin, beyond this one iPSC line, or beyond this specific chip geometry is not established and this note does not claim it is.
