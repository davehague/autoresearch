Getting the right answer and getting there the right way are different things to measure

automation-self-driving-labs declared a "verification" sub-thread at its 2026-08-12 review: is the measuring stick a loop would use to judge its own output actually sound. Most of this map's prior entries on that sub-thread ask whether an agent's final conclusion matches ground truth. ReplicatorBench asks a narrower and, for a loop, more load-bearing question: did the agent get there by doing the things a real replication requires, independent of whether its final label happens to be right.

The three-checkpoint structure

  1. Extraction — pull the claim's relevant details out of the source paper and retrieve the actual data resources needed to attempt a replication (not the code the paper may already ship with).
  2. Generation — design and execute the computational replication.
  3. Interpretation — read the computational output and correctly judge whether the claim's own preregistered replication criteria were met.

The paper's headline finding is a clean split: agents handle stage 2 well — they can design and run computational experiments competently — but stumble at stage 1, specifically at retrieving new data resources, not at the computation itself. That is a resourcing/retrieval failure, not a reasoning failure.

Why a loop should care about the shape of this failure, not just its existence

This vault's standing distinction between a closed-loop-ready assay's readout and its decision rule is a structural cousin of the same split: a machine-readable number is not the same thing as a sound interpretation procedure, and getting the first right says nothing about the second. ReplicatorBench shows the equivalent gap one level up — an agent that can competently run computation is not thereby an agent that can be trusted to have assembled the right inputs first. A closed loop that only checks "did the final number look right" inherits exactly this blind spot: it has no way to tell whether the agent quietly substituted the wrong reference dataset on the way there. That is the same failure shape as the correlated-blind-spot rail (shared/evidence-model.md) one level removed from chemistry — concordance at the output is read as confirmation, when the actual weak point was upstream and invisible from the final answer.

Zero chemical, biological, or toxicological content — the domain is social and behavioral science replications, drawing on DARPA's SCORE project's independent human-expert ground truth.
