Fencing the model in, rather than making it smarter

The problem being solved. The authors state it directly: large language models "often struggle with logical structures." That is the same failure the vault has now recorded from three directions — Hartung & Kleinstreuer's "AI does not necessarily deliver the exact same result for the same input every time" (ai-decision-rules-are-not-deterministic); the Lab Agent Protocol's finding that existing instrument standards were "built for deterministic software clients rather than probabilistic, goal-directed agents"; and ProtoPilot's self-evolving skill library, which makes a system non-reproducible even with frozen weights.

The proposed fix is architectural, not statistical. Rather than a larger or better-tuned model, the system wraps the agents in a logical scaffold:

  • symbolic relational learning — structure learned in a form that can be reasoned over, not just sampled
  • controlled vocabularies and structured experimental constraints — the agent cannot propose a well-formed-looking experiment that is meaningless in the domain
  • a graph database holding "all hypotheses, experiments and data" in machine-checkable form
  • "a novel representation of scientific hypotheses … using description logics" — a hypothesis becomes a formal object with entailments, not a sentence

Why this specific thing matters to this vault. On 2026-07-19 the vault ingested the Lab Agent Protocol and noted that its units/calibration/uncertainty-typed result schema answered Hartung's "lack harmonized ontologies" bottleneck — but LAP is a specification with no implementation and no adopters. This is the other half: an ontology-based scaffold actually built, actually driving instruments, and refereed. The two are complementary — LAP proposes how an agent should talk to a machine; this proposes how an agent should represent what it is trying to find out.

And it is the shape a regulator has already asked for, arriving from a third direction. Three sources now converge on the record being the hard part: ml-model-reporting-reproducibility counted the missing provenance in toxicology ML papers; ToxMCP built provenance bundles binding each numeric claim to a tool output; this encodes the hypotheses themselves in description logic so the chain of reasoning is inspectable, not just the numbers. A closed loop's problem is not only doing the science — it is being able to show afterwards what it did and why, which is precisely what FDA's credibility assessment exists to demand. None of the three cites the others.

The honest brakes.

  • No reliability numbers at all. This paper reports discoveries, not rates — no success-per-attempt figure, no failure count, no comparison against a human scientist, no ablation showing the scaffold is what made the difference. "Improves coherence and reliability" is the authors' claim, not a measurement in the abstract. Against ProtoPilot's 88.24% instrument pass rate and Pipette's 37–72% task success, this is the least quantified loop source the vault holds.
  • No toxicology, no regulatory endpoint, no hazard assay. Yeast metabolomics. The relevance is by transfer, and the vault says so.
  • Builders reporting their own system, as with every source in this column. funding_flag: none commercially — public Swedish and UK research funding, no platform being sold — but Ross King's group has advocated autonomous science since the original Robot Scientist. Consistent, not corroborating.
