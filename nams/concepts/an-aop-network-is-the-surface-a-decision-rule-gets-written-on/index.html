The scaffolding arrives before the rule, and this time it arrives before the battery too

Roughly two dozen method maps in this vault carry the same blocker in slightly different words: the assay produces a clean number and nothing published converts that number into a hazard call. The vault has catalogued three routes out of that state — a committee writes a rule (OECD Guideline 497's two-out-of-three logic; Test Guideline 439's viability cut-off), somebody waits for potency data that does not exist, or a model is fitted to the published record (quantitative-aop-probabilistic-modelling).

This source is the first route, caught in the middle of happening, on the endpoint where the vault knows the most about what is missing.

The thyroid is the one modality of the four-part core of endocrine screening with no adopted non-animal Test Guideline anywhere — 67 in-vitro methods catalogued in 2024 by this paper's own lead author, zero adopted, one already failed in validation. See endocrine-thyroid-disruption-nams. What arrives now is not a method and not a rule. It is a modular adverse outcome pathway network — the causal diagram of how a chemical disturbs thyroid hormone, decomposed into separable modules — with the existing methods pinned onto the specific steps each one can observe.

Why a mapping is a real advance and still not a rule

What a mapping gives you. Before it, "run the thyroid panel" is a list of assays. After it, each assay has a stated position in a causal account, so two results can be combined rather than merely counted. It also makes the blanks visible: a component of the network with no method mapped to it is a research gap that can be named and funded rather than a silence.

What it does not give you. Nothing here states what pattern of results across the network constitutes a positive. The step from "these three key events fired and that one did not" to "this chemical is a thyroid disruptor" is exactly the step every automatable-open-loop map in this vault is missing, and it is still missing. The destination is "a future update of OECD Guidance Document 150" — the standing manual for interpreting endocrine test results — which is an intention held by researchers, not an instrument adopted by a regulator. regulatory_status: proposed.

For a loop, the sequencing is the interesting part

The vault flagged, on 2026-07-13, that thyroid was the one place where its correlated-blind-spot rail could be applied before the concrete sets — the battery does not exist yet, the methods are in validation right now, and how they will be combined is still being decided. Every other blind spot in this vault was found in a battery assembled decades earlier, where the finding could warn and could not change the design.

This source is that moment arriving. The composition of the future thyroid battery is being argued in public, from a causal account, with the method-to-component mapping written down. Two questions the vault has already prepared are answerable now and will not be later:

  1. Do any two mapped methods sit on the same node of the network? The vault already flags TTR-ANSA and TTR-FITC as one vote rather than two — same molecular initiating event, same assay principle, different fluorescent probe. A network with methods pinned to nodes makes that visible by construction, for every pair, instead of by inference from a taxonomy.
  2. Has anyone run a metabolically activated thyroid-hormone displacer past the cell-free arm? The map's domain_gate records that the transthyretin assays have no metabolic competence, so a chemical whose metabolite does the displacing reads negative. Tonight's other ingest (metabolic-competence-did-not-subsume-the-simpler-model) is the first measured attempt anywhere in this vault to test whether adding metabolic competence fixes that class of miss, and the answer was partial and bidirectional.

Neither question is asked in the retrievable text, and both are cheap to ask of a framework that is still being drafted. Logged in docs/open-gaps-log.md.

Rebutted by: the-key-event-network-is-a-function-of-the-system-it-was-read-from — a qualification of the surface, arriving the same night from an unrelated endpoint. This note treats a mapped adverse-outcome-pathway network as the stable object a rule would be written on. Reconstructing such networks from a curated multi-system toxicogenomic collection returns networks that reconfigure by biological context: shared early perturbations diverge across systems into organ-specific outcomes, and a conserved core is reached by system-specific routes. A rule written over one is fixed only after somebody specifies which biological system it was read from, and no framework in this vault — including the thyroid one — states that argument. The surface is still worth building; it is a surface with a coordinate nobody has labelled.
