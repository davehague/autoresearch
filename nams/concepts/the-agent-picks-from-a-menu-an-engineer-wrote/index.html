The containment boundary in an agentic lab is a list of pre-approved verbs

This vault has ingested eleven self-driving-lab architectures. They differ in transport protocol, in orchestration model, in whether the agent is one model or six. They agree, without discussing it, on one thing: the agent never writes the code that moves the hardware.

PUDA is the first to say it as a design principle rather than an implementation detail.

"Edge services expose only reviewed driver methods, so an agent can request an action but cannot rewrite device-control code during a run."

What that actually means

Two ways to build an AI that runs a laboratory:

  1. The agent generates instructions — code, G-code, protocol files — and the hardware executes what it generated. Flexible; the agent can attempt manipulations nobody anticipated.
  2. A human engineer writes each physical operation in advance as a named command with typed parameters and allowed ranges. The agent's job is to pick which command, with which arguments. It cannot invent a thirteenth verb.

PUDA is emphatically the second, with a validation gate in front of it: "Before any command reaches hardware, PUDA checks that the requested operation uses a known command name, required inputs, valid parameter types, and allowed value ranges."

An agent operating this laboratory has the expressive power of a menu.

Why this belongs in a toxicology vault

For discovery chemistry the constraint is a real cost — an agent that cannot author a new manipulation cannot find one, and a large part of the self-driving-lab pitch is finding things people did not think to try.

For regulatory toxicology the constraint is the requirement. An OECD Test Guideline is a fixed sequence of physical operations with specified parameters and specified ranges. The whole point of an adopted guideline is that the procedure does not vary with who runs it. A laboratory automation layer whose action space is a reviewed, typed, range-checked list of pre-authored operations is not a compromise against guideline compliance — it is a fairly direct encoding of it.

Nobody in the eleven prior architectures says this, and neither does PUDA, whose references are entirely materials and chemistry. It is recorded here as the vault's observation about a property the source documents, not as a claim the source makes.

What it does not touch

The half that is empty.

"PUDA does not decide which hypothesis to test or which experiment is scientifically optimal. The agent owns that reasoning."

Which is to say: the same gap. This vault's blocker inventory is dominated by methods whose readout is machine-perfect and whose interpretation has no published rule. PUDA makes the execution layer auditable, deterministic and replayable, and explicitly hands the interpretation back to an unspecified agent.

Two of the vault's sources have now measured that unspecified agent's execution reliability and found it the weakest link; none has measured its decision reliability at all (automation-self-driving-labs). PUDA adds a twelfth architecture and a zero-th measurement.
