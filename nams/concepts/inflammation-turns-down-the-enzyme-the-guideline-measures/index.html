The adopted test measures how much a chemical raises an enzyme — in a cell whose baseline an immune state can lower

OECD Test Guideline 445A (adopted 2026) asks a bounded, quantitative question: does this chemical increase the amount and activity of the liver's cytochrome P450 drug-processing enzymes in HepaRG cells, by how many fold, against defined positive controls. The readout is machine-read and the interpretation rule is fixed, which is why this vault grades it closed-loop-ready.

This study, in the same cell line, shows that an inflammatory state pushes those same enzymes down — messenger RNA and activity both — while leaving the cell's efflux pumps untouched. It is a clean, selective effect, not the cells being generally sick. And it happens in the HepaRG monoculture as well as in co-culture with macrophages, which is itself notable: the immune cells were not required to produce the state.

What this does and does not say about the guideline. It does not refute it. Test Guideline 445A specifies healthy, uninflamed cultures, and the study did not run the guideline's protocol or report fold-induction values under inflammation. The guideline's decision rule was not tested and has not failed.

What it says instead is a statement about the baseline the rule is applied to. An induction assay measures a ratio — treated over control. If a biological state can move the denominator, then the number the rule consumes is conditional on a variable the guideline does not ask about. In a patient, that variable is common: infection, inflammatory disease, an immune response to the drug itself. The direction matters too — inflammation lowering baseline enzyme levels is the opposite direction from induction, so a chemical tested against a suppressed baseline could read as inducing more than it does.

Marked as a vault inference, not a source claim. The source does not mention Test Guideline 445A, does not run it, and makes no regulatory argument. The connection above is this vault applying the source's measured direction to the guideline's readout, and it is recorded as an open question on the map rather than as a status move. The second finding, which lands somewhere else entirely. Three drugs known for idiosyncratic liver injury — damage that strikes a small minority of patients unpredictably at normal doses, and that standard tests miss — became synergistically more toxic under inflammation. That is a candidate mechanism for a failure mode the vault has already characterised structurally: the liver-injury battery in hepatotoxicity-dili-in-vitro-pbk-integration carries an intra-battery blind spot stating that all three of its in-vitro components are single-cell-type, short-exposure measurements with no immune component, and therefore "fail together on immune-mediated (idiosyncratic) and slowly cumulative liver injury." This source adds an inflammatory axis to a dish and the missed drugs start showing up. It is one laboratory, three compounds, no accuracy figure and no threshold — a direction, not a method — but it is the first source in the vault to put a candidate fix against that specific documented gap.
