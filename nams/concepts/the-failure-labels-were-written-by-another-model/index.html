The failure labels were written by another model

This vault's sharpest rail says that two assays in one battery which fail on the same chemicals for the same structural reason cast one vote, not two — and that an automated system trusting the battery's decision rule will read their agreement as confirmation and compound the error rather than catch it.

The rail keeps arriving in shapes the schema was not built for. By 2026-07-29 it had four: between two maps; inside a single map, where five readouts share one cell line; between a method and its reference standard, where the validation chemicals' reference values came partly from the methods under validation; and between a model and the assays it was trained on, where a model trained on a screening panel is then used to choose the next screen.

This is the fourth shape again, one layer further down: a model and the labels it is graded against.

Because hand-labelling twenty thousand trajectories is impractical, the failure type, timing and severity labels were produced by a GPT-5.4 annotation pipeline. The benchmark then measures whether a fine-tuned vision-language model agrees with those labels. Where the annotator is systematically wrong — a failure mode it does not recognise, a temporal boundary it consistently misplaces — the benchmark scores a model highly for reproducing the annotator's blind spot, and there is no human-labelled subset, no inter-annotator agreement figure and no technician baseline reported that would let anyone find out.

Why this specific instance is worth recording

Not because the work is careless. The simulator, dataset and code are public, and the paper's own limitations section is unusually direct about the synthetic-to-real gap.

It is worth recording because of what the system is for. This is not a model predicting a chemical's toxicity, where a wrong answer is a wrong answer. It is a safety monitor — a component whose entire function is to notice that something went wrong when nothing else did. A monitor validated against labels produced by a model inherits that model's notion of what counts as wrong, and the specific failure this whole line of work exists to catch is the one that looks fine.

A monitor cannot certify a class of failure that its own ground truth does not contain. The vault records that as the honest limit on the 90.83%, alongside the domain-shift collapse to 71.02% on unseen scenes.
