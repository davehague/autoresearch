The escape hatch this vault tracks for NAM readouts also automates the animal test underneath them

Three maps in this vault (genotoxicity-in-vitro-micronucleus, developmental-toxicity-zebrafish-teratogenicity, carcinogenicity-cell-transformation-assay) each carry a demonstrated machine-vision "escape hatch" from human-in-the-loop: a deep-learning scorer that automates a readout a trained human currently scores by eye. Yong et al. (2026) is the same technical pattern — whole-slide imaging plus a supervised deep-learning classifier, validated against a gold-standard comparator (flow cytometry, r = 0.926) — but applied to OECD TG 474, the in-vivo rodent micronucleus test, an animal method, not a NAM. The mice are still dosed daily for up to three weeks and bled; what is automated is only the scoring of the blood smear afterward.

Why this sharpens rather than duplicates the vault's reduction-vs-replacement schema gap. automation-self-driving-labs already carries two computational-connective instances of a model that is graded off the loop_readiness ladder because it has no physical assay, yet whose own data or purpose is animal-derived — GanCtrl (2026-08-26, writes a rat study's control arm from that study's own treated animals) and PMAL (2026-09-05, an active-learning selector trained on 120,384 animal lethality points). Both sit at the model layer. This source is the same confusion one layer down, at the instrument/readout layer: a real, physical, machine-vision-automated assay — fully closed-loop-ready by the ladder's own readout + decision-rule test — whose only input is a live, dosed animal. The ladder's rule 2 ("the method's own prediction model consumes an in-vivo study → bench-bound") was written for models that consume animal data as a training input; it has no test for a readout method that requires an animal as its subject. Three independent instances now (GanCtrl, PMAL, this one) across two different layers of the same loop — a pattern, not a coincidence, and one this vault's docs/backlog.md schema-gap items should track together.

What it does not do. It does not touch genotoxicity-in-vitro-micronucleus's own loop_readiness or correlated_blind_spot fields — a different assay entirely (in vivo mouse blood vs. in vitro cell culture), no shared chemical domain, no shared failure mode tested. No correlated_blind_spot row is set.
