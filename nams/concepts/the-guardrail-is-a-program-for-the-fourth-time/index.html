Four independent teams built an autonomous laboratory, and all four put the safety in ordinary code

The pattern is now firm enough to state as a finding rather than an observation.

SystemWhat actually enforced safety
GPT-5 + robotic cloud lab, cell-free protein synthesis (2026-07-26)a hand-written type schema plus hand-written protocols; the authors deliberately did not let the model write the protocols, and one of the two failures was fixed by editing the schema
AEGIS on an Opentrons liquid handler (2026-07-28)a curated rule database checked against the plan before execution
Agentic quantum-sensing loop (2026-08-02)a deterministic verification program; the agent has no hardware access at all and every request is checked before the queue accepts it
This onea three-level gate — is the command well-formed, is it consistent with what has already happened, is it physically possible — all ordinary conditional code, checked before any motor moves

Four groups, four domains, four architectures, one answer: the AI proposes and a program disposes. Nobody is trusting the model to be safe. Everybody is putting a deterministic filter between it and the world.

The specific mechanism here

Every proposed action is validated as the conjunction of three checks — interface (is the call well formed), procedural (does it make sense given the recorded laboratory state), physical (is it feasible given the current masses, volumes, and what the arm is holding). The paper's own example is homely and exactly right:

"Γproc blocks taking the pH meter when the robotic arm is still holding a test tube."

On failure, execution halts and a structured error goes back to the planner as feedback. The gate does not correct the plan; it refuses it and says why.

⚠ Read the headline number the right way

The paper reports gate intercepts falling from 6.00 to 0.67 per run — a 60% reduction — as a benefit of adding memory. A gate intercept is the safety system working. Fewer intercepts means the planner proposed fewer illegal actions once it had experience to retrieve; the gate is doing exactly as much work per illegal action as before. Nothing in the paper measures what happens without the gate, and the authors do not claim otherwise. Presenting fewer safety interventions as a safety improvement is the kind of framing this vault is here to unpick, and the honest statement is: the planner got better; the safety property never moved off the gate.

What it means for the loop

The vault's loop_readiness axis grades whether a machine could make the call. This is a standing qualification underneath that axis, now with four instances behind it: in every built system the vault holds, the thing preventing the machine from doing something catastrophic is written by a person, in advance, in ordinary code — and it can only cover the failures somebody thought to write down.

That limit is the same one AEGIS carried: an assay whose invariants nobody has written down gets no protection. Applied to toxicology, it is this vault's dominant blocker appearing one layer below the interpretation layer. The methods with no agreed decision rule are, for exactly the same reason, the methods with no writable safety invariant.
