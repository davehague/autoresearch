A battery composed by counting a database inherits that database's holes

⚠ Abstract-only ingest. See the source note.

The admission inside the method

The proposal is: rank key events by how often they appear across disease-linked adverse outcome pathways, then build assays for the top of the list. The authors then add a second, independent framework — the key characteristics of toxicants, a list of properties a toxicant can have, assembled by expert consensus rather than by pathway curation — and they say why: "to ensure coverage beyond current AOP limitations."

That clause is the interesting part of the paper. They are saying that the database is not a map of toxicology; it is a map of the toxicology that has been written up as pathways. Where nobody has authored an AOP, the frequency count returns zero, and zero is indistinguishable from "no such mechanism exists."

Why the vault should hold this as a standing caution, not a criticism of one paper

The failure mode generalises to every automated selection procedure the vault tracks, and it has a name here: a selection rule reads its source corpus, and the corpus's silences become the rule's confident negatives.

The vault holds the same shape in three other places:

  • imputed-descriptors-put-a-blind-spot-in-the-feature-matrix — a model whose inputs were filled in where data was missing carries the gap forward as if it were a measurement.
  • uncertainty-guided-selection-finds-ignorance-not-answers — a loop that chases what it does not know goes where the data is thin, which is not the same as where the answer is.
  • a-selection-loop-that-builds-the-model-it-selects-against — the loop's own choices shape the evidence it will later be judged on.

And the vault's own coverage blanks are what this would miss. There is no validated non-animal method for the placenta (no-validated-nam-assesses-the-placenta); no validated in-vitro method for thyroid disruption in the sense the regulators need (thyroid-no-validated-in-vitro-method); no validated method for photoallergy or photogenotoxicity (photoallergy-photogenotoxicity-no-validated-method). A frequency count over published pathways will not surface any of those as a gap. It will simply not mention them, and a panel built from it will look complete.

The loop reading, and it is the uncomfortable one

This is a procedure a machine could execute, re-execute nightly, and act on. That is the appeal. It is also the risk: the corpus grows in the direction of what is already studied, so a loop that selects assays by corpus frequency and then generates data on those assays feeds its own next selection. Nothing in the method notices that the endpoint with no pathways written for it is the endpoint most in need of one.

The authors' fix — bolt on a second, human-assembled framework — is a real fix and it is also a human step. The completeness check on an automated selection rule is currently expert judgement, which is the same answer this vault keeps arriving at from every direction tonight.

What it does not license

  • The vault has not read what the key-characteristics integration actually did. The abstract states the intent; the execution is unread.
  • This is not a claim that AOP-Wiki is unreliable. It is a claim, made by the authors themselves, that it is incomplete — which is true of every curated scientific database and is only dangerous when something counts it and treats the count as coverage.
