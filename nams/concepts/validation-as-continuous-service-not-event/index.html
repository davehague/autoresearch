Validation as a monitored service, not an event

Every validation in this vault is an event: a protocol is frozen, a blinded chemical set is run across several laboratories, a report is written, a body signs it. JaCVAM did it for TG 494 across three labs. ECVAM did it for the CFU-GM myelotoxicity assay in a blinded international trial. EU-NETVAL is doing it for eight thyroid methods now. The output is a verdict on an artefact that will not change.

Hartung & Kleinstreuer argue that shape cannot survive contact with a model that retrains. Their proposal is a companion post-validation AI agent that would:

  • retrieve newly available data continuously, "scouring the internet for new, model-relevant information", plus donated and proprietary data;
  • assess data quality before ingesting it;
  • monitor the current model version's performance against it;
  • trigger retraining when new data meaningfully enriches the set — and "regular automated retraining … e.g., annually" regardless;
  • back-test: "re-running older predictions using the latest model version. If discrepancies arise … the agent will flag these discrepancies and alert previous users of the model to ensure transparency and provide an opportunity to reassess earlier decisions or interpretations."

Why this belongs in this vault and not just in an AI-governance one

It is a closed loop. Data in → performance evaluated → model updated → next cycle. It is the exact architecture the vault's central question asks about — "a robot runs the assay, an AI picks the next experiment, a model updates" — with one substitution: the thing being updated is the method's validity status rather than the method's prediction.

The vault has recorded loops proposed for discovery (Robin), demonstrated for execution (Tox21), and specified for plumbing (agent-to-instrument-edge-is-unstandardised). This is the first loop the vault has seen proposed for governance — and it comes from the two people who would have to run it.

The back-testing component is the genuinely novel piece, and it has no analogue anywhere else in the vault. Every wet method here, once adopted, produces results that stand. Nobody re-runs a 2019 TG 439 skin irritation call because the guideline was corrected in 2026. A model that retrains changes its answer to questions already asked, and Hartung & Kleinstreuer's response is to make that change notifiable: retroactive alerts to prior users. A validated method that can retroactively withdraw a past verdict is a new object in regulatory science, and the vault has no axis that describes it.

What this costs the loop, and it is the second invoice this week

regulatory-acceptance-ai-model-credibility recorded FDA's price: model risk = model influence × decision consequence, where a closed loop maximises model influence by construction. That is a regulatory charge, and it is arguable — a proportionality rule, not a bar.

This is a different and more concrete charge: an operational one. A closed loop with a learned decision rule does not merely need to be validated; on this proposal it needs a standing, funded, monitored validation service attached to it for as long as it runs, plus an obligation to tell people it was wrong. Neither the FDA framework nor this vault's loop_readiness ladder has anywhere to record that cost.

The pattern, stated across three literatures in six days: robotics solved the hands (Tox21, 2013), agentic AI is solving the mind (Robin, 2026), and every remaining source says the expensive part is the decision layer — the bottleneck (Hartung 2025), the product (the vault's dominant blocker: 14 maps with no agreed rule), the regulatory price (FDA's model influence), and now the ongoing maintenance liability.

Honest weight

A proposal in a perspective article — no implementation, no pilot, no adoption, no primary data. evidence_tier: in-silico-mechanistic, strength: suggestive, stance: open-question. It moves no method's status and no method's loop tier.

Two directional pressures recorded: the first author is proposing a framework (e-validation) he co-authored, and both authors' institutions would gain the "new role" the paper describes for validation bodies. That does not make the argument wrong — the non-determinism problem it responds to (ai-decision-rules-are-not-deterministic) is real and structural — but the proposed solution happens to be a permanent job for the proposers' own field, and the vault records that rather than laundering it.
