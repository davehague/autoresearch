A strong extrapolation model for Tox21, built on a corpus that removed the exact curves the map's blocker is about

automation-tox21-qhts-platform's loop_blocker names two things: ambiguous "class 5" curves that a human manually corrects by masking/unmasking data points, and the absence of any published procedure converting an AC50/outcome call into a hazard determination. This source was surfaced by the sweep precisely because a foundation model achieving macro-F1 0.985 on Tox21 outcome prediction reads, from the abstract alone, like a candidate escape hatch for the first half of that blocker.

Reading the full text changes the answer. The preprocessing pipeline (Methods, "structural, data-quality, and assay-content filters") explicitly drops "ambiguous concentration annotations [3,073 lacking a curve_class2 (cc2) label or with cc2 = 5]" before any training happens. cc2 = 5 is this vault's own documented ambiguous-curve category — the one automation-tox21-qhts-platform already cites as requiring human masking/unmasking. Tox21mer does not learn to resolve that ambiguity; it is trained on a corpus that has already had it removed. And what it predicts — the existing assay outcome label and AC50 — are exactly the two objects the map already records as lacking a fixed hazard-conversion rule. Nothing about a decision rule is proposed, attempted, or claimed.

Why direction: limits rather than loop-move. The natural reading of the abstract's performance numbers would be a loop-readiness promotion candidate; the full text shows the model operates entirely downstream of, and does not touch, the specific ambiguity the map's tier is blocked on. loop_readiness stays automatable-open-loop on automation-tox21-qhts-platform — this is a correction of what a strong-looking abstract implies, not new evidence that the loop is any closer to closing.

What the source is genuinely good for. Distillation into "chemistry-only student models for large-scale external screening" is a real, different capability: predicting likely Tox21-style outcomes for compounds that were never run on the physical robot at all, which is an experiment-budget result in the same family as a-better-panel-buys-fewer-experiments-not-a-better-answer (Xu et al. 2026's finding that fewer readouts can match full-panel performance). It is not evidence that the decision-rule gap is closing.

Bias watch. funding_flag: none — NIH/NIEHS intramural, no competing interests declared — but the same institutional-interest pattern the vault already records for xu-2026-tox21-expanded-panel-dili-cardiotoxicity: NIEHS staff modeling NIEHS's own share of the Tox21 programme's data. Preprint, not yet peer reviewed, random (not scaffold- or time-based) SMILES splits — the authors' own limitation, which may inflate the reported performance relative to a harder external-chemical benchmark.
