The materials-science loop layer names the same gaps this vault names from biology, without ever citing it

This vault's central premise is that the self-driving-lab literature and regulatory toxicology "barely cite each other" (CLAUDE.md). This source is a clean instance of that disconnect and, at the same time, evidence against reading it as two unrelated problems: Chen et al.'s taxonomy — built entirely from soft-matter chemistry, with no biological or toxicological application anywhere in it — organizes self-driving labs along exactly the dimensions this vault's own loop_readiness ladder and infrastructure entries use: decision horizon, uncertainty modeling, human involvement, constraint handling, failure recovery. Its named open challenges — "multi-modal representation, calibrated uncertainty, safe exploration, and shared benchmark infrastructure" — read as a materials-science restatement of gaps this vault has documented one at a time from the biology side: system-entropy-is-the-cost-of-a-shared-sdl-facility (shared infrastructure at scale), no-free-autonomy-limit-grounds-loop-ready-is-not-endorsed (a formal limit on what sensing/measurement can support), and nam-data-processing-pipeline (the missing standardization layer between a machine-readable result and a machine-runnable decision).

What this does not do. It supplies no new empirical result, no accuracy number, no wet-lab finding, and touches no toxicology or regulatory-acceptance question. It is a reference taxonomy, not evidence that moves any method's tier — graded in-silico-mechanistic (argument, not data), the same rung this vault has repeatedly flagged as overloaded (review/opinion documents have no dedicated evidence rung; see docs/backlog.md, first logged 2026-07-12).

Why it is still worth the ingest. Per stages/01-sweep, self-driving-lab literature overwhelmingly comes from chemistry and materials, and the highest-value find in that literature is one that closes a loop on a regulatory tox assay — this is not that, but it is exactly the kind of infrastructure reference a tox-domain closed loop would eventually have to borrow vocabulary and benchmark design from, since nothing structurally equivalent exists inside toxicology's own literature yet.
