The correlated-blind-spot rail, moved from assays onto training data

Three ways to be "active"

Automated screening asks a simple question of every chemical: did anything change in this well? Something can change for three quite different reasons.

  1. Target engagement. The chemical genuinely did the biological thing being asked about — bound the receptor, switched on the reporter gene. This is the signal.
  2. Non-specific cytotoxicity. The chemical killed the cells. A dead cell stops doing nearly everything, which registers as a change in nearly every readout in nearly every assay.
  3. Assay interference. The chemical interfered with the instrument, not the biology. It fluoresces on its own under the detector's wavelength (autofluorescence), or it inhibits the reporter enzyme the assay uses to report on something else, so the light goes out for a reason that has nothing to do with the biological question.

The screening programmes know all of this and built defences. They run counter-screens — additional control assays whose only purpose is to identify categories 2 and 3 — and they publish the flags. Tox21 goes further and multiplexes a viability control into the same well, which this vault already records.

The flags are published. The models drop them, because the convenient artifact to download is the hit-call table, and the hit-call table is what everybody trains on.

The load-bearing sentence

"Because the confounders are structurally systematic, they are exactly the kind of signal a structure-based model will capture."

This is the part worth reading twice, and it inverts the usual intuition about noisy labels.

Random label noise makes a model worse and shows up as poor test performance. This noise is not random. Chemicals that fluoresce share chemical features. Chemicals that inhibit luciferase share chemical features. Broadly cytotoxic chemicals share chemical features — lipophilicity, reactivity, surfactancy. A model that predicts from molecular structure will learn these features cleanly and easily, because "does this molecule glow" is a far simpler function of structure than "does this molecule perturb this signalling pathway."

So the artifact is more learnable than the biology, and the test set contains the same artifact. A high held-out accuracy is not evidence against this failure mode. It is what this failure mode looks like.

Why this is the sharpest thing in the vault about closing the loop

The vault's central object is: robot runs the assay → model picks the next experiment → model updates. This commentary describes what that machine does when the training data is unfiltered screening output.

  • The model half learns from the robot half's output, artifacts included.
  • The artifact is structure-linked, so the model learns it well and scores well.
  • The model then selects what to test next, preferring chemicals resembling what it learned from — which are disproportionately the artifact-tripping chemicals.
  • Those come back "active." The loop reads confirmation and tightens.

This is the vault's correlated-blind-spot rail with the second assay removed. The rail says two assays that fail on the same chemicals for the same structural reason cast one vote, not two, and an automated system reads the concordance as confirmation and iterates into systematic error. Here there is no second assay: the model is agreeing with the data it was trained on. Same failure, one component fewer, and correspondingly harder to notice — there is no second opinion to be suspicious of.

It is also the same shape as lcl-metabolic-gap-multiplies-rather-than-repeats, where a shared blindness compounds rather than merely repeats because the outputs are chained rather than compared. A loop chains its model to its assay by construction.

The evidence is weak and the vault says so plainly

This is a Commentary. No data, no re-analysis, no experiment, no number attached to any claim. Three authors, none affiliated with a screening programme. evidence_tier: in-silico-mechanistic, strength: suggestive. The mechanism is sound and entirely unquantified: nobody has shown how much of any published toxicity model's performance is artifact. That measurement is the obvious next study and this is not it.

The four proposed controls are not recorded — the abstract announces them without naming them and the full text was behind a subscription. The vault does not invent the contents of a section it has not read. Open gap.

And the screening programmes are not the failure here. They built the counter-screens and publish the flags. The failure is downstream, in consumption. automation-tox21-qhts-platform already records Tox21 answering the cytotoxicity confound "with a multiplexed viability control in the same well, NOT with cross-assay concordance." The control exists. The models leave it in the file.
