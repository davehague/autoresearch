A national regulator adopts the technology class this map has tracked since it opened — but not, provably, the same instance of it

What this adds

This map has held regulatory_status: none since it was coined (2026-07-07): the underlying science (Wallace et al. 2023's rat↔human ALI concordance) is real but developer-involved, and no OECD in-vitro Test Guideline existed for acute inhalation. This is the first regulatory-acceptance event this map has ever carried. EPA's New Chemicals Division has formally built 3-D human airway tissue plus computational modeling into its TSCA review process for surfactant inhalation risk, with implementation memoranda and worked example evaluations published alongside the 27 August 2026 announcement.

Why regulatory_status moves to under-validation rather than higher. This is not an OECD Test Guideline — no international body adopted anything. It is a single national agency's own implementation decision, backed by its own technical-basis documents rather than an ECVAM/ICCVAM ring trial. That is a real, weaker-than-OECD-TG shape of acceptance, but a stronger one than "proposed" (a research suggestion): EPA is using this today, in an active federal review program, with published worked examples. under-validation is the closest fit on the vault's four-value ladder, flagged here — as the vault flagged the TSCA list's own "listing is not a validation" problem — as an approximate fit for a genuinely new shape of acceptance.

Why evidence_tier and Status do NOT move

This is the axis-independence lesson in its cleanest form yet on this map. EPA's action is a regulatory decision, not a new experiment: no new TEER/MTT concordance number, no new reference-chemical panel, no in-vivo predictivity data accompanies it. The map's evidence_tier stays peer-reviewed-method and its Status stays emerging — the acceptance axis moved without the science axis moving at all, on the same event, which is exactly what the vault's whole three-axis discipline exists to keep visible rather than blur together.

What is NOT known, and why it matters

The specific technology is unnamed. Every source read this run describes EPA's method by function ("3-D human airway tissue") and never by vendor, product, or cell source. This map's existing evidence base names MatTek's EpiAirway/HAEM by name. Whether EPA adopted that same product, a competing primary-tissue reconstruction, or an immortalized-cell-line-based model is not stated anywhere read this run — logged as an open gap rather than assumed. This is not academic: see an-immortalized-cell-model-is-hard-to-reproduce-across-labs, which raises a reproducibility concern that applies only if the second possibility is true.
