The verdict is arithmetic. Choosing what to run it on is not.

The SENS-IS assay's data-interpretation procedure is fully computable — count how many named genes cleared a 1.25-fold threshold, compare against a floor of seven, band the potency by the lowest concentration that still triggers (sens-is-fixed-prediction-model-on-human-skin-tissue). On the vault's ladder that is the property that earns the top loop-readiness rung.

This note is the finding that sits upstream of all of it, and it comes from the developer's own paper.

What was measured

Fifty putative pre- and pro-haptens run blind. For most, the standard epidermis-only reconstructed skin handled them. For "a limited subset of aromatic compounds reported to require extensive metabolic activation", it did not: potency "appeared to be underestimated." Re-running those on a full-thickness model — epidermis plus a dermal layer containing fibroblasts, so a second cell type and more enzymes — "improved potency characterisation … while not increasing potency estimates for substances already adequately detected." The improvement tracked "increased induction of phase I and phase II biotransformation genes."

Three things are true at once and all three matter:

  1. The failure direction is under-protective. The thin tissue does not throw false alarms about safe chemicals. It calls strong allergens weaker than they are. In a hazard-classification context that is the expensive direction.
  2. The fix is real and does not cost accuracy elsewhere — the deeper tissue did not inflate the compounds already handled. This is the developer reporting a clean escalation path, and it is a good result.
  3. Nothing tells you when to escalate. The selection criterion in the paper is "reported to require extensive metabolic activation" — a judgement someone forms by reading the literature about a specific molecule.

Why the third one is a loop finding and not a footnote

For a laboratory this is an ordinary professional call, made once, cheaply, by a person who knows the chemistry. It barely registers as a limitation.

For an automated system it is the entire problem, because it is exactly the step that cannot be looked up. A loop handed a novel structure has no published procedure for deciding whether epidermis is deep enough. Its options are both bad:

  • Run full-thickness on everything. Correct, expensive, and it discards the throughput advantage that motivated automating in the first place. It also throws away a validation base — the guideline's reproducibility numbers were generated on epidermis.
  • Run epidermis on everything. Cheap, fast, and it silently under-calls an unknown fraction of metabolically demanding allergens. Unknown because the paper does not report how many of the 50 needed escalation.

And the failure is invisible from the output. The assay returns a well-formed potency band either way. There is no signal in the result that says this chemical was run on tissue that was too thin for it — the gene counts simply come back lower, which reads as a weaker allergen. A loop iterating on those numbers gets a confident, well-formatted, systematically under-protective answer, and nothing in its own telemetry disagrees with it.

There is a partial escape and it should be named rather than assumed: the paper reports the deeper tissue's advantage tracked induction of phase I and phase II biotransformation genes — genes that are already inside the SENS-IS signature being read. In principle a rule could be written on the assay's own output — if the biotransformation genes fire, re-run deeper. Nobody has written it, and this vault does not invent decision rules. But it is the cheapest imaginable version of the fix, and it is the kind of thing worth watching for in the adopted guideline if one appears.

The pattern

This is the fourth distinct way the vault has now seen a deterministic rule undermined by something upstream of it — alongside a rule whose threshold depends on plate composition, a rule with a measured uninformative band, and a rule whose constants the guideline lets you retune (sens-is-prediction-model-parameters-are-user-retunable). Every one of them is invisible to a loop-readiness assessment that reads only the data-interpretation procedure.

The generalisation, which the vault should carry forward: closed-loop-ready grades the back half of an assay. Nothing in the vault's schema grades the setup. Tissue depth here; light source in the phototoxicity tiers; ambient oxygen across the whole in-vitro column. A closed loop inherits every pre-analytical choice of the protocol it automates, and pre-analytical choices never appear in a result table.
