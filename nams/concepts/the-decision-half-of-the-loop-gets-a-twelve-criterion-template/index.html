The decision half of the loop gets a twelve-criterion template

Every autonomous-laboratory source this vault holds automates the doing: a robot that runs the assay, a model that picks the next experiment, a monitor that watches the pipette. The vault's own thesis says the binding constraint is elsewhere — that the missing piece is the rule converting a measurement into a call, and that nineteen of its method maps are blocked precisely there.

This source is the first to attack that leg directly, and it does so by pointing at an existing human artifact rather than inventing one.

GRADE Evidence-to-Decision is a template used in evidence-based medicine to move a guideline committee from evidence to recommendation through twelve stated criteria — problem size, benefit, harm, certainty of evidence, how much people value the outcomes, the balance, resource use, cost-effectiveness, equity, acceptability, feasibility. Its entire purpose is that the judgement gets written down criterion by criterion instead of being made in a room.

That is a data-interpretation procedure for a policy decision, which is the object this vault keeps looking for and keeps not finding. It already exists, it is widely used, and — the essay's actual argument — it is executed by people reading papers, which does not scale to exposome-sized evidence.

The proposed division of labour maps one agent family per kind of judgement: pull the findings out, judge how badly each study was done, say how uncertain the answer is, separate cause from correlation, price the options, and check the system after deployment.

What this is and is not

It is a specification, and it is worth having as one. The vault has recorded convergence between the regulatory-toxicology and autonomous-science literatures three times without either side citing the other. This is a fourth, and the most explicit: a toxicologist writing in a toxicology journal describing an agent architecture.

It is not evidence. Nothing was built. No agent family exists, no benchmark was run, no error rate is reported, and no comparison against a human committee was attempted. The twelve criteria are a list; the six families are a list; the mapping between them is asserted to be clean. A named architecture with no implementation moves nothing on any axis, and none of this vault's maps changes tier because of it.

Note also which criterion the essay does not remove. Criteria like how much do people value this outcome and is this equitable are not underspecified rules waiting to be written down — they are value judgements. An agent family assigned to them is not automating a procedure; it is standing in for a constituency. The essay's own fifth governance requirement — human accountability — is the concession that this leg does not fully automate, and it is the honest part of the argument.
