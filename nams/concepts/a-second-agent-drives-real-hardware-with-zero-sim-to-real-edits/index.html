The execution leg gets a second real-hardware instance, from a different lab and a different physical domain — and the honest scope is still narrow

automation-self-driving-labs has recorded exactly one prior source of an AI agent independently operating real scientific hardware toward its own goal: isogawa-2026-agentic-nv-autonomous-quantum-sensing (MIT, nitrogen-vacancy defects in diamond). Chen et al. 2026 (Stanford/SLAC) is the second, on different hardware entirely: an LLM agent using Model-Context-Protocol tool calls autonomously aligns a single crystal (Co₃Sn₂S₂) on a real six-circle diffractometer at the Stanford Synchrotron Radiation Lightsource, at 16.0 keV. The transfer claim is the headline: the agentic workflow was built and validated in a virtual replica of the beamline, then deployed on the physical instrument with reported zero code changes — planning, action, and interpretation all transferred without modification.

What it does not claim. No success rate, number of trials, or comparison against a human beamline scientist's alignment time is reported in the press coverage or precursor-preprint abstract read this run. The task itself is explicitly narrow — six degrees of freedom, a sharply binary success criterion (aligned or not) — and reported commentary flags that viability as the search space grows in dimensionality is untested. This is consistent with this map's running finding that real-hardware agentic execution has so far only been demonstrated on low-dimensional, well-instrumented, narrowly-scoped tasks (alignment, single-defect selection) rather than anything resembling the branching, multi-step decision structure of a toxicology assay readout.

Why it still belongs here, not merely as noise. Two independent instances, two different laboratories, two unrelated physical domains (quantum sensing; X-ray scattering), zero-code sim-to-real transfer in both cases — that consistency is itself informative: it suggests the current ceiling on real-hardware agentic execution is task dimensionality and instrumentation quality, not domain-specific expertise. Neither instance touches biology, chemistry, or hazard assessment. The honest non-crossover, as with every prior physics/materials entry on this map.
