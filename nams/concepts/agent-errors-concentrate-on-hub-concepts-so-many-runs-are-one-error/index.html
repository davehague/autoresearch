Agent errors concentrate on hub concepts — so many runs are one error, not many

The correlated-blind-spot rail is this vault's sharpest standing finding: when two assays in a battery fail on the same chemicals for the same structural reason, that battery casts one vote, not two — and an automated system that trusts the battery's decision rule reads the agreement as confirmation and iterates confidently into systematic error. The vault has already recorded the rail one layer up, between models (multiple-frontier-models-are-one-vote-not-six) and between a benchmark and its own audit (the-instrument-that-audits-the-benchmarks-is-itself-unreliable).

This is the rail at the knowledge layer, and it comes with a distribution. Auditing 141 failed agent trajectories, about a third of failures were workflow problems — the agent ran out of reasoning, or the answer extractor broke. The other 67% traced to wrong domain knowledge, and those were sharply non-uniform: one concept cluster accounted for nearly half of all of them, with a long tail of concepts contributing fewer than five cases each. The authors call this "systematic blind spots tied to specific high-traffic concepts" rather than random lapses.

Why the shape matters more than the rate. If errors were uniform, running an analysis many times and looking for disagreement would surface them — that is what redundancy is for. If they concentrate on the concepts that the most other concepts depend on, then many runs over the same knowledge base inherit the same wrong belief, agree with each other, and the agreement reads as corroboration. A hundred agent runs that all misunderstand one heavily-connected mechanism are one wrong belief, repeated fast.

And the vault's existing remedy carries over unchanged: the fix for a correlated blind spot is a measurement that fails differently, not more of the same measurement. Consulting the agent twice is a bigger battery, not an independent vote. What would break the correlation is a check whose route to the answer does not pass through the same concept graph — which, in a toxicology loop, means a wet measurement, not a second retrieval.

The repairability gradient is the practical part, and it is counterintuitive. Hub errors were comparatively recoverable; rare long-tail concepts collapsed to near-zero repairability. So the errors that propagate furthest are the ones most likely to be fixable once found, and the errors that are hardest to fix are the obscure ones nobody is looking at. For an automated system that means monitoring effort aimed at the hubs is well spent, and it leaves the tail unprotected.

Honest ceiling. A non-peer-reviewed preprint; one group built the concept graph, the benchmark and the metric; the hallucination labels were produced by model-based validators with no human-labelled subset and no inter-annotator agreement. The concept graph is biomedical (proteins, drugs, cell lines, pathology), so the specific hub — enzymatic catalysis — is a fact about that graph. No toxicology appears anywhere in the paper, and the transfer to a toxicology loop is this vault's inference, labelled as such.
