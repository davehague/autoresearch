Nine and nine is not agreement, and it is exactly what a summary metric would report as agreement

Two models. Twenty-two chemicals. Nine positives each. A summary table would show a perfect match on positive rate, and a paper reporting only that number would read as two independent systems converging.

The chemicals were not the same chemicals.

Why this note exists separately from the metabolism finding

The companion note (metabolic-competence-did-not-subsume-the-simpler-model) records what this result says about biology: adding metabolic competence trades one error profile for another rather than strictly improving on it. This note records what it says about measurement.

The vault's correlated-blind-spot rail is built on a single insight: agreement between two tests is only evidence if the tests could have disagreed for independent reasons. Every instance so far has been a case where they could not — shared missing metabolism, a shared reporter backbone, a shared cell line. This is a different failure of the same intuition, and in some ways a more embarrassing one: the two systems here are genuinely different, they genuinely disagreed, and a count-level summary hides it completely.

Nothing about this requires an exotic mechanism. It is arithmetic. Two binary classifiers with the same positive rate on the same sample can have any overlap from complete to none. The number that would settle it — per-chemical concordance — is not in the retrievable text.

The loop reading, which is the whole reason to keep this note

An autonomous system running a two-model panel needs a rule for combining their outputs. There are only a few candidate rules and this result damages the plausible ones:

  • "Trust the concordant call." Concordance at the chemical level is unquantified here and demonstrably incomplete. At the summary level it is perfect and meaningless.
  • "Trust the more biologically complete model." The whole-organism model also produced calls on three of seven chemicals whose primary mechanism is something else, where the simpler model produced none. Complete is not the same as correct.
  • "Escalate disagreements to a human." Available, honest, and it is the definition of human-in-the-loop — which is a demotion, not a solution, and would be the correct grading if anybody actually wrote that rule down. Nobody has.

Nothing published arbitrates a disagreement between these two systems. So the pair produces, per chemical, either a concordant answer whose independence is unestablished or a discordant answer with no procedure attached — and in neither case does the panel yield the thing a loop needs, which is a next experiment. This is the same diagnosis the vault recorded for the four-laboratory zebrafish behaviour study, where expert labs given identical data disagreed on up to a third of neurotoxicity calls: writing down whichever rule one of them used produces a reproducible loop that reproduces one laboratory's judgement, not the field's.

Cheap experiment nobody appears to have run, and it costs no new wet work: publish the per-chemical concordance table. The data exists; only the summary was reported. Logged in docs/open-gaps-log.md.
