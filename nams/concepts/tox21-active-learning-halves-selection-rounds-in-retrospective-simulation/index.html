A fourth field runs the deciding leg's own experiment, directly on Tox21 this time

Every prior source on automation-experiment-selection tested whether active learning helps in materials chemistry, cancer-drug-combination screening, or dose-response cytotoxicity — domains the vault reads as transferable to toxicology, never as toxicology. This source runs the test on the vault's own Tox21 dataset: the same ~8,000-compound, 12-pathway panel this vault already tracks as the real, physically-run NIH/EPA/FDA screening platform on automation-tox21-qhts-platform.

What it adds

Swapping a pretrained chemical-language-model embedding (MolBERT) in for the usual ECFP fingerprint, and pairing it with an information-theoretic acquisition rule (EPIG — targets uncertainty about the task's own label distribution, not generic parameter uncertainty), cuts the number of active-learning rounds needed to match conventional active learning's hit-identification rate roughly in half. Calibration converges fastest for the same combination.

How it sits next to this map's standing finding

The map's running account, built across materials chemistry (2026-08-12) and cancer-pharmacology drug-combo screening (2026-08-22), is that uncertainty-driven acquisition targets the model's own ignorance, not the world's answer — plain greedy exploitation often beats it, and calibration does not predict optimisation performance. This paper does not test a pure-greedy baseline, so it cannot directly confirm or refute that specific claim. What it does show, compatibly: its uncertainty-driven rule (BALD) trails its information-theoretic rule (EPIG) throughout — a second data point that which uncertainty-flavoured rule you pick matters more than "uncertainty, in general, helps," without closing the open question of whether either beats simple exploitation on this dataset.

The honest ceiling

Retrospective simulation, not a live loop. Every "round" reveals a label that was already recorded when Tox21 ran its real robotic qHTS campaign years ago — no robot chose a compound and no plate was run as a result of this paper's acquisition rule. The gain is a real demonstration that a smarter order to ask already-answered questions in would have cost less, which is the right first step before anyone tries it prospectively, but it is not evidence that a live active-learning loop on Tox21 would deliver the same number: the paper is silent on batch effects, assay drift, reagent cost, or anything a real campaign would have to handle that a lookup table does not.
