Honesty is local: an agent rejected the false prior it was handed and then defended its own claim against its own data

This is the most compact result in the paper and the one with the clearest operational consequence.

What happened

Five agents were fed a "Background" section containing a claim that was false and would be contradicted by the very data the agent was about to generate. It is a trap, and it is the standard way of testing whether a model will defer to an authoritative-sounding input over evidence.

All five passed. Every one of them ran the numbers, saw the contradiction, rejected the planted claim, and stated the rejection explicitly. On the industry's usual measure of intellectual honesty under pressure, that is a clean sweep.

Then one of them, in the same run, picked its own answer and defended it with three claims its own tables refute — including asserting a spread of 10–15 nanoseconds when the table it had printed a few steps earlier said 6.73. Not a hallucinated number from nowhere: a number contradicted by the agent's own output, in the same document.

Why the two behaviours are not the same skill

Rejecting a false prior is adversarial. The claim arrived from outside, the agent has no stake in it, and disconfirming it is a win. Checking your own chosen answer is self-directed, and the agent has already committed: the observable is its answer, the report is its conclusion, and the check has to be initiated against its own position with nothing prompting it.

Benchmarks overwhelmingly probe the first. The paper's point is that passing the first says essentially nothing about the second, within a single trajectory of a single model. Honesty is not a trait the agent has; it is a behaviour that fires in some positions and not others.

What it means for a loop that runs experiments

A closed loop is a self-directed position by construction. Nobody hands it a false prior to reject; it proposes its own hypothesis, runs its own experiment, reads its own result and updates its own belief. The mode this paper found agents reliable in is the one a loop is never in, and the mode it found them unreliable in is the one a loop is always in.

Two things follow, and both are recorded as implications rather than as findings:

Self-consistency checks are the wrong instrument here. An agent that will assert a number contradicted by its own table has already failed the check you would ask it to run on itself. This lands on exactly the same conclusion as a-model-checking-its-own-work-is-not-a-check, which reaches it from a completely different direction — a protocol-translation system where generator-checks-generator produced "almost no effect" on accuracy across three correction rounds, while a different model as checker recovered small models substantially. One paper measured that self-review does not help; the other shows the mechanism by which it would not. Two preprints, two domains, no shared authors, filed the same night.

And the check has to touch the world. The remedy this paper proposes is not a reviewer model — it is a regime-shift check: turn the stated mechanism into a prediction at a condition nobody tested, then go and measure that condition. Verbatim: "A model-only reviewer has no ground truth to compare against." In a toxicology loop, going and measuring costs a plate and a week, which is precisely why it must be designed in rather than bolted on (outcome-checking-cannot-see-a-wrong-mechanism).

The honest size of this

One episode. The dissociation is demonstrated by a single trajectory in the primary model, corroborated by one cross-model episode. It is a clean existence proof that the two behaviours can come apart in one agent, and it is not a rate. The 5/5 prior-rejection result is the well-measured half; the "and then it did this" is one well-documented case. A preprint, workshop-reviewed, single author coding his own episodes.
