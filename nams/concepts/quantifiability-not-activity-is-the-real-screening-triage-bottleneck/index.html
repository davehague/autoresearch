Quantifiability, not activity, is the real screening-triage bottleneck — and the signal that predicts it is more transferable than chemical structure

Every triage system automation-experiment-selection has previously recorded asks one question before committing an expensive measurement: is this candidate active, or is the cheap screen's signal noise? This source shows that question is the wrong gate for a large share of wasted follow-up experiments in a real 32,971-pair screening campaign: 37% of unsuccessful dose-response profiles were run on compounds that were genuinely active — the activity call was correct — but the response was too weak or incomplete to fit a usable potency curve. Even a perfect activity classifier would not have prevented most of that waste, because activity and quantifiability are different properties of the same measurement.

The transferability result is the sharper finding for this vault. A model using only the cheap screen's own response-curve features (no molecular structure at all) predicted quantifiability at AUROC 0.886, and that number barely moved (to 0.883) when tested on chemical scaffolds the model had never seen. A model using only molecular structure (Morgan fingerprints) started weaker (0.761) and collapsed toward chance (0.599) on the same scaffold-disjoint test. What the assay measured about this specific run generalises to new chemistry better than what the molecule looks like — the inverse of the usual QSAR framing this vault's in-silico-qsar-read-across column holds, where structure is the whole basis of the prediction.

The deployment-realistic number. Under a leakage-safe rolling evaluation (each release scored using only chronologically prior releases, the closest analogue to real lab deployment this map has seen), ranking by predicted quantifiability retained 90% of the potencies a full campaign would produce while profiling only 55.4% of promoted pairs — a genuine, prospectively-simulated 44.6% reduction in dose-response experiments, beating the screening-heuristic baseline on 7 of 8 chronological test windows.

OPAL asks whether an adaptive measurement-selection rule is safe to trust before deploying it; this source asks a narrower, upstream question — whether the follow-up measurement would be informative at all — on the same class of cheap-screen-to-expensive-profile funnel. Neither addresses the other's question.

Honest ceiling. Preprint, single author, proprietary dataset of unstated provenance relative to the author; drug-discovery potency/activity screening, not toxicology — no chemical hazard call, no Test Guideline, no regulatory endpoint anywhere in the paper. The transfer to a toxicology dose-response NAM (OECD TG 439, 432, 249) is this vault's structural inference, not the paper's claim.
