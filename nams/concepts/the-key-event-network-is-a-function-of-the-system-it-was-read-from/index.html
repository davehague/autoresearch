The causal diagram is not one diagram, and the vault has been treating it as one

An adverse outcome pathway is toxicology's causal diagram — chemical perturbs a molecule, which changes something in a cell, then a tissue, ending in visible harm, with the intermediate steps called key events. Its defining property, and the reason it is attractive, is that it is supposed to be chemical-agnostic: it describes the road, not the traffic.

This vault has been leaning on that property hard. Two batteries built independently in one night both chose what to measure from a published pathway rather than from assay availability (an-aop-network-used-as-a-battery-design-tool). A Bayesian quantitative pathway model was recorded as "the missing decision rule, in computable form" (quantitative-aop-probabilistic-modelling). Tonight's thyroid framework maps existing methods onto network components as the surface a rule would be written on (an-aop-network-is-the-surface-a-decision-rule-gets-written-on).

Every one of those moves assumes the network is stable across the systems it will be applied in.

What this source measures

It curates and harmonises the public gene-expression evidence for PFAS — the thousands-strong family of persistent fluorinated industrial chemicals — across multiple compounds and multiple biological systems, reconstructs key-event networks from it, and adds fresh measurements in macrophages (tissue immune cells, an "under-investigated" context for this endpoint).

The result is stated as context-dependence, not noise:

  • Toxicity arises from shared early molecular perturbations that then diverge across biological systems to produce organ-specific outcomes.
  • In the liver there is a conserved mechanistic core underlying steatosis — fat accumulating in liver cells — activated through system-specific pathways shaped by the individual PFAS's physical chemistry and by the biological context.
  • Immune processes are central across contexts, which is not where a hepatocyte-centred account would have looked.

Why this pushes back rather than merely extends

A network that reconfigures by biological system is still a real and useful scientific object. What it is not is a fixed data-interpretation procedure, and that specific property is what this vault's third axis turns on. The closed-loop-ready tier requires a rule that is fixed; a rule written over a network whose topology depends on the system it was read from is fixed only after somebody specifies the system, and no method map in this vault records that specification as part of its decision procedure.

This is the same defect the vault has now catalogued three times in three unrelated places, and it is worth seeing them together because the pattern is the point:

  1. A transcriptomic genotoxicity biomarker whose published three-classifier rule is fixed but not sample-independent — two of its three legs are batch-relative, so a loop choosing its own next compounds changes what its own classifier is conditioned on.
  2. A three-dimensional skin comet decision procedure, one of whose three criteria compares the result against the testing laboratory's own historical control range, so the rule is a function of local history and does not transfer between sites.
  3. This: a key-event network that is a function of the biological system it was reconstructed from.

Each needs a specification change rather than a research programme — somebody has to write down the missing argument. That is a much cheaper fix than "nobody has written a rule at all," and the vault should stop lumping the two together.

The corpus brake, restated because it applies here in full

A network mined from the published toxicogenomic record inherits that record's choices — which PFAS were studied (the notorious long-chain few, out of thousands), which cell systems were fashionable, which doses were used, and the field's documented preference for publishing positives. A network fitted to that corpus will agree with that corpus, and that agreement is what the failure mode looks like, not evidence against it. Identical structure to models-trained-on-hit-calls-learn-the-assay, one layer up. No accuracy, calibration or held-out test is reported anywhere in the accessible text.
