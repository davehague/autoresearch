The methods work, the regulators accept them, and they still are not used — because of a loop

This vault grades every method on three axes: does the science hold (evidence_tier), has anyone accepted it (regulatory_status), and could a machine run it (loop_readiness). All three are properties of the method.

None of them predicts whether anybody actually uses it.

The vault already had the counter-example, measured. Japan's medicines regulator went into its own approval files for 2020–2024 and counted what applicants filed: non-animal methods in 22 of 115 tests — about one in five — even where an adopted Test Guideline existed (regulatory-acceptance-japan-pmda-nams). Adoption and use are different facts, and the vault recorded the gap without being able to explain it.

This is a proposed explanation, and its shape is what matters. A room of regulators, industry scientists, NGO staff and academics was walked through two structured workshops and asked to model the system they work inside. The output is not a list of complaints. It is a causal diagram: factors connected by reinforcing loops (an effect that amplifies its own cause) and balancing loops (one that damps it).

What a feedback-loop claim commits you to

If uptake were a list of independent barriers — no decision rule here, no validation there, no guideline for that — the rational strategy is to work the list. Fix the cheapest item, then the next.

If uptake is a feedback structure, working the list does not work. The system absorbs a point fix and returns to its prior behaviour, because the thing that produced the barrier is still producing it. What you need instead is a leverage point: a place where a small intervention changes how the whole structure behaves.

That is a falsifiable difference in principle, and this paper does not test it. It builds the model; it does not validate it against uptake data. This is a hypothesis about structure, drawn from what a room of experts said, with no numbers attached.

Why an autonomous-lab vault should care

Because a closed loop is the most extreme possible instance of "changing established practice," and this model names the two things it would run into.

The first — supply chain — is the-reagent-supply-chain-is-a-named-leverage-point and the vault has been tracking it one assay at a time as access_gate.

The second — educational and institutional support for people changing what they do — has no representation in this vault at all. Every rung of the loop_readiness ladder asks whether a machine could execute the method. No rung asks whether the organisation around the machine can absorb the change. On this model that is not an implementation detail; it is one of two named leverage points.

The honest limits

  • No toxicology. No assay, no endpoint, no guideline, no performance number. No method in this vault moves on any axis because of this source, and none should.
  • Not a sample. The participants were experienced practitioners recruited into a project whose stated purpose is promoting NAM uptake. A room convened to explain why good methods aren't used has a directional interest in the answer being systemic rather than scientific — i.e. not the methods' fault.
  • Full text unread. The specific loops and the model diagram sit behind ScienceDirect's bot wall today; this note carries only what the published abstract states, quoted.
