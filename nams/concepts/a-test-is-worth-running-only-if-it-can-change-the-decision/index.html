A test is worth running only if it can change the decision

Value of information is a decision-theory idea with a one-line definition: an experiment's worth is not how interesting its result is, but how much it changes what you would do afterwards. Run the decision forward under every outcome the experiment could produce. If the action is the same in all of them, the experiment is worth nothing — you have bought a number, not a decision.

Three industrial toxicologists propose it as the gate on whether a toxicity test should be run:

"Value-of-information frameworks should guide whether tests meaningfully shift decisions."

Why this belongs in a vault about closed loops

A self-driving laboratory's defining question is not how do I run this assay — the robots have been able to do that since 2013. It is which experiment next. The standard machinery for answering it is an acquisition function, and the most common family of acquisition functions maximises expected information gain: pick the experiment whose result would most reduce uncertainty about the thing you care about.

Value of information and expected information gain are the same construct. One is written in a regulatory-toxicology commentary that does not mention automation anywhere; the other is the core loop of every Bayesian-optimisation-driven lab in the materials and chemistry literature.

This vault has now caught that convergence three times:

  1. 2026-07-28 — a 28-author autonomous-science roadmap independently derived the vault's own thesis: "Producing a candidate discovery is no longer the hard part, but verifying it is."
  2. 2026-07-25 — OECD's eye-hazard guidance turned out to name conditional independence as a battery-design rule, i.e. the correlated-blind-spot rail as a cited statistical concept with a 2008 literature.
  3. Tonight — the loop's experiment-selection criterion, arrived at from the regulatory side.

Each time, neither literature cites the other. That disconnect is this vault's premise, and it keeps being confirmed by finding the same object described twice in incompatible vocabulary.

The asymmetry that makes it more than a coincidence

There is a reason to think this convergence is real rather than a coincidence of phrasing. Both fields face the same underlying scarcity — experiments cost money and time, and there are far more possible experiments than budget. Any field that takes that constraint seriously arrives at the same criterion. Toxicology arrives at it as a governance rule (do not require a test that cannot change a regulatory outcome); autonomous labs arrive at it as a control rule (do not spend a plate on an experiment that cannot reduce uncertainty). Same mathematics, different consumer.

And it exposes what regulatory toxicology would need before a loop could use it. Expected information gain requires a quantified prior and a quantified decision consequence. Toxicology has neither in a computable form: the "decision" is a hazard classification defined by committee, and the prior is expert judgement. The criterion transfers cleanly; the inputs do not. That is the same wall recorded on 2026-07-26 about the missing objective function, seen from the other side.

Honest brake: a commentary with no data, no worked example and no adoption by anyone, written by employees of a chemical company with a direct commercial interest in running fewer tests. Recorded as a convergence worth watching, not as evidence that anything works.
