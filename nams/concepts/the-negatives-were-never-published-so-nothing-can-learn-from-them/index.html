The negatives were never published, so nothing can learn from them

The other half of this map's problem

ml-model-reporting-reproducibility exists because the toxicology machine-learning literature often does not let you check its models: interpretation methods reported in roughly half of papers (2022–2024), missing -value handling, data availability and code availability substantially underreported (ml-toxicology-interpretation-and-code-reporting-gaps). The map's loop_blocker is not accuracy, it is accountability.

This note adds the half that sits upstream of all of it. It is not only that you cannot audit what was published. It is that an entire class of result was never published to audit.

Why a missing class is not the same as missing data

Software framing, because it is exact. Imagine a package registry that accepts only libraries whose tests passed, silently discards every failed build, and is then used to train a model predicting whether an approach will work. The model does not learn that approach X fails — it has never seen a single instance of X failing. Its estimate of the failure rate is not noisy or wide; the observations are structurally absent, and no amount of additional data from the same source fixes it, because the same filter is applied to that data too.

Toxicology's registry works the same way: a result showing nothing is harder to place than a result showing something. So the corpus that every structure-based model, every read-across, every (Q)SAR is fitted to is the literature with an entire class of outcome removed by the publication process, not by the biology.

Two places it bites a closed loop, and they are different failures

The model half. A structure-based model trained on that corpus is calibrated against a world in which very little is inactive. This is a second, independent mechanism producing the defect models-trained-on-hit-calls-learn-the-assay already records — there the training labels carry the assay's own confounders (cytotoxicity, interference) because the counter-screen flags were dropped; here an entire class of label is simply not present. Same downstream symptom: a model that scores well on held-out data drawn from the same filtered pool, and cannot be caught by held-out data drawn from that pool. Related: the-knowledge-graph-is-thinnest-where-the-actives-are and a-failure-detector-trained-on-failures-that-never-happened.

The deciding half — the sharper one. The machinery that chooses which experiment to run next — Bayesian optimisation, active learning — works by maintaining a belief about where the interesting region is, and it needs to know where things did not work at least as much as where they did. A prior built from a literature with the negatives stripped out does not start merely uninformed; it starts confidently wrong about the shape of the space, and the loop then spends its budget confirming that shape. See automation-experiment-selection, and specifically experiment-selection-under-known-cost-is-the-loops-other-half — a cost-aware policy needs a likelihood model saying how much each cheap measurement tells you about which hypothesis is right, and that number cannot be estimated from a corpus where one branch of the outcome was never recorded.

This is the correlated-blind-spot rail, moved one layer further up. The rail says two assays that fail on the same chemicals for the same structural reason cast one vote, not two, and an automated system reading their agreement as confirmation compounds the error. Here the shared failure is not between two assays but between every study of every assay — they were all filtered by the same publication process before the model ever saw them. A loop cannot detect it by cross-checking sources, because the filter was applied to all of them.

What this note does not claim

It has no number in it. The Comment supplies no estimate of the unpublished fraction in toxicology, no publication-rate comparison, and no worked case of a NAM delayed by a missing negative. The argument is old and widely accepted, and being widely accepted is not evidence. evidence_tier: in-silico-mechanistic, strength: suggestive — and the vault's tier ladder still has no rung for a comment or opinion piece, the fifth instance of that schema gap.

It also does not downgrade any method map. Nothing here says a specific model in this vault is wrong. It says the class of evidence they are all fitted to has a known, unmeasured hole in it — which is a statement about the ground, not about any building on it.

And it names an underused fix. Publishing the failures is a regulatory_status-neutral, cheap intervention that improves the model layer without improving a single assay — the same category of leverage as next-generation-validation-replaces-the-ring-trial and eight-methods-that-broke-when-a-second-lab-ran-them, where what a second laboratory could not do turned out to be the load-bearing information. The vault's own habit is worth checking against this: an autoresearch ledger that only ingests published sources inherits the same filter, and its "no source found" is not the same as "nothing happened."
