The machine-vision escape hatch arrives in materials chemistry too — but the loop it's attached to isn't closed yet

The finding, plainly

automation-self-driving-labs already tracks machine-vision scoring as the escape hatch from human-eye-scored readouts in toxicology (micronucleus foci, cell morphology). This source is the identical move in a different domain: foam morphology, conventionally assessed by scanning electron microscopy (SEM, requiring destructive sample cutting and a human or image-analysis-software judgment call), is instead classified by an unsupervised machine-learning algorithm (k-means clustering on RGB surface photographs) running autonomously as part of a robotic foaming cell. The authors validate it qualitatively against off-line SEM on the same samples and report concordance.

What this is NOT, stated as plainly as the authors state it themselves

The paper's own final paragraph before the Conclusions: "Work is in progress to operate the entire system with AI-based methods for autonomous experiment configuration and adaptive tuning of the foaming conditions... These methods will be trained by using experimentally acquired data." That is a closed loop proposed, not demonstrated. What exists today is: a robot that executes a fixed foaming protocol, a sensor that measures the product, and a clustering algorithm that classifies the image. Nothing in this paper yet picks the next experiment from the last one's result. This is the execution + measurement half of a self-driving lab, explicitly not yet the closed-loop half — consistent with this map's running finding that "self-driving lab" claims in the literature cluster heavily on the execution side and far less often demonstrate adaptive experiment selection in the same paper.
