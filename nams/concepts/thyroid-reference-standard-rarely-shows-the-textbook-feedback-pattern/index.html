The in-vivo reference standard the thyroid NAMs are validated against has its own blind spot

The finding, plainly

Not a NAM — a systematic review of 234 published rodent toxicology studies, asking how often the textbook hypothalamic-pituitary-thyroid (HPT) axis negative-feedback pattern (chemical blocks thyroid function → T4 falls → pituitary senses it → TSH rises) actually appears in the published data. It rarely does. The most common single pattern is T4 falling with no TSH response at all — the feedback loop's own second half absent from the record more often than present. Current EU/ECHA-EFSA regulatory guidance leans on exactly the canonical two-hormone pattern (plus thyroid histopathology) to call a chemical a thyroid disruptor. The authors' own words: regulators should "not solely rely on the canonical serum hormonal patterns" to judge adversity.

Why this lands on THIS map specifically

endocrine-thyroid-disruption-nams tracks eight in-vitro methods in EU-NETVAL validation (including the TTR-ANSA/TTR-FITC pair this map already flags as a correlated_blind_spot) plus the US EPA/NICEATM thyroid-microtissue assay, all being validated against an in-vivo reference standard this review now shows is itself unreliable in a structured, high-frequency way — not an occasional outlier result, but the single most common finding pattern in 234 studies. This is the identical shape as endocrine-thyroid-disruption-nams's own 2026-07-29 entry (Bernasconi et al.) on the EU validation study, which found the reference set had to be built by expert committee because the in-vivo test cannot supply mechanism-specific ground truth. This source gives that admission a quantitative base rate: 58/184, not an isolated caveat.

What it does not do

It proposes no replacement rule and no new method — it diagnoses a gap in the existing animal reference standard, explicitly recommending updated in-vivo test methods (molecular endpoints added) and better standardization, not a non-animal alternative. stance: pushes-back against the implicit reliance on the canonical pattern as validation ground truth, not against any specific NAM or this map's Status, evidence_tier, or loop_readiness — none of which move. The map's existing domain_gate and correlated_blind_spot entries are unaffected in substance; this sharpens the case for why they matter.
