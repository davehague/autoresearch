An LLM agent orchestrates the model layer this vault already tracks, without changing what that layer is

This vault's in-silico-qsar-read-across map already holds (Q)SAR and read-across as the vault's computational-connective layer — the model layer a loop would update. This source is the first evidence in the vault of an LLM agent orchestrating that layer as a multi-step pipeline rather than a single model call: predict hazard for the parent → generate metabolites (BioTransformer 3.0) → predict hazard for each metabolite → synthesize against retrieved literature and regulatory data.

Why direction: loop-move and not validates. Nothing here is a new toxicological finding about Cashmeran or polycyclic musks — the vendor's own literature retrieval surfaced pre-existing ToxCast, ECHA and NOAEL data that already supported a low-risk call. What is new is the orchestration pattern: an agent chaining a metabolism-simulation tool to a hazard-prediction tool and iterating, which is architecturally closer to what a loop's model-update step would need to do than a single static QSAR prediction is.

Why the tier does not move. Per the deterministic ladder (shared/evidence-model.md), a pure model with no physical assay is computational-connective regardless of how many tools an agent chains together — chaining models is still modeling. This concept extends the map's evidence at single-lab-exploratory (one worked case, proprietary models, no reference-chemical panel) without touching the map's loop_readiness tier.

The honest limit, stated by the vendor itself. The system explicitly keeps a human reviewing output after every cycle and is not claimed to replace the toxicologist's judgment — the architecture the vendor calls "human-in-the-loop" is this vault's human-in-the-loop vocabulary used correctly and voluntarily, a rare case of a commercial AI claim that does not overreach into removed-human-oversight territory.

Bias watch, stated plainly. funding_flag: [industry, method-developer] — Human Chemical Co. built and demonstrated its own commercial platform on its own proprietary models, in a paper whose Conflicts of Interest section attributes each vendor section by name. No independent lab has reproduced any part of this pipeline.
