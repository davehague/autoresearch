The Ames test in nanolitre droplets — the readout stops needing a person, in a format that is not the adopted test

The Ames test (genotoxicity-ames-bacterial-reverse-mutation, OECD Test Guideline 471) sits at automatable-open-loop on this vault's third axis for a stated reason: colony counts are countable by machine, but the guideline publishes no fixed positive/negative call rule. Cao et al. built a format that supplies one — in a single laboratory, for one bacterial strain.

What the format does

The culture is pushed through tubing as a train of nanolitre droplets, each an independent micro-culture, read optically as it passes a detector. Mutation is scored as the fraction of droplets in which revertants grew — "revertant" meaning a bacterium that has mutated back to being able to make an amino acid it was engineered to need, which is how the Ames test detects mutation in the first place. Instead of a technician counting colonies on a plate, a threshold applied per droplet:

"A threshold-based evaluation enabled robust quantification of stochastic mutation events at single-droplet resolution."

And the claim that puts this in this vault:

"reduced reagent consumption by > 90%, generated statistically powerful datasets within 48 h, and eliminated subjective scoring."

The dose-response is textbook and worth recording because it shows the format behaves: with the reference mutagen 4-nitro-o-phenylenediamine, revertant-positive droplet fraction rises with dose and then falls off above 8 µg/mL as the chemical starts killing the bacteria outright. The cell-density work matters for the same reason — 10⁶–10⁷ cells/mL was the window that "maximized sensitivity while limiting spontaneous revertants", i.e. that separated real mutation from the background rate at which these bacteria fix themselves anyway.

Why the map's loop_readiness does not move

Because the guideline is what would have to change, and it did not. The vault's axis grades the method as adopted: TG 471's data-interpretation procedure is what an automated system would have to execute, and it still publishes no fixed call rule. A single laboratory demonstrating a threshold in a research format is the existence of an escape hatch, not a change to the door. The parallel is exact with zebrafish-machine-vision-malformation-scoring — a Vision Transformer showed the eye-scoring step of the zebrafish assay is learnable, and that map correctly stayed human-in-the-loop.

What does change is the reading of the blocker: "no agreed decision rule" is no longer an architectural fact about the biology. Someone has now written a rule down and run bacteria against it.

What is missing, and one of the gaps is serious

S9 metabolic activation is never mentioned in the abstract. TG 471 requires testing ± S9 — homogenised rat liver added to the well as a stand-in for mammalian metabolism, so that chemicals which only become mutagenic after a body modifies them are still caught. Whether this format runs with S9, cannot, or simply was not tested with it is unknown. It is the single most consequential unknown here, and it is deliberately not guessed: see automating-an-assay-fragment-is-not-automating-the-assay.

Also absent: the threshold's value, any concordance against plate-format Ames, any reference-chemical panel beyond one mutagen, any second laboratory. evidence_tier: single-lab-exploratory; regulatory_status: none — the plate assay's adoption does not travel with the biology into new hardware.
