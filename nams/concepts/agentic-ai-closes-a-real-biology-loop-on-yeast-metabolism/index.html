The crossover the sweep has been watching for — biology, not chemistry or materials, but still not toxicology

This map's founding complaint (2026-08-01, carried forward on automation-self-driving-labs since 2026-07-13) is that the self-driving-lab literature is almost entirely chemistry and materials science, and that a source closing the loop on biology would be the highest-value crossover this vault's sweep could find. This is the first one. Eve — rebuilt with LLM agents and a symbolic logical scaffold meant to correct LLMs' documented weakness at logical structure — generates hypotheses about yeast metabolism, chooses which to test, directs automated cell-culture and metabolomics platforms to run them, and revises disproven hypotheses for the next round: the full discovery/learning loop this map exists to track, running on living cells rather than a materials-synthesis robot.

What this is not. Zero chemicals tested for hazard, zero toxicological endpoints, zero regulatory content, and zero overlap with any method this vault otherwise tracks. The crossover this vault actually wants — a closed loop on a regulatory tox assay — has still not arrived. This is the closest analog found to date: the same architecture (LLM agent + lab automation + feedback), one domain closer (biology instead of materials), still one domain away (systems biology instead of hazard assessment).

Logical scaffolding as a partial answer to a standing map concern. Several sources already on automation-experiment-selection and its parent raise the uncertainty-estimate/reliability question for AI-driven experiment selection. This source's explicit symbolic/logical scaffold — built because LLMs "often struggle with logical structures" on their own — is a concrete design response to that concern, though demonstrated on one organism in one laboratory with no independent replication, so it resolves nothing yet; it is recorded as a design pattern worth tracking, not as evidence the reliability question is closed.
