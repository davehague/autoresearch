The gap between "the command parses" and "the command is safe" gets a name and a failing benchmark score

This vault's central rail is that loop_readiness: closed-loop-ready is never an endorsement — "a machine could make the call" is not "a machine should make the call" (shared/evidence-model.md). Zhang et al. 2026 supply the sharpest concrete instance of that distinction this vault has seen at the infrastructure layer: an AI agent driving a self-driving lab can generate a command that is syntactically correct — it parses, it addresses the right instrument, it uses valid parameters — and still be physically unsafe to execute, because the device API has no representation of the underlying physics or chemistry. They name this the "Syntax-to-Safety Gap" and show, against the public LabSafety Bench, that today's foundation models fail it: syntactic correctness does not imply physical safety, and the gap is large enough to be measured, not theoretical.

Why this belongs on the loop-infrastructure map and not on any assay. This is not a claim about any toxicology method's validity, acceptance, or loop tier — it is a claim about what building the loop machinery itself would require before any assay could be safely automated inside it. The proposed fix is architectural: Operational Design Domains (formally verified operating boundaries, borrowed from autonomous-vehicle safety engineering), Control Barrier Functions (continuous real-time state monitoring that intervenes before an unsafe state is reached, not after), and a transactional protocol ensuring the digital plan and the physical execution cannot silently diverge. None of these are toxicology-specific; the paper is explicit that this is general SDL infrastructure, grounded against two existing systems (UniLabOS, already in this vault; and "Osprey").

Why it matters to this vault's specific question anyway. If a future autonomous NAM loop is ever built — running an actual regulatory assay end-to-end — it inherits whatever safety architecture the underlying SDL platform has, or does not have. A closed-loop-ready assay with an instrument-readable readout and a fixed decision rule (the vault's own tier ladder) still requires something underneath it verifying that the AI's sequence of physical actions stays inside a safe operating envelope. This source is the first evidence this vault holds that the field's own foundation models fail that check today, on a general benchmark, before any chemical-specific hazard is even in play. evidence_tier: in-silico-mechanistic — a framework paper with one benchmark evaluation, not a wet-lab or regulatory-tox result; strength: suggestive — a single paper's benchmark run, not independently replicated. funding_flag: none — an academic framework proposal, not a platform vendor's safety claim about its own product.
