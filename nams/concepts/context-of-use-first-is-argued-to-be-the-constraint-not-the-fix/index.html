The rule written to make non-animal methods easier to accept is argued to be what constrains them

Context of use is the stated job a method is being validated for. Since ICCVAM's 2024 framework it has been the governing principle of the whole validation paradigm — "The COU determines the detailed criteria and implementation of the key concepts" — and it arrived as relief. The old model made you prove a method worked in general, across many laboratories, before anyone could use it for anything; ICCVAM itself called that "lengthy and resource-intensive." Context of use replaced a universal bar with a task-specific one.

Zhu & Locke argue the relief has a cost that shows up on complex models: "Validation of new approach methodologies increasingly requires developers to define a context of use (CoU) before establishing scientific credibility, constraining complex in vitro models."

The mechanism is ordering. Name the job first and the validation record only ever accumulates evidence about that job. A liver-on-a-chip validated for drug-induced liver injury screening (hepatotoxicity-liver-chip-mps) generates data on metabolism, transporter function and dose–response as a side effect of running — and the validation framework has nowhere to put it, because none of it is in the declared context. The next applicant, wanting a different job from the same platform, starts over.

The proposal splits the exercise in two: Phase 1 characterises what the model does and does not do, application-independent; Phase 2 asks whether that characterised model is good enough for a particular declared job, repeatably, against one Phase 1 record; a shared data repository carries Phase 1 evidence between them. The claimed win is on cost structure — characterise once, qualify many times.

Why this is new in the vault's thread. validation-paradigm-nam-confidence holds five actors conditioning or demoting the ring trial, and every one treats context-of-use flexibility as the fix. The only existing pushback (Jacobs et al. 2024) defends inter-laboratory reproducibility, not the ordering. This is the first source arguing that CoU-first is itself the binding constraint — and it comes from the animal-replacement community, arguing against a rule regulators wrote to help them.

⚠ It is not obviously right, and the honest reading matters. "Characterise the model independent of application" is uncomfortably close to a restatement of the pre-2024 paradigm the field abandoned as unaffordable. The abstract does not say what evidence Phase 1 demands, who funds it, whether inter-laboratory reproducibility survives into it, or what stops it becoming the same open-ended bar under a new name. That question decides whether this proposal strengthens or weakens the vault's formally-validated tier, and the full text is paywalled.

For a loop, it multiplies rules before it simplifies them. Moving "what does this number license?" entirely into a repeatable Phase 2 makes each instance smaller and more checkable — which is the shape an automated system can encode. It also means many more such rules must exist, and this vault's standing finding is that on 24 maps they do not.
