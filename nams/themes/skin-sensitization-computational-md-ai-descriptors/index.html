Molecular dynamics / AI descriptor framework for skin sensitization — a proposed computational layer — method

Status: emerging (2026-09-17). Single source, a perspective with no primary data — evidence_tier: in-silico-mechanistic throughout, another instance of the vault's missing review/perspective evidence rung.

What we believe now

Skin sensitization already has the vault's most mature computational layer: structural alerts, read-across, and QSAR models are established inputs to OECD GL 497's Defined Approaches (SARA-ICE is a named, adopted computational component). This map holds a proposed extension of that layer — not yet built — that would add covalent molecular docking and molecular dynamics (MD) simulation as a mechanistic descriptor source, on the theory that existing computational tools capture whether a chemical is structurally reactive but not how — geometry, residue-level accessibility, contact persistence — it engages a specific protein target.

Two targets are named, each mapped onto an existing assay's AOP key event: a peptide panel modelled on the DPRA's own reagents (KE1, skin-sensitization-dpra), and the KEAP1 protein whose perturbation underlies the KeratinoSens NRF2/ARE readout (KE2, skin-sensitization-keratinosens). The stated intent throughout is a complementary evidence layer for early ingredient prioritization, not a replacement for either wet assay or for GL 497's Defined Approaches — and the source is explicit that none of it has been tested: no chemical run, no descriptor computed, no model trained.

Loop readiness

loop_readiness: computational-connective — not a physical assay; this would be a model layer, the kind of thing a loop updates rather than runs. Scored off the ladder per shared/evidence-model.md. Whether it would ever reach closed-loop-ready behaviour once built is unanswerable from a proposal with no implementation — there is no readout to grade and no decision rule to check, because there is no working model.
