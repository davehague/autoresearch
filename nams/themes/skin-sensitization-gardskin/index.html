What we believe now

GARDskin exposes the human myeloid leukaemia SenzaCell line (standing in for the dendritic cells that present foreign material to the immune system in real skin) to a test chemical for 24 hours, then quantifies 196 named genes — the GARDskin Genomic Prediction Signature — by NanoString nCounter. The expression vector is fed to a published support-vector-machine classifier, producing a Decision Value; **mean DV

= 0 (n=3) classifies the chemical a sensitiser.** This addresses the same key event 3 (dendritic-cell activation) that h-CLAT and U-SENS address, by an entirely different readout technology — a transcriptomic signature rather than a surface-protein marker.

Two protocol extensions, evaluated here for the first time in this vault:

  • GARDskin DR — the same assay run across six concentrations, interpolating the lowest dose giving a positive DV (cDV0), convertible to a potency value (micrograms/cm^2) that functions as a quantitative point of departure.
  • GARDskin MD — the same assay run on ISO 10993-12 polar/non-polar extracts of a solid material, built specifically to test medical devices and (by extension, in this paper) wearables.

The one measurement in this vault: all six wearable-relevant chemicals were correctly classified as sensitisers, while the animal comparators (LLNA, Guinea Pig Maximization Test, Buehler) each missed or gave conflicting calls on most of the same six. This is a real finding and a narrow one — the study ran zero non-sensitiser chemicals by deliberate design (potency assessment needs positives), so no specificity or false-positive rate is computable from it in either direction. → gardskin-genomic-signature-catches-sensitizers-the-animal-tests-missed

Loop readiness

loop_readiness: closed-loop-ready — by the deterministic ladder in shared/evidence-model.md:

  • Readout? Fully instrument-read. NanoString nCounter gene-expression quantification, no human eye anywhere in the chain.
  • Decision rule? Fixed and published. A trained SVM model plus a DV >= 0 threshold — the same rung that makes h-CLAT and U-SENS loop-ready, applied to a different marker.
  • Inputs? No in-vivo study consumed. Not bench-bound.

And the tier is not an endorsement, in the usual two ways. access_gate — the SenzaCell line, the gene panel, the NanoString requirement and the classifier are all SenzaGen's proprietary platform; standing this leg up elsewhere means going through the method developer, the same shape as U-SENS's L'Oréal gate. correlated_blind_spot — see below; the slot-substitution risk under GL 497 applies here as it does to U-SENS, with an important mechanistic caveat the other pair does not carry.

⚠️ Correlated blind spot — the same slot, a genuinely different mechanism, and an open question

OECD Guideline 497's 2026 edition treats h-CLAT, U-SENS and GARDskin as substitutable sources at the same key-event-3 slot — a permutation using any one of them is presented as equivalent for battery-composition purposes. The battery-composition risk that follows is the one already flagged twice on this endpoint: a defined approach run with GARDskin and a defined approach run with h-CLAT look like two different batteries and cast one vote on the same key event.

But GARDskin is mechanistically less redundant with h-CLAT/U-SENS than they are with each other. h-CLAT and U-SENS read the identical marker (CD86 surface-protein up-regulation) on two immortalised human myeloid lines; GARDskin reads a 196-gene transcriptomic signature in a different cell line (SenzaCell) via a classifier trained on the whole expression pattern, not one surface protein. That is a materially different measurement of the same key event — closer in spirit to the TG 496/TG 492 "orthogonal mechanism" case this vault has flagged as a good counter-design than to the CD86/CD86 pair.

What is not known, and is not assumed either way: whether SenzaCell carries the same metabolic-incompetence gap already flagged against THP-1 and U937 (the shared reason both existing KE3 assays are suspected of under-detecting pro-haptens — chemicals that only become sensitisers after enzymatic activation in real skin). Neither the founding GARDskin validation literature nor this paper's abstract states SenzaCell's xenobiotic-metabolism status. Logged as an open gap rather than inferred. If a future source confirms SenzaCell shares the gap, this row upgrades to the same shared-mechanism wording as the h-CLAT/U-SENS pair; if it confirms SenzaCell is more metabolically competent, GARDskin becomes a genuine candidate for closing part of that gap rather than compounding it.
