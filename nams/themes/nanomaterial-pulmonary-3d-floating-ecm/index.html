Status: emerging (2026-09-15). One laboratory (Korea Institute of Toxicology, KAIST, KRISS), one nanomaterial class (20 nm silica) carrying the full quantitative comparison, no interlaboratory replication. evidence_tier: single-lab-exploratory. regulatory_status: none — the underlying pillar/well platform architecture is named as a technical reference in ISO/TR 22455 (a technical report, not a Test Guideline), and this specific floating-ECM lung assay claims no formal validation.

What we believe now

The problem this method targets. Two nanomaterial-specific confounds a molecular NAM never faces: nanoparticles aggregate and sediment in static 2D culture medium, changing the effective dose cells receive independent of the nominal concentration; and many nanomaterials optically interfere with the fluorescence/absorbance readouts viability assays use, corrupting the signal itself.

The platform. Human bronchial epithelial cells (BEAS-2B) embedded in a floating ECM spot, in a 384-pillar/well automated HTS format. Cells never settle onto a fixed well bottom the way sedimented nanoparticles do, so particle sedimentation and cell position are decoupled — the mechanism the method is built to exploit.

The headline result. In serum-containing medium, 20 nm silica nanoparticles aggregate from ~70 nm to ~3000 nm within hours (DLS/Turbiscan-confirmed). A conventional 2D assay on this medium calls the material cytotoxic (IC50 127.7 µg/mL); the 3D floating format, run on the identical cells and material, shows no cytotoxicity at all. In serum-free medium, where the particles do not aggregate, 2D and 3D agree — both read cytotoxic, 2D IC50 69.2 µg/mL. The paper's interpretation: the 2D complete-medium result is a sedimentation artifact (aggregated mass gravitating onto adherent cells delivers a locally concentrated dose the nominal concentration does not reflect), and the 3D format corrects for it. No third, independent dosimetry method confirms this is the ground truth rather than merely the more internally consistent story; the vault records it as the source's own interpretation.

Why this belongs in the loop-readiness thesis specifically. This is not a case of a missing decision rule in the usual sense (an assay whose readout is objective but whose call needs expert judgment). Here the readout is objective and reproducible within each condition, but the same fully automated pipeline, run correctly, gives opposite calls depending on an upstream physical variable (serum content driving aggregation) that the assay itself does not measure or flag. A loop trusting either format alone, without independently tracking nanomaterial stability, cannot tell a true negative from a sedimentation-masked negative, or a true positive from a sedimentation-driven false positive.

Loop readiness

loop_readiness: automatable-open-loop. The instrument stack (automated liquid handling, fluorescence plate imaging, four-parameter dose-response fitting to IC50) is as machine-native as anything in this vault's assay column. What is missing is not human judgment about morphology or histology — it is a published, fixed rule for which culture condition's answer to trust, and an automated check on the nanomaterial's own stability state before the toxicity call is accepted. Until that rule exists (or the physicochemical-stability characterization is itself automated and gated into the decision), this is automatable-open-loop, not closed-loop-ready: a machine could run every step, but nothing in the source specifies which of two disagreeing, equally-automatable answers a loop should act on.

Open gaps

  • No orthogonal dosimetry method confirms which format's complete-medium call (cytotoxic vs non-cytotoxic) is closer to the true delivered dose — the argument is internal consistency, not an external reference standard.
  • Whether the sedimentation-artifact finding generalizes beyond 20 nm silica to other aggregation-prone nanomaterial classes is not established by this source.
  • The ISO/TR 22455 technical-reference claim has not been independently checked against the ISO document itself.
