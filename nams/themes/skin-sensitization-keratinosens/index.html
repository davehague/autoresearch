KeratinoSens — ARE-Nrf2 keratinocyte activation (skin sensitisation KE2) — method

Status: consensus (2026-07-05) — regulatorily adopted on both axes. evidence_tier: regulatory-adopted, regulatory_status: OECD-TG-adopted (OECD TG 442D). A component of the 2-out-of-3 defined approach; the validated reference method for the ARE-Nrf2 key-event slot.

What we believe now

KeratinoSens reads the keratinocyte-activation key event (KE2) via an ARE-Nrf2 luciferase reporter. It calls sensitiser vs non-sensitiser at 77% accuracy (155/201), 78% sensitivity, 76% specificity vs LLNA, ~85% within/between-lab reproducibility. One input to the 2o3/ITS defined approaches — used in combination. Cytotoxicity can confound the signal; specificity (~76%) is middling.

Loop readiness

loop_readiness: closed-loop-ready — ARE-Nrf2 luciferase induction read as luminescence against EC1.5/IC50 thresholds.
