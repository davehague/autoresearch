What we believe now

BCPredictor (Qiu, Wu, Wan, Gao, Zhao, Zhuang & Jiang 2026) is a multi-modal deep-learning model — a graph attention network over molecular structure fused with a fully-connected network over structural descriptors, breast-cancer-relevant bioassay activity, and estrogen-/progesterone-receptor docking scores — trained on 897 compounds to rank environmental chemicals by evidence of rodent mammary-tumor hazard. On an independent external benchmark it reports AUC 0.928, recall 0.892, with the mechanistically- anchored features (bioassay + receptor docking) improving AUC by up to 7.8% over structure alone. Deployed as a free, cloud-hosted web interface for single-compound and batch screening.

No prior map in this vault addressed mammary-tumor/breast-cancer-specific computational screening; the two physical carcinogenicity assays (carcinogenicity-cell-transformation-assay, carcinogenicity-hepatocyte-rds-nongenotoxic) measure a different information type (cell transformation foci; receptor-dependent-species proliferative response), and in-silico-qsar-read-across has no endpoint-specific instance for this question.

Loop readiness

loop_readiness: computational-connective — not a physical assay (rule 1 of the deterministic ladder). The open question is not whether the output is machine-readable (a ranking score is) but (a) whether performance holds outside the 897-compound training domain, and (b) that the training/evaluation labels are rodent-derived — the model predicts what an animal study would find, not a NAM-grounded ground truth, so a loop using this tool to select the next chemical to test is still one step from replacement rather than at it, the same schema gap this vault logs for PMAL and GanCtrl.
