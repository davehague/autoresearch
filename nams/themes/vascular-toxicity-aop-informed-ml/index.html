Vascular toxicity, AOP-informed machine learning — new endpoint — method map

🚩 NEW MAP, auto-coined 2026-09-27 — and it opens a new endpoint, vascular-toxicity: chemical damage to blood-vessel biology (endothelium, angiogenesis), distinct from the cardiac-muscle/rhythm readouts already held under cardiotoxicity (cardiotoxicity-hipsc-cm-proarrhythmia, cardiotoxicity-triculture-heart-on-chip) and from the broader cardiovascular-risk review at zhang-2026-ai-cardiovascular-toxicity-water-contaminants-review. Status: emerging (2026-09-27). One source, single-lab, structure-based machine learning trained against another automated screen's own classifications rather than against measured biology or an in-vivo reference. evidence_tier: single-lab-exploratory. regulatory_status: none — no Test Guideline, no defined approach, no acceptance pathway exists or is proposed for this endpoint.

What we believe now

AOP 509 on the OECD's public AOP-Wiki is titled "Nrf2 inhibition leading to vascular disrupting effects" — a published causal chain from a molecular trigger (inhibition of Nrf2, a master antioxidant- response transcription factor) through a defined sequence of key events to a vascular adverse outcome.

toukak-2026-aop-informed-ml-vascular-toxicity trained fourteen multilayer-perceptron models, one per key event along that chain, to predict — from a chemical's structure alone (Morgan fingerprints) — whether it would register as active at each step, using EPA ToxCast high-throughput bioassay hit calls as the training ground truth. Applied to 312 emerging organic pollutants (chemicals detected in wastewater with little or no direct toxicity data), the models reached 70–95% accuracy (varying by key event) against that ground truth, and the resulting per-chemical activation profiles flagged ketoconazole, sertraline, and miconazole as vascular-toxicity-relevant — consistent, per the source, with separate literature reports on those three drugs.

Read the chain's weakest link plainly. The model's "ground truth" throughout is not measured vascular injury — it is another automated screening program's (ToxCast's) own hit calls. High accuracy here means the structure-based model reproduces ToxCast well. It says nothing about whether ToxCast's own classifications, or the AOP's key-event-to-adverse-outcome linkages, correctly predict vascular harm in an animal or a human. No dose-response, no calibration, and no comparison to an apical in-vivo endpoint is reported.

Loop readiness

loop_readiness: computational-connective — scored off the ladder, per the deterministic assignment order in shared/evidence-model.md: no physical assay exists in this method's own operation (it consumes structure and another screen's labels, and outputs a prediction); it is a model layer a loop would update, not an assay a loop would run.

  • What it would need to become anything more. A working automatable-open-loop or closed-loop-ready vascular-toxicity NAM would need a physical assay with a machine-readable readout — this method supplies neither; it supplies a computational pre-screen over an existing screen's outputs.
  • The training-target problem is the loop-relevant one. A model trained to reproduce a screening program's own hit calls, then used to prioritise which chemicals get real attention next, is the MODEL ↔ ITS TRAINING ASSAYS correlated-blind-spot shape already logged in docs/backlog.md (2026-07-29): the model is not an independent check on ToxCast, and an automated triage system trusting its output as confirmation would be trusting the training assay's own blind spots by construction. No formal correlated_blind_spot row is set — that shape currently has no field in the schema (same open item logged against quantitative-aop-probabilistic-modelling), and there is no sibling vascular-toxicity map yet to pair it with.
