Bayesian-uncertainty-gated QSAR for metallic-nanoparticle toxicity — method

Status: emerging (2026-11-06). Coined from a single two-author academic study; no independent replication, no regulatory engagement, no external reference panel beyond the pooled 1,363-record training set.

Sub-threads: none — one founding study, one argument. [reviewed 2026-11-06 @ 1 bullets]

Why this map exists

nanomaterial-nam-landscape names a generic computational layer — "AutoML, generative AI, nano-QSAR" — as an enabling technology class, and its 2026-10-02 entry gave nano-QSAR its first performance figure (a descriptor-only classifier). This source is coined into its own map, the same way nanomaterial-pulmonary-3d-floating-ecm and nanomaterial-genomic-transcriptomic-biomarkers were, because it supplies a specific, measured technology distinct from both: a QSAR-feature + Bayesian Neural Network pipeline whose real contribution is a stated, numeric confidence-gated decision rule for when a prediction should be trusted versus referred back to the bench — the closest thing any computational- NAM source in this vault has supplied to the active-learning / uncertainty-aware triage logic an autonomous screening loop would actually need to run unattended.

What we believe now

On 1,363 pooled in-vitro cytotoxicity records across 25 metallic-nanoparticle formulations, evaluated under formulation-grouped cross-validation, a Bayesian Neural Network (BNN) matches or slightly exceeds Random Forest on raw discrimination (ROC-AUC 0.979 vs. 0.974) but underestimates toxicity at the naive 0.5 threshold (recall 0.520) and is worse-calibrated than plain logistic regression (ECE 0.130 vs. 0.046). Its distinctive output is per-prediction uncertainty, which on its own flags most misclassifications (AUROC 0.92) but — this is the finding that matters for a loop — does not rise for formulations outside the training descriptor space; that failure mode is caught only by an independent leverage (applicability-domain) check. Combining both criteria retains 44.2% of the test set as "confident enough to act on," where recall rises to 0.942 and the false-negative rate falls to 0.058; the remaining 55.8% is explicitly routed to confirmatory testing rather than given a model-only call.

Loop readiness

loop_readiness: computational-connective — rule 1 of the deterministic ladder: no physical assay, a pure model, scored off the physical-readout ladder entirely. Unlike most computational-connective entries in this vault, this one is not graded on predictive accuracy alone — its contribution is a confidence-gated triage rule with stated numbers, which is the mechanism an active-learning loop would use to decide whether to trust a prediction or schedule a confirmatory wet-lab run. This is not an endorsement of the underlying toxicity call — the BNN is not the most accurate or best-calibrated model tested, and the uncertainty estimate has its own documented blind spot (training-domain extrapolation), patched only by a second, unrelated check.
