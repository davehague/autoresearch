Machine-learning models in toxicology — the model layer's own quality record — model-layer map

🚩 CONVENTION DEPARTURE — flagged for human review. Not a method map, not a framework map, not an infrastructure map — a model-layer quality map. Its endpoint (model-layer-quality) is not a toxicological endpoint, and its subject is not a method but the reporting practice of an entire class of methods. The vault's fifth non-method map. Logged in docs/open-gaps-log.md. Git is the undo.

The loop_readiness value is a judgment call, recorded as one. computational-connective is assigned because the subject of this map is the model layer a loop would update — but the tier was written for models ((Q)SAR, PBK), and this map grades an audit of models. not-applicable was the alternative. The choice was made because a not-applicable grade would hide this finding from the loop-readiness view, which is exactly where it belongs. Schema strain, logged.

Status: emerging (2026-07-18). One source, a systematic review. evidence_tier: peer-reviewed-method records only the standing of the sourcing instrument — the vault's tier ladder still has no rung for a review or a perspective, and this is now the third instance of that schema gap (after the FDA draft guidance, 2026-07-12, and Hartung's perspective, 2026-07-13).

Why this map exists

The vault has always graded the model half of the loop optimistically. Its two computational-connective maps — in-silico-qsar-read-across and pbk-qivive-toxicokinetics — are described as "the model layer a loop would update," and in-silico is genuinely the furthest-along thing in the vault (under ICH M7, a (Q)SAR prediction can already replace the Ames test outright).

Separately, the vault holds regulatory-acceptance-ai-model-credibility, where FDA prices a model by model risk = model influence × decision consequence — how alone the model is in the decision, times what happens if it is wrong. A closed loop maximises model influence by construction, so it draws the heaviest evidentiary burden the framework can impose.

What was never checked: whether the toxicology machine-learning literature can actually pay that bill. This map is that check.

What we believe now

"many different machine learning methods are used in toxicology, often with appropriate internal validation. However, in only half of the cases, interpretation methods are used." — Kappenberg et al. 2026 (PMID 42059907), Archives of Toxicology

A systematic review of toxicology machine-learning papers indexed in PubMed or published in Computational Toxicology, 2022–2024, assessing methods used and how they are reported. Its findings:

What was checkedWhat was found
Internal validationGenerally done, and done appropriately — the good news, and it is real
Interpretation methodsUsed in only ~half of cases
Missing-value handling"very frequent gaps in reporting"
Data availabilitySubstantially underreported
Code availabilitySubstantially underreported

The reframe this forces. The vault has spent every run asking whether a model is good enough. This source asks whether anyone can tell — and reports that, about half the time, the paper does not say how the model reached its answer, what was done with the holes in the data, or where the data and code are.

The blocker on the model half of the loop is not accuracy. It is accountability. Nothing here says the models are wrong. It says you frequently cannot check — and "you cannot check" is precisely the thing FDA's credibility assessment is designed to refuse.

The honest brake, stated because it matters: this measures reporting practice, not model correctness. A group that never published its code may still have an excellent model. Under-reporting is evidence about the literature, not about the science — and this map must never be cited as if a method were refuted.

Loop readiness

loop_readiness: computational-connective — not a physical assay; this is the model layer itself. The loop_blocker is the accountability gap above. Note what does not follow: no method map's tier moves on this source. A finding about how a field writes up its models is not a finding about any one model.

Through-line

  • 2026-07-25 — This map turns out to be the measurement of what an exemption permits. The ICCVAM Validation Workgroup's framework (March 2024 — validation-paradigm-nam-confidence) exempts, in footnote 1, "large scale roboticized high-throughput screening assays and machine learning-based in silico approaches" from step 5 of building confidence, interlaboratory evaluation. The substitute the report offers for the ML case is documentation: "Use of computational algorithms, e.g., machine learning models, and software (including version number) should be well-documented to ensure reproducibility." This map measured how well that documentation is actually done. Kappenberg et al. found interpretation methods reported in only about half of 2022–2024 toxicology machine-learning papers, with missing-value handling, data availability and code availability substantially underreported. So: the regulator waives the requirement that a result reproduce elsewhere, and accepts a documentation requirement in its place, and the documentation requirement is the one the literature already fails. Not an accusation of wrongness — the same diagnosis this map has carried since it was coined: nothing says the models are wrong, only that the record needed to check them is not being kept. Two useful notes: the version-pinning requirement is exactly the remedy the vault named for the closed-loop-ready tier's determinism problems (2026-07-19 Bayesian rule, 2026-07-24 Markov chain Monte Carlo estimator), now stated by a federal framework rather than inferred; and ICCVAM specifies no distinct confidence-building procedure for computational methods beyond documentation and context of use.   • 2026-07-22 — The model layer acquires a case where the model replaces the control, not the test. Ingested the virtual-control-group (VCG) proposal inside Kopańska & Hartung 2026 — synthetic control cohorts assembled from historical control-animal data instead of dosing fresh controls, claimed within the EU VICT3R consortium to cut animal numbers by 15–20%, "in some cases… even up to 30%." It lands here rather than on a method map because a VCG is not an assay: it is a model substituting for a measurement, statistically the same act as a (Q)SAR standing in for a test. The acceptance gate is the most concrete criterion in the whole framework — "Type I error inflation remains within a pre-specified margin", an explicit admission that synthetic controls will raise the false-positive rate and a demand that the increase be bounded and declared in advance — plus preserved operating characteristics across labs and animal substrains (covariate shift, named as such). Two brakes. A control group is not only a baseline estimate, it is the study's internal check that this run worked — healthy animals, normal housing, competent technique — and a historical control cannot detect that today's run was anomalous, because it was not there. And a synthetic control is only as good as the documented provenance of the historical data it is built from (strain, lab, decade, husbandry) — exactly the metadata this map exists to record the field is worst at keeping. Status holds at emerging; stance: open-question, no VCG performance data in the source. And the vault's line holds: VCGs reduce animals, they do not replace them, and this map does not report the two as the same achievement. → virtual-control-groups-synthetic-controls

  • 2026-07-26 — The accountability blocker reaches the wet lab, and a trained scorer turns out to carry an applicability domain of its own. Status held at emerging; loop_readiness: computational-connective unchanged. Three of tonight's five sources land here. (1) The European Commission's Joint Research Centre — the unit hosting EURL ECVAM — names domain shift as the operative failure mode for a deployed deep-learning image scorer: "caution must be exercised to appropriately define the range of applicability of a model and avoid domain shift." That is a second applicability domain, defined by the training images rather than by chemistry, stacked on top of the assay's chemical domain — and no guideline in this vault measures it. It is invisible to every acceptance criterion the assay already runs, because those test the biology, and a plate can be perfectly valid on images the model has never seen the like of. The vault already holds a measured instance and had filed it wrongly: carcinogenicity-cell-transformation-assay's scorer drops from AUC 0.95 on its training chemical to 0.87 on unseen chemicals — recorded as "single-lab, weaker evidence", when it is more specifically the model's applicability domain being crossed and the cost being visible because somebody tested for it. (2) The recommended controls are release engineering, not toxicology: version control of training data and models, verification "with a fixed set of input images and by proving that the results obtained are consistent" (a golden-file regression test), problem-specific metrics rather than accuracy on the abundant class, and multi-annotator checks. The class-balance point lands directly on genotoxicity-buccal-micronucleus-cytome, whose reviewed models score 98%/95% on the abundant easy cell classes and 82–85% on the micronucleated cells carrying the entire signal. (3) ⚠ And the accountability blocker gets its cleanest wet-lab instance yet: cardiotoxicity-hipsc-cm-proarrhythmia (coined tonight) has a working, fully mechanical decision rule — median ROC-AUC 0.982 — whose weights, training data and code are "available from the corresponding author upon reasonable request." This map's blocker says the problem is "not accuracy — ACCOUNTABILITY … the literature frequently does not let you check." That is exactly it, in a method, with a number attached. → a-trained-scorer-has-its-own-applicability-domain, a-decision-rule-that-exists-but-is-not-published

  • 2026-07-27 — A second failure mode for the model layer, upstream of the reporting one. Status and loop_readiness both HELD. This map's blocker is "not accuracy — ACCOUNTABILITY … the literature frequently does not let you check." iqbal-2026-learning-the-assay-not-the-hazard adds a complementary problem one step earlier: the training labels themselves. Screening hit-calls conflate target engagement with non-specific cytotoxicity and assay interference; the flags separating them are published and routinely dropped; and because the confounders are structure-linked, the resulting model scores well precisely because it learned the artifact. Put the two together and the model layer has a problem the vault had not stated: you cannot audit your way out of this one. Full reporting of code, data and interpretation methods would document a model that learned the wrong thing perfectly. Accountability is necessary and not sufficient. A Commentary, no data, nothing quantified; this map's own domain gate applies — it grades a practice across a literature and refutes no named model. → models-trained-on-hit-calls-learn-the-assay

  • 2026-08-05 — A MODEL PAPER THAT REPORTS ITS OWN LOSING METRIC — AND THE LOSING METRIC IS THE ONE THAT MATTERS. Status HELD at emerging; loop_readiness HELD at computational-connective. Ingested albi-2026-semantic-knowledge-qsar-gnn (iScience 29:116937, DOI 10.1016/j.isci.2026.116937). Primary home is in-silico-qsar-read-across; this map keeps the reporting finding. This is the good case by this map's own measures — open access, public data, five random runs per configuration with standard deviations throughout, calibration reported alongside discrimination, model explanations quantified against a benchmark's ground-truth attributions, an explicit limitations section, and a funding_flag: [method-developer] disclosed in substance (the senior author built the knowledge graph being evaluated) rather than hidden. And it publishes the comparison that undercuts its own headline: AUROC up significantly, AUPRC and MCC not better than a plain random forest. ⚠ The reporting lesson is the one this map exists for, and it is a metric-selection lesson. The 2026-07-19 entry above recorded a paper whose abstract claimed "reliability and generalizability" for a result below its own majority-class baseline, because no convention required the comparison that would catch it. Here the comparison was made and was published — and a reader who stops at the abstract, which says "semantic models improve discrimination while maintaining calibration comparable to structure-only QSAR models," still walks away with the wrong impression, because "discrimination" is doing work there that only AUROC supports. Candour in the body does not survive compression into the abstract, and this map has now seen the failure from both directions: the missing comparison, and the present-but-unsurfaced one. → the-metric-that-improved-is-not-the-one-a-decision-uses

  • 2026-08-19 — The other half of this map's problem arrives: not what the literature fails to report, but what it never published at all. Status HELD at emerging; loop_readiness HELD at computational-connective. Ingested caldeira-2026-negative-results-nams (Alternatives to Laboratory Animals (ATLA), Comment article, DOI 10.1177/02611929261470751, PMID 42485650, online 22 July 2026; not open access — the SAGE landing page served a Cloudflare bot-verification interstitial at the browser rung, a new non-retrieval route for this repo's log — digest built from the complete published abstract, which for a one-page Comment is effectively its thesis). (1) The claim: negative and null results are largely not published, which repeats experiments unnecessarily (with an animal cost) and "delays the development, validation and uptake of alternative methods, including NAMs" — a method-development programme cannot see which designs already failed, and a validation exercise cannot see which laboratories already could not reproduce a method. (2) ⚠ The vault's extension, which the Comment does not draw. This map already grades whether the toxicology machine-learning literature lets you check its models; the missing negatives mean an entire class of result was never published to check. That is a structural absence, not noise — a model fitted to that corpus has not observed a failure rather than being uncertain about one, and no additional data from the same source repairs it, because the same filter produced that data too. (3) It bites the loop in two different places. The model half gets a second, independent mechanism for the defect models-trained-on-hit-calls-learn-the-assay already records. The deciding half gets the sharper version: Bayesian optimisation and active learning shape a posterior over where the interesting region is, and they need the failures at least as much as the successes — a prior built on a filtered literature does not start uninformed, it starts confidently wrong, and the loop then spends its budget confirming that shape. (4) The rail, one layer up. The shared failure here is not between two assays but between every study of every assay, all filtered by the same publication process — so a loop cannot catch it by cross-checking sources. (5) No number in it.   • 2026-08-20 — Two ripples about what a published model does and does not let you check. Status HELD; loop_readiness unchanged. (a) A model you can use and cannot audit. shen-2026-bbbprofiler-se3-transformer-bbb (Environmental Science & Technology 60(32): 22653–22664, DOI 10.1021/acs.est.6c06459) deploys a blood–brain-barrier predictor as a free public web tool while the paper describing it is paywalled with no free deposit anywhere (Europe PMC has no full-text entry; OpenAlex reports oa_status: closed; pay-per-view USD 48; the supporting information is access-gated). So the predictions are freely obtainable and the method is not. Dataset construction, split protocol, comparator baselines and calibration are unread — recorded as gaps, not estimated. This is the same shape as the access_gate this vault set on login-gated model endpoints on 2026-08-14: what is gated is the ability to CHECK. Added 2026-07-19 — this map's finding, with a face on it

No status moves and no tier moves. But deep-learning-dart-prediction-recall-gap (Ahn et al. 2026) is the first paper ingested since this map opened that can be measured against it — and the result sharpens the map's own framing.

By this map's criteria, Ahn et al. is a good case: publicly funded, funding_flag: none, data shared, an imbalance-appropriate primary metric (F1) chosen and justified, an applicability domain computed and applied, limitations enumerated, and the failure of the paper's own headline method (multi-task learning) reported plainly. It does more of the right things than the median paper this map audited.

And its abstract still claims "balanced predictive performance … confirming the reliability and generalizability" of an external result that — on a set that is 83% positive — scores F1 0.68 against a majority-class baseline of ≈0.91. The paper reports no baseline comparison. (That arithmetic is a vault inference on the authors' own numbers, flagged as one.)

This refines the map's central claim. The finding was "nothing says the models are wrong, but you frequently cannot check." Here you can check — the data are shared and the class balance is in the paper's own Table 1 — and the claim still outran the arithmetic. So transparency is necessary and not sufficient. The missing artefact is not only disclosure; it is a required comparison. No convention in toxicology machine learning obliges a model to be reported against the null model appropriate to its own dataset, and on imbalanced safety data that is precisely the comparison that decides whether a model is doing anything at all.

For an autonomous loop the stakes are higher than for a reader. A human skims the abstract and moves on. A loop that ingests published model performance to decide which model to trust will select on the reported number — and on imbalanced endpoints the reported number can be maximised by a model that has learned the base rate and nothing else. (Vault inference, flagged as one.)

Added 2026-07-21 — someone proposed the missing artefact

  • automation-self-driving-labs gains ToxMCP (Djidrovski 2026), and it is the fitting for this map's gap. This map measured the absence: interpretation, data and code reported in only about half of toxicology ML papers. ToxMCP proposes provenance bundles that bind every numeric claim to a tool output, recording software versions, model hashes and timestamps, exportable as an audit bundle. That is the artefact whose missing-ness this map counted — accountability as infrastructure rather than as author discipline. Two caveats keep it honest: it is a proposal (one author, no executed reproducibility evaluation — its own protocol is future work), and it addresses reporting/traceability, not model correctness, which this map has always kept separate. No status or tier moves. The gap this map named now has a proposed answer; it does not yet have a demonstrated one.
