What we believe now

The eye-irritation battery (eye-hazard-iata-gd263) is built entirely from physical measurements — tissue viability, protein denaturation, barrier electrical resistance. This map holds the endpoint's first machine-learning classifier predicting ocular irritation directly from chemical structure, with no cells and no tissue anywhere in the pipeline.

Lu, Dey, Zhao, Wallqvist & AbdulHameed 2026 (NAM Journal, US Defense Health Agency) compared 49 model configurations — seven molecular representations (structural fingerprints, Mordred physicochemical descriptors, two chemical-language-model embeddings, raw molecular graphs) crossed with nine machine-learning algorithms — on 3,665 compounds (1,824 irritants, 1,841 non-irritants) compiled from the OECD eChemPortal. A deliberately hard train/test split (Butina structural clustering, not random) forced the held-out test set to contain chemicals structurally distinct from the training set.

The best model — TabPFN (a tabular prior-data-fitted transformer) on Mordred descriptors — scored 0.76 accuracy / 0.52 Matthews correlation coefficient (MCC) under cross-validation, but only 0.70 accuracy / 0.40 MCC (0.81 sensitivity, 0.57 specificity) on the 550-compound held-out test set — a real, measured drop when facing genuinely novel chemistry, which the authors call "moderate" generalization. An applicability-domain filter retained 91.8% of the test set as "in-domain," where accuracy rose modestly (0.71/0.42) — real evidence the domain filter does something, though the gap to a strong predictive result remains wide.

The model returns a binary irritant/non-irritant call. Every adopted eye method in this vault's battery targets the three-way UN GHS classification (Category 1 serious eye damage / Category 2 irritation / No Category). The authors state plainly that their model cannot support legally compliant GHS labeling, and position it as a screening/prioritization tier, not a replacement for any wet-lab method.

Loop readiness

loop_readiness: computational-connective — not a physical assay (rule 1 of the deterministic ladder). The open question for this axis is not whether a machine can read the output (it already does — a model score is as machine-readable as it gets) but whether the model's generalization to novel chemistry is strong enough, and its output granular enough (binary vs. three-way GHS), to feed a loop that would otherwise defer to the wet-lab battery. Neither is yet demonstrated.
