What we believe now

Colonoids are miniature gut-lining tissues grown from a donor's own stem cells in a supporting gel, which self-assemble into something with the layered architecture and cell types of real colon epithelium. They are primary human tissue from a named donor, not a cell line — which makes them biologically honest and completely unstandardised.

The endpoint they are aimed at is a real and largely uncovered one. Damage to the gut lining is among the most common dose-limiting toxicities in cancer treatment and a frequent reason patients stop therapy. This vault holds maps for skin, eye, liver, kidney, lung, heart, blood, brain, thyroid, testis and fish. It has held none for the gut, and the non-animal coverage is essentially nil — gastrointestinal-toxicity-has-no-non-animal-method.

What the opening source actually established, and it is a methodological finding rather than a performance one. Doxorubicin (a DNA-damaging chemotherapy) was run through human colonoids, mouse colonoids and mouse colon tissue, with whole-transcriptome readout. All three converged on the same core damage programme — cell-cycle arrest, DNA-damage response, repair, apoptosis, and a shared p53 gene set (BAX, INKA2, ZMAT3). That convergence is reassuring and nearly undiscriminating: it is what almost any DNA-damaging agent does to almost any dividing tissue.

Underneath it, the same dataset gave two different answers at two resolutions. Gene by gene, the closest match to mouse colon was the mouse colonoid — species dominates. Grouped into pathways, the two colonoid systems resembled each other — culture format dominates. Both true, of the same experiment. The consequence is stated in full at species-and-format-imprint-at-different-data-resolutions: "does the non-animal model agree with the animal study?" has an answer per resolution, and the resolutions rank the models differently — so a validation study reporting a single concordance number has silently chosen a winner.

What the authors say it is not. "Missing vascular, immune, and systemic context means clinical validation remains necessary." An epithelium-only model can say what a drug does to gut lining cells. It cannot say what happens to a gut.

Loop readiness

loop_readiness: automatable-open-loop — by rule 4 of the deterministic ladder: machine-readable readout, no fixed data-interpretation procedure.

Readout: whole-transcriptome sequencing. Fully machine-generated and machine-parseable — no human scores anything by eye, which is what keeps this off the human-in-the-loop rung. Organoid culture is also a recognised automation target; nothing about the physical format is the obstacle.

Decision rule: none, and the reason separates this from most of the vault's automatable-open-loop maps. The usual case is administrative — the measurement is settled and nobody set the cut-off, as with OECD Test Guideline 493, where the guideline states outright that no agreed interpretation method exists. Here the measurement has never been anchored to an outcome at all. There is no validated reference chemical set, no accepted comparator, no regulatory question the number is supposed to answer. You cannot write a data-interpretation procedure for a measurement nobody has shown predicts anything. That needs an anchoring study, not a committee — a distinction the vault flagged as a schema problem on 2026-08-26 and that this map is now a second instance of.

And there is a data-layer trap specific to this endpoint. The source benchmarked its results against the Comparative Toxicogenomics Database — the public curated record of which chemicals change which genes — and found it "highlighted underrepresented GI-relevant signals, indicating gaps in intestinal toxicogenomic annotations." The obvious way to build a decision rule here would be to score against that database. It is thinnest on exactly the tissue-specific biology this endpoint needs, so a loop treating it as ground truth would be most confident about the biology the database happens to cover.
