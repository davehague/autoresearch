Ames bacterial reverse mutation test (OECD TG 471) — genotoxicity — method

Status: consensus (2026-07-07) — regulatorily adopted on both axes. evidence_tier: regulatory-adopted, regulatory_status: OECD-TG-adopted (OECD TG 471). The gene-mutation member of the in-vitro genotoxicity battery — pairs with the micronucleus test (TG 487) to close the genotox-battery gap flagged since 2026-07-06.

What we believe now

The bacterial reverse mutation test exposes auxotrophic strains of Salmonella typhimurium and Escherichia coli (≥5 strains) to a chemical at ≥5 concentrations, ± S9 metabolic activation; a mutagen induces reverse mutations restoring amino-acid synthesis, counted as revertant colonies. It detects point mutations (base substitutions + frameshifts) — the gene-mutation endpoint the chromosome-damage micronucleus test (TG 487) does not cover. Adopted as OECD TG 471 (first 1997; revised 26 June 2020, merging the former TG 471 + TG 472). Trustworthy for its endpoint, with the field's standard caveats: no single genotox assay stands alone (read within a battery), and Ames has a known false-positive tendency for some chemical classes that follow-up testing resolves.

Loop readiness

loop_readiness: automatable-open-loop — Colony counts are countable by machine, but no fixed call rule is recorded. Note the asymmetry worth watching: under ICH M7 a (Q)SAR prediction can already replace this assay outright — the computational layer is regulatorily ahead of the automated one.

  • Blocker: TG 471 publishes no positive/negative decision threshold.
  • Blocker annotated 2026-08-07 — the escape hatch exists and does not clear the blocker. A single laboratory has demonstrated a fixed threshold rule in a droplet-microfluidic format that "eliminated subjective scoring" (droplet-ames-removes-the-person-who-counts-colonies). It covers one of the ≥5 required strains and does not report whether it runs ± S9 metabolic activation, and the guideline's rule is still absent — so the tier holds at automatable-open-loop. What changed is that the blocker is now known to be solvable in principle rather than architectural.

PARC Work Package 5 pairs this assay (TG 471) with the in-vitro micronucleus test (TG 487) and the Bhas-42 cell transformation assay as the Tier 1 genotoxicity/carcinogenicity screen for eight BPA replacement chemicals — the three-way combination covering gene mutation, chromosome damage and non-genotoxic transformation.   • 2026-08-07 — ⚠️ SOMEBODY WROTE THE MISSING CALL RULE AND RAN BACTERIA AGAINST IT — FOR ONE STRAIN OF FIVE, IN A FORMAT THAT IS NOT THE ADOPTED TEST. Status HELD at consensus; loop_readiness HELD at automatable-open-loop; the loop_blocker is annotated, not cleared. Ingested cao-2026-droplet-microfluidic-ames-mutagenicity (Journal of Applied Toxicology 2026 Aug, PMID 41566874; TU Ilmenau micro/nanotechnology institute + German Federal Institute of Hydrology; funding_flag: [none] provisional — the full text is paywalled (Wiley HTTP 402) and the funding statement itself was not readable, and this remains a method developer reporting their own format's throughput). (1) The loop-move claim, in this vault's own vocabulary. A tube-based droplet-microfluidic Ames test: the culture is broken into nanolitre droplets, each an independent micro-culture read by multiparameter optical detection, and mutation is scored as the fraction of droplets containing revertants against a fixed threshold rather than by a technician counting colonies. "reduced reagent consumption by > 90%, generated statistically powerful datasets within 48 h, and eliminated subjective scoring." Optimal inoculum 10⁶–10⁷ cells/mL ("maximized sensitivity while limiting spontaneous revertants"); reference mutagen 4-nitro-o-phenylenediamine gave a clean dose-response with cytotoxic suppression above 8 µg/mL. droplet-ames-removes-the-person-who-counts-colonies (2) Why the tier does NOT move. The vault's third axis grades the method as adopted: TG 471's own data-interpretation procedure is what an automated system would have to execute, and the guideline still publishes no fixed positive/negative call rule. One laboratory demonstrating a threshold in a research format is the existence of an escape hatch, not a change to the door — the identical discipline already applied to developmental-toxicity-zebrafish-teratogenicity, where a Vision Transformer showed the eye-scoring step is learnable and that map correctly stayed human-in-the-loop. What changes is the reading of the blocker: "no agreed decision rule" is no longer an architectural fact about the biology. (3) ⚠️ AND THE AUTOMATED PART IS A FRAGMENT OF THE ASSAY, WITH THE MOST CONSEQUENTIAL QUESTION UNANSWERED. TG 471 requires ≥5 strains at ≥5 concentrations, each ± S9 metabolic activation. This is TA98 alone — a frameshift detector, one of the panel's several distinct detectors — and the abstract never mentions S9 in either direction. Not asserted as absent; recorded as the open question, because the answer decides whether a cheap high-throughput genotoxicity format rebuilds the exact missing-metabolism blind spot the vault already records for the ROS assay ↔ 3T3 NRU pair. A screening cascade that runs the cheap format first, at scale, would filter out bioactivation-dependent mutagens before anything expensive saw them — and an automated system handed a threshold rule has every incentive to read a screen as an answer. automating-an-assay-fragment-is-not-automating-the-assay (4) evidence_tier: single-lab-exploratory, regulatory_status: none. One lab, one strain, one mutagen, no reference-chemical panel, no concordance against plate-format Ames, no threshold value published, no ring trial. The plate assay's adoption does not travel with the biology into new hardware.

  • ⚠️ A blind-spot QUESTION, deliberately not a blind-spot FLAG. correlated_blind_spot is not set on this map. If a future full-text read confirms no-S9, this format shares the exact missing-biotransformation failure mode the vault records for the ROS assay ↔ 3T3 NRU pair, and the flag should be set then — on the format, which the schema currently cannot address separately from the assay. Logged in docs/open-gaps-log.md.
  • The ICH M7 asymmetry gets sharper, not weaker. The layer that skips the bacteria entirely is further ahead than the layer that runs them faster.
