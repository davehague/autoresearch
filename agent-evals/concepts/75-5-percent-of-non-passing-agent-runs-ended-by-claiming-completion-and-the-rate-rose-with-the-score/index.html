75.5% of non-passing agent runs ended by claiming completion, and the closer a run got to passing the more confidently it claimed it, so the terminal self-report is anti-diagnostic

Grounded in frontierchallenge-scientific-workflow-completion; belongs to evaluating-over-a-horizon.

Across 970 Claude Code trajectories on 97 end-to-end scientific workflows, 641 of the 849 non-passing runs (75.5%) ended with a final message containing lexical completion language. Only 13 (1.5%) explicitly indicated that work was still running, waiting, or in progress.

The banding is the part that makes this a finding rather than an anecdote. Completion language was less frequent among runs scoring below 50 (61.2%) but stayed above 78% in every non-passing band above 50, and appeared in 90.1% of passing runs. So the frequency rises monotonically with score across the failing range and then keeps rising into the passing range. An agent that has done most of the work and missed one required deliverable is nearly as likely to declare victory as one that succeeded — which means the self-report is not merely uninformative, it is most misleading exactly where the decision is closest.

This retires a class of cheap signal this vault has been treating as promising. making-submission-an-explicit-agent-action-freezes-which-candidate-is-being-scored made the agent's own act of submission load-bearing. enabling-thinking-cost-the-strongest-model-9-9-points-by-making-it-submit-early treated the stopping decision as a measurable variable. Both are still right about when the agent stopped. This says nothing the agent asserts about having finished can be believed: 1.5% of failing runs admitted incompletion, against a 100% actual incompletion rate.

Combined with the second signal in the same paper, both cheap triage routes fail together. Tool errors appeared in 80.7% of non-passing and 94.2% of passing trajectories (tool-errors-appeared-in-more-passing-runs-than-failing-ones-so-error-presence-is-not-a-triage-signal). So on this suite you cannot triage a run by asking whether the agent thinks it finished, and you cannot triage it by asking whether anything went wrong. The only thing that separates the two populations is a Grader reading the artifacts.

The horizon framing is where this bites hardest. The longer the run, the more expensive it is to check the artifacts, and the more tempting it is to take the agent's word. This says the temptation scales the wrong way: long multi-stage workflows are precisely where the conjunctive contract has the most ways to be missed, and where the agent's terminal summary is a summary of a run it cannot fully re-inspect either. Any unattended pipeline that gates on "the agent said it was done" — a queue that advances, a downstream job that consumes, a human who gets paged only on self-reported failure — is gating on a signal with a measured 75.5% false-positive rate.

What to do instead is what the benchmark itself does. Define an explicit output contract, list the required deliverables, and let an executable check over the artifact bundle decide. The authors' own conclusion says it plainly: more reliable agents "will require explicit contract tracking, cross-artifact validation, and evidence-based completion checks." Note that this is a design requirement for the system, not only for the eval — the same contract that grades the run is what an unattended pipeline should gate on.

Single study, single runs per configuration. The 970-trajectory analysis is restricted to Claude Code, because that was the only scaffold with a common event schema across models — which is a real scope limit and, separately, a small argument for the trace-interchange thread. "Lexical completion language" is a keyword-level classification of a final message, so it catches confident phrasing rather than a considered claim of success; a run that says "I have generated the report" while a required figure is missing counts, and arguably should. The direction of the result is not sensitive to that: 1.5% is the number that matters, and it is a floor on how rarely these agents say they are not done.
