The serving quantization decides whether temperature zero is deterministic which is a tenth unwritten variable

Grounded in the-replay-gap-static-evaluation-of-model-switching; belongs to evals-that-localize-the-fix.

Auditing its own control arm, the paper reports: "temperature-0 'determinism' is configuration-dependent: FP8-served controls diverge on over 90% of forks while AWQ-served ones remain near-identical."

A tenth term for the restated model-or-harness question, and it invalidates a control almost every eval here relies on. The running list of things that move an agent's measured performance and go unwritten now reads: risk carrier, environment parameters, reasoning effort, judge severity, evaluation disclosure, network egress, instruction surface, trial count, execution transport (replaying-the-same-model-reply-through-an-added-parser-lowers-success-by-55-to-73-points-so-the-execution-transport-is-a-variable-nobody-declares) — and now the serving configuration. It differs from the others in what it attacks. The first nine change the measured value; this one changes whether repeated measurement means anything, because "we ran at temperature 0" is the standard sentence an eval uses to claim it does not need repeated runs.

Read against the vault's error-bar problem, it makes the problem worse in a specific way. a-single-agent-configuration-run-three-times-has-a-standard-error-of-6-to-12-points-which-is-the-size-of-most-harness-effects-recorded-here establishes that run-to-run variance is the size of most effects recorded here and nearly nobody measures it. The implicit defence — temperature 0, so there is nothing to measure — now depends on a serving detail that no methods section states. Two teams reproducing the same eval on the same weights at the same temperature can sit on opposite sides of over-90%-divergence and near-identical, and neither would know.

Cheapest repair on the list, and it is a sentence. State the serving stack and quantization alongside the model name and temperature. The stronger version, which this paper did and which costs one extra arm: run same-configuration control forks and report their divergence, so the reader sees the noise floor rather than being asked to assume it is zero.

Bounds. One study, reported as an audit of its own controls rather than as a contribution, with two quantizations named and no sweep. It is about action-sequence divergence in a multi-step agent — the setting that amplifies small sampling differences — so it does not directly claim that single-turn temperature-0 output is non-deterministic under FP8, only that agent trajectories built on it are. That amplification is the point for anyone evaluating agents.
