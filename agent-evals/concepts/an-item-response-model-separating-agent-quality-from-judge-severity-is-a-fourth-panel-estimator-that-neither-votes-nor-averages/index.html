An item response model separating agent quality from judge severity is a fourth way to resolve a judge panel, and the first that neither votes nor averages

Grounded in companionbench-judge-severity-separated-from-agent-quality; belongs to what-the-headline-number-averages-away, and bears on what-an-eval-costs-to-run and evals-that-localize-the-fix.

CompanionBench scores 28 agents with a cross-family judge panel and then fits an Item Response Theory model that separates agent quality from judge severity. The panel is cross-family for a stated reason — to dilute same-family favouritism — alongside scale drift, both named as biases prior companion benchmarks left unexamined.

Why this extends. This vault has been tracking judge configuration as an unpriced parameter with no convention behind it: self-judging, a cross-family panel of three on taste axes only, and three judges with majority voting (a-third-judge-configuration-in-one-month-three-judges-with-majority-voting-on-every-axis-widens-an-already-unjustified-range). The complaint was that "three judges" covers at least two different estimators reported identically. Here is a fourth, and it differs in kind rather than in setting. Voting and averaging both treat judges as interchangeable instruments and pool their outputs; a severity model treats each judge as an instrument with its own calibration and estimates the agent net of it. Outvoting a harsh judge and correcting for one are different operations that produce different rankings.

The decision it changes. It gives the aggregation table in what-the-headline-number-averages-away a row it did not have. The table's three regimes — substitutes, opposing groups, gates — all assume the components being combined are measurements of the thing. Judges are measurements of the thing plus a property of the judge, and the right response to that is to model the nuisance term rather than to pick a pessimism setting over it. It also localizes: a score that moves between judge panels is a judge effect, not an agent effect, and the two-factor model/harness frame has no slot for the measuring instrument as a variance source.

Two practical limits are worth stating up front. Severity separation needs many agents scored by the same judges before the parameters are identifiable, so it is available to whoever runs a leaderboard and not to a team scoring one system against a rubric. And it does not reduce the bill — the panel still runs on every item, and the correction is analysis afterwards. That places it with fixed-subset extraction in the category of value that comes from an analysis rather than from a runtime behaviour.

Why single-study. One paper, in a domain this vault cannot independently assess, and the severity separation is reported as a construction choice rather than as a measured result. There is no stated figure for how far the rankings moved once severity was factored out — which is exactly the number that would turn this from a technique into a finding. Anyone citing it should cite it as a technique.

What would move this. The delta: a leaderboard published twice, once pooled and once severity-corrected, with the rank changes reported. That is the judge-axis version of the mean-versus-weakest-link demonstration in mean-and-weakest-link-aggregation-produce-completely-disjoint-top-fives-on-a-54-model-public-leaderboard, and it would be worth as much.
