A judge no stronger than the agent it scores yields no usable signal which is an admissibility condition six configurations here never state

Grounded in label-free-harness-evaluation-teacher-relative-lift; belongs to design-for-verifiability.

"Traditional LLM-as-a-judge offers little signal because it is no stronger than the agent it evaluates." And, as a reported result rather than a motivation: "We further show that LLM-as-a-judge between similarly powered models yields no usable signal."

Six judge configurations are catalogued in this vault and not one states a required capability gap between judge and judged. The list includes a benchmark reusing its own generator model as its Faithfulness judge, a cross-family panel of three on taste axes, three judges with majority voting, an item-response model separating severity, a sampled-screenshot baseline, and a panel of small judges priced at one-seventh. Every one is argued on correctness or on cost. This adds a precondition that sits underneath all of them: name the judge model and the agent model, and if they are the same tier, say what you think the score means.

It turns self-judging from a stylistic complaint into the limit case of a measured null. judge-configuration-is-an-unpriced-construction-parameter-with-two-benchmarks-choosing-opposite-defaults recorded a benchmark judging its own generator's output and this vault has objected to it on general grounds. A capability gap of zero is the extreme of "similarly powered," so the objection now has a stated mechanism and a reported result behind it rather than an intuition.

It cuts against the cheapest judge result on file rather than agreeing with it. a-panel-of-small-judges-beat-a-single-large-one-at-one-seventh-the-cost-which-is-the-first-price-on-a-judge-configuration is the strongest cost argument in this vault for a diverse panel of small models. A panel of small judges rating a frontier agent is exactly the configuration this finding says returns nothing — so the 7× saving may hold on tasks where the small judges are strong enough for the material and evaporate as the agent under test gets better. That is a testable and unrun prediction: hold the judge fixed, vary the agent's tier, and see where the correlation with human labels collapses.

It also bounds the machine-audit lead this vault has been pricing. the-best-automated-critical-error-attribution-reaches-34-percent-accuracy-so-a-machine-audit-is-triage-rather-than-measurement found the best automated attributor at 34% accuracy. If judging requires a capability gap, part of that ceiling is structural rather than methodological — an attributor built on the same model family as the agent it audits is in the similarly-powered regime by construction, and no prompt engineering fixes it.

Bounds. One domain (cybersecurity), reported as a finding with no rates, no models named and no definition of "similarly powered." It is asserted in an abstract as a supporting result for the paper's actual method, so it has had less scrutiny than the main claim. Direction only — the point at which a capability gap becomes sufficient is unstated, which is the number a team would need.
