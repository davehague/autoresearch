Three repeat runs of an agentified evaluator spanned 0.33 Bradley-Terry units against a fixed protocol's 1.61

Grounded in harnesseval-w-agentified-world-model-evaluation; belongs to design-for-verifiability.

The whole evaluation pipeline was run three times over 330 cases and 18 world models. The resulting model rankings move very little: "the envelope of the three fits spans only 0.33 Bradley-Terry units," against the fixed-protocol baseline's 1.61 — "4.9× wider." All sub-agents are held to "a VLM with the same backend, temperature, and frame-sampling configuration."

This vault argues about judge stability constantly and has almost never measured it. Prompt design, panel composition, anchoring, position and verbosity bias, capability gaps — all of it is reasoning about why a judge might be unstable. The direct measurement is three runs and a spread, it costs three runs, and this is the first source here to report it for a whole instrument rather than for an individual rating.

The direction is counterintuitive and that is the interesting part. A pipeline that spawns eight sampled sub-agents per skill has many more stochastic draws than a single rubric call, so the naive expectation is more variance, not less. It gets 4.9× less. The reading that fits: a discrete per-sub-question score is a low-variance output — a sub-agent asked "was the target visible" has few ways to waver — and combining many of them in code averages noise out. A single free-form global verdict has no such averaging, and its variance lands directly on the ranking. So decomposition buys stability for the same reason it buys discrimination (decomposing-one-global-judgment-into-grounded-sub-questions-took-pairwise-accuracy-from-31-9-to-71-7-percent-and-the-draw-rate-from-52-2-to-1-8), and the two findings are one mechanism seen twice.

It gives this theme's grader-validation collection a sixth procedure, and the cheapest one yet. Known-good outputs, holdout agreement against human labels, letting the agent argue an item is broken, difficulty residuals, matched-pair audits against a nuisance variable — every one of those requires building something. Re-running your existing eval twice more and reporting the spread of the resulting rankings requires nothing but compute, and it is the only one of the six that measures the instrument end to end rather than one component of it.

And it is the number that makes any other delta readable. A judge whose rankings move 1.61 units on repetition cannot support a claim about a difference smaller than that. This is the same argument three-run-verdict-agreement-of-74-7-percent-published-beside-a-harness-comparison-is-the-noise-floor-this-vault-has-been-asking-for makes from the task side, arriving independently on the same night from the grader side: publish the rerun spread next to the effect, or the effect has no scale.

Bounds. Single study. Three runs is enough to bound a spread and not enough to estimate a variance, and no confidence interval is given. Bradley-Terry units are not a portable scale — 0.33 versus 1.61 is a ratio worth carrying, the absolute numbers are not. The comparison is against two specific WBench protocols rather than fixed rubrics in general. Temperature is held fixed but not stated, and a low-temperature baseline would narrow both envelopes; this vault already holds that temperature-0 is not a free error bar. No per-model or per-case stability is reported, only the aggregate ranking envelope, so a model could be moving substantially while the fit stays tight.
