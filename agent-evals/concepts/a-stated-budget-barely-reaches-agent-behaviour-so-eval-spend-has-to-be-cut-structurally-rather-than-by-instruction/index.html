A stated budget barely reaches agent behaviour, so eval spend has to be cut structurally rather than by instruction

Grounded in ecoagent-bench-budget-constrained-agents; belongs to what-an-eval-costs-to-run.

EcoAgent-Bench sweeps the budget across a threshold that should change the right answer, and watches GPT-5.4's escalation rate move from 0% to 3%. The budget is stated explicitly, the actions are explicitly priced, and the agent barely responds.

Why this belongs to a theme about eval cost. It is a boundary result rather than a direct one. This theme is about what a suite costs each time it fires, and the tempting cheap lever — tell the agent it has a small budget, tell it to prefer the cheap tool, cap it in the prompt — is the lever this source finds inert. A three-point behavioural response to an explicit priced budget means prompt-level thrift is not a cost control. It is a request.

That leaves the structural levers as the only ones with evidence behind them: cut the item count (adaptive-item-selection-reproduces-full-benchmark-rankings-at-80-to-99-percent-lower-cost-so-eval-set-size-is-a-dial), ship a fixed informative subset instead of live machinery (a-fixed-informative-item-subset-extracted-once-captures-most-of-the-savings-without-adaptive-machinery-in-the-loop), and settle the judge-count question (judge-configuration-is-an-unpriced-construction-parameter-with-two-benchmarks-choosing-opposite-defaults). All three change what the harness executes. None of them asks the model for anything.

The sharper version. If you want an agent to spend less during an eval, take the expensive action away from it rather than pricing it. Remove the tool, cap the tier at the harness, refuse the escalation. The finding here is about a stated budget, and the natural reading is that stated constraints are weaker than enforced ones — which is the same lesson the vault has already learned about self-reported artifacts (an-agents-recorded-plan-recovers-only-part-of-the-true-prerequisite-structure-so-grading-against-the-plan-grades-the-narration).

Why single-study. One sweep, one model, one benchmark, and the escalation rate is a narrow behavioural readout rather than total spend. It is entirely possible that a differently phrased budget, or a budget enforced with visible running totals, would land harder — nobody has tested that. Treat this as a reason not to assume prompt-level budgets work, not as proof that they cannot.
