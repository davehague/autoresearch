A confidence-routed model cascade is an accuracy-preserving claim that only an eval can hold up

Grounded in hamel-ai-product-engineering-notes; belongs to what-an-eval-costs-to-run.

A cascade "route[s] classification tasks to a small model when it's confident and to a large model when it's not," described as "preserving the large model's accuracy."

The technique is ordinary; the qualifier is the whole claim, and it is empirical. "Preserving the large model's accuracy" is a statement about the small model's confidence calibration in the region above the routing threshold — that where it is confident it is also right, at a rate close enough to the large model that the difference does not show. That is true at some threshold and false at others, and the threshold is a number somebody has to measure. Quote the cost saving without it and the sentence is empty.

This vault has a standing complaint that cost levers are published without the accuracy they spent, and the cascade is the cleanest example of a lever where the two numbers are inseparable. Every efficiency result on file has the same structure and most of them handle it worse: the 10.9x-calls-for-0.16x-cost jury, the corpus-pruning family, the 48% token reduction from minimal harness provisioning. In each case the saving is only meaningful beside the quality it did or did not cost, and in each case the pair is what a team needs to decide. The cascade makes the coupling unavoidable because the routing threshold is literally the dial that trades one for the other — which makes it a good template for how the rest should be reported: not a saving and an accuracy, but a curve.

The eval it requires is small and specific. Run the full corpus through both models, record the small model's confidence on every item, and plot achieved accuracy and cost as the threshold sweeps. The threshold where the curve leaves the large model's accuracy is the answer, and the shape of the curve near it tells you how much margin you have when the input distribution shifts — which it will, and which is the failure mode a single validated threshold does not survive.

Bounds. A one-line session description in a practitioner index, with no reported threshold, no corpus, no accuracy delta and no cost figure. Classification is also the friendliest case for this technique: the confidence signal is well-defined, the output is checkable, and the item is short. Nothing here says a cascade behaves this way on generation or on agentic work, where "confidence" has no agreed meaning and the check itself costs a judge.
