Six agent conditions covered 25 to 35 percent of the corpus and declared the analysis complete so a machine error analysis pass needs a coverage denominator

Grounded in shankar-agent-assisted-qualitative-analysis; belongs to what-an-eval-costs-to-run.

Six agent configurations doing grounded-theory open coding over 451 tweets. "Most conditions covered around 25-35% of the tweets." Best was exp2-codes at 68%; worst exp3-hierarchical at 5.5%. Per condition: exp1 28.6%, exp2-codes 67.8%, exp2-memo 30.6%, exp3-hierarchical 5.5%, exp3-independent 25.3%. The mechanism is stated plainly: instructed to work through the entire corpus, "agents don't do this"; "at some point they stop and declare the analysis complete."

It pushes back on the vault's one report of the transcript-audit obligation being paid by machine. parallel-error-analysis-agents-over-stored-traces-is-the-first-report-of-the-transcript-audit-obligation-being-paid-by-machine was recorded 2026-08-10 as unvalidated, with a prior from do-automated-evals-work that automation would find the mechanical failure classes and miss the ones needing domain taste. This is the first measurement of that automation on a structurally identical task — read a corpus of unstructured text, induce a category system, assign categories — by an author with no stake in the result, and the taste prediction lands verbatim: "agents can do the mechanical parts of qualitative analysis fast, but they have no taste."

Coverage is the worse problem and the one nobody was watching for. Taste failures at least produce visibly shallow categories. An agent that silently reads a third of the traces and returns a failure taxonomy returns something that looks complete, and no downstream step detects the missing two-thirds. It also breaks the vault's own stopping rule: twenty-traces-with-no-new-failure-category-is-the-first-stated-stopping-rule-for-the-transcript-audit-obligation says stop when 20 consecutive traces yield nothing new, and an agent that quits early because it decided it was done satisfies that rule trivially and wrongly, since traces never read cannot contribute a new category. Saturation rules assume a reader who keeps reading.

The repair is free and belongs on every automated analysis pass: report the coverage denominator. Count the traces that received at least one label, print it beside the taxonomy. It costs nothing, it needs no ground truth, and on this evidence the number will be embarrassing often enough to be worth printing. That is the same class of check as reporting scored n against submitted n (preserving-a-nan-score-instead-of-coercing-it-is-an-aggregation-decision-the-harness-was-making-silently) — an integrity denominator the machinery already has and does not surface.

The cost reading, which is why this sits in this theme. The transcript-audit obligation is the largest unpriced line item in this vault, and machine execution was the one lead for paying it cheaply. This does not close that lead — the human-reviewed condition worked much better, and cheaply — but it prices the naive version correctly at somewhere between a fifth and a third of the work, with no signal that the rest is missing.

Limits. One practitioner, one exploratory study, 451 short informal texts rather than agent traces, one model, one run per condition, no repeated runs. Descriptive statistics from a single pass, so treat the percentages as orders of magnitude. Against that: it is the only ablation on human involvement in qualitative analysis in 48 sources, and coverage this far below 100% is not a marginal effect that a second run would erase.
