Detailed rubrics and environment feedback partly repaired a failure that looked like the agent's

Grounded in fragility-of-self-improving-agents-variance-task-order-underspecification; belongs to design-for-verifiability.

Manual inspection of the agents' memory banks led to a hypothesis that "task and environment underspecification" drives the observed fragility. The test: feed better specification — "detailed rubrics and environment feedback" — into the memory-construction step. Result: it "partially closes the performance degradation," and "significant gaps still remain, suggesting that other uncharacterized factors contribute."

The direction of the repair is what matters. The intervention was applied to the eval, and the agent got better. Nothing about the method changed. What changed was how clearly the task said what success was and how much the environment told the agent about what had happened. Some fraction of a published fragility result was therefore a property of the benchmark's specification, misattributed to the system under test. This theme's whole argument is that an instrument has properties which have to be checked before its readings mean anything; underspecification is one of those properties, and this is the first result here that measures it by removing it.

The diagnostic is unusually cheap and generalises past self-improving agents. The authors read what the agent had written into its own memory. An agent that accumulates confident, wrong procedural notes is telling you the task never disambiguated the thing it guessed at — and any agent with a persistent scratchpad, memory bank, skill file, or notes directory leaves that artifact behind. This vault's cheapest instruments have all had this shape: read something the run already produced rather than building a new probe. label-count-correlating-with-input-length-at-rho-0-81-is-a-free-detector-for-an-agent-paraphrasing-instead-of-analysing is the same move on a different artifact.

The honest limit is the part that should be quoted back at anyone using this to excuse a weak result. The repair is partial. "Significant gaps still remain" means underspecification is a contributor and not the explanation, so a team that tightens its rubrics should expect some of the fragility to survive. That is the correct shape for a hypothesis validated by intervention rather than proved — and it is more credible than a clean fix would have been, because a clean fix from a hand-formed hypothesis is usually a sign the hypothesis was fitted to the data.

Bounds. Hypothesis formed by manual inspection, tested on the same two systems it was formed from, with no numbers in the abstract for how much was recovered. Suggestive.
