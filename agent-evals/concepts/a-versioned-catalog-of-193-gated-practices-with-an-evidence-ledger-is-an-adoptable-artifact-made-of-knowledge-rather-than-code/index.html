A versioned catalog of 193 gated practices with an evidence ledger is an adoptable artifact made of knowledge rather than code

Grounded in engineering-reliable-coding-agents-system-around-the-model; belongs to build-vs-adopt-eval-tooling.

"a versioned catalog of 206 reliability records: 193 gated practices, including 56 developed in depth, plus 13 research leads; an evidence ledger; ... runnable evaluation and reliability protocols; and five reusable agent skills with evidence maps." Its methods also "record which search lanes were executed, which remain unexecuted."

Every adoptable artifact this theme has catalogued is executable; this one is not. Runners, metric libraries, governance plumbing, task corpora, reference environments, generators, distillates, adapter contracts — eight kinds, all code or data. A versioned practice catalog with an evidence ledger is a different purchase: what you take is a set of practices each carrying a stated evidence grade, and the version number is load-bearing, because practices decay the way scores do (evaluation-scores-are-perishable-knowledge-claims). It is the closest thing in this vault to an adoptable answer to "what should we be doing," as opposed to "what should we run."

The test it has to pass is the one this theme derived from the last packaged-practice artifact. a-packaged-eval-skill-is-labelled-a-floor-by-its-own-author-and-names-six-things-that-generalize-across-projects found that every item in a transferable eval skill was a procedure and none was a criterion — the generic layer knows how to run error analysis and not what counts as an error. A 193-item catalog will be adoptable to the extent its records are procedures and inert to the extent they are criteria, and the five bundled agent skills put it in exactly the same category as that earlier artifact. Nobody has checked the ratio, and the abstract does not say what a "gated practice" is gated on.

The methods disclosure is the coverage denominator this vault demands of machine analysis, volunteered by a human review. six-agent-conditions-covered-25-to-35-percent-of-the-corpus-and-declared-the-analysis-complete-so-a-machine-error-analysis-pass-needs-a-coverage-denominator asks every analysis pass to print what it read; recording which search lanes ran and which did not is that instruction applied to a literature search, and it is the first coverage denominator printed by any source here. Worth generalising: any analysis that could have been incomplete should state what it did not read — which makes the review's own limits checkable rather than rhetorical, and is a norm a single team can adopt without anyone's cooperation.

Bounds. Single-author monograph; 17 of its case records are the author's own systems, and this vault has discounted self-validating single-author artifacts hard before. None of the 206 records is visible in the abstract, so the catalog is recorded as a described artifact rather than an assessed one — no ratio of procedures to criteria, no statement of the evidence grades' distribution, and no independent read of whether the "gated" practices are gated on anything measurable.
