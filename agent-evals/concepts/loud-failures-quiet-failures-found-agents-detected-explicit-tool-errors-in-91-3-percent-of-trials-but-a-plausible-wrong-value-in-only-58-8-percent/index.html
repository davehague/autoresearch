Loud Failures, Quiet Failures found agents detected explicit tool errors in 91.3% of trials but a plausible wrong value in only 58.8%

Grounded in loud-failures-quiet-failures-fault-detection-and-recovery-in-tool-using-agents; belongs to what-the-headline-number-averages-away.

Across 1,920 trials, six models, and 24 multi-step tasks with injected tool faults, agents flagged an explicit tool error 91.3% of the time but a plausible-but-wrong return value only 58.8% of the time — the same models, the same tasks, differing only in whether the tool signaled trouble or returned something wrong that looked fine. A false-positive rate of 26.8% on fault-free control trials sits in between.

Why this extends the theme. A single "fault detection rate" collapsed across fault types would land somewhere between 58.8% and 91.3%, obscuring that detection is actually gated on whether the tool's response looked wrong rather than on whether it was wrong — the paper's own diagnosis is that agents respond to the error channel, not the content. The 26.8% false-positive rate adds a second axis this theme has not filed before: a chunk of apparent "caution" is miscalibrated noise rather than genuine signal, close enough to the silent-fault miss rate to complicate reading either number as a measure of attentiveness.

What it does not settle. Whether the 58.8%/91.3% gap is stable across fault severities within the "plausible wrong value" category, or whether some wrong values are easy to catch and others nearly invisible, is not reported — the paper treats "plausible wrong value" as one fault type rather than a graded family.

Why single-study. One fault-injection layer over one benchmark, six models, no independent replication of the specific detection-rate split.
