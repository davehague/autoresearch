Agents followed a written standard over contradicting code in 39 of 39 trials so a stale instruction file costs more than no file

Grounded in working-set-of-a-coding-agent-coherence-debt; belongs to evals-that-localize-the-fix.

"Availability does not settle every edit: where standard and code disagree, agents follow the standard even when it prescribes the worse code, so a stale convention file costs more than no file." The cell: 39 of 39 trials across two harnesses, a perfect separation, offered by the authors as a boundary on their own framework rather than as a headline.

The finding is about a file almost every repository now has. CLAUDE.md, AGENTS.md, a contributing guide, a migration note, a style doc. This says that when such a document contradicts the working code, the document wins — not sometimes, in every trial tested — and that it wins even where following it produces the worse result. So the instruction file is not a hint the agent weighs against evidence; it is an authority that overrides evidence.

The eval consequence is a control nobody applies. This vault has recorded harness deltas from 7.5 to 28.9 points and has spent runs arguing about what a harness comparison holds fixed — model, decoding, tool surface, seed quality. The instruction file is a harness component with measured authority over the agent's decisions, and no harness comparison in this vault reports it. A comparison of two harnesses run against repositories with different convention files is not a comparison of the harnesses, and given the size of the effect here it may not be a comparison of anything.

It also puts an expiry date on a build-side artifact. a-versioned-catalog-of-193-gated-practices-with-an-evidence-ledger-is-an-adoptable-artifact-made-of-knowledge-rather-than-code argued that written, versioned practice is an adoptable artifact. This is the liability side of the same claim: a written practice that the code has moved past is worse than nothing, because an agent will honour it. Whatever process keeps such a catalogue current is not documentation hygiene, it is a correctness dependency — the same standing maintenance obligation re-executing-predicted-tool-calls-against-live-apis-grades-effect-rather-than-path-and-accepts-multiple-valid-routes carries because its oracle is external and mutable, arriving here from the instructions side rather than the grader side.

The direction of the asymmetry is worth stating plainly. Absent facts produce wrong work rather than absent work (the agent fabricates). Present-but-stale facts produce confidently wrong work. Between the two, the paper's own summary is that the stale case is the more expensive one, because a missing fact at least leaves the agent's prior in play while a stale document replaces it.

Bounds. Single study, single result, and the authors flag its limits themselves: a perfect separation over 39 trials still leaves a wide interval at the lower bound ([0.91, 1.00]), and "these cells do not separate authority from modality or read order" — the standard may be winning because it is prose, or because it arrived first, rather than because it is a standard. Two harnesses only. The conflicts were constructed by the authors, so nothing here says how often real convention files contradict real code, which is the number that would make this actionable rather than alarming.
