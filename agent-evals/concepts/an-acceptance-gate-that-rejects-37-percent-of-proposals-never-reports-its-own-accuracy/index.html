An acceptance gate rejecting 37% of harness proposals never reports its own accuracy, so the unchecked-grader problem has moved one layer up into the machinery that decides what ships

Grounded in opsharness-self-evolving-rca-harness; belongs to the-judge-as-a-maintained-dependency.

A dual-gate verifier decides which self-generated harness changes get promoted into a live RCA system. It rejects 37% of proposals on average, and accepted proposals require 1.7 attempts. The gate's effect on final accuracy is enormous and measured — 0.83 with it, 0.33 without (removing-the-verification-gate-left-a-self-evolving-harness-worse-than-one-that-never-evolved).

What is never reported is how often the gate is right. Nobody measured how many of the rejected 37% were good proposals wrongly discarded, or how many promoted changes were bad ones the outer gate happened to miss. The gate's false-reject and false-accept rates are unmeasured, and the discarded proposals are destroyed along with their stage environments, so they cannot be re-examined later.

This is the exact shape this vault has documented one layer down, arriving one layer up. a-public-scoring-service-shipped-a-three-level-status-label-with-no-published-validation-of-what-it-means and a-shipped-similarity-gate-caught-zero-of-fifty-six-meaning-breaking-edits-and-never-exceeded-0-700-balanced-accuracy-across-ninety-cells are about graders nobody validated. This is a meta-grader nobody validated: a component whose judgements determine what the production system becomes, evaluated only by the downstream accuracy of the system it shaped.

The distinction matters because downstream accuracy is a weak test of a gate, and asymmetrically so. A gate can be badly calibrated in the reject direction and still produce a system that improves — it just improves slower than it should, and nothing in the metric reveals the gap. False rejects are invisible by construction: the proposal is gone, the counterfactual was never run, and the harness that would have existed is unobservable. The only visible failure mode of an over-strict gate is an opportunity cost nobody can price. With verification consuming 49.8% of the evolution token bill (verifying-harness-changes-took-49-8-percent-of-the-token-bill-of-an-evolution-cycle), that is half the budget spent by an instrument of unknown precision.

The measurement is cheap and this vault already has the recipe. Keep a sample of rejected proposals instead of tearing down their stage environments, promote them into a shadow harness, and run the same held-out testbed against both. That is the paired counterfactual paired-with-and-without-trials-make-the-skill-rather-than-the-agent-the-unit-that-gets-a-score describes, applied to the gate's decisions rather than to the harness's components — and a harness proposal is removable in exactly the way that method requires. The reason it is not run is the same reason nobody validates any of the graders in this theme: the system appears to work.

It also completes a pattern worth naming. This vault's judge thread began with LLM judges scoring outputs. It has since found the same unchecked-instrument shape in a drift guard, a public scoring service, a retry classifier, and now an acceptance gate over harness changes. The common property is not that the instrument is a language model — the inner gate here is arithmetic — but that it is a component whose output is a decision rather than a number, so nobody thinks to ask for its error rate.

Single study, and the criticism is about an absence rather than a demonstrated failure — no evidence is offered here that this particular gate is miscalibrated, and its measured effect on the outcome is strongly positive. The claim is that a component with a 50-point effect on final accuracy and 50% of the token budget has no reported accuracy of its own, which is a gap in the reporting rather than a defect in the system. Filed at open-question for that reason. The obvious counter-argument is that the gate's decisions are definitionally correct because it applies a stated rule; that holds for the inner gate, which is arithmetic on measured accuracy and cost, and fails for the outer gate, whose held-out testbed is a resampled stratified sample and therefore an estimate with sampling error nobody quantifies.
