Run 26 promoted to a standing rule that frontier-validated mitigations recover roughly a third on the open checkpoint — three independent confirmations, no disconfirming instance (the-open-weight-model-is-the-one-that-cannot-use-the-disclosure, the-prompt-level-fix-recovers-three-times-less-on-the-open-model). That rule was scoped, deliberately, to instruction-shaped scaffolding: a disclosure, a system-prompt mitigation, a skill catalogue — anything the model has to execute.

Task-CoEvolve's output is executable harness code. The harness executes it, not the model. Under the run-25 split — structure ports, requested judgment does not — this is the prediction for the other side, and it holds at 78% rather than 33%. It is the first direct measurement of the split's structural half, and it is the decision-relevant half, because harness code is what we would actually build.

Discounts: one benchmark, one rollout per task per iteration, no repeats, 10 candidates; 35B-A3B is open-weight but not small; and the search was run separately per backbone, so this compares two searches rather than one harness transplanted between models.
