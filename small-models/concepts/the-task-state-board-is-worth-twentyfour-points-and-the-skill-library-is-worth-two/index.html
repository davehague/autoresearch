Externalised task state gives +23.9; the curated skill library gives +2.0; letting the model choose when to use it recovers a third of the difference

Recuris splits agent memory into a Working Memory that tracks task progress and an Experiential Memory (a skill library) whose entries are retrieved by current task state rather than by the model deciding to look. Ablated on τ²-Retail / τ²-Airline with the deployment model:

Variantτ²-Retailτ²-Airline
Base — no memory58.175.5
Experiential memory only60.1 (+2.0)77.0 (+1.5)
Model-controlled skill invocation65.6 (+7.5)—
Working memory only82.0 (+23.9)79.5 (+4.0)
Both (Recuris)83.6 (+25.4)84.0 (+8.5)

The expensive artifact is the cheap one. A skill library — the thing agent frameworks are mostly built to curate — is worth 2.0 points on its own. An externalised, continuously-updated record of what the task has and has not done is worth 23.9. And the library only becomes useful once retrieval is state-grounded: model-controlled invocation captures 7.5 of the 25.4 available.

This is the mechanism behind run 25's null. MemTrapBench found every memory framework tested scoring below no memory at all (every-memory-framework-scored-below-no-memory-at-all). Those frameworks are the 60.1 and 65.6 cells: experiential memory with model-controlled invocation. Run 23 independently found that skill retrieval precision collapses from 30% to 3% as a library grows (skill-retrieval-precision-collapses-from-30-to-3-percent-as-a-library-grows) — the same failure, measured on the retrieval side.

It is also cheaper. 101k agent tokens per success against 147k for the full-library-in-context baseline: the structured option costs 46% less per success. That inverts run 21's finding that semantic retrieval costs more tokens than grep at equal success (semantic-retrieval-costs-more-tokens-than-grep-at-equal-success) — here the structured option wins on both axes at once, which is rare enough in this vault to be worth acting on.

Externalised task state was already the vault's best-supported harness intervention, from run 9's 28.9 points on WeaveBench onward. This is the third independent replication and the first with a clean ablation against the alternative. Which component of it matters is domain-dependent: on τ²-Retail the status board dominates (−17.3 when removed), on τ²-Airline the write review does (−13.5).

Discounts: ablation run on one deployment model on two benchmarks from the same family (τ²); the τ²-Airline column shows a much smaller total effect (+8.5 vs +25.4), so the 23.9 is not a general magnitude; no wall-clock or dollar cost for the evolution loop that produces the memory; and the memory was evolved on a single model then transferred, so all numbers are transfer numbers.
