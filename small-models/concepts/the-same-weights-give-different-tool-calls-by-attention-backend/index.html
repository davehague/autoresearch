Hold the checkpoint, the GPU and the prompt fixed, change only the attention kernel or the cache dtype or the parallel degree, and the agent runs a different command

A practitioner instrumented the serving stack under Qwen3.6-27B on RTX PRO 6000 Blackwell hardware with ~96k–100k-token real network-automation prompts, following divergent decode paths to completion rather than forcing them back to the reference.

  • Attention backend. FlashAttention 2 / Flash Inference / Triton agree bit-for-bit early in the prompt, then cluster into disagreement later, in a pattern that depends on prompt content rather than scaling with context length. FA2 selected GigabitEthernet0/1/4 where the reference selected GigabitEthernet0/0/1.201, cascading into wrong network commands.
  • KV-cache precision, at fixed BF16 weights: INT8 made tool-calling errors and recovered; INT4 did not, producing reproducible failures to close tool-call envelopes.
  • Weight quantization at a 96k prompt: BF16 ✓, FP8 E4M3 W8A8 ✓ (~20% peak top-1 flips), INT8 W8A16 ✓ (~15%, best), NVFP4 W4A16 ✗ (~50%), AWQ W4A16 ✗ (~35%). Both 4-bit failures emitted show run where show arp was required.
  • Tensor parallelism. Tool calls succeeded at TP1, failed at TP2, succeeded at TP4 — attributed to NCCL graph differences.
  • One vLLM container image carried 734 packages, 252 via pip/uv.

Run 26 added the execution path, chat template, compaction policy, output ceiling and effective sample size to the conditions a harness A/B must name. This adds four more — attention backend, KV-cache dtype, tensor-parallel degree, quantization format — and demonstrates each flipping a tool call at fixed weights. A failed tool call is a failed task, so these are not rounding errors against the harness deltas this vault tracks. No open-model number held here reports any of the four.

It also gives a-fifth-to-a-third-of-correct-answers-flip-where-metrics-look-clean its operational form: a flipped answer, when the model is driving a shell, is the wrong command rather than the wrong fact. The conservative floor implied — FP8 and INT8 held, both 4-bit weight formats broke — is stricter than the "Q4_K_M is fine" consensus this vault has carried since run 4.

Discounts: one self-published practitioner, no peer review, no released dataset; top-1 agreement measures argmax consistency and not semantic correctness, which the author states; the domain is network-device configuration where a single token is the answer, so the effect is maximally visible there; the TP result is a single anecdote with no ablation. Treat the direction as the finding and the percentages as illustrative.
