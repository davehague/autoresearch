The same harness carries five backends across three model families with no per-backend tuning — and an open backend inside it beats every shipped commercial agent

OneDayAgent runs unmodified on GLM-5.2 (744B, open weights), Gemini-3.1-Pro-Preview, Qwen3.5-397B-A17B, Qwen3.6-27B and Qwen3.5-9B, scoring 0.613 → 0.821 on AgentIF-OneDay (104 open-ended day-long tasks across work, study and life). GLM-5.2 tops it at 0.821, leading on every task type, domain and rubric dimension; Qwen3.5-9B floors it at 0.613.

For scale, shipped agent products on the same benchmark: AutoClaw 0.799, Codex on GPT-5.5 medium 0.664, Manus 0.645, Genspark 0.635, ChatGPT-Agent 0.626. The harness's own no-modules baseline — backend in the scaffolding, no decomposition, no verification — already scores 0.771, above four of the five products.

Two things this buys the vault.

A portability control it has never had. Run 9 established that no model verdict here is interpretable without its harness named, because harness variance is large enough to flip a model's reputation (open-model-live-use-robustness-is-disputed-and-tracks-the-harness). This inverts the design — pin the harness, sweep the model — and the ordering survives across three families. That makes 0.613–0.821 a model measurement taken under a fixed scaffold, and it is a template for our own experiment: fix the harness first, then vary the model, not the reverse.

A second open-model win on unbounded work. An open-weight backend above every commercial agent product on day-long open-ended requests extends the pattern from open-weight-model-ties-frontier-on-private-uncontaminated-codebase to a third task class. It sits directly against open-weights-in-the-best-harness-still-trail-frontier-in-a-stock-sdk, which found the opposite on long-context benchmarks the same night — and the two are compatible, because the tasks differ in whether the model or the scaffold holds the material.

Discount carefully, because the headline comparison is the weakest part. Beating Codex and AutoClaw is a product comparison, not a harness swap — those run different models under different scaffolds, so nothing there isolates the harness. Only the internal 2×2 ablation is controlled, and it is small (decomposition-and-verification-are-sub-additive). The benchmark, the rubric and the harness are all the authors' own. Only the two endpoint scores are visible in the accessible tables, so the middle three backends cannot be placed. No token or dollar cost is reported anywhere — only latency (mean 3,216.8s per task) and volume (~9,000 backend calls across 104 tasks, ~87 per task), which is a large bill that nothing prices. The authors scope their own claim to this benchmark.
