The DRAM squeeze damages the cheap end of self-hosting hardest, because every low-cost local configuration trades VRAM for bulk system memory

The intuitive reading of a 4–9× DRAM increase is that it hurts the expensive path — datacenter accelerators, big VRAM, the configurations that already cost six figures. It is the wrong way round. The all-in-VRAM path is hurt by the 87% GPU increase (the-hardware-side-of-buy-vs-build-took-an-87-percent-price-increase) and barely touched by system DRAM at all. The cheap path is the one priced in the component that moved 4.3–9.3×.

Every low-cost local configuration in this literature buys its affordability by spending host memory instead of VRAM: MoE expert offload to system RAM, llama.cpp CPU-assisted decoding, KV cache spilled out of the accelerator. The canonical example surfaced the same day as this price report — a 143–144 GiB quantized DeepSeek V4 Flash running across four second-hand RTX 3060 12 GB cards at a 360k+ context, with 34 blocks' worth of experts held in 128 GB of DDR4-3200. That build's memory cost roughly $222 in August 2025 and roughly $614 now, and a DDR5 equivalent went from $329 to $3,399. The RAM is now comparable to or more than the GPUs.

That inverts something this map has assumed without stating. The argument for training and serving our own has leaned on a long tail of cheap configurations making entry gradual — start on commodity parts, scale if it works. The gradual-entry ramp is the part that repriced, and it repriced against the direction of the decision. The expensive configurations are proportionally less affected than the cheap ones, which means the hardware cost curve got steeper at the bottom precisely where a pilot would start.

What is open is whether it matters for us specifically, and the answer depends on a number this map has never had. If our workload fits in accelerator memory — and run 22's serving results put a 27B in 22.3 GB per card at INT4 — then host DRAM is a build-cost line item and not a constraint, and none of this binds. If it does not fit, the offload configurations that would rescue it are now several times more expensive than the build guides say. Nobody has priced our actual target configuration at current component prices, and every figure in this vault's feasibility ledger predates the move. That is a one-afternoon exercise and it has not been done.
