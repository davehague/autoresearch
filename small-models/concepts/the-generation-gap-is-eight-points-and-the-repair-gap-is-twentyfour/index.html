Kimi K3 falls to 14.0 on GameFix. The rest of the open tier: GLM 5.2 13.4, MiniMax-M3 10.3, GLM 5.1 7.0, Qwen3.7-Max 5.5.

The open tier is near-frontier at producing and far from it at repairing, and this is the third time the same divergence has appeared under a different name. Run 25's SWE-bench Science: visible tests saturate at 93–100% while exact repair runs 14–48% (visible-tests-saturate-while-exact-repair-is-half). Run 28's 450M specialist: 87/100 structural completion against 44/100 strict pass (structural-completion-at-87-percent-hides-strict-pass-at-44). Producing the shape of an answer is close to solved; producing a correct one is not; and the open tier's deficit lives almost entirely in the second.

The operational consequence is a rule for reading everything else in this vault: check which of the two any benchmark is measuring, because the friendly numbers are consistently the first kind.

One caution against the vault's own framing. At 39.0/100, the frontier leader fails 61% of this benchmark and the authors say plainly it is "far from saturated." On genuinely hard agentic work neither option works yet, which shrinks the marginal value of the open-vs-frontier comparison this vault is built on.

Discounts: unrefereed preprint, single run per configuration, no seeds or variance; GameGen and GameOpt rely on human-judged experience and visual quality with acknowledged subjectivity; GameOpt's turn and content are confounded by the authors' own admission, so retention cannot be separated from difficulty; every open model ran in Claude Code, never a native harness (sixteen-of-seventeen-agents-ran-in-one-vendors-harness), so the 23.8 is an upper bound; injected bugs are synthetic; the paper never labels weight availability, so the open/closed split is ours; and game development is not our workload class.
