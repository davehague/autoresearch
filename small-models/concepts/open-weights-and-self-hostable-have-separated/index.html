The open model that closed the gap needs 160–200 GB at 4-bit; the one you can host is a different artifact

GLM-5.3-Flash is 320B total parameters for 18B active. Activation cost is small — 50.2 output tokens/s measured independently — but residency cost is set by the total, not the active count. At 4-bit that is roughly 160–200 GB before context: a 512 GB Mac Studio, or a multi-GPU server, priced in the component run 23 found had repriced four-to-nine-fold in twelve months (system-memory-repriced-four-to-nine-fold-in-twelve-months).

This vault has treated "open weights" and "self-hostable" as one column since run 1, and tonight they separated. The open model that came within 3.1 points of frontier on Terminal-Bench 2.1 (an-mit-licensed-open-model-is-three-points-off-the-frontier-on-terminal-bench) is not a model we can own. The open model we can own — Qwen3.8-27B at 17 GB in 4-bit (four-bit-replicates-the-agentic-score-and-two-bit-costs-seven-points) — is a weaker and separately-measured artifact. Any argument that moves a capability number from the first onto the cost basis of the second is equivocating.

Renting it is the cheapest credible option on the board, and that is an argument against building. List price $0.15 / $0.50 / $0.03 per million input / output / cached-input tokens, with a launch promotion at half that expiring 9 September 2026 — the promotion is not the planning basis (a-thirty-day-promotion-is-not-a-price-basis). Even at list, run 30's arithmetic gets worse for the build side: $10,000 already bought a Mac Studio or 100 billion tokens of an open frontier model (ten-thousand-dollars-of-hardware-buys-fewer-tokens-than-ten-thousand-dollars-of-api), and this release lowers the rented rate again while raising the hardware needed to match it.

The architecture is aimed at exactly this. Hybrid sparse plus linear attention, claimed at 3.01× less attention computation and a 4.44× smaller KV cache than GLM-5.3 — a serving-cost optimisation, sized for datacenters, on the axis run 28 measured as ~70% of agentic wall clock (an-agentic-run-is-seventy-percent-prompt-processing). The frontier of open weights is being built to be rented, not to be owned, and this is the second consecutive release in that direction.

Discounts: the 160–200 GB figure is an estimate from the parameter count, not a measured deployment — no quantized memory footprint has been published for this checkpoint; sparse-MoE weights can be partially offloaded, so the hard residency floor may be lower in practice at a throughput cost nobody has measured; the efficiency multipliers are vendor claims with no independent replication; and one release is a datapoint, not a trend, however well it fits the previous one.
