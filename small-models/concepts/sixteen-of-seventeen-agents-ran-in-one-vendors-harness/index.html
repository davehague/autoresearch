Sixteen of seventeen agents were benchmarked inside one vendor's harness — and the one model moved out of it gained 2.4 points

On GameXpert-Bench's GameFix track, every configuration ran in Claude Code except two: GPT-5.6-sol and GPT-5.5 were additionally run in Codex, their own vendor's harness.

GPT-5.6-sol (xhigh)26.729.1+2.4
GPT-5.5 (xhigh)16.116.3+0.2

No open-weight entry was ever run in a harness built for it. DeepSeek V4 Flash (15.2), Kimi K3 (14.0), GLM 5.2 (13.4), MiniMax-M3 (10.3), GLM 5.1 (7.0) and Qwen3.7-Max (5.5) were all measured in a scaffold shipped by the vendor whose model tops the board at 39.0.

So the 23.8-point gap from Opus 5 to the best open model is an upper bound on the model gap, and the paper contains its own evidence for why. Run 27's Task-CoEvolve found searched harness code carries to an open model at four fifths of its frontier gain (structural-harness-search-carries-to-the-open-model-at-four-fifths); run 20's AutoDesign lifted five open-weight targets 11–20 points with a designed harness (a-designed-harness-lifts-five-open-weight-targets-11-to-20-points). Neither correction was applied to a single row here.

Note also that the harness effect is not constant across models — 2.4 points for one GPT tier and 0.2 for the next. Run 21 found harness choice moves average performance, not peak (harness-choice-moves-average-performance-not-peak); this is a second instance of the effect refusing to behave like a fixed offset, which means "add N points for a native harness" is not a correction anyone can apply from the outside.

This is the tenth open-vs-frontier comparison in this vault measured through a frontier vendor's default SDK, and it extends the standing complaint (open-weights-in-the-best-harness-still-trail-frontier-in-a-stock-sdk) into its weaker form: open weights in someone else's SDK, against frontier in its own.

Discounts: unrefereed preprint; single run per configuration with no variance, so a 2.4-point swing has no error bar; effort settings are chosen per model and not held constant; the two harness-swap rows are both closed models, so nothing here measures the swap on an open one.
