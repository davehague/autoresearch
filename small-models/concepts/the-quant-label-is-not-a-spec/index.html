The same quantization name from four different builders is not the same artifact — Q4_K_M was non-monotonic in three of four builds and fine in the fourth

Testing LFM2.5-2.6B GGUFs from four independent publishers, the author found Q4_K_M behaving non-monotonically — measurably worse than quantizations below it in bit width — in LiquidAI's own build, mradermacher's and noctrex's, while bartowski's build of the same nominal quantization showed no such anomaly. The report's blunt instruction is "DO NOT use Q4_K_M."

This upgrades the vault's precision confound from a labelling requirement to a provenance requirement. Since run 9 the rule has been that no model verdict is interpretable without its precision named alongside its harness (quantization-erases-long-tail-knowledge-invisibly, operator-quantization-cuts-cost-at-benchmark-parity). That is now insufficient: Q4_K_M from one publisher and Q4_K_M from another are different artifacts, differing by more than the nominal bit width would predict, and at least one of them is defective. Precision must be pinned by build, not by label.

Two consequences follow. Prospectively, any comparison we run records the exact quantization artifact — publisher, file hash, imatrix or not — the same way we would pin a grader version. Retroactively, it weakens a class of evidence this vault already treats cautiously: every practitioner report of an open model behaving badly in live use is a report about one build, and a published "we ran it at Q4" result is not reproducible from its own description. That is a plausible partial mechanism for the dispute in open-model-live-use-robustness-is-disputed-and-tracks-the-harness, where users running nominally identical open weights disagreed on whether the model could follow rules at all — the disagreement was attributed to harness, and build variance is a second candidate nobody in that thread controlled for.

Limits. One model, one author, one metric family (perplexity and KLD on wikitext), no replication. The anomaly is reported across builds but not explained — quantizer version, imatrix calibration data, or a measurement artifact are all live, and which it is decides whether this generalises to other models or is specific to this one. Three of four is a small denominator on which to condemn a quantization format generally.
