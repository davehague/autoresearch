Moving task state outside the growing context lifts long-horizon agents 5.5–28.9 points, across two model families and three benchmarks

LongHorizon-Harness reframes long-horizon execution as task-state management and pulls the state out of the context window: a manager holds explicit task state and selects the next subtask, a fresh-context executor performs it, and a read-only auditor verifies the environment before the next round — state updates only on independently confirmed facts. An AgentAdapter swaps model and harness backends without modifying their native loops, which is what makes the result a claim about the harness rather than about any one agent.

The numbers: Qwen 3.7-Plus 51.8% → 80.7% on WeaveBench, 69.7% → 77.2% on Terminal-Bench 2.1, 2.8% → 8.3% on OSWorld 2.0; Claude Opus 4.7 20.0% → 34.3% on an OSWorld 2.0 subset. The gain appears on both a weaker and a frontier model, and across two interaction domains.

This is the first measurement in this vault of a harness on open-ended agentic work rather than verifiable short-answer tasks — the hole named explicitly at the close of harness-engineering-vs-default-sdk and again in combined-small-model-plus-custom-harness. It confirms harness-design-is-a-large-quality-lever-on-small-models on a much less bounded task class, and extends the run 7 build rule rather than contradicting it — see environment-verification-succeeds-where-self-inspection-fails for why this is compatible with self-inspection-harnesses-lose-to-repeated-sampling-at-equal-cost.

The gating caveat is cost. The one control that decided the run 7 result was matching token cost, and a manager plus fresh-context executor plus auditor is plainly more expensive per task than a single loop. No tokens-per-task figure is reported, so this cannot be placed against harness-iteration-adds-cost-not-quality at all — the vault's oldest harness finding is that harness work reliably buys cost, and nothing here rules out that this is a costlier way to buy accuracy rather than a free one. Secondary limits: no small or open-weight arm (Qwen 3.7-Plus is a closed API model), no ablation isolating which of the three components carries the effect, three days old and unreplicated.
