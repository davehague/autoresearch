800 annotated trajectories, 8 harness-model combinations, 45 failure patterns — and the patterns do not vary with the scaffold

The strongest form of this map's optimistic case is that agent failure is largely a scaffolding problem: give the model external state, verification and structure, and the failures go away. Run 9's +5.5 to +28.9 on open-ended agentic work, run 19's evolved harness at avg@55, run 20's five open-weight targets lifted 11–20 points all read that way.

AutoResearchEval is the first study here that varies both the harness and the model over a fixed task set and annotates where each run broke rather than only whether it broke. 100 tasks across 7 scientific domains and the full research lifecycle, 8 harness-model combinations, 800 trajectories, process-level annotation via a human-calibrated agent-as-a-judge over complete trajectories and intermediate artifacts, distilled into 45 empirically-grounded failure patterns. The result: the same patterns recur across all 8 combinations, including the strongest models tested, which is why the authors locate the deficit at the model level rather than in any particular scaffold.

If failure were scaffold-shaped, varying the scaffold would have varied the failures. It did not. That is the cleanest evidence this map holds that a meaningful fraction of agent failure is a model residual the harness cannot supply — the same shape as run 20's observation that coordination competence did not transfer down the model ladder, and consistent with run 12's finding that the optimiser model outweighs the harness 1.8:1 (optimizer-model-outweighs-harness-when-an-llm-builds-the-harness) and run 17's 11:1 (builder-capability-outweighs-the-platform-eleven-to-one).

Two limits keep this from being decisive, and the authors name the first themselves: they explicitly do not test whether orchestration-level interventions can close the deficit. And "the same patterns recur" is a claim about presence, not rate — two systems can share a 45-item taxonomy and differ by a factor of five in how often they trip each item. A designed harness that halves the frequency of every pattern would show up in this study as "the same patterns."

It counts because the harness-varying design is one this map has been asking for and this is the first study to supply it with process-level annotation.
