Worst to best is 11.8 points on GLM-5.1 and 11.7 on Kimi-K2.6, with the model held fixed. This vault has been quoting harness effects measured against a paper's own default baseline — run 30 found that when AutoSaddler was finally run against an expert-tuned harness rather than a default, its gain collapsed from 10.0 to 2.5 (automatic-harness-search-beat-the-expert-tuned-harness-by-two-and-a-half-points). This table has no defaults in it. Every row is something a person actually installs, and the spread survives.

Two readings, and they differ in what they license:

  • The generous one: picking the right SDK is worth ~12 points on an open backbone, comparable to run 20's designed harness lifting five open targets 11–20 points (a-designed-harness-lifts-five-open-weight-targets-11-to-20-points).
  • The disciplined one: PILOT's margin over the best baseline is 5.0 on GLM-5.1, 4.4 on Kimi-K2.6, 5.3 on the average — and it loses SWE-bench Multilingual to Pi, 72.7 to 72.9. The 12 points is the cost of choosing badly; the 5 points is the return on choosing well. Only the second is a build case.

The ranking is also not stable across backbones: Hermes is worst on GLM-5.1 (60.1) and mid-table on Kimi-K2.6 (64.0); OpenCode and Pi swap order. A harness recommendation does not transfer across models, which is run 21's finding that harness choice moves average performance rather than peak (harness-choice-moves-average-performance-not-peak) showing up as rank instability, and it means our own harness selection has to be re-run on whatever checkpoint we actually deploy.

Gains concentrate where the vault expects: PILOT reaches 55.0% on Hard with both backbones against Pi's 50.0 and 48.3, and at peak iteration the additional passes sort Easy +2/+1, Medium +6/+7, Hard +8/+12. That is run 29's self-discovery cliff (the-self-discovery-cliff-is-three-to-four-times-larger-on-open-models) being partially paid down by scaffolding.

Discounts: two runs per configuration is above this literature's norm and still not an interval; both backbones are large open MoEs, not anything we would serve on one machine; Terminus-2 and Mini-SWE-Agent each appear on only one benchmark, so the five-way comparison is really four-way per table; and the winning harness is the authors' own, evaluated by the authors.
