Full-parameter agent fine-tuning ran in 8.41 GB against GRPO's 58.88 GB — the cluster requirement was a property of backpropagation, not of training

Agentic ESOpt fine-tunes long-horizon LLM agents with evolution strategies instead of RL, and the headline is a memory figure. On Qwen3.5-4B, peak GPU memory: ESOpt 8.41 GB, agentic GRPO 58.88 GB, agentic PPO 89.40 GB — a stated 85.7% reduction against GRPO, at full-parameter optimization rather than adapters. The mechanism is that ES never runs a backward pass: it perturbs parameters, runs inference, and scores whole trajectories, so peak memory is inference memory plus population bookkeeping. No optimizer states, no gradients, no stored activations, no critic.

This is the number this map has been asking for and not getting. Run 22's ClawGym II supplied the strongest new training lever in the vault and no cost figure of any kind. Agent Lightning, ingested the same day as this, says "modest compute" and stops (a-9b-gains-14-6-points-on-swe-bench-through-a-minimal-harness). Run 21 priced environment construction at ~29,000 synthesis tokens each (a-verified-rl-environment-costs-under-thirty-thousand-tokens) but not the training that consumes them. 8.41 GB is one consumer card, and it reframes the constraint that has made agentic RL a cluster activity as optional rather than intrinsic.

The wall-clock is the quieter half and may be the better one: on Sudoku at horizon H*=15, ESOpt reaches the answer in 9.4 hours against GRPO's 19.0, at 9.4 EFLOPs against 10.9. ES is not buying memory with compute here — it wins on both, because RL is spending its compute on a credit-assignment problem that grows with horizon and ES's does not exist. If that holds, it inverts the standing assumption that gradient-free methods are the cheap-but-worse option.

Two limits before treating it as settled. The memory comparison is 4B only — nothing shows the 8.41 GB figure scaling to the 27B arm the paper also runs, which is the size we would actually deploy. And the authors' own stated limitation is that ES requires more trajectory samples than some RL methods, so in any setting where task evaluation is expensive — which describes every real agentic environment — the sample count is the cost, and it is unreported. A footprint and a duration are not a bill.
