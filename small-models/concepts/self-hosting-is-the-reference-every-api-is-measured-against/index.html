The yardstick in the Endpoint Accuracy Index is a self-hosted deployment — buying an open model means buying someone else's inference stack too

Artificial Analysis does not score endpoints against each other. It benchmarks each serverless provider against its own self-hosted deployment of the official open weights on B200s under SGLang or vLLM, and defines that deployment as 100%. Every provider number — down to DeepInfra's 73% on GLM-5.2 (max) — is a statement of how much of the self-hosted result survives the trip through someone else's stack.

This pushes back on how this map has framed its own question. Self-hosting has been carried as the expensive option that must justify itself against an API price, with the burden of proof entirely on the build side (self-hosting-savings-erased-below-engineer-scale-thresholds). In the only published instrument that measures both, self-hosting is not an option being scored — it is the definition of correct, and buying is the thing with the error bar.

That does not make it cheaper. It touches neither of the two numbers that would settle this map (our real utilization, our marginal engineer cost), and the honest reading is narrow: running the official weights ourselves is the only configuration whose identity we control. But it adds a term the buy-vs-build comparison has never carried. The model you buy is defined by a stack you cannot inspect, which can be requantized or reconfigured without notice — the quality counterpart to open-model-api-prices-are-not-a-stable-planning-input, where the same vendor moved the price unilaterally. Thread (g) has been asking whether running our own is cheaper at an acceptable spread; this says the spread exists on the quality axis as well, and only on the buy side.

Practical form: any comparison we run against an API endpoint is a measurement of model and endpoint, in the same way run 9 established that no model verdict is interpretable without its harness named (open-model-live-use-robustness-is-disputed-and-tracks-the-harness). Pin the endpoint and the date, or re-run the baseline.
