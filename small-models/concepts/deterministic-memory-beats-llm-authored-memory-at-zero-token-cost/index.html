A memory subsystem that spent 0 LLM tokens beat one that spent 28.6 million, by 5.4 F1 — harness work that buys accuracy and costs nothing, by moving the work out of the model

Zero-Mem replaces LLM-driven agent memory with deterministic machinery: it preserves the original interaction traces rather than rewriting them into model-authored summaries, indexes them through an entity–context graph plus a temporal hierarchy, and fuses retrieval with evidence closure and deterministic calibration. The LLM is invoked only for the final answer.

  • LoCoMo (GPT-4o-mini reader): 59.15 F1 / 52.96 BLEU-1 vs GAM 53.75/47.51, CompassMem 52.18/44.09, SimpleMem 48.02/41.68.
  • HotpotQA vs GAM: 72.07 vs 63.22 (56K), 66.43 vs 64.56 (224K), 65.04 vs 59.81 (448K).
  • LLM tokens on memory operations: 0, against 28,570,674 for GAM and 877,086 for LightMem. Total time 334.77s vs 9,237.25s / 788.76s; 0.22s vs 6.00s / 0.51s per query — a 57.6% latency cut against the fastest baseline.
  • Evaluated with a closed reader (GPT-4o-mini) and an open 14B one (Qwen2.5-14B-Instruct).

This pushes back on the reading consolidating in this theme. harness-swap-moves-cost-not-quality-on-real-engineering-tasks and harness-cost-spread-replicates-on-an-open-model both find harness choice moving cost while quality stays flat — which invites the summary "harness work buys economics, and every harness costs something." Zero-Mem improves accuracy while spending none of its budget, because it does not arrange more model calls; it removes them.

It is compatible with the run 9 build rule, and arguably its cleanest instance. The rule holds that a loop earns its cost when it closes against something outside the model and is worthless when it closes against the model (environment-verification-succeeds-where-self-inspection-fails). Zero-Mem's referent is the preserved raw trace, an immutable external record. What it displaces — LLM-authored summarisation and consolidation — is the memory-system form of self-inspection: the model editing its own account of events with nothing to check it against, the same shape as the machinery killed in self-inspection-harnesses-lose-to-repeated-sampling-at-equal-cost. The principle can now be stated without reference to loops: put the model where judgement is needed, deterministic code everywhere else, and give every check an external referent.

Scope it honestly. This is long-context conversational QA, not agentic execution — LoCoMo and HotpotQA make "memory operations" much closer to a retrieval problem than to the state-tracking a coding agent does. The graph-plus-hierarchy index is a substantial engineering build whose cost is not weighed against the token savings claimed. Code is promised only after peer review, so nothing is reproducible yet. One paper, unreplicated, no ablation separating the graph from the temporal hierarchy from the calibration step, and gains flatten past top-10 retrieval candidates.
