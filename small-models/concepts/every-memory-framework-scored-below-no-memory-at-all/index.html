Five memory frameworks, two models, ten configurations, and not one beat having no memory — with a control showing it is the memory's scope, not its presence

MemTrapBench grades what a retrieved memory does to the answer, holding retrieval itself correct. Every planted memory is faithfully recorded and semantically relevant; each one is also out of scope for the current query, which the model answers correctly with no history at all.

Ten of ten configurations lose to the baseline. The five frameworks span raw full text, staged compression and consolidation, an OS-style memory manager, query-aware semantic retrieval, and a commercial system — no storage or compression strategy protects against it, and the ordering is not even stable across the two models (FullText is Gemini's second-worst and Qwen's second-best).

The control is what makes this actionable. On the Task Boundary subset: no memory 92.29, trap-free memory that preserves the task and the relevant history 94.39, trap-inducing memory 31.05. Clean history helps. So the claim is not that context is harmful — it is that a stored memory carries the scope in which it was true, and none of these systems carries the scope with it.

The length sweep says the damage is not gradual accumulation. At 25% of the history the average is already 36.03; at 100% it is 31.05. Almost all of the loss arrives the moment memory is introduced, and the remaining 4.98 points spread across the rest, most of it between 25% and 50%. Truncating a memory store is not a mitigation.

This sharpens run 17's cost finding rather than repeating it. That source found a memory system's break-even against no memory at all ranges from turn zero to never (break-even-against-no-memory-at-all-ranges-from-turn-zero-to-never) and priced it. This one says the accuracy ledger can also be negative, at the same time. Together: a memory subsystem in a custom harness can cost money that never pays back and lower the answer quality that motivated it.

It is also the same anchoring mechanism recorded twice elsewhere — a stale convention file beating working code in 39 of 39 trials (a-stale-convention-file-costs-more-than-no-file), and supplied domain guidance costing a strong model 4.4 points on real repairs (supplied-context-helps-the-weaker-model-and-hurts-the-stronger-one).
