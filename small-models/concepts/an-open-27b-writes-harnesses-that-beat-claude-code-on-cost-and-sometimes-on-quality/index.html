The harness optimizer is finally open-weight, and it is 27B

Every harness-improvement result on this map has run its optimizer on a closed frontier model — DarwinX (run 19), AutoDesign (run 20), HSI (run 26), Task-CoEvolve (run 27), and most recently AutoSaddler, where every arm ran on Claude Opus 4.6 (every-arm-of-the-harness-search-ran-on-a-frontier-model). JIT-Agent-27B is built on Qwen3.6-27B and generates harnesses directly, with no search loop in the deployment path.

The token reduction is larger and more consistent than the score gain: 0.64× and 0.40× and 0.59× the tokens, against +5.5, +4.0 and −3.1 points. Run 24 found harness token spend varying 12.8× at identical test outcomes (harness-token-spend-differs-12-8x-at-identical-test-outcomes); this is that spread pulled on purpose, and it is the half of the ledger this map has consistently under-weighted.

Two structural consequences. First, run 27's irreducible frontier-inference term — 2.4–3.3 hours of meta-agent proposal per search, independent of evaluation budget (a-harness-search-costs-117-dollars-and-22-hours) — is removable by training the generator rather than prompting it, which is the same move run 28 recorded for environment authoring (the-open-model-authored-environments-at-three-percent-then-eighty-three). Second, and less comfortably: generation has no acceptance test. Run 30 priced the acceptance test at 11.4 points and found an unfiltered loop scoring below its own baseline (the-acceptance-test-outweighs-the-diagnosis-and-the-patch-combined). A generator that emits a harness per request never rejects one. Whether the training run internalised the filter or simply removed it is the paper's central unmeasured question.

Discounts: no training cost, data volume or GPU-hours published for JIT-Agent-27B, so the open optimizer is unpriced; three benchmarks, one backbone in the controlled comparison; no seeds or intervals; and the authors state their four-module protocol is deliberately thinner than production runtimes, which makes the AgentIF loss expected rather than surprising.
