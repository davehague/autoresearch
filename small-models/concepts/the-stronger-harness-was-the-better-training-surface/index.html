Training the same model through two harnesses paid more through the better one — +14.81 via Claude Code against +9.98 via OpenClaw

Every size-and-scaffold result on this map has pointed one way. Run 17 put harness uplift on the target's headroom at r=0.75, not on model size (harness-uplift-tracks-headroom-not-model-size). Run 19 replicated it across a fifty-point uplift range (the-headroom-law-replicates-across-a-fifty-point-uplift-range). Run 20 got the tightest control yet, seven agent configurations at fixed task and fixed scaffold, uplift falling as base score rose (harness-uplift-and-base-score-are-inversely-related-across-seven-agents). The standing corollary is that the better the starting point, the less the intervention buys — and run 21 sharpened it into a warning that the pairing's two levers sort opposite ways on base size, so they trade rather than stack.

ClawGym II holds the model fixed (Qwen3-30A3B) and varies the harness, and the ordering comes out the other way. RL through Claude Code gains 14.81 Pass@1; RL through OpenClaw gains 9.98. The stronger, more elaborate execution system was not the one with less room to give — it was the one that paid more.

The axes are genuinely different and that is the point worth holding. The headroom law is measured over base model scores with the scaffold fixed; this is measured over scaffolds with the model fixed. Nothing here contradicts the law as stated. What it contradicts is the loose version this map has been reasoning with — interventions pay out where there is room, so stacking them yields diminishing returns — because here two interventions compounded: the better harness plus training through it beat the weaker harness plus training through it, by 4.8 points.

A mechanism that would explain it, untested by the paper: RL needs a signal, and a harness that fails informatively — that decomposes, verifies, retries against something real — produces trajectories with more learnable structure than one that fails flatly. On that reading the better harness is not less room, it is better supervision, which is the same external-referent story this map has been telling since run 12 arriving at the training stage instead of the inference stage. Cheap to test and nobody has: run the same RL through a deliberately minimal harness and see whether uplift falls further.
