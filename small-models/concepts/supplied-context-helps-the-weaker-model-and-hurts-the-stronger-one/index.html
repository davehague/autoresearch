Handing an agent the relevant domain knowledge raised the weaker model 6.6 points and cost the stronger one 4.4 — the headroom law arriving at the level of plain context

A paired ablation on the 91 SWE-bench Science tasks where explicit scientific guidance can be removed without disturbing the repository or executable context, run on two configurations at opposite ends of the score range:

configurationwithout guidancewith guidancechange
GPT-5.6-sol (xhigh) / Codex36.26%31.87%−4.39
DeepSeek-V4-flash (high) / Claude Code16.48%23.08%+6.60

The token response inverts with it. Guidance cuts GPT-5.6-sol's mean input from 3.86M to 3.70M tokens and output from 43.75K to 40.25K. It raises DeepSeek-V4-flash's input from 4.84M to 7.40M — 53% more — and output from 128.43K to 159.26K. The stronger model spends less and does worse; the weaker spends much more and does better.

Task-level transitions show this is real churn, not a shifted margin. GPT-5.6-sol solves 8 tasks only with the guidance and 12 only without it, with 21 in both. DeepSeek-V4-flash solves 9 only with and 3 only without, with 12 in both. Guidance is not adding a layer on top of what each agent already did — it redirects both, helpfully in one case and harmfully in the other.

This vault has the headroom law for inference-time scaffolding across a fifty-point uplift range and seven agent configurations (harness-uplift-and-base-score-are-inversely-related-across-seven-agents, the-headroom-law-replicates-across-a-fifty-point-uplift-range, harness-uplift-tracks-headroom-not-model-size) and, since last run, at the training stage (training-uplift-is-largest-through-the-weakest-harness). This is the same ordering for the cheapest intervention of all — text in the prompt — and it is the first observation in the vault where the uplift on the stronger model is negative rather than merely small.

The mechanism the authors give for the negative half is anchoring: supplied prose "can also induce anchoring, scope spillover, or premature reliance on a supplied explanation." That is the same mechanism as a stale convention file beating working code in 39 of 39 trials (a-stale-convention-file-costs-more-than-no-file) and as a faithfully recorded, semantically relevant memory dragging a model below its no-memory baseline (every-memory-framework-scored-below-no-memory-at-all). Three sources, three task families, one failure: an agent treats supplied text as authoritative over the code and the environment in front of it.

If it holds, the practical reading is uncomfortable for context engineering as a universal good. Loading a frontier model in a default SDK with our conventions, domain notes and architecture prose may cost accuracy while saving tokens; loading the candidate open checkpoint with the same material may buy real points at a large token premium. Those are opposite decisions from the same artifact, and nobody currently measures which side they are on.
