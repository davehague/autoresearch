The layer between the model's Bash and the shell that runs it is worth 55 to 73 points, and no benchmark names it

QuoteBench holds the model's reply fixed and varies only the transport: 56 one-shot tasks from 14 incident-derived operation families, replayed through one deliberately unescaped added parser. Escaping at that interpolation point reproduces the raw-path outcome exactly, so the damage is attributable to the boundary rather than to generation.

Two things follow. Raw generation is saturated — four configurations at 94.6% or above — so the spread that still discriminates models is not command generation, it is what happens to the command afterwards and whether the model anticipates it. And the transport collapses everything to a band: eight configurations spanning 21 points on the raw path land within 11 points of each other, all between 19.6 and 30.4, once the parser is inserted.

The families are the ones that bite in production: write-file, JSON writing, Git operations, environment passing, heredocs, argument passing, hostile filenames, find/glob, grep counting, sed replacement, and two simulating SSH-like nested execution. Validation is exact final state.

Grade: suggestive — eight configurations agreeing on the direction and a clean causal construction (fixed replies, one deliberately unescaped interpolation point) make the effect solid within its scope. The scope is narrow and the authors say so: one mechanism, one-shot Bash under quotation hazards, results characterizing the benchmark rather than deployment prevalence, single stored generation per task with no repeats, primary testing on GNU/Linux, and multi-turn recovery excluded — a real agent would see the mangled command fail and retry, and how much of the 55–73 points returns on turn two is unmeasured and probably large.
