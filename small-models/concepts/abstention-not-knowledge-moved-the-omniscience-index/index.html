A knowledge index rose 10 points while its accuracy component fell 4 — the model got more cautious, not more knowledgeable

Artificial Analysis's Omniscience Index nets factual accuracy against hallucination. Between the two 27B checkpoints:

  • Omniscience Index: −20.02 → −9.98 — a 10-point improvement.
  • Accuracy: 19.6% → 15.58% — a 4-point regression.
  • Hallucination rate: 49.27% → 30.29% — an 18.98-point improvement.

The index improved because the model stopped guessing, not because it knew more. Both readings are correct descriptions of the same two rows, and they support opposite sentences. Anyone quoting the index would report that the newer checkpoint is better at knowledge; anyone quoting the component the word knowledge names would report the reverse.

This vault reads composite indices constantly, and mostly as capability. Run 22 took the band off the Intelligence Index. Run 20 read a poster-generation composite. Run 15 recorded that a single open model's accuracy swings 27 points across API endpoints (api-endpoint-changes-an-open-models-accuracy-by-27-points). Run 12 found the grading model is a variable that has to be pinned (grader-model-is-a-fourth-variable-that-has-to-be-pinned). Add the general form of this one: any index that nets a capability against a failure mode will report progress for a model that merely got more cautious.

That is not a criticism of the index — abstention is genuinely valuable and a hallucination rate falling from half to under a third is a real improvement in reliability. It is a warning about substitution inside a composite. The rule this vault should adopt: before quoting a netted score, read which component moved. The −20.02 → −9.98 line and the 19.6% → 15.58% line describe the same pair of models, and only one of them is about knowing things.

There is a second-order consequence for the harness half. A model that abstains more is a model that reaches for tools more — which the practitioner reports independently confirm — and run 24's coherence-debt work found that whether an agent says it is blocked instead of fabricating is a model property ranging from 100% to 0% (a-missing-fact-produces-wrong-work-not-a-stopped-agent). A falling hallucination rate on a knowledge benchmark is the closest public proxy we have for that property, and nobody is using it that way.
