Told about the execution boundary, six closed models recovered 30 to 61 points and the single open-weight model recovered exactly zero

QuoteBench's mitigation is a sentence: disclose to the model that its output will be reparsed before it reaches a shell. Because escaping at the interpolation point reproduces each replayed reply's raw-path outcome, any recovery under disclosure has to come from the model changing what it generates. Recovery, measured as the disclosed-generation nested cell minus the raw-generation nested cell:

  • Six configurations recover 30.4 to 60.7 points — GPT-5.6-sol, GPT-5.5, Opus-5, Opus-4.8, Gemini-3.1-Pro, Gemini-3.5-Flash.
  • Qwen3.5-27B, the only open-weight model in the table, recovers 0.0.
  • Gemini-3.1-Flash-Lite recovers −5.4.

That is the third independent instance of one shape in three runs. Run 24: whether an agent reports being blocked rather than fabricating spans 100% to 0% by model, and the one open-weight configuration in the table sits at zero (a-missing-fact-produces-wrong-work-not-a-stopped-agent). Run 25: a free system-prompt mitigation for a memory defect recovers 11.8/14.9/11.3 points on a frontier-band model against 4.2/2.5/2.6 on an open 30B (the-prompt-level-fix-recovers-three-times-less-on-the-open-model). Run 26, here: 30.4–60.7 against 0.0. A practitioner artifact from the same run reports the fourth informally — frontier models load matching skills as a matter of course while local Qwen models read the catalog and ignore it (the-shipped-effort-dial-had-three-real-levels-and-a-truncating-default).

Run 25 proposed the split that these confirm. Scaffolding that supplies structure — an external verifier, a compiled procedure, a reshaped environment, a worked demonstration — is executed by the harness and follows the headroom law, paying more where the model was weaker. Scaffolding that requests judgment — "check your work," "reconsider whether this applies," "escape for the parser downstream" — is executed by the model, and does not, because the model is the component we deliberately made weaker. Disclosure is pure requested judgment, and on the open side it bought nothing.

This is the pairing's largest unpriced term. A substantial fraction of what harness engineering consists of in practice is instructions, and every study validating an instruction-shaped mitigation on a frontier model is, on this evidence, overstating its value on the checkpoint we would deploy — by a factor of three at best and by everything at worst.

One qualification that changes how to use it: disclosure is not free where it works either. Telling GPT-5.6-sol about a boundary that is not actually present costs it 39 points on the raw path (94.6% → 55.4%). The mitigation is conditional on the transport really being there.

Grade: suggestive — one open-weight model in eight is a thin basis on its own, and Gemini-3.1-Flash-Lite recovering −5.4 offers the competing reading that this is a weak-model effect rather than an open-model effect, which would be better news for the pairing and is not separable here. What lifts it above single-study is that it is the third such observation across three task families with no disconfirming instance yet. A second open model recovering normally would substantially weaken it, and that experiment is cheap.
