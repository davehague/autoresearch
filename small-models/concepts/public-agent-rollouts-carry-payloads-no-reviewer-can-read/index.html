315,320 encrypted reasoning blocks scraped from public repos decoded to 367 PII artifacts and 182 credentials — and the same field can hide an injection

The same interchangeability that breaks anti-distillation (frontier-teacher-traces-are-a-supply-we-do-not-control) makes every published agent session log readable. Panfilov et al. scraped 315,320 encrypted reasoning blocks from public repositories and decoded them, recovering 367 PII artifacts and 182 credentials. Developers share these logs without knowing what the opaque blocks contain. Two further consequences: hazardous content appears in the trace even where the final visible output correctly refuses, and payloads can be embedded entirely inside encrypted blocks to poison public agentic rollouts with nothing visible in the text.

The defensive reading is the one that touches something we would actually do, and it is a filter no data pipeline currently has. Public rollout corpora are a training input for the build order's front end. A rollout corpus can carry an executable payload in a field no reviewer reads, because the field is ciphertext and looks like noise. Any trace corpus we ingest needs its encrypted blocks stripped or decoded before it becomes training input.

This is the vault's recurring invisible-in-the-summary defect (distillation-harms-are-invisible-in-aggregate-metrics, rubric-rl-silently-drops-signal-recoverable-by-self-distillation) one stage earlier than any prior instance: the others hide in a metric, this one hides in the corpus. It is a companion to input-ablation-detects-spurious-distillation-supervision — that probe grades whether supervision is about the input; nothing grades whether the input is what it appears to be.

Second-order and ours: if we archive frontier teacher sessions as the build order requires, those archives contain replayable blobs. Sharing them would publish a decryption oracle for our own prompts. The 367-PII figure says this is already happening at scale, unknowingly.

Open, not settled: nobody has measured whether poisoned rollouts in public corpora actually transfer damage into a distilled student, or at what prevalence.
