The cheapest open-model API announced an unquantified increase with a founder-stated 2–10× envelope — the number under this vault's most convex cost curve is not a constant

DeepSeek told developers it will raise API prices "significantly," with no figure and no date. Founder Jun Song's public framing is that even after a 2×–10× rise, DeepSeek would still undercut most Western APIs. Current V4 Flash list: $0.14/M cache-miss input, $0.0028/M cache-hit, $0.28/M output; V4 Pro: $0.435 / $0.003625 / $0.87. Context is capacity, not margin — V4 Flash processed 8 trillion tokens on 2026-08-01 — and no official reason was published.

The direct casualty is the run-11 cost curve. GDPevo's table put DeepSeek-V4-Pro-Preview at 48.79% for $0.040 per completed task against Opus-4.8's 67.07% for $1.36, which is where the "18.28 points buys 97% of the bill" reading came from (open-model-trades-seven-points-for-61-percent-of-the-bill). Apply the top of the announced envelope and that row lands near $0.40 — still cheap, no longer a 34× convexity story. Nothing about the model changed. The rent did.

The structural point outlasts the specific number. The cost of running an open checkpoint on hardware we control did not move; the cost of buying access to one moved by an unspecified multiple on a vendor's unilateral notice. Every serving-economics estimate on this vault's maps — utilization under P99 sizing, accelerator memory fit, weight and cache precision, cost per completed task — sits on the buy side of that comparison. Run 10's instruction to rebuild estimates in cost per completed task needs a second axis: under a price we set, versus one we do not. That is the first argument this vault has collected for building that does not depend on beating an API on unit cost.

Carry the caveat honestly: "significant" is not a measurement, 2–10× is a founder's aside rather than a schedule, and the increase could land at the bottom of the range or not at all. What is established is variance, not magnitude — and the vault had been modelling this input as fixed.
