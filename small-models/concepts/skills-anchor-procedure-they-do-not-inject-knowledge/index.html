Skills work by stabilizing an execution path the model could already walk — 65.7% procedural anchoring against 4.5% knowledge injection

Across 8,135 trial records and a taxonomy built from 238 unique labels over 240 open-coded trajectories, the dominant mode by which a skill library helps is procedural anchoring: 65.7% of cases, against explicit knowledge injection at 4.5%. The authors' phrasing is that "skills work when noisy trajectories become procedural anchors that stabilize execution" and that they "stabilize action rather than inject missing facts."

That corrects the implicit model behind a line of evidence this vault has accumulated without examining. Skill libraries compress 346× and score higher (skill-libraries-compress-346x-and-score-higher); textual skill patches lift a frozen 4B by 23 points (textual-skill-patches-lift-a-frozen-4b-by-23-points); skill text can supervise training and be dropped at inference (skill-text-can-supervise-training-and-be-dropped-at-inference); a library costs $8.95 to build. Every one of those reads naturally as content transfer — the library knows something the model does not. On a 65.7/4.5 split, it mostly does not. What is being transferred is a groove.

The reframe resolves a tension this map has been carrying since run 19 rather than creating one. SKILLER contradicted the headroom law cleanly — Qwen3.5-9B gained 4.3–20.4 points where the 4B gained 1.8–13.3 (skill-gains-favour-the-9b-over-the-4b-against-the-headroom-law) — and the restatement that fixed it was headroom is addressable only where the intervention supplies something the model can execute. Anchoring is the textbook case of an intervention needing a competence floor: you cannot stabilize a path the model cannot walk. A knowledge-injection mechanism would predict the opposite ordering, with the weaker model gaining more. This paper supplies from the mechanism side what run 19 reached by reconciling two datapoints.

It also predicts where skills will and will not pay for us, which is the same place run 22's demonstration result landed. One recorded demonstration doubled strict success on a user's own workflow (one-demonstration-doubles-strict-success-on-a-users-own-workflow) while progress moved only 13 points from an already-high base — converting near-misses into completions, a conventions fix rather than a capability fix. Anchoring is the mechanism for exactly that shape. Expect skills to pay where our checkpoint already almost works, and to do little where it does not.
