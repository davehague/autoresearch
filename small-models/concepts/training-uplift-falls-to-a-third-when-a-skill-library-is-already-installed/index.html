On the same 27B, the same task and the same training method, uplift was +6.69 with no skill library and +2.42 on top of one — the two levers do not stack

Agentic ESOpt runs Qwen3.5-27B on WebArena-Lite in two configurations. From the no-skill baseline: 29.47% → 36.16%, +6.69 points. With Trace2Skill already installed: 33.94% → 36.36%, +2.42 points. Both arms land within 0.2 points of each other — 36.16 and 36.36 — which is the shape of two interventions reaching the same ceiling by different routes rather than adding.

This is the cleanest instance in the vault of a pattern that has been assembled from scattered pieces. Run 12 measured decomposition and verification as sub-additive (decomposition-and-verification-are-sub-additive). Run 20's headroom control found uplift falling as base score rises across seven agents (harness-uplift-and-base-score-are-inversely-related-across-seven-agents), and run 21 drew the conclusion for the pairing: the training and harness levers sort opposite ways on base size and therefore trade rather than stack. Run 22 looked like a counterexample — ClawGym II's two interventions compounded by 4.8 points (the-stronger-harness-was-the-better-training-surface). This is a like-for-like instance in the other direction: model fixed at 27B, task fixed, training method fixed, and the only thing varied is whether a prior intervention was already there.

The consequence for the pairing is a budgeting one and it is unwelcome. This map's proposition is small model + custom harness, and it has been implicitly costed as two investments whose gains add. On this evidence they largely do not — and the arithmetic gets worse, not better, as each lever is applied. The second lever bought 36% of what the first did. If that ratio survives replication, the right build order is to pick the cheaper lever first and then measure, rather than budget for both. This vault's cost ledger says the skill library is the cheap one: $8.95 for a compact model's library (a-skill-library-for-a-compact-model-costs-nine-dollars-to-build), against a training run with no published price at all.

The obvious alternative reading, which the paper does not exclude: WebArena-Lite may simply cap near 36% for a 27B, and both arms are hitting the benchmark's ceiling rather than each other's. That would make this a saturation artifact and not a sub-additivity finding. Distinguishing them needs a harder task or a stronger base, and neither is reported.
