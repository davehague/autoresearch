45 failure patterns collapse into one missing loop — check output against evidence, revise when it fails, question the path — which is this map's design rule stated as a model deficit

Fifteen runs of harness results have converged on one rule from four independent directions. Runs 7–12 reached it by argument: internal referents are cheap and small, external referents are expensive and large (internal-referents-are-cheap-and-small-not-worthless). Run 17's census found eight frontier builders reaching the compatible half by selection — deterministic code and format enforcement in ~100% of self-written harnesses (eight-builders-chose-deterministic-code-over-verification-loops). Run 19 found an automated population search rediscovering it unprompted, every one of seven kept skills a way of grounding output in real execution (an-automated-search-converged-on-external-verification-unprompted). Run 20 found a meta-harness optimizer converging on validators and a rendered-artifact critic (a-designed-harness-lifts-five-open-weight-targets-11-to-20-points).

AutoResearchEval arrives at the same rule from the failure side. Across 800 annotated trajectories, its 45 failure patterns converge on a single deficit, which the authors state as the absence of a metacognitive loop: "the ability to check what they produced against what they found, revise when it does not hold up, and question whether the path they took was sound." That is the external-referent rule, written as the thing agents do not do.

The convergence is worth more than either observation alone, because the two literatures are measuring opposite ends of the same claim. One says the interventions that work are the ones supplying an external check. The other says the failures that dominate are the ones an external check would catch. Neither was designed to test the other.

It also sharpens the reading of the companion finding that these failures do not vary across 8 harness-model combinations (the-same-failure-patterns-recur-across-all-eight-harness-model-combinations). The authors read that as locating the deficit at the model. The alternative this map cannot dismiss is that the scaffolds tested did not implement the fix — run 17 found verification passes in only 12% of harnesses that frontier models wrote for themselves, the rarest technique on its list. The study does not report which of its 8 harnesses contained verification machinery, so both readings survive. What does not survive either way is the assumption that a shipped harness supplies the loop by default; the base rate says it usually does not.
