Three community tunes, four quant providers and a hand-written chat template land 8.4 points below the newer base with none of it

On tool-eval-bench hardmode at 50% context pressure, 65 runs with 95% intervals (max 176 points):

ModelScore95% CIn
Qwen3.8-27B (dense, current gen)152.6[149.4, 155.8]5
Ornith-1.5 (tuned 35B-A3B)144.2[141.7, 146.7]10
Tiel-Coder (Ornith + imatrix + template)144.0[141.8, 146.2]10
Qwen3.6-27B (dense, prior gen)134.8[131.2, 138.4]5
KAT-Coder-V2.5-Dev (tuned 35B-A3B)133.8[131.8, 135.8]15
Ornith-1.5-Heretic (abliterated)132.2[130.6, 133.8]10
Qwen3.6-35B-A3B (base)131.5[129.9, 133.1]10

The entire community tuning stack on the older 35B-A3B — three independent tunes, quants from four providers, a code-weighted imatrix, a custom chat template — spans 131.5 to 144.2. One generation of base model improvement, with none of that work applied, is 152.6, intervals non-overlapping.

This is the second independent benchmark to say it. Run 29's SWE-bench Live table had the same shape: TielCoder tied Opus 4.6 medium and lost to Qwen3.8-27B, which the vault already runs (a-22gb-four-bit-local-model-tied-a-frontier-medium-on-twelve-of-twentyfive).

For a build decision this orders the levers. Choosing a current-generation base is worth more than the sum of everything the community applies to a one-generation-old one. It also sharpens run 19's finding that post-training alone tripled a fixed 27B on a coding benchmark (post-training-alone-tripled-a-fixed-27b-on-a-coding-benchmark) — the post-training that matters is the lab's, done at pre-training scale, not a hobbyist's on top of a shipped checkpoint. And it is a caution for a-domain-specialist-cost-thirtyfive-thousand-b200-hours-and-moved-its-base-two-point-nine-points, which builds on this same one-generation-old base.

Discounts: single suite, single scoring metric; the dense-vs-MoE comparison confounds architecture with generation; a 35B-A3B activates 3B parameters and runs far faster than a dense 27B, so this is a quality ranking with the speed axis removed.
