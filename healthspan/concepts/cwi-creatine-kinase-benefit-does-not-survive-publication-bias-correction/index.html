A second independent pooling finds the same thing: CWI's creatine-kinase benefit is a publication-bias artifact

Thirty RCTs pooled show cold-water immersion modestly lowering post-exercise creatine kinase (CK) — a blood-based marker of muscle-membrane damage. The raw pooled effect (g=−0.24) looks like a real, if small, benefit. But Egger's test flags significant publication bias (p<0.001), and after trim-and-fill correction, the CK effect loses statistical significance.

This map already holds the identical finding from a different meta-analysis of the same literature (cold-water-immersion-damage-marker-benefit-fails-bias-adjustment: g=−0.43 collapsing to g=−0.160, non-significant, after trim-and-fill). Two independent poolings of overlapping-but-not-identical trial sets reaching the same "CK benefit is a bias artifact" conclusion is a real replication, not just a repeated claim — it makes the map's existing skepticism about CWI's biochemical recovery markers better grounded, not merely repeated. This source's genuinely new contribution is the body-region split: no significant difference between whole-body and partial immersion on CK, DOMS, CMJ or MVIC — and partial immersion significantly suppressed jump performance at 0h post-exercise (partial-cold-water-immersion-suppresses-jump-performance-immediately-post-exercise), the one new practical finding here.

For David: doesn't change anything about cold-water-immersion's standing position — the map already treats CWI's recovery-marker benefits cautiously and separately holds the more consequential finding that routine post-training CWI blunts hypertrophy adaptation. This is a second independent confirmation of an existing skepticism, not a new practical conclusion.
