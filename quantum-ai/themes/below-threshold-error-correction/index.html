Below-threshold error correction

Status: consolidating

Sub-threads: none — 4 bullets, one cluster of evidence per platform and per supporting tool; too early to split [reviewed 2026-11-04 @ 4 bullets]

Scope

Does adding physical qubits to an error-correcting code actually drive the logical error rate down on real hardware, on more than one platform? The standard is exponential suppression with code distance (a suppression factor Lambda above 1) and, eventually, logical error rates low enough for useful algorithms. Excludes error-detection-only counts, which live in logical-qubits-beyond-break-even.

Through-line

  • 2026-11-04 — AI-for-QEC evidence adds to the Willow line without changing the status. Google's reinforcement-learning control paper reports average logical error per cycle of 7.72e-4 for a distance-7 surface code and 8.19e-3 for a distance-5 color code on Willow, below the 0.143% in the original paper, though setups differ and we did not check comparability (google-reinforcement-learning-control-of-quantum-error-correction). That is a preprint from the same lab, so it narrows the open question about a Google follow-up without settling it. The decoder side is thinner: AlphaQubit's hardware evidence stops at distance 5 on Sycamore data (google-alphaqubit-learning-high-accuracy-error-decoding), and neural decoding in a live loop exists only at distance 3 (yang-real-time-surface-code-qec-with-fpga-neural-network-decoder). The real-time decoder in the Willow paper (63 microseconds, distance 5) is not described as neural. Status stays consolidating; see neural-decoders-for-quantum-error-correction.
  • 2026-11-04 — opened at consolidating. Google's Willow surface-code memory is peer-reviewed hardware data with Lambda = 2.14 +/- 0.02 and 0.143% per cycle at distance 7 (google-willow-qec-below-surface-code-threshold); a second, very different platform (neutral atoms) reports a matching 2.14x factor in a short characterization circuit (harvard-quera-universal-fault-tolerant-neutral-atom-architecture). Two platforms agreeing is the reason for consolidating and not emerging. It is not consensus: the neutral-atom figure is not a like-for-like scan to d=7, the Willow floor shows correlated errors about once an hour, and nobody has shown below-threshold logical gates in a deep circuit.
  • 2026-11-04 — background: the 2023 neutral-atom logical processor showed a logical gate improving from d=3 to d=7 (harvard-quera-logical-quantum-processor-reconfigurable-atom-arrays).

Open questions

  • A Google follow-up with logical gates, lattice surgery or a measured color-code Lambda below threshold; the RL-control preprint reports color-code logical error per cycle but no suppression factor, and no logical gates.
  • Whether the Willow correlated-error floor can be removed.
  • Trapped-ion and other platforms with a measured Lambda.
